# モデル世帯（架空）

制度改正の差分を見るための、**架空の**世帯です（実在の人のデータではありません）。CC0 1.0（[LICENSE](LICENSE)。0021）。

- 1ファイルが1つのエンジンへの要求（`engine.request` の JSON）です。世帯の入力は 0008 の形（値の箱・構成員・関係・働き方の期間・資産の器・保険契約）。
- 計算基準月は 2026年10月、表は2027年まで。令和8年度（2026年6月〜2027年5月）の住民税は、置き換え口（`residentTaxAssessments`。決定通知書の年税額）に架空の額を入れています（2025年の所得から計算するには、2024年12月〜2025年2月の保険料率などの制度データが要り、まだ入っていないため）。
- 標準報酬月額は置き換え口（`standardMonthlyRemuneration`）で入れています（標準報酬月額表の制度データがまだ無いため）。
- `engine/` で `npm run models` を流すと、令和8年度改正より前のパックの版（2026.1.0）と最新の版で、2027年の税・社会保険料と年間収支を並べます。CI の一致テスト（0005 の6）の入力にも使います。

| ファイル | 世帯 |
|---|---|
| `single25.json` | 単身・25歳・会社員（東京） |
| `single45.json` | 単身・45歳（介護保険の第2号）・会社員（大阪）・iDeCo・生命保険（新契約） |
| `dualNoKids.json` | 共働き・子なし（神奈川・埼玉） |
| `singleEarnerTwoKids.json` | 片働き・子2人（16歳未満）・生命保険・地震保険（愛知） |

| `highIncome.json` | 高収入（厚生年金の標準報酬・標準賞与の上限）・配偶者・大学生の子（特定扶養）・旧契約の生命保険・地震保険 |
| `dualHighTwoKids.json` | 共働きの高めの収入・子2人（23歳未満の扶養親族の生命保険料控除の特例） |
