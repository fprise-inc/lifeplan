# モデル世帯（架空）

制度改正の差分を見るための、**架空の**世帯です（実在の人のデータではありません）。CC0 1.0（[LICENSE](LICENSE)。0021）。

- 1ファイルが1つのエンジンへの要求（`engine.request` の JSON）です。世帯の入力は 0008 の形（値の箱・構成員・関係・働き方の期間・資産の器・保険契約）。
- 計算基準月は 2026年10月、表は2027年まで（下の表で別に書いた世帯を除く）。令和8年度（2026年6月〜2027年5月）の住民税は、置き換え口（`residentTaxAssessments`。決定通知書の年税額）に架空の額を入れています（2025年の所得から計算するには、2024年12月〜2025年2月の保険料率などの制度データが要り、まだ入っていないため）。
- 標準報酬月額は置き換え口（`standardMonthlyRemuneration`）で入れています。制度データの版 2026.3.0 で標準報酬月額表（健康保険・厚生年金）が入り、最新の版なら置き換え口を外しても給与から標準報酬月額を決めて計算できます（11件とも計算でき、6件は置き換え口と同じ等級）。ただし `npm run models` で比べる版 2026.1.0 は等級表を知らない時点の版で、外すとその版の計算が止まる（`E_PARAM_NO_VALUE`）ため、置き換え口を残しています。
- `engine/` で `npm run models` を流すと、令和8年度改正より前のパックの版（2026.1.0）と最新の版で、2027年の税・社会保険料と年間収支を並べます。CI の一致テスト（0005 の6）の入力にも使います。

| ファイル | 世帯 |
|---|---|

| `partTimeSpouse.json` | 会社員とパートの配偶者（社会保険は扶養、雇用保険あり）・子1人（福岡） |
| `highIncome.json` | 高収入（厚生年金の標準報酬・標準賞与の上限）・配偶者・大学生の子（特定扶養）・旧契約の生命保険・地震保険 |
| `dualHighTwoKids.json` | 共働きの高めの収入・子2人（23歳未満の扶養親族の生命保険料控除の特例） |
| `reemployment.json` | 59〜60歳・2027年3月に定年、4月から再雇用（契約社員） |
| `elderCare.json` | 64〜65歳（2027年3月に介護保険の第2号でなくなる）・同居の老親を扶養（北海道） |
| `unionConstruction.json` | 健保組合（料率を入力）・建設の事業の雇用保険・17歳の子 |

| `selfEmployed.json` | 自営業の夫婦と子（国民健康保険・国民年金。市町村の料率は架空の値を `premiumRates` に入れる）・50歳未満の定期便。表は2060年まで |
| `civilServant.json` | 公務員（共済。組合員の負担の率を入力）と会社員の共働き・2人とも50歳未満の定期便。表は2052年まで |

| `deferral.json` | 特別支給の老齢厚生年金を受け、基礎年金は70歳まで繰下げ。表は2050年まで |
| `pensionCouple.json` | 年金生活の夫婦（夫は後期高齢者医療、妻は国民健康保険と介護保険の第1号。受け取っている年金額の通知。年金からの特別徴収）。表は2050年まで |
| `parentalLeave.json` | 共働きの出産（母は産前産後休業・育児休業・育児時短就業、父は出生の月に育児休業）。表は2030年まで |
| `lifetime100.json` | 100年分の表（30歳の夫婦と0歳の子。勤めた後は加入歴から年金を推計）。根拠の記録「全部」の大きさを測るため。表は2125年まで |

令和8年度の住民税・標準報酬月額は、上の世帯と同じく置き換え口に架空の額を入れています。
