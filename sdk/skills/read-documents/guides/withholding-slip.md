# 給与所得の源泉徴収票の読み方

- `docType`: `withholdingSlip`
- 名義の人: 「支払を受ける者」の人（`holder`）。値の候補は `"member": "holder"`（今の働き方の期間に当たります）
- 単位: 円（その年の合計）。様式の金額の欄は「千」と「円」の2つの枠に分かれて印字されます（例: 「6,400 千｜000 円」）。**2つをつなげて円の整数**にする（6400000）。金額の左上に小さく「内」と書かれた額は内書き（その額の一部。未払の額・小規模企業共済等掛金など）で、足さない
- 時点: 答えの `asOf` は**年分の12月**（令和7年分 → `"2025-12"`）。照合の値の `year` は年分の年（2025）
- 確かめた資料: 国税庁の「給与所得の源泉徴収票（受給者交付用）」の様式（令和8年分）と記載要領、「給与所得の源泉徴収票等の法定調書の作成と提出の手引」の各欄の説明。本人に渡す源泉徴収票（受給者交付用）には個人番号の欄がありません（税務署提出用・給与支払報告書には個人番号の欄があります）

## 1. いちばん大事なこと: 支払金額は賞与込み

「支払金額」は、その年に支払いが確定した給与と賞与の**合計**です。ファイナンシアの入力は「年収（賞与を除く）」と「賞与（年間の合計）」の2つに分かれているので、**支払金額をそのまま年収の候補にしない**でください（賞与を二重に数えてしまいます）。

- 源泉徴収票だけのとき: 支払金額は**照合だけの値**にする（アプリの計算の給与と並べて差を見せる）。年収・賞与の値の候補は書かない。
- 賞与の額が分かる書類（賞与の明細・給与の年間の明細）も一緒に渡されたとき: 賞与 `employment.salary.bonus` に賞与の合計、年収 `employment.salary.annual` に「支払金額 − 賞与の合計」を書く。どちらも確かさ `medium`、`note` に足し引きを書く。
- 年の途中で就職した人は、前の勤め先の分を含めて年末調整していると、支払金額に前の勤め先の給与も入ります（摘要の欄に前の勤め先の分が書かれます）。その年の額を年収にしないで、照合だけにし、答えの外で FP に知らせる。
- 「中途就・退職」の欄に退職の印があるときも、照合だけにし、答えの外で FP に知らせる。

## 2. 読む欄

| 書類の欄 | 入力項目ID・場所 | 書き方 |
|---|---|---|
| 支払金額 | 照合だけの値 | `{"label": "支払金額（賞与込み）", "amount": …, "row": "cf.income.salary", "year": <年分>}` |
| 賞与の合計（一緒に渡された明細から） | `employment.salary.bonus` | 円の整数・`"period": "annual"`・確かさ `medium` |
| 支払金額 − 賞与の合計（同じとき） | `employment.salary.annual` | 円の整数・`"period": "annual"`・確かさ `medium`・`note` に「支払金額 ○円から賞与 ○円を引いた額」 |
| 給与所得控除後の金額（調整控除後） | 照合だけの値 | `label` は「給与所得控除後の金額」 |
| 所得控除の額の合計額 | 照合だけの値 | |
| 源泉徴収税額 | 照合だけの値 | `"row": "cf.taxSi.incomeTax"`・`"year": <年分>`（所得税と復興特別所得税の合計） |
| 社会保険料等の金額 | 照合だけの値 | 内書き（小規模企業共済等掛金。iDeCo の掛金を含む）があれば、別の照合の値「うち小規模企業共済等掛金」にする |
| 生命保険料の控除額・地震保険料の控除額・住宅借入金等特別控除の額・配偶者（特別）控除の額・特定親族特別控除の額・基礎控除の額・所得金額調整控除額 | 照合だけの値 | 額が書かれている欄だけ |
| 生命保険料の金額の内訳（新生命保険料・旧生命保険料・介護医療保険料・新個人年金保険料・旧個人年金保険料の金額）・旧長期損害保険料の金額 | 照合だけの値 | `label` は「新生命保険料の金額」のように欄の名前のまま。保険の契約の入れ漏れを確かめるのに使う（契約ごとの額ではない） |
| 国民年金保険料等の金額（社会保険料等の金額の内訳） | 照合だけの値 | |
| 住宅借入金等特別控除の額の内訳の「居住開始年月日（1回目）」 | `debt.housing`（`at` なし） | `"YYYY-MM"`。ローンの ID は書かない（FP が当てるローンを選ぶ）。確かさ `medium`。2回目の欄にも日付があれば、ローンが2本あることを答えの外で FP に知らせる |
| 住宅借入金等の内訳の「住宅借入金等年末残高（1回目）」・住宅借入金等特別控除可能額 | 照合だけの値 | 年末残高は控除に使う残高（連帯債務なら負担の分）で、ローンの残高そのものとは違うことがあるので、入力にしない |
| 配偶者の合計所得 | 照合だけの値 | 配偶者の収入は、配偶者の源泉徴収票か確定申告書で入れる |

- 年末調整をしていない源泉徴収票（「給与所得控除後の金額（調整控除後）」「所得控除の額の合計額」は年末調整をした人にだけ書かれる）でも、支払金額と源泉徴収税額は照合の値にする。
- 「種別」の欄（給料・賞与など）は読まなくてよい。支払金額は種別に関わらず給与と賞与の合計です。
- 控除対象扶養親族の数・16歳未満の扶養親族の数・障害者の数などの**人数は書かない**（家族は家族の項目で確かめる。人数が家族の項目と違いそうなら、答えの外で FP に知らせる）。

## 3. 読まないもの

- 個人番号（税務署提出用の写し・給与支払報告書には載っています）・受給者番号・支払者の個人番号または法人番号。
- 受給者・配偶者・扶養親族・16歳未満の扶養親族の名前とフリガナ・住所・受給者生年月日・役職名。支払者（勤め先）の名前・住所・電話番号。
- 「未成年者」「外国人」「死亡退職」「災害者」「乙欄」「本人が障害者」「寡婦」「ひとり親」「勤労学生」の印（人の事情の情報。家族の項目で FP が確かめる）。
- 摘要の欄の名前（前の勤め先の名前・扶養親族の名前）。
