# 固定資産税の課税明細書の読み方

- `docType`: `propertyTaxStatement`
- 何に使うか: 相続税の試算（「相続税も試算する」にチェックした世帯）の、不動産ごとの土地の面積・土地の固定資産税評価額・建物の固定資産税評価額（設計記録 0231・0235）
- 名義の人: 書かない（`holder` は書かない。納税義務者の名前・住所・番号は読まない）
- 単位: 地積は ㎡（小数2桁まで）、価格は円の整数
- 確認した資料: 課税明細書には国の決まった様式がありません（市区町村ごとに欄の並びと言葉が違います）。言葉は、多くの市区町村で使われている見出し（所在地番・登記地目・現況地目・登記地積・現況地積・価格・課税標準額・相当税額、家屋の家屋番号・種類・構造・床面積・価格）に合わせています

## 1. 読む欄

| 書類の欄 | 入力項目ID・場所 | 書き方 |
|---|---|---|
| （同じ敷地の土地と、その上の家屋） | `objects` に1つ | `{"key": "s1", "kind": "land:site"}`。**同じ敷地の筆（地番が続く・家屋と同じ所在の土地）は1つのまとまりにします**。離れた土地（別の場所の駐車場・貸地）は別のまとまりにします。`source.where` に「土地1〜2筆目・家屋1棟（家屋のある敷地）」のように、明細の何行目かを書く（所在・地番は書かない） |
| 土地の地積（㎡） | `plan.inheritanceTax` `["lands", "area"]` | ㎡の数（`"165.29"`）。現況地積があれば現況地積、無ければ登記地積。**まとまりの筆の地積を足した合計**。足したときは `note` に筆ごとの地積を書く（例「2筆の合計（120.50＋44.79）」） |
| 土地の価格（評価額） | `plan.inheritanceTax` `["lands", "fixedValue"]` | 円の整数・`"period": "once"`。**「価格」（固定資産税評価額）を読み、「課税標準額」は読みません**（課税標準額は住宅用地の特例などで減らした額で、相続税の倍率方式に使うのは価格です）。まとまりの筆の価格の合計。筆ごとの価格は照合だけの値（`references`）に1筆1つ |
| 家屋の価格（評価額） | `plan.inheritanceTax` `["lands", "buildingValue"]` | 円の整数・`"period": "once"`。家屋の「価格」。相続税では家屋は固定資産税評価額がそのまま評価額です（倍率 1.0）。同じ敷地に家屋が何棟もあれば足し、`note` に棟数を書く |

- 値の候補には `"newObject": "<objects の鍵>"` を書きます。FP が書類の読み取りの確認画面で、そのまとまりを世帯のどの不動産（持ち家・住まい以外の不動産）に入れるかを選びます。AI接続で世帯を受け取り、どの不動産か FP が言ったときだけ、`objects` を書かずに `"object": "<不動産の ID>"`（持ち家の ID か、住まい以外の不動産の口座の ID）を書きます。
- **地目**（田・畑・山林・雑種地・公衆用道路など）は入力の欄がありません。現況地目が宅地でない筆は、地積・価格の合計に入れず、`note` に「宅地でない筆があります（現況地目: 畑）」と書き、その筆の価格は照合だけの値にします（相続税では、宅地と評価の仕方が違うことがあります）。価格が0円・非課税の筆（公衆用道路など）も合計に入れず、`note` に書きます。
- **共有の土地・家屋**（持分の書いてあるもの）:
  - 家族（夫婦など）で共有している物件は、**持分をかけずに物件全体の地積・価格**を書き、`note` に持分を書きます（例「持分 1/2 の共有。物件全体の値です」）。亡くなる人の分は、アプリが持ち家・不動産の名義の割合で分けます（名義の割合は FP が持ち家の欄で確認します）。
  - マンションなど、敷地を多くの人で共有している（敷地権）土地は、**敷地全体の地積・価格に持分の割合をかけた値**（この部屋の分）を書きます。地積は小数2桁までで切り捨て、価格は円未満を切り捨てます。`note` に式を書きます（例「敷地 1,234.56㎡×持分 6,543/100,000」）。明細書の価格がもう持分の分になっているときは、かけずにそのまま書き、`note` にそう書きます。
  - どちらか分からないときは、物件全体の値を書き、確かさを `"medium"`、`note` に「持分 ○/○。家族の共有か、マンションの敷地権かを確認してください」と書きます。
- 書類の時点（`asOf`）: 明細書の年度の1月（賦課期日）。令和8年度なら `"2026-01"`。
- 都市計画税の欄・前年度の課税標準額・相当税額・負担調整・住宅用地の区分（小規模住宅用地など）は読みません（アプリは、見出しに「課税標準」「税額」「負担調整」がある候補を読みません）。

## 2. 読まないもの

- **所有者・納税義務者の名前・住所**（共有者の名前・「外1名」の書き方を含む）、通知書番号・納税義務者番号・宛名番号・物件番号・家屋番号。
- **土地・家屋の所在と地番**（「○○町123番4」など）。まとまりを分けるために見るのはよいが、`value`・`source`・`note` に書きません（アプリは、所在・地番らしい所を伏せ、所在・地番・所有者の見出しの候補を読まずに落とします）。
- 家屋の構造・床面積・建築年（入力の欄がありません。建物の評価額は家屋の価格から入ります）。
- 税額・課税標準額・都市計画税の額。
