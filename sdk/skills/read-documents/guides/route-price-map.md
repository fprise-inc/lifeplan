# 路線価図（国税庁）の読み方

- `docType`: `routePriceMap`
- 何に使うか: 相続税の試算（「相続税も試算する」にチェックした世帯）の、不動産ごとの土地の評価の入れ方（路線価×面積）・路線価（1㎡あたり）・借地権割合（設計記録 0231・0235）
- 渡されるもの: FP が国税庁の財産評価基準書（路線価図）の画面の写し・写真を渡し、どの土地か（どの道路に面した土地か）を指して頼みます
- 名義の人: 書かない（`holder` は書かない）
- 確認した資料: 国税庁「財産評価基準書 路線価図・評価倍率表」の路線価図の見方（路線価は1㎡あたりの価額を千円単位で表示し、数字の後ろの記号 A〜G が借地権割合）

## 1. 読む欄

| 書類の欄 | 入力項目ID・場所 | 書き方 |
|---|---|---|
| （FP が指した1つの土地） | `objects` に1つ | `{"key": "r1", "kind": "land:site"}`。`source.where` に「指定の土地の正面の路線」のように書く（地名・町名・道路の名前は書かない） |
| 土地の前の道路の路線価と記号 | `plan.inheritanceTax` `["lands", "routeMark"]` | **路線価図に印字されたままの文字**（例 `"250C"`）。数は直さず、記号も付けたまま書く。アプリが「250」を千円単位（1㎡あたり 250,000円）、「C」を借地権割合 70% に読み、土地の評価の入れ方を「路線価×面積」にします |

借地権割合の記号（国税庁の路線価図の決まり）:

| 記号 | A | B | C | D | E | F | G |
|---|---|---|---|---|---|---|---|
| 借地権割合 | 90% | 80% | 70% | 60% | 50% | 40% | 30% |

- 数は路線価図のとおり千円単位のまま書きます（`"250C"` を `250000` にしない）。桁区切り（`"1,250C"`）・全角・小文字のままでも読めますが、印字のとおりに書くのが先です。
- **2つ以上の道路に面する土地**（角地・二方路線など）: 入力の欄は路線価1つだけです。路線価の高い方（奥行が同じくらいなら、ふつうは高い方が正面の路線）の記号を1つ書き、ほかの路線の記号は `note` に書きます（例「側方の路線 200D があります」）。**側方路線影響加算・二方路線影響加算は、アプリは計算しません。** FP が必要なら、入力の「補正の率」に加算を含めた率を入れます。
- 路線価を丸・楕円・六角形などで囲む記号（地区の区分。ビル街・繁華街・普通住宅など）は入力の欄がありません。奥行価格補正などの補正率を決めるのに使うので、`note` に書くのはよい（例「普通住宅地区の記号です」）。
- **読めなかったとき**（数字がかすれている・画面が切れている・どの道路か分からない）は、推測で埋めず `"value": null, "unreadable": true` にします。アプリは、路線価と借地権割合を「読めなかった欄」にし、FP が路線価図を見て「直す」で入れます。どの土地か分からないときは、答えを作らずに FP に聞きます。
- **倍率地域**（路線価図が無く、評価倍率表を見る地域）の土地は、この書類では読みません。FP に「倍率地域です。入力の『評価倍率』に評価倍率表の倍率を、『土地の固定資産税評価額』に課税明細書の価格を入れてください」と伝えます（課税明細書は AI で読み取れます）。
- 書類の時点（`asOf`）: 路線価図の年分の1月（1月1日時点の価額）。令和8年分なら `"2026-01"`。

## 2. 読まないもの

- **場所の手がかり**: 路線価図のページ（図の番号）・地名・町名・丁目・道路の名前・住所の検索欄の文字・地図の印の名前。路線価図は公開の資料でお客さまの情報は含みませんが、指した土地の場所からお住まいが分かることがあるので、`value`・`source`・`note` に書きません（アプリも、路線価図の答えのページの番号を残さず、地番らしい所を伏せます）。
- お客さまの名前・住所（画面の写しに写っていても）。
- 評価倍率表の倍率（この書類の対象外）。

## 3. 答えの見本（架空の値）

正面の路線が「250C」、側方の路線が「200D」の角地:

```json
{
  "contract": "document-candidates@1",
  "docType": "routePriceMap",
  "asOf": "2026-01",
  "objects": [
    { "key": "r1", "kind": "land:site", "source": { "where": "指定の土地の正面の路線" }, "confidence": "high" }
  ],
  "values": [
    { "item": "plan.inheritanceTax", "at": ["lands", "routeMark"], "newObject": "r1", "value": "250C", "source": { "where": "正面の路線の路線価", "text": "250C" }, "confidence": "high", "note": "側方の路線 200D があります（側方路線影響加算は入れていません）" }
  ]
}
```
