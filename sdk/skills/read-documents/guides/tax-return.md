# 確定申告書（控え）の読み方

- `docType`: `taxReturn`（一緒に渡された青色申告決算書・収支内訳書も、この1通の答えにまとめてよい）
- 名義の人: 申告した人（`holder`）。値の候補は `"member": "holder"`
- 単位: 円（その年の額）。申告書の1桁ずつの枠に並んだ数字は、つなげて円の整数にする
- 時点: 答えの `asOf` は**年分の12月**（令和7年分 → `"2025-12"`）。照合の値の `year` は年分の年
- 確かめた資料: 国税庁「令和7年分 所得税及び復興特別所得税の確定申告の手引き」の手順2（収入金額等・所得金額等の計算。HTML）。申告書の様式（PDF）は開いていません。欄の記号・番号は年分の様式で変わるので、**欄の名前で読み**、記号・番号は `source.where` に添えるだけにしてください

## 1. 先に気をつけること

- **確定申告書の控えには個人番号が印字されていることがあります。** 第一表の個人番号の枠・本人確認の書類の写しは読まない。番号を `source.text` に写さない。
- 第一表の「収入金額等」（売上・収入）と「所得金額等」（収入から経費などを引いた額）を取り違えない。
- 事業所得の入力は**青色申告特別控除の前**の所得金額です（アプリが申告の仕方から控除を引きます）。

## 2. 読む欄

| 書類の欄 | 入力項目ID・場所 | 書き方 |
|---|---|---|
| 青色申告決算書の「青色申告特別控除前の所得金額」（決算書があるとき） | `employment.business.income` | 円の整数・`"period": "annual"`・確かさ `high` |
| 決算書が無いとき: 第一表の事業（営業等）の所得金額 ＋ 青色申告特別控除額 | `employment.business.income` | 同じ。確かさ `medium`、`note` に足した額を書く。不動産所得もある人は、控除が不動産所得から先に引かれていることがあるので確かさ `low` にし、`note` に「控除の割り振りを確かめてください」 |
| 白色申告（収支内訳書）の所得金額 | `employment.business.income` | 円の整数・年額 |
| 申告の種類（第一表の「青色」の印・青色申告決算書がある） | `member.taxReturn` `["method"]` | `"blue"`（青色）か `"white"`（白色）。種類を決める欄 |
| 青色申告特別控除額 | `member.taxReturn` `["blueDeduction"]` | 650,000円 → `"electronic"`、550,000円 → `"doubleEntry"`、100,000円以下 → `"simple"` |
| 事業（営業等）の収入金額 | 照合だけの値 | `label` は「事業（営業等）の収入金額」 |
| 不動産所得の収入金額・所得金額 | 照合だけの値 | 物件ごとの家賃・経費は、収益不動産の項目で FP が入れる（この手引きの範囲の外） |
| 給与の収入金額 | 照合だけの値 | `"row": "cf.income.salary"`・`"year": <年分>`。給与の入力は源泉徴収票の手引きで |
| 雑所得の公的年金等の収入金額 | 照合だけの値 | `"row": "cf.income.pension"`・`"year": <年分>` |
| 雑所得の業務・その他の収入金額・所得金額 | 照合だけの値 | |
| 社会保険料控除・小規模企業共済等掛金控除・生命保険料控除・地震保険料控除の額 | 照合だけの値 | 額が書かれている欄だけ |
| 所得税及び復興特別所得税の額（申告納税額の前の税額） | 照合だけの値 | `"row": "cf.taxSi.incomeTax"`・`"year": <年分>` |

- 申告の仕方・青色申告特別控除の欄は、事業所得のある人（自営業・フリーランスの働き方、事業所得の副業、事業所得の民泊・宿）の「働き方と収入」の確定申告と、収益不動産の持ち主の「申告」にあります。どちらも同じ値（人ごとに1つ）なので、どちらの人の欄かを気にせず `member.taxReturn` に書けばよい。どちらの欄も無い人（給与・年金だけの人）では、アプリが「この世帯に、この値を入れる欄がありません」と出し、FP が入れないにします（候補は書いてよい）。
- 事業所得の欄は、今の働き方が自営業・フリーランスなどの事業の期間の人にだけあります。会社員の副業の事業所得のように欄が無いときは、照合だけの値にする（アプリが「入れる欄がありません」と出します）。
- 損失申告・純損失の繰越し・分離課税（株式・不動産の譲渡）の欄は読まない（入力の欄が無い）。必要なら答えの外で FP に知らせる。

## 3. 読まないもの

- 個人番号・整理番号・利用者識別番号・還付金の受取口座（銀行名・口座番号）。
- 名前・フリガナ・住所・電話番号・生年月日・屋号・職業・世帯主の名前。
- 第二表の配偶者・扶養親族の名前と生年月日・個人番号、専従者の名前、寄附先の名前。
