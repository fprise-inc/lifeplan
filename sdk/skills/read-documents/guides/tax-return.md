# 確定申告書（控え）の読み方

- `docType`: `taxReturn`（一緒に渡された青色申告決算書・収支内訳書も、この1通の答えにまとめてよい）
- 名義の人: 申告した人（`holder`）。値の候補は `"member": "holder"`
- 単位: 円（その年の額）。申告書の1桁ずつの枠に並んだ数字は、つなげて円の整数にする
- 時点: 答えの `asOf` は**年分の12月**（令和7年分 → `"2025-12"`）。照合の値の `year` は年分の年
- 確かめた資料: 国税庁の申告書第一表・第二表の様式（令和7年分以降用）と「令和7年分 所得税及び復興特別所得税の確定申告の手引き」の手順2。下の表の記号・番号（ア・①・㊾など）は令和7年分以降の様式のものです。年分の様式で変わることがあるので、**欄の名前で読み**、記号・番号は `source.where` に添えるだけにしてください。様式の「G09」「G28」のような英数字は機械で読むための欄の符号で、書かない

## 1. 先に気をつけること

- **確定申告書の控えには個人番号が印字されていることがあります。** 第一表の上の「個人番号」の枠、第二表の配偶者・親族の個人番号の欄、本人確認の書類の写しは読まない。番号を `source.text` に写さない。
- 第一表の金額の欄は「単位は円」で、1桁ずつの枠です。課税される所得金額（㉛）の下3桁は「000」、税額の欄の下2桁は「00」と印字済みの枠があります。印字済みの0も含めて円の整数にする。
- 第一表の「収入金額等」（売上・収入）と「所得金額等」（収入から経費などを引いた額）を取り違えない。
- 事業所得の入力は**青色申告特別控除の前**の所得金額です（アプリが申告の仕方から控除を引きます）。

## 2. 読む欄

| 書類の欄 | 入力項目ID・場所 | 書き方 |
|---|---|---|
| 青色申告決算書の「青色申告特別控除前の所得金額」（決算書があるとき） | `employment.business.income` | 円の整数・`"period": "annual"`・確かさ `high` |
| 決算書が無いとき: 第一表の所得金額等の事業・営業等（①）＋ 青色申告特別控除額（59） | `employment.business.income` | 同じ。確かさ `medium`、`note` に足した額を書く。不動産所得もある人は、控除が不動産所得から先に引かれます。第二表の「住民税・事業税に関する事項」の事業税の「不動産所得から差し引いた青色申告特別控除額」があれば、①＋59−その額にする（確かさ `medium`、`note` に計算を書く）。その欄が読めなければ確かさ `low` にし、`note` に「控除の割り振りを確かめてください」 |
| 白色申告（収支内訳書）の所得金額 | `employment.business.income` | 円の整数・年額 |
| 申告の種類（第一表の上の「青色」の欄に印・青色申告決算書がある） | `member.taxReturn` `["method"]` | `"blue"`（青色）か `"white"`（白色）。種類を決める欄 |
| 青色申告特別控除額（第一表の「その他」の59） | `member.taxReturn` `["blueDeduction"]` | 650,000円 → `"electronic"`、550,000円 → `"doubleEntry"`、100,000円以下 → `"simple"` |
| 収入金額等の事業・営業等（ア） | 照合だけの値 | `label` は「事業（営業等）の収入金額」。所得金額等の①も「事業（営業等）の所得金額」として照合の値にしてよい |
| 不動産の収入金額（ウ）・所得金額（③） | 照合だけの値 | 物件ごとの家賃・経費は、収益不動産の項目で FP が入れる（この手引きの範囲の外） |
| 給与の収入金額（オ） | 照合だけの値 | `"row": "cf.income.salary"`・`"year": <年分>`。給与の入力は源泉徴収票の手引きで |
| 雑の公的年金等の収入金額（カ） | 照合だけの値 | `"row": "cf.income.pension"`・`"year": <年分>` |
| 雑の業務（キ・⑧）・その他（ク・⑨）の収入金額・所得金額 | 照合だけの値 | |
| 所得から差し引かれる金額の社会保険料（⑬）・小規模企業共済等掛金（⑭）・生命保険料（⑮）・地震保険料（⑯） | 照合だけの値 | 額が書かれている欄だけ。`label` は「社会保険料控除」のように |
| 専従者給与（控除）額の合計額（58） | 照合だけの値 | 家族に払った給与。家族の収入は家族の働き方で入れる |
| 所得税及び復興特別所得税の額（㊻。源泉徴収税額㊾・予定納税額を引く前の税額） | 照合だけの値 | `"row": "cf.taxSi.incomeTax"`・`"year": <年分>`。申告納税額（㊿）・納める税金・還付される税金は書かない（源泉徴収・予定納税の後の額で、その年の税の額ではない） |

- 申告の仕方・青色申告特別控除の欄は、事業所得のある人（自営業・フリーランスの働き方、事業所得の副業、事業所得の民泊・宿）の「働き方と収入」の確定申告と、収益不動産の持ち主の「申告」にあります。どちらも同じ値（人ごとに1つ）なので、どちらの人の欄かを気にせず `member.taxReturn` に書けばよい。どちらの欄も無い人（給与・年金だけの人）では、アプリが「この世帯に、この値を入れる欄がありません」と出し、FP が入れないにします（候補は書いてよい）。
- 事業所得の欄は、今の働き方が自営業・フリーランスなどの事業の期間の人にだけあります。会社員の副業の事業所得のように欄が無いときは、照合だけの値にする（アプリが「入れる欄がありません」と出します）。
- 損失申告・純損失の繰越し・分離課税（株式・不動産の譲渡）の欄は読まない（入力の欄が無い）。必要なら答えの外で FP に知らせる。

## 3. 読まないもの

- 個人番号・整理番号・利用者識別番号・還付される税金の受取場所（銀行・支店の名前・預金種類・口座番号・ゆうちょ銀行の記号番号）・公金受取口座の欄・税理士の名前と電話番号。
- 名前・フリガナ・住所・電話番号・生年月日・屋号・職業・世帯主の名前。
- 第二表の「配偶者や親族に関する事項」「事業専従者に関する事項」「退職所得のある配偶者・親族」の名前・**個人番号**・生年月日、別居の人の名前・住所、寄附先の名前。第二表の「所得の内訳」の支払者の名前・所在地。
