# 公的年金等の源泉徴収票の読み方

- `docType`: `publicPensionWithholding`
- 名義の人: 年金を受け取っている人（`holder`）
- 単位: 円（その年の合計）
- 時点: 答えの `asOf` は**年分の12月**（令和7年分 → `"2025-12"`）。照合の値の `year` は年分の年（2025）
- 確かめた資料: 日本年金機構「公的年金等の源泉徴収票」の見方のページ（HTML。支払金額・源泉徴収税額・区分・年金の種別・本人の欄・源泉控除対象配偶者・控除対象扶養親族の数・社会保険料の額・摘要）。源泉徴収票の様式（PDF）と、マイナポータルで届く電子データの仕様は開いていません

## 1. いちばん大事なこと: 年金の額は年金額改定通知書で入れる

源泉徴収票の「支払金額」は、その年に**支払われた**年金の合計です（所得税・社会保険料を差し引く前。年の途中で受け取りを始めた・額が変わった年は、1年分の年金額と違います）。ファイナンシアの年金の額は、老齢基礎年金・老齢厚生年金ごとの年額（年金額改定通知書・振込通知書の額）で入れるので、**支払金額を年金の額の候補にしない**でください。

- 支払金額・源泉徴収税額・社会保険料の額は**照合だけの値**にする（アプリの計算の公的年金・所得税と並べて差を見せる）。
- 年金の額を入れたいときは、年金額改定通知書の手引き（[pension.md](pension.md)）で読む。
- マイナポータルで届く源泉徴収票の電子データは、アプリではまだ読めません（仕様を確かめていないため）。PDF・紙は、この手引きで読む。

## 2. 読む欄

| 書類の欄 | 入力項目ID・場所 | 書き方 |
|---|---|---|
| 支払金額 | 照合だけの値 | `{"label": "公的年金の支払金額", "amount": …, "row": "cf.income.pension", "year": <年分>}` |
| 源泉徴収税額 | 照合だけの値 | `"row": "cf.taxSi.incomeTax"`・`"year": <年分>`（所得税と復興特別所得税の合計） |
| 社会保険料の額 | 照合だけの値 | 年金から天引きされた介護保険料・国民健康保険料（後期高齢者医療保険料）の合計。`row` は書かない |
| 年金の種別・区分 | （書かない） | 老齢・障害・遺族のどれかは、答えの外で FP に伝えてよい（障害・遺族の年金は非課税で、この票は出ません） |

- 年金の支払者が2つ以上（日本年金機構と企業年金・共済など）なら、1通ずつ答えを分ける（合計しない）。
- 扶養親族の数・本人の欄（障害者・寡婦など）の**人数・印は書かない**（家族の項目で確かめる）。

## 3. 読まないもの

- 基礎年金番号・年金コード・個人番号（マイナンバー）・支払者の法人番号。
- 受給者・配偶者・扶養親族の名前とフリガナ・住所・生年月日。
- 摘要の欄の名前。

    { "label": "源泉徴収税額", "amount": 12400, "row": "cf.taxSi.incomeTax", "year": 2025, "source": { "page": 1, "where": "源泉徴収税額", "text": "12,400" } },
