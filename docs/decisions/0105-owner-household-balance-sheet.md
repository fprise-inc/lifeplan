# 0105. 役員として働く人の家計の側のバランスシート（自社株・会社との貸し借り・連帯保証・体力の目安の分母）と、世帯ファイルの形式 0.48・会社と合わせたバランスシートの見本の段取り

- 状態: 採用（一部未確定）（2026-11-01）
- 固定の強さ: 骨格は、その他の資産の細目 `accounts[].subtype`（`ownCompanyShares` 自社株〔出資額〕・`loanToCompany` 会社への貸付金。表示だけで計算には使わない）、ローンの細目 `debts[].subtype` の `companyLoan`（会社からの借入金。計算はほかのローンと同じ）、構成員の `companyGuarantee`（会社の借入の連帯保証の額。負債の合計に入れない）、体力の目安の分母 `display.balance.guide.basis`（`living`・`livingLoan`）の意味と、形式 0.48 の変換の段。文言・欄の置き場所・点線の箱の見せ方・段で目指す文の言い方は変えてよい。会社と合わせたバランスシートの見本（下の6）は未着手で、段取りだけを決めた

## 背景

- 会社の役員（多くは中小企業の経営者）の家計は、会社とのお金のやりとりがあり、家計のバランスシートだけを見ると書き漏れが出やすい。自社株（会社に払い込んだ出資額）、会社に貸しているお金（会社の帳簿の役員借入金）、会社から借りているお金、会社の借入の連帯保証がその代表。
- 経営者個人と会社のバランスシートを合わせて見る考え方がある（2枚を並べ、自社株と資本金・貸し借りを相殺して1枚にする）。金融機関も融資の判断で両方を合わせて見る。ただ、会社の数字の入力と計算は家計のソフトの範囲を超える（0027 の8。法人役員は家計の側だけを扱う）。
- 家計の体力の目安（0027 の6）は「すぐ使えるお金が生活費の何か月分か」で見ていた。上の考え方では、生活費にローンの返済を足した毎月の固定の支出で何か月分かを見る（目安は6か月分、できれば12か月分）。
- 前提にする記録: 0008（世帯のデータの形）、0011（形式の版と変換・拡張領域）、0016（カスタム層）、0018（ヒアリングシート）、0025（全資産・全負債）、0027（資産と負債のタブ）、0052（住まい・ローン）、0104（形式 0.47）。

## 決定

### 1. 欄（役員の働き方のある構成員がいるときだけ出す）

- 役員の働き方（`employmentPeriods[].type` が `executive`）の期間を持つ構成員がいる世帯だけに出す（`app/src/workspace/input/officer.ts`）。会社の側の数字（会社の決算・会社の資産と負債）は入れない。
- **自社株（出資額）**: 貯蓄・運用の入力項目の「その他の資産」に「＋ 自社株（出資額）」。器の種類は `otherAsset` のまま、細目 `subtype: ownCompanyShares`。名義は役員の人。欄は「出資額（払い込んだ額）」で、評価額の増減率と種類の欄は出さない（出資額のまま見る）。説明「実際の株の価値はずっと高いことがあり、相続税に影響します」。相続税の目安（0039）は今までどおりその他の資産として額のまま数える（自社株の評価はしない）。
- **会社への貸付金**: 同じく「＋ 会社への貸付金」（細目 `loanToCompany`）。欄は「今の貸付金の残り」。返ってくる見込みは FP のメモで補う。
- **会社からの借入金**: 住まい・ローンの入力項目のほかのローンに「＋ 会社からの借入金」（細目 `companyLoan`、計算の種類 `other`、借りる人は役員の人）。金利の目安は 0%（根拠の文「会社からの借入の利率は契約で決めた率を入れてください（入れなければ利息なしで計算します）」）。返済の予定はほかのローンと同じくキャッシュフロー（`cf.expense.debt.other`）と負債の残高に入る。種類の選択肢の「会社からの借入金」は、役員のいる世帯（か、もうその細目の借入）だけに出す。
- **会社の借入の連帯保証の額**: 働き方と収入の入力項目の、役員の人の区画に「（その人）の会社とのお金（役員）」のまとまりを置き、欄「会社の借入の連帯保証の額」（構成員の `companyGuarantee`。今の額）を出す。自社株・貸付金・借入金をどこで入れるかを1行で案内する。保証の額は計算に使わない。
- 1件1つの枠: 自社株・貸付金・借入金はそれぞれ1件ずつの物（器・負債）で、入力の枠も1件1つ。

### 2. バランスシートの見せ方

- 分け方の部品（`report/src/bsGroups.ts`）: 細目のある器は換金しにくい資産の項目「自社株（出資額）」「会社への貸付金」、細目 `companyLoan` の負債はその他の負債の項目「会社からの借入金」にする。4つの分け方と足し算は変えない（額はエンジンの行のまま）。世帯から項目の名前を決めるところを写す部品 `bsHouseholdOf` を足し、アプリのタブ・提案書の図と年の抜粋の表・お金の3つの分け方で同じものを使う。箱の色は `--bs-ownShares`・`--bs-loanToCompany`・`--bs-companyLoan`（提案書は分け方ごとの色のまま）。
- 箱の説明: 換金しにくい資産に自社株があれば「自社株は出資額（払い込んだ額）で見ています。実際の株の価値はずっと高いことがあり、相続税に影響します。」、その他の負債に会社からの借入金があれば「会社からの借入金の返済は、毎年の支出に入っています。」を添える。
- **連帯保証は負債の合計に入れない**。資産と負債のタブの1年ずつ見る図の右（図の外）に、点線の箱「会社の借入の連帯保証 ○万円／保証を含めると純資産は○万円」を出す（今の年だけ。保証の額は今の額で、先の年は見込まない）。提示用の値は `BsYearModel.guarantee`（今の年だけ。ほかは 0）。
  - 理由: 保証は会社が返している間は家計から返済が出ず、キャッシュフローにも出ない。純資産の本体を変えると、図と表の数字の説明が難しくなる。保証を負債に数える見方は、1行の「保証を含めると」で示す。

### 3. 家計の体力の目安の分母

- 表示の設定の家計の体力の目安の幅（`bsGuide`。世帯ファイルの `display.balance.guide`）に、分母 `basis` を足す: `living`「生活費の何か月分」・`livingLoan`「生活費＋ローン返済の何か月分」。このタブの表示の設定で選ぶ。
- **選んでいないときの分母は世帯から決める**: 役員の働き方のある構成員がいる世帯は `livingLoan`、ほかは `living`（今までどおり）。保存は FP が選んだときだけ（`BalanceTabModel.guideBasis` が選んでいないときの分母）。
- ローン返済は、その年の住宅ローン・車のローン・奨学金・ほかのローン（会社からの借入金を含む）の返済の行の合計（`BsYearModel.loanPay`）。家賃収入で返す住まい以外の不動産のローン（負債の `property`）と、繰上返済・手数料の行は入れない。計算基準年が年の途中から始まるときは、生活費と同じく翌年の値で見る。
- 目安に届かないときの言葉は段で示す: 「目安（6〜12か月分）より**少なめ**です。まず3か月分、次に6か月分を目指しましょう。」（3か月分・目安の下限・上限のうち、今より上の2つ）。赤で煽らない（0027 の6 のまま）。前の文の「急な出費は値動きのある運用を崩すことになります」はやめた。
- 見出しの添え書きは「生活費＋ローン返済 月○万円で計算」、数字の単位は「か月分の生活費＋返済」。

### 4. ヒアリングシート

- 詳細版を `full` 版2にした（版1 は `retired`。書き出さないが、配ったシートを読むため同梱し続け、取り込める）。版1 の項目に、3. お仕事と収入の終わりに会社役員の方だけの欄を足した（`addedIn: 2`。人ごと）:
  - `hs.company.shares` 自社株の出資額（万円）→ 器 `otherAsset`・細目 `ownCompanyShares`
  - `hs.company.loanToCompany` 会社への貸付金（万円）→ 器 `otherAsset`・細目 `loanToCompany`
  - `hs.company.loanFromCompany` 会社からの借入金（今の残高。万円）と `hs.company.loanFromCompanyMonthly` その毎月の返済額（円。任意）→ 負債 `other`・細目 `companyLoan`（今の残高から。金利は 0% の仮の値、返済の月数は毎月の返済額から逆算し、無ければ5年の仮の値）
  - `hs.company.guarantee` 会社の借入の連帯保証の額（万円）→ 構成員の `companyGuarantee`（負債にしない）
- ご用意いただきたい書類に「会社の決算書（会社役員の方。会社との貸し借りや、会社の借入がわかるもの）」を足した。見直し（前回の値を記入）は版2 で書き出し、上の欄にも今の値を記入する。見本 `hearing/samples/full-2-sample.json`・`.xlsx` を置いた（0018 の7）。

### 5. 世帯ファイルの形式 0.48

- 足すだけの MINOR: `accounts[].subtype`・`debts[].subtype` の `companyLoan`・`members[].companyGuarantee`・`display.balance.guide.basis`。前の版のアプリは細目と保証の額を読み落として書き戻すので、版を上げて閲覧だけにする。変換の段（0.47 → 0.48）は形式の版だけを書き換える（前の世帯は細目なしのその他の資産・その他のローンのまま。分母は世帯から決める）。見本 `0.48/`。
- 入力項目ID `account.subtype`・`member.companyGuarantee` を足した（0004）。縮約版の許可リストに入れ、版を `reduced@26` にした（0015）。0.16 より後の欄の当て先の表に `field:work/{member}/officer/guarantee` を足した（0036 の追記）。
- 計算エンジンの部品は変えない（細目と保証の額は計算に使わない。会社からの借入金はほかのローンとして計算する）。モデル世帯の計算の結果は変わらない（役員のモデル世帯も、入力に足した欄が無いため）。資産と負債のタブの体力の目安は、役員のモデル世帯では分母が生活費＋ローン返済になる（画面の見せ方だけ）。

### 6. 会社と合わせたバランスシートの見本（カスタム層。未着手）

- 標準の画面には入れない（0027 の8 のまま。ふつうのライフプランに会社の数字は要らない。会社を顧問先に持つ FP 向けのカスタマイズ）。カスタム層の見本として作る。
- **未着手の理由**: 見本が使うカスタム層の仕組みが、まだ1つも動いていない。次がそろうまで、見本は作っても読み込めず、承認もできない。
  1. カスタム層のフォルダ（0016 の3。既定の場所・選び直し・データフォルダとの重なりの検査）を本体が読む仕組み（今は書き出しの先の検査で名前を使うだけ）。
  2. 計算部品の読み込み: `manifest.json` の検査、型を取り除く部品（0016 の未確定。Rust 製のどれにするか）、`@lifeplan/sdk` と相対パスだけの読み込み。
  3. 承認と指紋（0016 の6）: 事務所データの側の承認の台帳（親鍵による改ざん検出）、指紋での固定、保留・承認の画面（差分・読む入力項目・モデル世帯での差・ライセンス）、承認した中身の保存庫。
  4. 隔離実行（0016 の7）: 計算の要求ごとに作る quickjs の環境・`reads` で選んだ入力のコピーだけを渡す・上限・脱出テスト。今の `engine-host` は公式のエンジンだけを動かす。
  5. 差し込み口: 0006 の8つの差し込み口に、資産と負債のタブの見るもの（`BalanceTabModel.customViews` を作る）が無い。差し込み口の一覧は骨格なので、9つ目を足すか、別の形（帳票と同じ「見せる値だけを作る部品」）にするかを決める必要がある（0027 の未確定の「差し込み口の名前と入出力」）。
  6. 宣言型の入力欄 `fields/`（0016 の3・4。JSON Schema での検査・入力の画面に足す・値を拡張領域 `ext`・定義を `extDefinitions` へ。0011 の4）。今は拡張領域を読み書きして失わないところまで。
  7. 提案書の任意の章: カスタムの値を帳票の入力に渡す欄と、章を足す設定（独自帳票 `reports/` の見本はあるが、カスタムの計算の値を渡す口が無い）。
- **見本の中身**（仕組みができたら作る。決めておく）:
  - 会社の今の BS の入力（`fields/`・拡張領域）: 現預金・売上債権・在庫・その他の流動資産・固定資産（土地・建物など）・投資等・借入金（短期・長期）・その他の負債・資本金・剰余金、毎月の固定の支出と毎月の返済、基準日（会社の最新の試算表の月末）。会社の先の年の見込みは作らない。
  - 3つの段: ①家計（今の年の家計のバランスシート）と会社を並べる、②4つの組の相殺（経営者の自社株 ↔ 資本金〔ほかの株主の分を除く〕、経営者の会社への貸付金 ↔ 会社の経営者からの借入金、経営者の会社からの借入金 ↔ 会社の経営者への貸付金、経営者の会社への未払金 ↔ 会社の経営者への立替金）、③科目ごとに足した1枚。純資産は「会社の財産（剰余金）」と「個人の財産」に分けて並べる。組の両側が合わないときは「片方にしか載っていません」と知らせる。
  - 指標: 総合・個人・会社のそれぞれで、現預金 ÷ 毎月の固定の支出。目安は6か月分（できれば12か月分）。
  - 会社の段階（創業期・急成長期・不安定成長期・安定成長期・成熟期・異常時）を選ぶと、どちらの口座にお金を厚くするかの目安の1文を出す。
  - 会社の BS を実力に直す点検の一覧（売上債権・在庫・建物・土地を時価に・非上場株と経営者への貸付金をゼロに・保証）。直した額は FP が入れ、計算では直さない。
  - 出す先: 資産と負債のタブの `customViews`（同じ図の部品・共通の縮尺）と、その FP の提案書の任意の章（見本を有効にしたときだけ。既定は出さない）。
- **段取り**: カスタム層の最小の仕組み（1〜4 と 6）を先に1つの記録で決めて作り、差し込み口（5）を決めてから見本を作る。見本は `sdk/examples/` に置き、FP が自分のカスタム層に写して承認する形にする（帳票の見本 `sdk/examples/reports/` と同じ）。

## 理由

- **欄を役員のいる世帯だけに出す**: ふつうの世帯には要らない欄で、入力の画面が重くなる。役員の世帯では書き漏れが起きやすい所なので、その世帯にだけ目立つ形で出す。
- **自社株を出資額で入れる**: 自社株の評価（類似業種比準・純資産価額）は会社の数字が要り、家計のソフトの範囲を超える。取得の額でまず載せ、実際の価値との差は説明の文で伝える。
- **保証を図の外に出す**: 2 の理由のとおり。保証を忘れないことと、純資産の本体の説明しやすさを両立させる。
- **分母の初めの値を世帯で変える**: 役員の世帯は会社と合わせて毎月の固定の支出で見る考え方に慣れている FP が多く、その物差しと同じにすると説明しやすい。ほかの世帯は今までの見せ方を変えない。
- **見本を後にする**: カスタム層の仕組みを見本のために近道で作ると、0016 の承認・隔離の約束を崩す。標準の画面に入れる近道も取らない（0027 の8）。

## 影響

- 世帯ファイルの形式が 0.48 になる（0011 の5。0.47 のアプリは閲覧だけ）。
- 提案書のバランスシートの図と年の抜粋の表に、細目の項目（自社株〔出資額〕・会社への貸付金・会社からの借入金）が出る（分け方の部品が同じため）。連帯保証は提案書に出さない。
- ヒアリングシートの詳細版を書き出すと版2 になる。
