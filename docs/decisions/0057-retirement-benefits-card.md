# 0057. 退職金・企業年金のカードの中身（何件でも・種類ごとの欄・入れ方・目安の自動・年額の未入力）と世帯ファイルの形式 0.22

- 状態: 採用（一部未確定）（2026-10-27）
- 固定の強さ: 骨格（足した欄 `retirementBenefit.label`・`retirementBenefit.education` の名前と値の一覧と、どちらも計算に使わないこと、目安の退職給付を新しい世帯にだけ自動で足すこと、目安の無い年額を未入力の警告にすること、外したら勤め先を「該当なし」にすること）。欄の並び・簡易と詳細の分け方・文言・入れ方の選択肢の名前・標準の値（DB の年数・併用の割合・功績倍率）は後から変えてよい（変えたら追記に書く）
- 前提にする記録: 0007（制度データ・マスタと推定の目安の写し）、0008（世帯のデータモデル・値の箱・退職給付の追記）、0035（世帯ファイルの形式。足すだけの形）、0038（時点の部品）、0041（値の状態の操作・確かめの一覧）、0043（入力画面でプランを直す）、0045（カード。退職金・企業年金の枠）。受け取りの並びは 0058。

## 背景

- 計算エンジンの退職給付（`retirementBenefits`。退職一時金・確定給付企業年金・公務員の退職手当と年金払い退職給付・国民年金基金・役員退職慰労金）は、人ごとに何件でも、受け取り方（一時金・年金・併用）・年金の年額と年数・見込みの計算（公務員の俸給月額×支給率、役員の最終報酬月額×在任年数×功績倍率）・掛金を前から持てる。
- 画面は「1人1件」で、種類・見込み額・受け取る年月の3つの欄だけだった。年金だけの給付（国民年金基金・年金払い退職給付）は年額の欄が無く、選ぶと0円で計算された（知らせだけ）。公務員・役員を選んで「＋ 退職金を入れる」を押すと、0円の未入力の箱が入り、見込みの計算が働かなかった。
- 0045 で退職金・企業年金のカードの枠を作り、退職給付を働き方と収入から移した（中身は前のまま）。
- 退職一時金の目安の関数（勤続年数・辞め方・学歴。就労条件総合調査と東京都の中小企業の退職金の調査）は統計の写しにあり、新しく会社員・公務員として入れたときだけ、定年の目安を自動で入れていた。辞め方と学歴は使っていなかった。

## 決定

### 1. 人ごとに何件でも

- 人ごとの区画に、退職給付1件を1つのまとまりで並べる。「＋ 退職金・企業年金を足す」はいつでも出す（何件でも）。
- 足す種類の既定は働き方から: 正社員は退職一時金（2件目は確定給付企業年金）、公務員は退職手当（2件目は年金払い退職給付）、自営業は国民年金基金、役員は役員退職慰労金、ほかは退職一時金。種類は簡易の選択で変えられる。
- 最初の1件で、今の働き方が正社員・公務員なら、目安（2）で入れる。

### 2. 入れ方（目安で／額で）を退職給付1件ごとに

| 入れ方 | 中身 |
|---|---|
| 目安で | 退職一時金は統計の目安（勤続年数・辞め方・学歴）。公務員の退職手当と役員退職慰労金は見込みの計算（額を持たず、計算エンジンが出す） |
| 額で | 会社の見込み額の通知・規程の早見表の額。目安の額を初めの値として欄に置き（推定のまま）、額を打つか「✓ この値で確定」で確定 |

- 1件ごとに選ぶ（夫は会社の見込み額が分かり、妻は分からない、が普通にある）。選択は画面の側の値で、世帯ファイルには持たない（額の箱の状態と、見込みの計算の額の有無から読む）。
- 額で→目安で に戻すと、目安の額に戻し、入れていた額は根拠の文に残す。目安で→額で（見込みの計算の種類）は、額を入れるまで未入力（0円で計算中）。
- 目安を作れない種類（確定給付企業年金・国民年金基金・年金払い退職給付）には入れ方の欄を出さない（いつも額で）。
- 会社の退職金規程の計算部品で出す入れ方は、計算部品の差し込み口を開く回に足す（今は出さない）。

### 3. 種類ごとに要る欄（簡易／詳細）

| 種類 | 簡易 | 詳細 |
|---|---|---|
| 退職一時金（中退共・特退共を含む） | 種類・入れ方・見込み額・受け取る時期 | 名前・学歴（目安の元）・勤め先・勤続期間・障害者になったことによる退職 |
| 確定給付企業年金（企業年金基金・企業年金連合会を含む） | 種類・見込み額（一時金で受けた場合の額）・受け取る時期・受け取り方（一時金・年金・併用）・一時金の割合（併用）・年金の年額（空欄は一時金の額を年数と予定利率で直した額を補助に出す） | 年金の年数・保証期間（終身）・年金の始まり・1年の支払いの回数・予定利率・名前・勤め先・勤続期間・障害による退職 |
| 退職手当（公務員） | 種類・入れ方・見込み額（空欄は見込みの計算）・退職時の俸給月額（目安で のとき）・受け取る時期 | 退職の理由・名前・勤め先・勤続期間・障害による退職 |
| 年金払い退職給付（公務員） | 種類・年金の年額（必ず。終身の半分と有期の半分の2件） | 年金の年数・保証期間・年金の始まり・回数・支給の月・名前・勤め先 |
| 国民年金基金 | 種類・年金の年額（必ず）・本人の掛金（月額） | 保証期間・年金の始まり・回数・支給の月・掛金の始まりと終わり・名前・勤め先 |
| 役員退職慰労金 | 種類・入れ方・見込み額（空欄は見込みの計算）・最終報酬月額（目安で のとき）・受け取る時期 | 功績倍率・名前・勤め先・勤続期間・役員の在任期間・障害による退職 |

- 年金払い退職給付は「終身の半分」と「有期の半分」の2件に分けて持ち、名前で組にする（種類を選ぶと有期の半分を足す）。
- 欄の当て先は退職給付の物（`retirementBenefit.*`）。欄のキーは `retirement/<物>/<欄>` にした（前の `work/benefit/<物>/<欄>` は 0.16 の読み替え表のまま。当て先で当てるので、保存した差分には影響しない）。

### 4. 推定と既定の値（新しい世帯と、元の値が変わったとき）

| 値 | 推定 | 入れ直し |
|---|---|---|
| 退職給付があること | 新しく正社員・公務員として入れたとき（「会社員として入れる」・働き方の種類を選んだ）だけ1件を自動で足す。パート・契約・自営業・役員には足さない | 働き方を正社員・公務員以外に変えたら、目安のまま（自動で足したまま）の退職給付を外す。FP が額を入れた物は残し、「前の勤め先の退職金として残しています」の注意を出す |
| 退職一時金の額 | 統計の目安（勤続年数・辞め方・学歴。学歴が分からないときは大学・大学院卒の値） | 勤続（勤め先の期間）・辞め方・学歴が変わったら、目安のままなら入れ直す |
| 辞め方 | 働き方の期間の終わり方（働き方と収入のカードで入れる値を読むだけ）。無ければ働き方と収入のカードと同じ既定（終わりが60歳に達した月以後か定年の出来事なら定年、それ以外は自己都合。終わりを決めていない期間は定年） | — |
| 公務員の俸給月額・退職の理由 | 年齢の平均の給与月額÷12（目安）、辞め方から（定年・会社都合は定年等、ほかは自己都合） | 推定のままなら入れ直す |
| 役員の最終報酬月額・功績倍率 | 役員の期間の年収÷12、1.0（標準の値） | 最終報酬月額は推定のままなら入れ直す |
| DB の年金の年数・併用の割合 | 年金・併用を選んだとき 10年・半分（標準の値） | — |
| 受け取る時期 | 空欄は勤め先を辞めた翌月（計算エンジンの既定。欄に年月を添える） | 出来事・期間で動く |

- 値の箱を持たない値（最終の月給・理由・功績倍率・年数・割合）の推定は、退職給付の値の状態の欄の行（`retirementBenefit.estimate/finalMonthly` など）に持つ。前の版の見込みの計算の行（`retirementBenefit.estimate` の1行）も推定として読む。
- 古い世帯は黙って書き換えない（0035 の11）: 退職金の無い会社員・公務員には足さず、確かめの一覧の「未入力」と「推定で埋める」（0041）。統計の目安のままの額の入れ直しは、前と同じく推定のままの値だけ。

### 5. 年額の目安の無い物は未入力の警告

- 国民年金基金・年金払い退職給付の年額は、統計・公表の額の写しがまだ無いので推定を入れない。年額の欄は簡易に必ず出し、入れるまで「未入力（0円で計算中）」（確かめの一覧のいちばん上・カードの状態は未入力）。前の「選ぶと0円で黙って計算する」を直した。
- 国民年金基金の本人の掛金は任意の欄（社会保険料控除）。受け取り前で掛金が空なら「社会保険料控除を計算していません」の補助を出す。

### 6. 外したら「該当なし」、確かめの注意

- 退職給付を外して、その人の退職給付が無くなったら、今の勤め先の働き方の期間に「該当なし」の行を置く（もう目安で足さない。カードは「当てはまらない」になりうる）。「＋ 足す」で足すと該当なしの印を外す。
- 目安で自動で足した退職金は、確かめの一覧の「確かめの注意」（推定より上）に出す: 「勤め先に退職金の制度があるか確かめてください（制度がある企業の割合）」。押せるのは「制度がある（この額で確定）」と「制度が無い（外す）」。
- 公務員・役員の退職給付で見込み額が0円の確定（前の版の「＋ 退職金を入れる」の跡）は、確かめの注意に出し、「見込みの計算にする」「該当なし」を選べる（黙って変えない）。

### 7. 死亡退職金の1行

- 一時金の額を持つ退職給付がある人には、読むだけの1行「万一亡くなったとき: 受け取る前の退職一時金は、勤続の月数で按分して死亡退職金として遺族へ（相続税は 500万円×法定相続人の数まで非課税。相続税の目安に入ります）」を出す。非課税の額は制度データの写しから読む。計算は今のまま（計算エンジンの死亡退職金と相続税の目安。0039）。

### 8. 世帯ファイルの形式 0.22

- 退職給付に名前 `retirementBenefits[].label`（文字。表示用）と学歴 `retirementBenefits[].education`（`university`・`highSchoolOffice`・`highSchoolManual`。退職一時金の目安の元）を足した。どちらも任意で、計算には使わない（計算エンジンは読まない）。
- 足すだけの MINOR。0.21 のアプリは知らない欄を読み落として書き戻すので、版を上げて閲覧だけにする。0.21 → 0.22 の変換の段は形式の版だけを書き換える。見本 `crates/household-store/tests/fixtures/household-format/0.22/`。
- AI接続口の縮約版の許可リスト（0015）に学歴 `retirementBenefit.education` を入れ、版を `reduced@14` にした。名前 `retirementBenefit.label` は FP が書いた文なので、文章の項目として既定で外す。持ち帰り用のレポートでも名前は外す（種類から見せる）。

## 理由

- 入れ方を世帯ファイルに持たない: 額の箱の状態（統計の目安の推定・確定）と見込みの計算の額の有無で、どちらの入れ方かが一意に決まる。値を2か所に持つと食い違う。
- 年額の目安を入れない: 外れると年金の総額が大きく誤る。公表の額を原本で確かめるまでは、未入力の警告のほうが気づける。
- 自動で足すのを新しい世帯だけにした: 退職金0円は気づかないまま誤る上位だが、制度の無い勤め先（およそ4分の1）もあるので、確かめの注意の上位に出して外せるようにした。古い世帯は FP が押したときだけ。
- 外したら該当なし: 外しても次に働き方を選び直すとまた足される、を防ぐ。
- 名前と学歴を物に持つ: 名前は年金払い退職給付の組や企業年金連合会の年金の見分けに要る。学歴は勤続35年以上の定年で、大学卒と高校卒（現業）で目安がおよそ500万円違う。

## 代案（採らなかったもの）

- 入れ方を画面の側の記録（`WorkingHousehold` の区分の表）に持つ: 世帯ファイルの区画が増え、状態との食い違いを直す決まりが要る。
- 国民年金基金の1口目の額を仮の値で入れる: 原本で確かめていない額を推定として出すことになる。
- 年金払い退職給付を1件で持ち、終身と有期を内訳にする: 計算エンジンの形（1件に1つの年数）を変えることになる。
- 学歴を構成員に持つ: 構成員は家族のカードの物で、目安の元としてしか使わない。

## 追記

- 2026-10-29（入れ方の選択の欄を外した・該当なしの見せ方・死亡退職金の文・受け取りの並びの説明）:
  - **入れ方（目安で／額で）の選択の欄を外した**（決定の2を改める）。「どちらを選んでも何も変わっていないように見える」という指摘を確かめた。退職一時金で「目安で」→「額で」にすると、額はそのまま・推定の印もそのままで、計算も同じ。違いは根拠の文と、そのあと勤続・辞め方・学歴を直したときに目安を入れ直すか（目安で）止めるか（額で）だけで、画面からはほぼ見えない。公務員の退職手当・役員退職慰労金では「額で」にすると未入力の0円になり、計算が0円に変わる（見込みの計算が消える）。どの状態も見込み額の欄だけで作れる（空欄＝目安・見込みの計算、額を打つ＝額、「この値にする」＝目安の額で確定、空欄に戻す・「推定に戻す」＝目安）ので、選択の欄は二重の入り口で、「額で」で額を打たない状態はかえって分かりにくい。見込み額の欄の説明に「空欄のときは目安（勤続年数・辞め方・学歴からの平均）で計算し、勤続や学歴を直すと目安も直ります」と書き、選ぶ前に違いが分かるようにした。公務員・役員の俸給月額・最終報酬月額の欄は、見込み額が空欄のとき標準に出す（今までと同じ）。
  - **前の版の世帯の跡**: 入れ方は世帯ファイルに持たない（決定の理由のとおり）ので、形式は変えない。「額で」を選んで額を打っていない跡は、推定の入れ直し（`refreshRetirement`）で選択の無い形に読み替える。退職一時金の「目安の額を初めの値にした」推定は目安に戻し（推定のままなので入れ直してよい。値は勤続などが変わっていなければ同じ）、公務員の退職手当・役員退職慰労金の未入力の0円で見込みの計算の月給があるものは、額を外して見込みの計算に戻す。FP が打った額（確定・わからない・該当なし）は変えない。
  - **該当なしの見せ方**: 「＋ 退職金・企業年金を足す（今は「該当なし」）」のように、ボタンの名前に今の状態を書いていたのをやめ、人の区画の見出しの下に「該当なし」と出す（区画の説明の頭の「該当なし」を状態の言葉として出す。説明の残り「働き方を選び直しても目安で足さない」「足すと該当なしを外す」は「?」の中）。該当なしにしていない人（退職給付が無いだけの人）には出さない。区画の説明の状態の言葉に「該当なし」を足した（0077 の「まだありません」と同じ扱い）。
  - **死亡退職金の1行**（決定の7を改める）: 名前を「万一亡くなったときの扱い」にし、文を「万一亡くなったときは、」で始めた。勤続の月数で按分するのはこのアプリの目安の決まりで、実際の額は勤め先の退職金の規程で決まる（会社都合の率で払われることも多い）ので、普遍の決まりのように読める書き方をやめ、「額は勤め先の退職金の規程で決まります。このアプリでは、勤続の月数で按分した額を目安にします（「万一のとき」のタブで額を入れられます）」とした。非課税の言い方は制度データ（相続税の死亡退職金の非課税限度額。相続税法12条1項6号）の書き方どおり「死亡退職金の非課税限度額（500万円×法定相続人の数）」にした。
