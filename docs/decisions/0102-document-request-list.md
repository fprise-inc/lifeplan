# 0102. 書類のお願い（1段目）: 書類待ちの欄から送ってほしい書類の一覧を作り、お願いの文・ヒアリングシート・写す欄の手引きにする

- 状態: 採用（2026-10-31）
- 固定の強さ: 内部（画面の作り。後から変えてよい）。一覧は世帯から毎回作り、世帯ファイルにもヒアリングシートの定義にも何も足さないので、言葉・まとめ方・並びは後から変えてよい。「世帯ファイルに書類の画像を入れない」（0012）と「シートの配置の外の行は取り込みで読まない」（0018 の6）は前の記録のとおり

## 背景

- 値の状態の「書類で確かめる」（状態 `unknown`。画面と確かめの一覧では「書類待ち」）を、書類から写す7種の欄だけに残した（0041 の追記 2026-10-31）。欄の定義が確かめる書類の名前（`docCheck`。`app/src/workspace/input/checkDocuments.ts`）を持つ。
- 書類待ちの欄が増えても、FP がお客さまに「どの書類を送ってほしいか」を伝える道具は無かった。確かめの一覧の書類待ちの行は欄ごとで、同じねんきん定期便を2行・住宅ローンの返済予定表を4行のように並ぶ。
- 書類（保険証券・返済予定表・ねんきん定期便など）のやりとりは、FP がふだん使っている方法で行う。アプリの中で暗号化した受け取りを作るのは β の後に考える。
- 前提にする記録: 0012（持たない情報。書類の画像は受け取らず保存もしない）、0018（ヒアリングシートの形式・配置の指紋・公開した版を変えない）、0020（平文の書き出し）、0041（値の状態の操作と確かめの一覧）。

## 決定

1. **送ってほしい書類の一覧**（`app/src/workspace/input/docRequests.ts` の `docRequests`）
   - 確かめの一覧（`checkList`）の書類待ちの行から毎回作る。行には、確かめる書類・書類の持ち主・欄の名前を足した（`CheckRow.doc`。書類待ちの行だけ）。世帯ファイルの形は変えない（保存するものは無い）。
   - 同じ書類を持ち主ごとに1通にまとめる: 人の書類（ねんきん定期便・住民税の決定通知書・会社の退職金規程・制度の資料）は構成員ごと（退職一時金と企業年金など同じ人の物は1通）、保険証券は契約ごと（種類の名前か契約の名前と被保険者）、返済予定表はローンごと（住宅ローン・ローン。名前があれば名前）と車ごと（自動車ローン。車が2台以上のときだけ持ち主を添える）。持ち主が当て先で決まらない欄（住民税）は、欄の定義の `docFor`（構成員の ID）で決める。
   - 見出しの呼び方は「ご本人」「配偶者」など（`roles`）。FP が付けた呼び名は使わない（お客さまに渡す文に出るため）。同じ見出しが2つになるときは2件目から番号を添える。
   - 1通ごとに、その書類から写す欄（欄の名前・確かめの一覧の見出し・今の代わりの値・欄へ移る先）を並べる。
2. **画面**（`app/src/workspace/input/DocRequests.tsx`）
   - 入力のホームの見出しの「確かめの一覧」の隣に「書類のお願い（N通）」（書類待ちがあるときだけ）。確かめの一覧の「書類待ち」の見出しにも「書類のお願いにまとめる」。
   - 写す欄の手引き: 書類ごとに、欄・代わりの値・「開く」（その入力項目を開いて欄に移る。詳細の欄なら詳細にする。確かめの一覧の「開く」と同じ）。欄に書類の値を打つ（または「この値にする」）と書類待ちが消え（0041 の追記のとおり）、一覧は世帯から作り直すので、その欄・その書類はすぐ一覧から消える。
   - 「文をコピー」: メール・メッセージに貼るお願いの文（`requestMessage`）。書類の見出しと見たい所（欄の名前）、「証券番号・口座番号などは隠していただいてかまいません。」、写真でよいこと、送り方の一言（こちらが案内する方法〔アップロード用のリンクなど〕で、パスワード付きの圧縮ファイルは要らない・面談に持参でもよい）、写し終えたら削除することを入れる。**金額・代わりの値・番号・顧客番号・内部 ID は入れない**。お名前・事務所名は FP がその場で入れたときだけ入れ（保存しない。アプリを開いている間だけ覚える）、空なら「〇〇」「（事務所名）」の置きかえる所の印にする。
   - クリップボードへの写しは、今の「次回確かめることを写す」と同じ扱い（0020 の未確定の「クリップボードへの写しの範囲」のまま。中身に金額・番号が無いので警告と記録は付けない）。
3. **書類を安全に受け取るための FP 向けの説明**（`SAFE_SENDING`。書類のお願いの中の「書類を安全に受け取るには（FP 向け）」）
   - パスワード付きの圧縮ファイルをメールで受け取らない（同じ経路で送るパスワードは守りにならない）。
   - クラウドの保存サービスの、ファイルを出してもらうだけのリンク（「ファイルのリクエスト」などの名前の機能）で受け取る。期限を付け、受け取ったら閉じる（画面の文には特定のサービスの名前を書かない）。
   - 数字を写したら、受け取った書類を保存サービス・ダウンロードのフォルダ・メールの添付から消す。
   - 書類の画像は世帯ファイルに入れない（0012。写すのは数字だけ。番号類も入れない）。
4. **ヒアリングシート**（0018 の追記 2026-10-31）
   - 書き出しの画面に「書類のお願いを載せる（N通）」（書類待ちがあるときだけ。既定で載せる）。載せると、.xlsx の1枚目の配置の最後の行の1行あけた下に「今回お願いしたい書類」の見出し・書類の見出し・番号を隠してよい一文を書く（`WriteOptions.requestedDocuments`）。
   - シート定義・配置・項目キー・配置の指紋・管理の値・記入欄のシートは変えない。足す行は配置の外で、取り込みは読まない（0018 の6「管理の値と配置が指すセルだけを読む」）。シートの版を上げずに足せる。渡さなければ今までと同じバイト列（見本の確かめ `sample:check` もそのまま通る）。
   - 印刷用 PDF（0018 の8）はまだ無い。作るときは同じ一覧を同じ位置（1枚目の最後）に出す。
5. **後でアプリの中の暗号化した受け取りを作るとき**: この一覧の1通（`DocRequest`。書類と持ち主の鍵 `id`・写す欄の行の ID）を受け取りの単位にする。受け取った書類から値を写すのは今と同じ欄（`fieldKey`）で、写せば書類待ちが消え、一覧から消える。受け取った書類そのものは、今と同じく世帯ファイルに入れない（写したら消す）。受け取りの状態（頼んだ日・届いた日など）を持つ必要が出たら、そのときに形式を上げて足す（この回は持たない）。

## 理由

- **毎回作る**: 書類待ちの状態はもう世帯にある。一覧を別に保存すると、欄の状態と食い違う。作り直すだけなら、値を打った瞬間に一覧が合う。
- **持ち主ごとに1通**: お客さまに頼むのは書類の単位で、欄の単位ではない。人の書類は人ごと、契約・ローンの書類は契約・ローンごとに1通ある。
- **文に金額を入れない**: 文はメールやメッセージで平文のまま行き来する。見たい所の名前だけで頼める。
- **シートは配置の外に足す**: 公開した版の定義を変えずに、世帯ごとの中身を載せられる。取り込みは配置の指すセルしか読まないので、返ってきたシートの読み方は変わらない。
