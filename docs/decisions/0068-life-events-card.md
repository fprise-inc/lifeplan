# 0068. ライフイベントのカードの中身（ひな形・予備費・入る⇄出るの付け替え・基本生活費へ移す・この世帯の予定）

- 状態: 採用（一部未確定）（2026-10-27）
- 固定の強さ: 内部（世帯ファイルの形・エンジンの入力は変えない。並び・簡易と詳細・文言・ひな形の額・予定の一覧に載せる物は後から変えてよい）

## 背景

- ライフイベントのカードは、一時的支出・n年ごとの支出（出るお金の行）の2つのボタンと、入るお金の区画だけだった。よく使う予定（家族旅行・家電・結婚・大きな買い物・予備費）を1押しで入れられず、入るお金の区画は空のとき何を入れるかが分からなかった。
- 介護の費用は介護・親のカードに移った（0045・0059）が、ライフイベントには読むだけの1行が残っていた。
- 車の買い替え・教育の入学・住まいの購入などは別のカードにあり、「この年に大きな出費が重なっていないか」を入力の画面で一度に読む所が無かった。
- 前提にする記録: 0040（段階と例外の年）、0041（値の状態）、0044（お金の行）、0045（14枚のカード・ピン）、0048（基本生活費のカードの年払いの暮らしの支出）、0059（介護・親のカード）。

## 決定

### 1. 区画「出るお金（一時的支出・n年ごと）」

- 行の作りは 0044 のお金の行のまま（名前・時期・額・始まり・何年ごと・終わり・優先度の札、詳細の3まとまり）。種類は「一時的支出・n年ごとの支出」（既定）と「その他の支出」。表の行は8種と教育費・車の維持費のどれにも変えられる。
- **ひな形のボタン**（額は目安のボタンの値＝推定。時期は1年後）:

| ひな形 | 額・くり返し | 表の行 |
|---|---|---|
| 家族旅行 | 30万円・毎年 | 一時的支出 |
| 家電の買い替え | 25万円・8年ごと | 一時的支出 |
| 結婚の費用 | 額は未入力の警告（目安を作らない） | 結婚の費用 |
| リフォーム以外の大きな買い物 | 50万円・1回 | 一時的支出 |
| 予備費 | 毎年、足したときの基本生活費の1か月分（写す） | 一時的支出 |

  行が無いときは簡易に、行があるときは詳細に出す。同じ名前の行があるひな形は出さない。
- **予備費**は、足したときの基本生活費の月額（総額か費目の合計。生活費が無ければ人数の目安）を1万円単位に丸めて写す。生活費の割合として持ち続けない（生活費を直しても予備費は動かない）。根拠は「ひな形の目安（生活費の1か月分を毎年）」。
- 区画の説明に、優先度の札（必要・希望・夢）で「確実な分だけで見る」から外す物を決められることを書く。

### 2. 区画「入るお金（その他の一時的収入）」

- 種類は祝い金・お見舞い・一時の給付金／動産の売却（車以外）／一時所得／その他の入金（0044 のまま）。
- 行が無いときは **ひな形のボタン**「結婚のお祝い」「出産のお祝い」「一時の給付金」（種類 祝い金・お見舞い・一時の給付金。名前だけ入れ、額は未入力の警告）。
- 区画の説明に、ほかのカードで入れる種類の行き先を書く（相続・贈与／介護・親／家族／働き方と収入）。

### 3. 入る⇄出るの付け替え・基本生活費へ移す（行のボタン。詳細）

- 出るお金の行の「入るお金にする」: 同じ名前・額（値の箱ごと）・時期・伸び方の入るお金の行（種類 その他の入金）を作り、もとの行を外す。入るお金の行の「出るお金にする」は逆（種類 一時的支出・n年ごとの支出。表の行は1回なら一時的支出、くり返しならその他の支出）。プランを直しているときは、外す・足すの組の差分になる。
- くり返す出るお金の行の「基本生活費のカードへ移す（年払いの暮らしの支出）」: 種類だけを「年払い・数年おきの暮らしの支出」にする（表の行・額は変えない）。古い世帯の周期的な支出を、FP が選んで移すための物で、自動では移さない（0035 の11）。

### 4. 介護の費用はここに出さない

- 介護の費用（`careExpenses`）は介護・親のカードだけに出す。ライフイベントの出るお金の区画の読むだけの1行もやめ、「この世帯の予定」に介護の始まりとして読むだけで載せる。

### 5. 区画「この世帯の予定（ほかのカードを含む）」（読むだけ。詳細）

- 入力から読む（計算の結果ではない）。年の順に1行ずつ、見出しは「年（本人・配偶者の年齢）」、値は「入／出｜名前（額・1回／毎年／n年ごと／毎月）」、どのカードで入れるか。額は今の値段。
- 載せる物: 全部のカードのお金の行（くり返しは最初の年）、車の購入・買い替え（下取りを引いた額）・手放す、住まいの購入・売却、教育の入学（高校・大学）、退職給付の受け取り（時期が入っている物）、年金の受け取り開始（記録の無い人は65歳になった翌月）、介護の始まり、家族のカードで足した名前つきの出来事。
- **1回の出るお金が同じ年に2つ以上重なる年**を区画の説明に並べる（その年の入学も添える）。
- 見出しの年の範囲は計算の基準の年から表の最後の年まで。

## 残したもの（まだ出していない欄・仕組み）

- 予定の一覧の絞り込み（入る／出る・カード・優先度・この10年）と、行を押してそのカードのその行を開くこと。今は行ごとに「どのカードで入れるか」を出すだけ。
- 予定の一覧の住宅ローンの完済・保険の満期（計算の結果か、ローン・保険の欄から読む形を決めてから）。
- 行のメニュー「複製」「ほかのカードへ移す」「該当なしにする」「この行が無かったら」（保存しない自動の差分の作りを決めてから）。
- 時点の欄の「幅で並べて見る」と、結果の表の行を開いて物ごとに見る・「表に★で出す」（結果のタブの回）。
- 出るお金に打ったマイナスの額を入るお金に移す提案と、明細から来た行と手で入れた行の二重の点検。
- 夢・希望の支出（夢プラン。世帯ファイルの形を変えるので後の回）と、子への援助（結婚資金）の優先度（必ず・できれば。子への援助に優先度の欄が無い）。2026-10-31 の追記。

## 2026-10-31 の追記: ひな形の組み直し・種類と表の行・入るお金

### 1. ひな形（出るお金。10）

- 標準と詳細のどちらでも、行を足した後も出す。小さなボタン（`ActionDef.chip`）を、まとまりごとに1行（小さな見出しの後にボタン）で並べる（`GroupDef.chips`）。並びの上の1行は「よくあるライフイベント（当てはまるものだけ足してください）」（全部を入れなければと思わせない）。足したひな形はボタンの横に「入れた（2031年・80万円）」（3つまで。額が0円の行は「額は未入力」）を出し、ボタンは押せるまま（もう一度押すと、もう1行）。
- 当てはまる人のいないまとまりは後ろに回す（隠さない）: 親（構成員の親）のいない世帯の「親・お墓」、子がいなくて配偶者がもう家族の世帯の「家族の節目」（結婚の費用は、配偶者がいない・これから加わる世帯には当てはまるので、子がいないだけでは後ろにしない）。
- 足した行の額は推定（根拠は「よくある額の目安（…）」。原本で確かめた統計ではない）、額の無いひな形は未入力の警告。時期は既定で1年後。表の行はどれも一時的支出。優先度はひな形どおり（できればの物だけ `priority: "want"` を書く）。

| まとまり | ひな形 | 時期 | 額 | 優先度 |
|---|---|---|---|---|
| 家族の節目 | 結婚の費用 | 配偶者が家族に加わる時期（これからのとき）。無ければ1年後 | 未入力の警告 | 必ず |
| 家族の節目 | 子の成人式（振袖・スーツ・写真） | 20歳前の子ごとに、その子の20歳（1人1行） | 15万円 | 必ず |
| 家族の節目 | 子の結婚の援助 | 30歳前の子ごとに、その子の30歳 | 100万円 | （下の2） |
| 親・お墓 | 親の葬儀（世帯が払う分） | 推定（下の3）。親ごとに1行 | 120万円 | 必ず |
| 親・お墓 | 法事 | 葬儀の行の1年後（一周忌）。無ければ1年後 | 20万円 | 必ず |
| 親・お墓 | お墓・仏壇 | 1年後 | 未入力の警告（「?」に0〜300万円ほどと幅があること） | 必ず |
| 楽しみ・学び | 特別な旅行 | 1年後 | 未入力の警告（「?」に海外80万円・国内30万円ほど） | できれば |
| 楽しみ・学び | 大きな買い物（趣味の道具など） | 1年後 | 50万円 | できれば |
| 楽しみ・学び | 資格・学び直し | 1年後 | 30万円 | できれば |
| 備え | 予備費 | 毎年（今までどおり） | 生活費の1か月分（写す） | 必ず |

- 足したかは行の名前の形で見る（行の名前は FP が直せる）。特別な旅行は1回の行だけ数える（前の「家族旅行」〔毎年〕は数えない）。特別な旅行は名前の欄に中身（ハワイ旅行・結婚20周年の旅行など）を書く1つのひな形。
- 人ごとのひな形（成人式・葬儀・子の結婚の援助）は、もう行がある人を飛ばして足す（全員にあれば全員にもう一度）。足す相手がいなければボタンを押せなくし、横に理由（「20歳前の子がいません」など）。
- 外したひな形: 「家族旅行（毎年30万円）」（ふだんの旅行は基本生活費の「趣味・娯楽」。0100 の追記 2026-10-31）、「親の長寿のお祝い（還暦・古希など）」（額が小さく要らない）。孫の誕生のお祝いは置かない。前に入れた行はふつうの行のまま。「リフォーム以外の大きな買い物」は「大きな買い物（趣味の道具など）」にした（前の行の名前はそのまま。足したかの名前の形には入れる）。
- ほかの入力項目への案内は区画の説明の文だけ（読むだけの行は置かない）: 「ふだんの旅行・帰省は基本生活費に入れます。ここには特別な旅行を入れます。家電・スマホの買い替えも基本生活費、住まい・車・教育・介護・贈与はそれぞれの入力項目で入れます」。
- 夢・希望の支出（夢プラン）は世帯ファイルの形を変えるので、この回では入れない。

### 2. 子の成人式はライフイベントに残す・子の結婚の援助は子ども・教育の子への援助を使う

- **子の成人式**: 時期は子の年齢（`memberAge`）で持つ。前は、子の年齢で始まる周期的な支出を子ども・教育の、その子の所に出していた（`childOfPeriodic`）。これを**種類の無い古い行だけ**にした（前に足した留学など。種類 `general`・`other` の行は、子の年齢で始まってもライフイベントに出す）。新しく足す子の年齢の教育の行は前から種類 `education` で子ども・教育の行なので、変わるのは「種類のあるライフイベントの行で、子の年齢で始まる行」だけ（形は変えない）。
- **子の結婚の援助**: 新しい行を作らず、子ども・教育の入力項目の「子への援助」（`goals[].education.gifts`。使い道 `wedding`・結婚資金）に、子が30歳になる時期（子の年齢）で1人100万円を足す（贈与する人は選ばない＝世帯から出す。計算は前からの「結婚の費用」の行）。同じ援助を2つの所で入れて二重に数えないため。ライフイベントの出るお金の区画には、子への援助（結婚資金）の読むだけの行「子への援助（結婚資金）」を出し、直すのは子ども・教育の入力項目。教育の目標の無い子で、これからの学校がある子には足さない（ボタンの横に「先に子ども・教育で進路を入れてください」。進路の推定を後から入れられなくなるため）。これからの学校が無い子は、段の無い教育の目標を作って入れる。
  - 子への援助には優先度の欄が無いので、援助は「必ず」として計算する（「確実な分だけ」の見方で外せない）。優先度を持たせるには形を変える必要があり、この回ではしない。

### 3. 親の葬儀の時期（聞かない推定）

- 親が亡くなる見込みを聞くのは重いので、時期は聞かずに推定する（時期の欄の仮の印。欄のキー `ev/<行の ID>/from`。直すと外れる）:
  - 親に亡くなる見込み（`leaves`）が入っていれば、その時期（形のまま写す）。
  - 親の生年月があれば、その親の年齢と性別の平均余命（簡易生命表。マスタデータ `lifeTable.lifeExpectancy`。相続税の目安の亡くなる見込みと同じ読み方）を足した年齢（親の年齢で持つ）。
  - 親がいない（生年月も無い）ときは、本人より30歳上の親とみて、その年齢の平均余命（男女の平均）を足した年の本人の年齢で置く（本人30歳なら56歳ごろ、40歳なら57歳ごろ、50歳なら60歳ごろ、60歳なら65歳ごろ）。
  - どれも過ぎていれば1年後。
- 香典のひな形は置かない（「?」に「香典は入るお金で入れられます」）。葬儀の費用を相続税から引く扱いは相続・贈与の入力項目で見る（「?」に書く）。
- 法事は、葬儀の行（いちばん早い物）の1年後（年齢で持つ時期は年齢を1つ足す）で、時期は仮の印つき。

### 4. 種類・ボタン・表の行

- この入力項目で足す出るお金の行は、種類1つ（`general`。名前は「ライフイベントの支出」。前は「一時的支出・n年ごとの支出」）。種類の選択は出さない（`other`「その他の支出」の前の行は読めるが、ボタンでは足さない）。
- 「＋ 一時的支出（1回）」「＋ n年ごとの支出」「＋ その他の支出」をやめ、「＋ ほかの支出を足す」（1回・1年後。額は目安の推定。名前は空で、FP が書く）の1つにした。
- 表の行は**一時的支出（`cf.expense.lumpSum.other`）に決めて**選ばない（予備費・結婚の費用も）。前に別の行を選んだ行は、詳細に読むだけで「キャッシュフロー表の行」を出し、そのまま計算する。
- 時期の選択は「1回」「年ごと」（毎月を出さない。毎月の支出は基本生活費）。前に毎月で入れた行は、毎月も残して見せ、行の説明に「毎月の支出は基本生活費の入力項目で入れます（この行は毎月のまま計算します）」。
- 優先度（必ず／できれば）は標準と詳細のどちらでも、行の右に出す（前は詳細）。
- 名前の無い行の呼び方は時期で決める: 「一時的支出」「毎年の支出」「3年ごとの支出」「毎月の支出」（前は「n年ごとの支出」）。
- 付け替え: 入るお金の行を出るお金にするとき、表の行は1回でもくり返しでも一時的支出（前はくり返しなら「その他の支出」）。「基本生活費の項目へ移す」は、表の行が年払いの暮らしの支出で選べない行（一時的支出など）なら「基本生活費に含める」にする（前は表の行を変えず、移した先で「前に選んだ行」になっていた）。
- 明細の取り込みの候補（`statement/src/candidates.ts`）: 車の候補は種類 `car`（車の入力項目の「車の修理・用品など」）、住まいの修繕の候補は種類 `repair`（住まいの「修繕・リフォーム」）にした（前は種類が無く、ライフイベントの行になっていた）。表の行は今までどおり。

### 5. 入るお金

- ひな形（結婚のお祝い・出産のお祝い・一時の給付金）も小さなボタンにし、行を足した後も出す。時期: 結婚のお祝いは配偶者が家族に加わる時期（これからのとき）、出産のお祝いは生まれる予定の子が加わる月（いなければ1年後）。出産のお祝いの「?」に「出産育児一時金は自動で計算します」。
- 「動産の売却（車以外）」の「?」: 実家じまい・遺品整理での家財や骨董品、住み替えでの家具、貴金属・時計・ブランド品・美術品・コレクション・楽器、バイクなど車以外の乗り物の売却。「1個30万円を超える貴金属・美術品などは税がかかることがあります（課税の扱いを選び直してください）」。
- 「一時所得」の「?」: 「懸賞の賞金・競馬の払戻し・法人からもらうお金など。生命保険の満期・解約は保険の項目で計算します」。
- 区画の説明に「香典もここで入れられます」。

### 6. 提案書とお金の3つの分け方

- 提案書の「ライフイベント」の表（`report/src/build.ts` の events）に、ライフイベントの入力項目の行（出るお金・入るお金。くり返す行は最初の年。名前と額、くり返しは「毎年30万円」「3年ごとに40万円」）と、子への援助（結婚資金）を載せる。前は教育の入学・独立・退職・年金・車・ローンの完済などだけで、ライフイベントの行が載っていなかった。
- お金の3つの分け方（0032）: 周期的な支出の1回の行（何年ごとが1で終わりがあり、表の中で払う年が1つだけの行）を、ふだんの支出でなくできごとの支出に数える（前は何年ごとが1の行をどれもふだんの支出にしていたので、1回の結婚の費用などが「使うお金」の月額に入っていた）。毎年・毎月の行は今までどおりふだんの支出。

### 見本の世帯の結果
