# 0068. ライフイベントのカードの中身（ひな形・予備費・入る⇄出るの付け替え・基本生活費へ移す・この世帯の予定）

- 状態: 採用（一部未確定）（2026-10-27）
- 固定の強さ: 内部（世帯ファイルの形・エンジンの入力は変えない。並び・簡易と詳細・文言・ひな形の額・予定の一覧に載せる物は後から変えてよい）

## 背景

- ライフイベントのカードは、一時的支出・n年ごとの支出（出るお金の行）の2つのボタンと、入るお金の区画だけだった。よく使う予定（家族旅行・家電・結婚・大きな買い物・予備費）を1押しで入れられず、入るお金の区画は空のとき何を入れるかが分からなかった。
- 介護の費用は介護・親のカードに移った（0045・0059）が、ライフイベントには読むだけの1行が残っていた。
- 車の買い替え・教育の入学・住まいの購入などは別のカードにあり、「この年に大きな出費が重なっていないか」を入力の画面で一度に読む所が無かった。
- 前提にする記録: 0040（段階と例外の年）、0041（値の状態）、0044（お金の行）、0045（14枚のカード・ピン）、0048（基本生活費のカードの年払いの暮らしの支出）、0059（介護・親のカード）。

## 決定

### 1. 区画「出るお金（一時的支出・n年ごと）」

- 行の作りは 0044 のお金の行のまま（名前・時期・額・始まり・何年ごと・終わり・優先度の札、詳細の3まとまり）。種類は「一時的支出・n年ごとの支出」（既定）と「その他の支出」。表の行は8種と教育費・車の維持費のどれにも変えられる。
- **ひな形のボタン**（額は目安のボタンの値＝推定。時期は1年後）:

| ひな形 | 額・くり返し | 表の行 |
|---|---|---|
| 家族旅行 | 30万円・毎年 | 一時的支出 |
| 家電の買い替え | 25万円・8年ごと | 一時的支出 |
| 結婚の費用 | 額は未入力の警告（目安を作らない） | 結婚の費用 |
| リフォーム以外の大きな買い物 | 50万円・1回 | 一時的支出 |
| 予備費 | 毎年、足したときの基本生活費の1か月分（写す） | 一時的支出 |

  行が無いときは簡易に、行があるときは詳細に出す。同じ名前の行があるひな形は出さない。
- **予備費**は、足したときの基本生活費の月額（総額か費目の合計。生活費が無ければ人数の目安）を1万円単位に丸めて写す。生活費の割合として持ち続けない（生活費を直しても予備費は動かない）。根拠は「ひな形の目安（生活費の1か月分を毎年）」。
- 区画の説明に、優先度の札（必要・希望・夢）で「確実な分だけで見る」から外す物を決められることを書く。

### 2. 区画「入るお金（その他の一時的収入）」

- 種類は祝い金・お見舞い・一時の給付金／動産の売却（車以外）／一時所得／その他の入金（0044 のまま）。
- 行が無いときは **ひな形のボタン**「結婚のお祝い」「出産のお祝い」「一時の給付金」（種類 祝い金・お見舞い・一時の給付金。名前だけ入れ、額は未入力の警告）。
- 区画の説明に、ほかのカードで入れる種類の行き先を書く（相続・贈与／介護・親／家族／働き方と収入）。

### 3. 入る⇄出るの付け替え・基本生活費へ移す（行のボタン。詳細）

- 出るお金の行の「入るお金にする」: 同じ名前・額（値の箱ごと）・時期・伸び方の入るお金の行（種類 その他の入金）を作り、もとの行を外す。入るお金の行の「出るお金にする」は逆（種類 一時的支出・n年ごとの支出。表の行は1回なら一時的支出、くり返しならその他の支出）。プランを直しているときは、外す・足すの組の差分になる。
- くり返す出るお金の行の「基本生活費のカードへ移す（年払いの暮らしの支出）」: 種類だけを「年払い・数年おきの暮らしの支出」にする（表の行・額は変えない）。古い世帯の周期的な支出を、FP が選んで移すための物で、自動では移さない（0035 の11）。

### 4. 介護の費用はここに出さない

- 介護の費用（`careExpenses`）は介護・親のカードだけに出す。ライフイベントの出るお金の区画の読むだけの1行もやめ、「この世帯の予定」に介護の始まりとして読むだけで載せる。

### 5. 区画「この世帯の予定（ほかのカードを含む）」（読むだけ。詳細）

- 入力から読む（計算の結果ではない）。年の順に1行ずつ、見出しは「年（本人・配偶者の年齢）」、値は「入るお金：／出るお金：名前（額・1回／毎年／n年ごと／毎月）」（2026-10-31 に「入／出｜」から改めた。追記）、どのカードで入れるか。額は今の値段。
- 載せる物: 全部のカードのお金の行（くり返しは最初の年）、車の購入・買い替え（下取りを引いた額）・手放す、住まいの購入・売却、教育の入学（高校・大学）、退職給付の受け取り（時期が入っている物）、年金の受け取り開始（記録の無い人は65歳になった翌月）、介護の始まり、家族のカードで足した名前つきの出来事。
- **1回の出るお金が同じ年に2つ以上重なる年**を区画の説明に並べる（その年の入学も添える）。
- 見出しの年の範囲は計算の基準の年から表の最後の年まで。

## 残したもの（まだ出していない欄・仕組み）

- 予定の一覧の絞り込み（入る／出る・カード・優先度・この10年）と、行を押してそのカードのその行を開くこと。今は行ごとに「どのカードで入れるか」を出すだけ。
- 予定の一覧の住宅ローンの完済・保険の満期（計算の結果か、ローン・保険の欄から読む形を決めてから）。
- 行のメニュー「複製」「ほかのカードへ移す」「該当なしにする」「この行が無かったら」（保存しない自動の差分の作りを決めてから）。
- 時点の欄の「幅で並べて見る」と、結果の表の行を開いて物ごとに見る・「表に★で出す」（結果のタブの回）。
- 出るお金に打ったマイナスの額を入るお金に移す提案と、明細から来た行と手で入れた行の二重の点検。

## 追記

- 2026-10-29: 出るお金のひな形のボタンを名前だけにし（額を出さない）、足した行の額と何年ごとを推定（根拠は「よくある額の目安」「よくある間隔の目安」）にした。家電の買い替えのひな形は、基本生活費の年払いの「家電・家具の買い替え」と重なるので外した（前に入れた行はふつうの行のまま）。詳しくは 0044 の追記（2026-10-29）。
