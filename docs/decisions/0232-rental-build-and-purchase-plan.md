# 0232. 収益不動産の建てる・買う予定（支払いのある取得）と、相続税の評価の材料

- 状態: 採用（一部未確定）（2026-11-19）
- 固定の強さ: 世帯のデータの欄（`accounts[].property.planned` の `type`〔`buy`・`build`〕・`at`・`parts`・`equipmentLife`・`costs`・`equity`・`assessed`）の名前と意味、表の行 `cf.expense.lumpSum.realEstatePurchase`（計算式ID `asset.realEstate.purchase`）、`asset.realEstate` の任意の出力（`years[].assessed`・`years[].rentedShare`・`facts.planned`。約束の版 1.7）は骨格。自己資金の省略の決め方・予定の月より前の売る予定の扱い・建物の固定資産税評価額の推定の式（画面の側）・画面の並び・標準と詳細の分け方・文言は変えてよい（変えたら追記に書く）
- 前提にする記録: 0028（住まい以外の不動産の中身・ローンは負債の `property`）、0039 の9（持ち始める時点 `holdFrom`）、0052（住まいの購入）、0079〜0082（収益不動産の入力項目・お金の欄・税と出口・分析の数字）、0112・0181（固定資産税の推定・新築の評価額の割合と経年減点補正率）、0123（貸していない不動産）、0126〜0128、0145（標準と詳細）、0011（世帯ファイルの形式の版）

## 背景

- 収益不動産（0079）は、今持っている物件を入れる作りだった。これから買う物件・持っている土地に建てる賃貸の建物を、支払いと一緒に入れる場所が無かった。
- 持ち始める時点（`holdFrom`。0039 の9）は相続・贈与で受け取る物件のためで、受け取るときの支払いが無い。買う・建てるときは、自己資金の支払い・ローンの借入れ・建物の減価償却が要る。
- 資産の多い世帯では、土地に賃貸物件を建てる場合と建てない場合の比較（手残りと相続税の差）がよく求められる。プランを分けて比較できるよう、予定を1つの物件の欄で表せるようにする。相続税の計算（貸家・貸家建付地の減額など）は別の回で作るので、この回は評価の材料（建物の固定資産税評価額と、貸している割合）を読める形にする。

## 決定

### 1. 欄（`accounts[].property.planned`）

| 欄 | 意味 |
|---|---|
| `type` | `buy` 土地ごと買う・`build` 持っている土地に建てる |
| `at` | 買う・建物の引き渡しを受ける時点 |
| `parts` | 購入代金・建築費の内訳（`land`・`building`・`equipment`。`build` は土地を読まない）。今の `acquisition.parts` と同じ形 |
| `equipmentLife` | 建物附属設備の耐用年数（省略は法定15年。中古で買うなら簡便法） |
| `costs` | 取得の諸費用（仲介手数料・登記・不動産取得税・設計の費用・ローンの手数料など） |
| `equity` | 自己資金（予定の月に手元のお金から払う額） |
| `assessed` | 建物（設備を含む）の固定資産税評価額（`at` の年の額。値の箱。画面が推定で入れる） |

- 予定のある物件は、持ち始める時点（`holdFrom`）を読まない（予定の時期がその代わり）。減価償却の引き継ぎ（`depreciationCarryover`。0126）も読まない（これから取得する物件に確定申告の数字は無い）。
- ローンは今までどおり負債の型で入れ、`debts[].property` で物件を指す（0028）。借入の月を予定の月にすれば、その月から返済が始まる（返済の部品は変えない）。

### 2. 土地ごと買う（`buy`）

- 予定の月から持つ（持ち始める時点と同じ扱い。年末の評価額はその年から）。評価額（時価）は購入代金の合計を予定の年の額とし、土地の割合は入れた割合 → 代金の土地の割合で分ける。器の時価（`marketValue`）は読まない。土地は土地の評価額の増減率、建物は構造の耐用年数で動かす（0025 の2・0028 の2 のまま）。
- 取得（減価償却・帳簿価額・売ったときの取得費・所有期間）は予定の欄から作る（`property.acquisition` は読まない）。建った年の省略は予定の年（新築）。中古で買うなら建った年を入れ、減価償却は簡便法の年数（0028 の4）。

### 3. 持っている土地に建てる（`build`）

- 器の時価を土地の額とみなす（土地の割合 1。入れた土地の割合・建った年は読まない）。建てる前の年は土地だけ。予定の年の年末から、建築費（建物と建物附属設備）を予定の年の新築の建物として足し、構造の耐用年数で減らす。
- 減価償却の基は建物と建物附属設備の建築費に、取得の諸費用を額の比で分けた分を足した額（0080 の3 と同じ分け方）。新築の法定耐用年数（建物附属設備は15年か入れた年数）。
- `property.acquisition` は土地の取得として読む（売ったときの取得費の土地の分と、所有期間）。土地の取得価額が無ければ（相続した土地など）、売ったときの取得費は、売却価格を評価額の土地と建物の比で分けた土地の分の概算取得費（5%）と、建物の分（建築費＋諸費用−償却の累計）の合計（売却価格の5%のほうが大きければそれ）。所有期間は土地の取得の年月で分け、無ければ長期とみなす。
- 土地の取得のための借入の利息の分（0028 の4）は、建物と建物附属設備の償却の基を超える借入の割合で分ける（今までと同じ式）。

### 4. どちらも

- 予定の月に、自己資金を一時の支出 `cf.expense.lumpSum.realEstatePurchase`（計算式ID `asset.realEstate.purchase`。名義の人・物件の ID）で払う。**自己資金の省略は、代金（建てる予定は建築費）＋取得の諸費用−計算基準月以後に借りるこの物件のローンの借入額**（0円より下げない）。計算基準月より前に借りたローン（今あるローン）は引かない。
- 家賃（貸し始めの省略も予定の月）・経費・大きな修繕・減価償却は予定の月から。貸し始めを予定の月より前にしても、予定の月より前は貸していない（建てる前の土地の貸付けは、同じ物件では入れられない。未確定の1）。
- 予定の月が計算基準月より前なら、支払いは表に載らない（もう払った）。持っている・貸しているのは予定の月から。前の年の不動産所得（住民税・国民健康保険料のため。計算基準年の2年前から）も、予定の月より前は入れない。
- **売る予定が予定の月か、それより前なら、売らない**（知らせ `N_ASSUMED`〔`realEstate.planSaleIgnored`〕。`debt.schedule` も売ったときに返さない。改訂12）。同じ年の後の月に売るなら、買って売る（年末の評価額は無く、支払いと売却の手取りが同じ年に出る。所有期間は短期）。
- 分析の数字（0082）は今の作りのまま、持っている月が表にある年から出るので、予定の年より前は出ない。取得価額の合計は、建てる予定は土地の取得価額（あれば）＋建築費、自己資金は払う額（`facts.acquisition.equity`）。
- 表の行: 画面と提案書の表に、予定のある物件があるときだけ「不動産の取得」の行を出し、「一時的支出（旅行など）」から外す。提案書のライフイベントは「〇〇を取得」「〇〇に建物を建てる」。

### 5. 相続税の評価の材料（任意の出力。評価額〔時価〕・税は変えない）

- **表の評価額の行は時価のまま**（0079 の追記 2026-11-06。購入代金・建築費を時価の基にする。住まいの購入〔0052〕と同じ）。建物の固定資産税評価額は表に出さず、相続税の評価の材料として持つ。
- 予定の欄 `assessed`（建てた・買った年の建物の固定資産税評価額）を、画面が推定で入れる: **建物の価格（建物と建物附属設備）×新築の評価額の割合**（事務所の推定の値 `preset.housing.propertyTax.buildingRatio`。今は40%。0181 の2。経過年数1年の補正率0.80をかけた後の割合）を1万円に丸めた額。推定のままの額は建築費・購入代金に合わせて入れ直し（`refreshEstimates`）、FP が入れた額（評価証明書など）は変えない。
- `asset.realEstate` の出力 `years[].assessed`: 予定の年から、`assessed` を固定資産評価基準の経年減点補正率・再建築費評点補正率で評価替えの年ごとに動かした額（0181 の1 の式。計算エンジンの `sdk` の `assessedBuildingRatio`。画面の `buildingValueRatio` と同じ値になることをテストで照らす）。
- `years[].rentedShare`: 貸している物件の、年末の月に貸している割合（1−空室率。今の実際の家賃収入で入れた物件は 1。年末の月に貸していなければ 0。民泊・宿は出さない）。予定の無い物件にも出す（相続税の貸家・貸家建付地の評価の賃貸割合の近似）。
- `facts.planned`: 予定の形・月・払う自己資金。

### 6. 入力の画面（収益不動産の入力項目）

- 区画の「＋ 建てる・買う予定」: 土地ごと買う予定の物件を足す（時期は今から1年後の目安の印。予定の形を「持っている土地に建てる」に変えられる）。まだ貸していない物件（貸していない土地を「収益不動産へ移す」で移した物件など）には、土地と建物のまとまりに「＋ この土地に建てる予定」。
- まとまり「建てる・買う予定」（標準）: 予定の形・時期・購入代金（土地・建物）か建築費（建物）・取得の諸費用・自己資金（空欄は代金＋諸費用−これから借りるローンの額を薄く見せる）。詳細: 建物附属設備・その耐用年数・建物の固定資産税評価額。まとまりの説明に、控えめに「相続の直前の極端な借入れ・購入で評価を下げると、通達どおりの評価が認められないことがある（令和4年4月19日の最高裁判決）」の一文。
- 土地ごと買う予定の物件は、評価額・評価額の時点・取得の欄を出さない（土地と建物のまとまりは構造と建った年だけ）。建てる予定は、評価額を「今の土地の評価額」、取得を「土地の取得価額」「土地の取得の年月」（詳細）として出す。どちらも持ち始める時点・減価償却の引き継ぎは出さない。
- 「＋ この物件のローン」は、予定の物件では予定の月から借りる形で足す。
- 物件の一覧表（入力から出せる今の数字）: 予定の月が計算基準月より後なら、月の収入は0、土地ごと買う予定の評価額は0。種類の横に「2030年7月に買う予定」などを書く。

### 7. 世帯ファイルの形式

- 任意の欄を足したので、形式の版を `0.85` に上げる（足すだけ。変換の段は版だけを書き換える。前の版の世帯は欄が無い＝予定の無い物件）。

## 理由

- **持ち始める時点とは別の欄にする**: 持ち始める時点は支払いの無い取得で、相続税の目安の「その時点から財産に入る」の読み方も決まっている。支払い・ローン・新築の償却を足すと意味が変わるので、別の欄にした。
- **建てる予定は同じ器に建物を足す**: 土地はもう器として持っていて（評価額・名義・取得）、建てた後も同じ土地の上の物件。別の器にすると土地を二重に数えるか、土地の器を消す必要がある。
- **自己資金の省略を「代金＋諸費用−これから借りるローン」にする**: 住まいの購入（0052）の頭金と同じく、借入れはお金の流れに入れず（ローンは返済だけ）、手元から出る額だけを払う。ローンの額を直すと自己資金も合わせて動く。
- **表の評価額は時価のまま**: バランスシートの評価額は、ほかの物件・住まいと同じ時価で比較する。固定資産税評価額を表に出すと、建てた年に純資産が建築費の6割ほど下がって見え、手残りの比較と混ざる。相続税の評価は別の材料として持ち、相続税の計算の回で使う。
- **建物の固定資産税評価額の式を 0181 と同じにする**: 住まいの固定資産税の目安と同じ割合・同じ補正率で、事務所で見直すときに1か所で済む。計算エンジンには推定の割合を持たせず（画面が値の箱で入れる）、法令の値の補正率だけを持つ。

## 代案（採らなかったもの）

- 持ち始める時点に「買う」印を足す: 相続で受け取る物件の読み方（支払いが無い・相続税の目安の時点）と混ざる。
- 建てる予定を別の器（建物だけの器）にする: 土地と建物の行・取得費・事業的規模の数え方が2つの器に分かれ、売るときに合わせられない。
- 表の評価額を固定資産税評価額にする: 上の理由のとおり。
- 自己資金を必ず入れさせる: 入れ忘れで支払いが0円になる。代金とローンから出せるので省略できるようにした。

## 未確定・未対応（控えめに扱っていること）

1. **建てる前の土地の貸付け**（駐車場・貸している土地）の収入は、同じ物件では入れられない（予定の月より前は貸していない）。入るお金の行で建てる前の年までの額を入れて足す。建て替え（今の建物を壊して建てる）の取り壊しの費用・今の建物の帳簿の残りの経費は扱わない。
2. **所有期間**: 建てた建物を売るときは、土地の取得の年月で長期・短期を分ける（建物の分を短期として分けない）。建物の分の譲渡益は多くないので、土地の分に合わせた。
3. **不動産取得税・登録免許税**は取得の諸費用に含めて入れる（別には計算しない。0081 の未対応のまま）。建物の分は償却の基に足す。
4. **建物の固定資産税評価額**は、相続の時点に評価額が付いていない家屋（建てた年）の扱い（類似の家屋の評価額から・費用現価の7割）を見分けず、建てた年の額をそのまま使う。新築の評価額の割合（40%）は推定の値で、建物の価格に設計・設備の分が多いほど実際は低い（0181 の2）。
5. **相続税の計算**（貸家の評価〔固定資産税評価額×(1−借家権割合×賃貸割合)〕・貸家建付地の減額・小規模宅地等の特例）は、別の回で作る。この回の `assessed`・`rentedShare` はその材料。
6. 建てる予定の物件の固定資産税・都市計画税（経費の費目）は推定しない（今の収益不動産と同じく、経費の欄に入れる）。

## 確かめたいこと

- 自己資金の省略（代金＋諸費用−これから借りるローン）で、実務の資金計画の見方に合うか（つなぎ融資・中間金の支払いの月のずれは入れていない）。
