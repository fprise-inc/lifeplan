# 0096. 保存できていない変更を黙って捨てない（世帯を切り替える・アプリを閉じる前の確かめ）

- 状態: 採用（2026-10-31）
- 固定の強さ: **保存できていない変更が消える操作の前に、FP に選ばせる**（黙って捨てない）ことは骨格。パネルの文言・ボタンの並びは内部（後から変えてよい。変えたら追記に書く）
- 前提にする記録: 0011（世帯ファイル）、0023 の7（分岐）、0024（同期フォルダ）

## 背景

- 世帯の自動保存は、変更から少し待ってまとめて書く。世帯を切り替える・アプリを閉じるときは待たずに書く（flush）。
- 書けなかったとき（読み書きの失敗・鍵が読めない など）も、そのまま次の世帯を開いて、保存できていない変更を捨てていた。アプリを閉じるときも、書けたかどうかを見ずに閉じていた。上の帯の「保存の失敗」の札は出ていたが、切り替える・閉じる操作の前には何も出なかった。
- 直らない失敗（鍵が無い・分岐 など）では自動保存を止めるので、止めた後の「保存していない変更があるか」の目安（`dirty`）は偽になり、変更が残っていることも分からなかった。

## 決定

### 1. 保存できていない変更があるかを、自動保存を止めた後も分かるようにする

- 自動保存（`app/src/workspace/store/autosave.ts`）は、最後に書けた本文と今の本文が違えば「保存できていない」とする（`unsaved`）。直らない失敗で止めた後も同じ。保存しない世帯（見本・閲覧だけ・ほかの人が開いていて止めている間）は、もともと保存しないので数えない。
- 最後の失敗の符号を持つ（`failure`。書けたら・開き直したら消す）。
- 保存し直す（`retry`）は、止めた後でも1回だけ試す。止めた後の変更も入れるため、今の画面の本文を渡して書く。

### 2. 世帯を離れる前に確かめる

- 世帯を切り替える（世帯の一覧から開く・見本を開く・新しい世帯を作る）・アプリを閉じる前に、残りを待たずに書く（`saveBeforeLeave`）。書けたら今までどおり、聞かずに進む。
- 書けなかったら、中央のパネル（`app/src/workspace/store/LeaveDialog.tsx`）で理由を添えて選ばせる:
  - **保存し直す**: もう一度書く。書けたら進む。書けなければ「もう一度保存しましたが、保存できませんでした」と添えて、もう一度選ばせる
  - **変更を捨てて切り替える（閉じる）**: 最後に書けたところまでの内容が残る
  - **やめる**（Esc も同じ）: この世帯を開いたままにする。世帯の一覧から開こうとしていたときは、一覧も開いたまま
- 分岐（ほかの PC・ほかの人が先に保存していた）のときは、保存し直しても同じなので、「保存し直す」の代わりに「分岐を選ぶ」（分岐を選ぶ画面を開き、離れるのはやめる）を出す。
- 中身を消す操作（世帯の完全削除）と、今の画面の中身を新しい世帯として保存する操作は、変更が消えないので確かめない。

### 3. アプリを閉じるとき

- 本体は、閉じる前に画面へ残りを書かせ、済んだら閉じる（`app_close_ready`。待つのは最長4秒）。
- 画面が FP に聞くときは、先に本体へ待つのをやめてもらう（`app_close_cancel`。新しい命令。引数なし）。その回の時間切れでは閉じない。FP が「保存し直す」で書けた・「捨てて閉じる」を選んだら閉じる。「やめる」なら閉じず、次に閉じようとしたときは初めから同じ流れになる。
- 画面が隠れるとき（`pagehide`）は聞けないので、今までどおり書くだけ。

## 他の案

- 失敗したら次の世帯を開かない（聞かずに止める）: 直らない失敗（鍵が無い など）のときに、ほかの世帯へ移れなくなる。捨てる道も要る。
- 書けなかった本文を手元に別に残しておく: 暗号化した世帯ファイルの外に平文を置くことになる（0011・0013）。

## 追記

- 2026-10-31（プランの帯から外すとき）: 外すプランに保存していない変更（結果のタブで動かした値）があるときも、黙って捨てずに同じ形のパネル（`app/src/workspace/ChoicePanel.tsx`。`app/src/workspace/plans/BandDropDialog.tsx`）で選ばせる。今までは、プランの一覧で帯から外すと知らせなしに捨て、帯の「×」は「プランを外しました」とだけ出して変更も捨てていた（どちらも元に戻すで戻せた）。
  - プランの一覧で帯から外す: **上書き保存して外す**（動かした値でプランを上書きしてから外す。プランは一覧に残る）／**変更を捨てて外す**（保存した中身のまま一覧に残る。知らせに「元に戻す」）／**やめる**（帯に残す）
  - 帯の「×」（一覧からも外す。元に戻すで戻せる）: **変更ごと外す**（知らせに「保存していない変更も捨てました」と「元に戻す」）／**やめる**。このプランを元にしたプランがあれば、**上書き保存してから外す**（元にしたプランは上書きした中身を引き継ぐ）も出す
  - 保存していない変更が無いプランは、今までどおり聞かずに外す

- 2026-10-31（世帯を切り替える・アプリを閉じるときの、プランの保存していない変更）: 結果のタブで動かした値（プランの保存していない変更）は世帯ファイルに入らないので、世帯を切り替える・アプリを閉じると黙って消えていた。保存する世帯（保存した世帯で、閲覧だけ・ほかの人が開いていて保存を止めている間・自分で作った見本を見ているだけ、のどれでもない）では、離れる前に同じ形のパネル（`app/src/workspace/plans/DraftsLeaveDialog.tsx`）で選ばせる。
  - **上書き保存して切り替える（閉じる）**: 保存していない変更がある全部のプランを、動かした値で上書きする（元にしたプランから先に。`app/src/workspace/plans/leaveDrafts.ts`）。上書きした本文を、そのまま待たずに保存してから離れる（保存できなければ、上の 2 の確かめが続けて出る）
  - **変更を捨てて切り替える（閉じる）**: プランは保存した中身のまま残る
  - **やめる**（Esc も同じ）: この世帯を開いたままにする。閉じるときは、本体に待つのをやめてもらう（上の 3 と同じ）
  - 保存していない変更が無ければ聞かない。アプリの見本・保存していない世帯は、世帯ごと保存しないので聞かない
