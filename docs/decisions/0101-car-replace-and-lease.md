# 0101. 車の買い替え（買い替え続ける・この1台だけ・○歳まで）・手放す月に買わない・リースと長期レンタル（月額）・次の買い替えの時期は「今から」だけと、世帯ファイルの形式 0.45

- 状態: 採用（一部未確定）（2026-10-31）
- 固定の強さ: 骨格は、車の `purchase.replace`（`{kind: "repeat"}`・`{kind: "none"}`・`{kind: "until", until}`、省略は repeat）と `lease`（`type`・`monthly`・`from`・`termYears`・`includes`）の形と意味、車は `purchase` か `lease` のどちらか1つ、入力項目ID `car.replace`・`car.lease`、計算の式 `expense.car.lease`、SDK の `carPurchaseMonths`。目安の年数（13年・5年・70歳）・欄の並び・標準と詳細・文言は後から変えてよい

## 背景

- 車は「周期ごとに買い替え続ける」形しか無く、2台目・今の車に乗り続ける・ある年齢で買い替えをやめるといった、よくある形を入れられなかった（周期を大きくする・手放す時期を手前にするなどの工夫が要った）。
- 買い替えの月と手放す月が同じとき、その月に買ってから手放していた（`m <= until`）。同じ決まりが計算エンジンの車の部品（お金の動きと評価額）・車の入力項目の一生の費用・この世帯の予定・提案書の出来事の5か所に写してあった。
- リース・長期レンタルは、車両の価格を0円にして月額を出るお金の行で入れる工夫だけだった（0069 の残したもの）。月額に含む税・車検・保険を維持費から外す所も無かった。
- 「次の買い替えの時期」「購入の時期」は4つの入れ方のどれでも入れられ、年齢で入れると名義の人の年齢と周期の関係が読みにくかった。
- 「手放した後の移動の費用を足す」は名義の人ごとの最後の車に出ていて、ほかの人の車がまだあるのに足せた。
- 前提にする記録: 0008（車のひな形）、0038（時点の部品）、0041（値の状態）、0069（車の入力項目）、0077（足した物1件を1つの枠に。2026-10-31 の追記）、0078（標準の欄）。

## 決定

### 1. 買い替え（車ごと。名義のすぐ下、標準）

| 選び方 | 形 | 計算 | 出さない欄（値は残す） |
|---|---|---|---|
| 買い替え続ける（○年ごと） | 省略（`{kind: "repeat"}` も同じ） | 前のとおり周期ごと | — |
| この1台だけ（買い替えない）／今の車に乗り続ける（買い替えない） | `{kind: "none"}` | これから買う車は1回だけ買う。今の車は買わずに乗り続ける | 周期・下取り。今の車はさらに次の買い替えの時期・価格・買い方（手放す時期を買い替えのすぐ下に出す） |
| ○歳まで買い替える | `{kind: "until", until}` | until の月まで買い替え、その後は手放す時期まで最後の車に乗る | — |

- どの車も「買い替え続ける」で始める（2台目からも）。2台目からの「?」に「2台目は、買い替えずにこの1台だけのことも多いです」と添える。
- 「○歳まで買い替える」は詳細だけで選べる（標準の選び方は2つ）。その形の車は標準でも3つ目を出し、年齢の欄「買い替える年齢（○歳まで）」も標準で出す。年齢は働く最後の「○歳まで」と同じ読み方（その年齢になる前の月まで。`memberAge` で、70歳までは `{years: 69, months: 11}`）。選んだときは70歳まで（推定）。手放す時期より後の年齢なら「手放す時期より後の年齢なので、『買い替え続ける』と同じです」と知らせる。
- **この1台だけで手放す時期が空**のときは、目安を推定で入れる（値の状態の行 `car.until`）:
  - これから買う車: 買ってから **13年**。出来事「車の購入」からのずらし（`{event, offset: {years: 13}}`）で持ち、購入の時期を動かすと一緒に動く（0038）。根拠は一般財団法人 自動車検査登録情報協会の「平均使用年数」（令和7年3月末現在。乗用車〔軽自動車を除く〕13.35年。https://www.airia.or.jp/publish/file/shiyounensuu_2025.pdf 。原本の PDF で確かめた、2026-10-31）を年に丸めた値。
  - 今の車: **今から5年**（標準の値）。
  - 手放す時期を空にすると目安に戻る。買い替える形に戻したとき、推定のままの手放す時期は外す（最後まで）。FP が入れた手放す時期は残す。
  - 目安の年数は、マスタデータ（`data/master/`）の値の形が年を整数でしか持てない（13.35年を持てない）ので、ほかの車の目安と同じく `hearing/src/estimates.ts` の `CAR_ESTIMATE`（`keepYears`・`keepYearsOwned`）に根拠の文と出典を書いて置いた。推定の目安の見直しの一覧ができたら、そこにも載せる。

### 2. 手放す月には買わない（SDK の `carPurchaseMonths`）

- 購入の月は、手放す月より前の月だけにした（`m < until`）。決まりは SDK の純粋な関数 `carPurchaseMonths`（`engine/src/sdk/cars.ts`）1つにし、計算エンジンの車の部品（`expense.car`・`asset.car`）・車の入力項目の一生の費用（`lifetimeCost`）・この世帯の予定（`schedule.ts`）・提案書の出来事（`report/src/build.ts`）がどれもこれを呼ぶ（画面は `app/src/workspace/input/carPurchases.ts` で年月を解いて呼ぶ）。
- 買い替えの決まり（repeat・none・until）も同じ関数が持つ。

### 3. リース・長期レンタル（月額。部品 `expense.car` の改訂4）

- 車の入力項目の「＋ カーシェア・レンタカー」をやめ、車を足すボタンの並びに「**＋ リース・長期レンタル（月額）**」を置いた。ときどき使うカーシェア・レンタカーは、基本生活費の「交通費」で入れる（交通費の説明に前から書いてある）。
- 車に `lease`（任意）: 種類 `type`（`carLease` カーリース／`longRental` 長期レンタル）・月額 `monthly`・借り始め `from`（省略はもう借りている）・契約の年数 `termYears`（表示だけ。詳細）・月額に含む物 `includes`（`taxAndCompulsory` 税・自賠責、`inspectionMaintenance` 車検・メンテ、`insurance` 保険。省略は種類の既定）。リースの車は `purchase` を持たない（スキーマで `purchase` か `lease` のどちらか1つ）。
- 月額に含む物の既定: カーリースは税・自賠責と車検・メンテを含み、保険は含まない。長期レンタルは全部含む。
- 計算（式 `expense.car.lease`）:
  - 月額を借り始め（省略は計算基準月）から手放す時期まで毎月、表の行「車の維持費」（`cf.expense.living.car`）に出す。契約の年数が終わっても精算せず、同じ月額で続ける。月額は物価で伸ばさない（契約の額）。
  - 購入・ローン・下取り・評価額は無い。
  - 月額に含む物は内訳から数えない（税→自動車税、車検・メンテ→車検、保険→自動車保険）。値は世帯に残し、内訳の欄も出さない。この入力項目では自賠責保険は車検の額の中に入れているので、「税・自賠責」の「?」にそう書いた。
  - 合計で入れる車の維持費の目安は、月額に含む物の目安を引いた額（カーリース 27.4万円、長期レンタル 20.4万円）。推定のままなら、種類・含む物を直したときに入れ直す。合計の欄の「?」は「月額に含まれない分（駐車場・燃料など）を入れます」。
  - 万一のときの扱い・手放す時期・手放した後の移動の費用・続きの車（同じ月額のリースを手放した翌月から）は、ほかの車と同じ。
- 月額の目安は入れない。足したときは0円で、値の状態の行に「未入力（リース・長期レンタルの月額を入れてください。0円で計算中）」（確かめの一覧の未入力）。

### 4. 時点の入れ方

- 「次の買い替えの時期」とこれから買う車の「購入の時期」は「今から○年後」だけで入れる（`modes: ["now"]`）。時点の部品に `strictModes` を足した（使える入れ方だけで見せる）:
  - 年齢で入っている前の値は、同じ月の「今から」で見せ、「年齢（○歳）で入っています。直すと『今から』の形で入れ直します」と1行添える。直すと今からの形（年月）で書く。
  - この車の購入の出来事を指しているときは、出来事の時点を見せて直す（出来事が動き、指している物も動く）。出来事の名前は、出来事から選べない欄でも出す。
  - ほかの出来事から決めた値は、今からで見せて「出来事（…）から決めた時点です。直すと『今から』の形にし、出来事から切り離します」と添える。直すと年月にする。
  - 過ぎた時点（今からで言えない月）は年月のまま見せ、「過ぎた時点（…）が入っています。『今から○年後』で入れ直してください」と知らせる。
- **続きの車**（ほかの車を手放した翌月が購入の時期の車）の購入の時期は読むだけにした: 「車1を手放した翌月（今から12年後）」、説明「車1の手放す時期で直します」。

### 5. 手放した後の移動の費用

- 「＋ 手放した後の移動の費用を足す」は、**世帯が最後に手放す車**（どの車も手放す時期が入っていて、手放す月がいちばん後の車）にだけ出す（名義の人ごとの最後の車ではない）。車の枠の中のまとまり（キー `ev/car/<ID>/afterCar`）で、見出しは「この後、世帯に車がありません」。
- 手放す時期の「?」に、運転免許の更新で認知機能の検査が始まる75歳ごろを目安にする FP も多いことを書いた。既定は今までどおり「最後まで」。

### 6. 評価額（部品 `asset.car` の改訂3）

- 購入の月は `carPurchaseMonths`（手放す月には買わない・買い替えの決まり）。
- この1台だけの車と、○歳まで買い替える車の最後に買った車は、買った月から手放す月に0になるように定額で下げる（手放す時期が無ければ前のとおり周期で下取りの額まで）。今の車に乗り続けるときは、次の買い替えの周期の前に買ったとみなして同じように下げる。
- リース・長期レンタルの車は評価額を持たない。

### 7. 世帯ファイルの形式 0.45

- 足すだけの MINOR。0.44 → 0.45 の変換の段は形式の版だけを書き換える（買い替えの無い車は買い替え続ける）。0.44 のアプリは知らない欄を読み落として書き戻し、リースの車（`purchase` が無い）を読めないので、版を上げて閲覧だけにする。
- 見本 `crates/household-store/tests/fixtures/household-format/0.45/`（0.44 の見本に、今の車に乗り続ける車〔手放す時期は今から5年の推定〕・この1台だけのこれから買う車〔手放す時期は出来事「車の購入」から13年後の推定〕・70歳まで買い替える車・長期レンタルの車〔月額・借り始め・契約の年数・月額に含む物〕を足したもの）。
- 入力項目ID `car.replace`（`purchase.replace`。`car.purchase` の中の欄なので、部品は `car.purchase` を読めば入る）・`car.lease`。AI接続口の縮約版の許可リストに入れ、版を `reduced@24` にした（決まった形の値と数。文章の項目ではない）。
- 画面の欄のキーは `ev/car/<ID>/…`（買い替えは `replace`・`replaceAll`・`replaceUntil`、リースは `ev/car/<ID>/lease/…`）。足した物1件を1つの枠に描く決まり（0077 の 2026-10-31 の追記）で、車の枠の中に並ぶ。

## 残したもの

- **手放すときの売却額**（次の候補）: 手放す月に売却額（評価額か下取りの目安）を入金にする計算はまだ無い。この1台だけの車は手放す月に評価額が0になるので、売却額を入れるときは評価額の下げ方も合わせて決める。
- 残価設定ローン（最後の回の額・返す／買い取る）、リースの途中でやめるときの額・契約の終わりの精算。
- 車の種類（軽・普通・大きい車・電気自動車）ごとの目安。平均使用年数の 13.35年は軽自動車を除く乗用車の値で、軽自動車の値は同じ資料に無い。
- 推定の目安の見直しの一覧（別の変更で足す予定）に、平均使用年数（13年）・今の車の5年・70歳までを載せる。

## 見本の世帯の結果

- 架空のモデル世帯（`data/modelHouseholds/`）の結果は変わらない（車を持つ2世帯〔`dualAssetsTwoKids`・`unexplainedSpending`〕は、買い替えの月と手放す月が重ならない）。全51世帯の年ごとの表と年の合計を、前の版と比べて確かめた。
- 変わるのは、買い替えの月と手放す月が同じ月の車だけ（その月の購入・ローン・下取りが無くなり、評価額もその月の買い替えが無くなる）。
