# 0174. 扶養・第3号の判定の月（その月の収入の状況で見る・第3号は扶養の月だけ）と、住民税の非課税のひとり親・寡婦

- 状態: 採用（一部未確定）（2026-11-08）
- 固定の強さ: 内部（部品の計算の決まり）。世帯ファイルの形式の版・エンジンの入力・部品の約束の版は変えない。sdk に関数 `deriveHealthStatus`・`currentOutlook` と値の一覧 `HEALTH_STATUS_PARAMS`・`HEALTH_STATUS_READS` を足した（試験版）。制度データ `regulation.tax` に値を1つ足した（2026.19.0。原本と2つの読み方で照らし合わせ済み）
- 前提にする記録: 0003（月が最小単位・表の外の月の追記）、0006（部品の依存は循環しない）、0007（制度データ）、0008（4 の健康保険の種類と国民年金の種別を導く・追記 2026-10-25 の1 の扶養）、0037（雇用保険の給付と扶養）、0156（婚姻の状態とひとり親・寡婦）、0169（未確定の住民税の非課税のひとり親・寡婦）、0171（任意継続の家族・亡くなる前の扶養の見込み）

## 背景

1. 被扶養者・第3号の判定の「その月からの1年の収入の見込み」（0008 の追記 2026-10-25 の1）は、その月から12か月に払われる給与・事業所得・年金を足していた。そのため、まだ始まっていない仕事や年金を先に数え、決まっている退職の後の月を数えなかった。妻が 2029-04 から年200万円で働く世帯では、収入の無い 2028-12〜2029-03 の4か月が国民健康保険・第1号になり、年200万円のパートを 2029-03 に辞める妻は、働いている 2028-09 から第3号になっていた。実際の認定は、その時の収入の状況（今の給与の月額×12 など）で見て、働き始めた月から扶養を外れ、辞めた翌月から入る。
2. 健康保険の種類（`socialInsurance.healthStatus`）と国民年金の種別（`pension.category`）は、別々に見込みを数えていた。種別の部品は期間に書いた健康保険の種類（国民健康保険など）を見ないので、国民健康保険に入っている月に第3号になることがあった（第3号は被扶養配偶者が要件で、国民健康保険に入っている人は第3号でない）。
3. 住民税の非課税の判定（`residentTax.exemption`）に、前の年の合計所得金額が135万円以下の寡婦・ひとり親を非課税にする決まり（地方税法295条1項2号・24条の5第1項2号）が無かった（0169 の未確定）。

利用者の判断（2026-11-08）: 1 は見込みを「その月の収入の状況が続くとしたら」で見る、2 は第3号を健康保険の種類が扶養の月だけにする。どちらも実際の認定に合わせる。

## 決定

### 1. 収入の見込みは、その月の収入の状況が続くとしたらの年額（`socialInsurance.healthStatus` 改訂9・`pension.category` 改訂6。sdk の `currentOutlook`）

- 0008 の追記 2026-10-25 の1 の「その月からの1年の見込み」を改める。見込みは、その月の収入の状況がその先も続くとしたらの年額:
  - 給与（賞与・通勤手当を含む）と事業所得は、その月に続いている働き方の期間ごとに、その月からの12か月の額。期間の最後の月より後の月は、その1年前の月とみなす（その仕事が続くとしたら。賞与も1年分入る）。1年前の月が期間の始まりより前なら、その月の賞与を除く額とみなす。
  - その月にまだ始まっていない期間・もう終わった期間は数えない。働き始めた月から見込みに入り（扶養を外れる）、辞めた翌月から外れる（扶養に入る）。
  - 公的年金（老齢・遺族・障害）は、その月の年額（部品の出力の月ごとの年額）。受け始めた月から見込みに入る。障害年金を受ける人の基準（180万円）は、その月に障害年金を受ける人に使う。
- 表の外の月は、期間の最後の月より後の月として同じく1年前の月とみなす（0003 の追記の決まりは保たれる。表の長さで判定を変えない）。
- 0171 の8（亡くなる前の扶養の見込みに、亡くなった後の月を入れない）は、先の月の年金を数えなくなったので、そのための決まり（亡くなる月から先を1年前の月とみなす）は要らなくなった。亡くなる前の月は、遺族年金をまだ受けていないので見込みに入らず、亡くなる人の給与は期間が亡くなる月で終わるので、続くとしたらの額になる（同じ結果。0171 のテストで確かめる）。

### 2. 第3号は、健康保険の種類が第2号の配偶者の扶養の月だけ（`pension.category` 改訂6。sdk の `deriveHealthStatus`）

- 第3号は、20〜59歳で、その月の健康保険の種類が扶養（`dependent`）で、扶養する人がその月に第2号の配偶者のときだけ。健康保険の種類は `socialInsurance.healthStatus` と同じ決まりで導く（中身を sdk の `deriveHealthStatus` に移し、両方の部品が呼ぶ）。
- 期間に国民健康保険・任意継続などと書いた月、扶養の判定に通らない月、扶養する人が配偶者でない（子の扶養など）月は第1号。
- 期間に扶養（`healthInsurance.kind: dependent`。FP の上書きで、扶養する人は書かない）と書いた月は、配偶者が第2号なら第3号。今までは種別の部品だけが収入の基準を見ていたので、扶養と書いたパートの給与が賃金の伸びで130万円を超えると、健康保険は扶養のまま国民年金は第1号になっていた。上書きを両方に当ててそろえる。
- **種別の部品は、見込みに公的年金を入れない**。年金の額は加入の記録から出し、加入の記録は国民年金の種別から出すので、種別の部品は年金の部品を呼べない（部品の依存は循環しない。0006）。そのため、障害年金・遺族年金を受ける20〜59歳の配偶者と、特別支給・繰上げの老齢年金を受ける60〜64歳の第2号の配偶者（2分の1の決まりの扶養する人の収入）では、健康保険の種類と種別が食い違うことがある（未確定）。

### 3. 住民税の非課税の寡婦・ひとり親（`residentTax.exemption` 改訂6）

- 前の年の合計所得金額が135万円以下（制度の値 `residentTax.exemption.personal.incomeLimit`）の寡婦・ひとり親には、住民税の均等割・所得割をかけない（地方税法295条1項2号・24条の5第1項2号。分離課税に係る所得割〔退職所得〕は除くので、その分はそのまま）。
- 寡婦・ひとり親は `tax.survivorStatus`（所得税の寡婦控除・ひとり親控除と同じ決まり。婚姻の状態は `maritalStatus` と世帯の関係の終わり方。前の年の12月31日の現況）で判定する。地方税法292条1項11号・12号の要件（合計所得金額500万円以下・生計を一にする子など）は所得税と同じ。
- 合計所得金額は、総所得金額等（`tax.totalIncome` の `total`）に分離課税の譲渡所得（`separate`）を足した額。退職所得は現年分離課税なので入れない。
- 同じ号の障害者・未成年者は扱わない（障害者の区分の入力が無い。未成年者に収入がある形はまれ）。
- 値は e-Gov の地方税法の条文（令和8年10月1日の版）と江戸川区の説明の2つで照らし合わせ、施行日は今の文言（ひとり親と135万円）が最初に現れた e-Gov の版の2021-01-01（`reviewed`）。

### 4. 部品の版

- `socialInsurance.healthStatus` 改訂9、`pension.category` 改訂6（読む項目に構成員の世帯の外・加わる月・扶養の欄、働き方の期間の健康保険の種類、お金の行の仕送りを足し、`memberScope` に働き方の期間。読む制度の値に扶養の基準を足した）、`residentTax.exemption` 改訂6（`tax.survivorStatus` を呼ぶ）。約束の版は変えない。

## 理由

- 被扶養者の認定の「今後1年間の収入の見込み」は、実際には今の収入の状況（月額×12、年金の年額）で見られ、働き始めた・辞めた・受け始めた月で切り替わる。先の1年に払われる額で見ると、まだ決まっていない仕事・年金で何か月も先に扶養を外れ、結果がその月の現実と合わない。
- 第3号の認定は被扶養者の認定と同じ基準で行われ、国民健康保険に入っている人は第3号にならない。健康保険と国民年金の判定を1つの関数にすれば、同じ月に食い違わない（年金の収入の分を除く）。
- 種別の部品から年金の部品を呼ぶには、部品の分け方（加入の記録の作り方）を変える必要がある。年金の収入が当たる形（障害年金を受ける配偶者・60〜64歳で年金を受ける会社員の配偶者）はまれなので、今回は近似にとどめる。
- 住民税の非課税の寡婦・ひとり親は、所得税の寡婦控除・ひとり親控除と要件が同じなので、同じ判定の部品を使う（判定を2つ持たない）。

## 影響

- 計算の結果が変わる（見本の世帯。直す前と後の全期間の合計）:
  - `educationTwoKids`: 扶養と書いたパートの妻（年120万円から賃金の伸び）が、2034-02〜2042-08 も第3号になる（今までは見込みが130万円を超えて第1号）。国民年金保険料 約209.4万円が減り、社会保険料控除が減る分、住民税が 約17.3万円増える。
  - `sampleParentsCare`: 同じく扶養と書いたパートの妻が 2034-02〜08 も第3号。国民年金保険料 約13.7万円が減り、住民税が 約1.3万円増える。
  - `housingPurchase`・`housingGiftFromParents`: 本人が 2059-05 に辞め、年金を受け始める前の 2059-06 の1か月が、会社員の配偶者の扶養になる（今までは先の年金を数えて国民健康保険）。国民健康保険料 約7.3万円が減り、所得税・住民税が 約1.2万円増える。
  - `lifetime100`・`lifetime100Assets`・`lifetime100Plan`: 同じく 2061-05 の1か月が扶養になる。国民健康保険料 約5.6万円が減り、所得税・住民税が 約0.7万円増える。
  - `incapacityDisability`: 障害年金を受け始める 2029-08 の1か月が国民健康保険になる（今までは最初の支払いの月の前なので扶養）。国民健康保険料 約1,500円が増える。
  - 住民税の非課税の寡婦・ひとり親は、見本の世帯に当たる形が無く変わらない（`sampleSingleParent` は合計所得金額が135万円を超える。テストの世帯で確かめた）。
- 働き始める・辞める予定を入れた世帯では、扶養・第3号の切り替わりの月が、その月の収入の状況で決まる（働き始めた月・辞めた翌月）。今までの「先の1年の見込み」で最大11か月ずれていた国民健康保険料・国民年金保険料が動く。
- 世帯ファイルの形式の版・エンジンの入力・画面は変えない。

## 未確定

- 種別の部品の見込みに公的年金を入れない近似（2 の太字）。障害年金・遺族年金を受ける20〜59歳の配偶者、特別支給・繰上げの老齢年金を受ける60〜64歳の第2号の配偶者で、健康保険の種類と種別が食い違うことがある。直すには、国民年金の種別のうち第1号と第3号の分け方を、年金の額を出した後の部品に移す（加入の記録は第1号・第3号を分けずに作る）必要がある。
- 自分が任意継続に入っている月も第3号にしない（利用者の判断の2 のとおり）。法令では、第3号は第2号の被扶養配偶者であることが要件で、自分の健康保険の種類は要件にしていないので、任意継続を選んだ収入の少ない配偶者は第3号になりうる。利用者に確かめる。
- 見込みの「その月の収入の状況」は、その月に払われる給与・事業所得の額で見る。その月に入れた期間が休業（育児休業など）で給与が0なら、続くとしたらの額も休業の後の月の額になる（自分の勤め先の健康保険に入っている月がほとんどなので、扶養の判定には当たりにくい）。
- 住民税の非課税の判定のうち、障害者・未成年者（295条1項2号の残り）と、均等割の非課税の基準（同条3項）の合計所得金額に分離課税の譲渡所得を足すか（今は総所得金額等だけ）は、扱っていない。寡婦・ひとり親の判定の時点は、賦課期日（1月1日）でなく前の年の12月31日の近似。
