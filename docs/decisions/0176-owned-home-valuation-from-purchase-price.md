# 0176. 今住んでいる持ち家を買った値段から推計する（標準では評価額を聞かない・土地は割合でなく金額で・詳細の欄を中枠に分ける・固定資産税の目安の根拠・今の時価の「?」）

- 状態: 採用（一部未確定）（2026-11-08。2026-11-09 にヒアリングで聞く問いを足した）
- 固定の強さ: 内部（画面の欄の出し方・並び・言葉・推定の印。世帯ファイルの形式の版・計算エンジン・書く値の形は変えない。土地の値段は今までの `residences[].valuation.landShare` に、買った年月は `valuation.asOf` に書く）
- 前提にする記録: 0025（持ち家の評価）、0041（推定と未入力の数え方）、0078（標準と詳細の分け方）、0112（固定資産税の推定）、0115（注文住宅の土地の代金）、0136（11. 評価の入れ方 `valuation.basis`）、0144（1. 未入力の警告の欄を入るまで標準に出す）

## 背景

利用者が開発中のアプリで持ち家の入力項目を触り、次の判断を出した（2026-11-08）。

1. 「＋ 持ち家（今住んでいる）」の標準に「持ち家の評価」の評価額（未入力の赤い印。0144 の1）が出る。標準では評価額はいらず、推計するべき。「評価額・固定資産税などを入れる」を開くと欄が出すぎて分かりにくい。
2. 今住んでいる家の土地は、割合でなく買った値段で把握している人が大半。土地と建物の値段、全体と土地の値段のどちらでも答えられる形が望ましい。
3. 住宅をこれから買う場合も、土地は割合でなく「土地をいくらで買うか」の金額で入れるのが自然。
4. 固定資産税は、入った物から自動で計算するほうがよいのでは（難しければ今のままで十分）。
5. 評価の入れ方を「今の時価で」にしたとき、先の年でどう減っていくのかが分からない。評価額の「?」に説明を入れる。

購入の予定の評価（物件の価格を購入の月の額にし、土地は上昇率、建物は耐用年数で減らす）は、利用者が「とても良い」としている。

## 決定

### 1. 今住んでいる持ち家の標準の欄（`stages/housing.ts` の `ownedPriceFields`・`ownedHomeValue.ts`）

- 今住んでいる持ち家（購入の予定でも、住み始めが計算の基準の月より後の相続する家でもない家）で、評価の入れ方が「買った値段で」（入れていなければ、評価額が無いか、その額の時点が計算の基準の月より前。下の3）のとき、標準に次の欄を出す。評価額の欄は標準に出さない。
  - **買った年月（住み始め）**: 住み始めの欄の名前を変えて標準に出す（住まいが1つでも）。
  - **買った値段（土地と建物の合計）**: `valuation.value`（その額の時点の額）。入れないと未入力の警告（今の家が資産に入らないため。0144 の1 の決まりのまま）。欄の下に「2026年の評価額の目安（推定）: 約…（土地…・建物…）」。
  - **うち土地の値段**・**うち建物の値段**: 世帯ファイルには土地の割合（土地÷合計）で書く。空欄なら目安の割合（前提条件の土地の割合・既定30%）で分け、欄の下に「空欄なら合計の30%（約…万円）で計算します」。
- 推計は購入の予定と同じ計算エンジンの `housing.valuation`: 買った値段を買った年月の額として土地と建物に分け、土地は前提条件の上昇率（入れていなければ物価上昇率）で毎年動かし、建物は構造の耐用年数で定額に減らす（新築の値の20%で止める）。建った年が空欄なら買った年の新築とみなす（中古で買ったなら詳細の「建物が建った年」）。
- 評価額は欄に書かない推定（欄の下の読みと、中枠の見出しの横の1行に「推定」と出す）。今の時価が分かるときは、詳細で評価の入れ方を「今の時価で」にして評価額を入れる。

### 2. 土地と建物の値段の入れ方（どの組み合わせでも答えられる）

- 合計と土地: 土地を直すと、合計はそのまま（建物＝合計−土地）。
- 土地と建物: 合計がまだ無いときに土地を入れると合計＝土地（割合 1）。続けて建物を入れると合計＝土地＋建物。
- 建物から先に入れたとき: 合計＝建物・土地0（割合 0）。続けて土地を入れると合計＝土地＋建物（土地が0のとき・合計より大きい土地を入れたときは、建物をそのままにする）。
- 合計と建物: 土地を入れていなければ、土地＝合計−建物。土地を入れていれば合計＝土地＋建物。
- 合計を直したときは、土地と建物を同じ割合のままにする。片方だけ入れていた（割合が 1 か 0 の）ときは、入れた方の額のまま。
- 土地・建物の欄を空にすると目安の割合に戻す（片方だけで入れた合計なら合計も外し、足す前の形に戻す）。
- 割合の文字は、合計×割合の円未満を切り捨てる計算エンジンで入れた土地の値段がそのまま出るように、小数12桁で切り上げて作る（`shareOfLand`。例: 1,234万円÷3,456万円）。
- 今住んでいる家で割合を入れる欄は出さない（買った値段で入れる家）。今の時価で入れる家だけ「土地の割合」（建った年からの目安。0136 の11）を詳細に残す（今の時価は土地の分が分からないことが多く、建物が古くなった分だけ土地の割合が大きくなる目安が自然なため）。

### 3. 買った年月と評価の時点（`valuation.asOf`）

- 買った値段を入れたとき、評価の入れ方を「買った値段で」（`basis: purchase`）にし、その額の時点を住み始め（計算の基準の月より後なら計算の基準の月）にして、値の状態の行 `residence.valuation/asOf` に推定の印「住み始めと同じ（買った年月）」を付ける。
- 印のある時点は住み始めについてくる: 住み始めの欄を直したとき（欄の書き込みの後）と、推定の入れ直し（`refreshEstimates` の `refreshOwnedHomeAsOf`。住宅ローンの「借りた年月（入居の年月）」で住み始めが動いたとき。0136 の10）。今の時価にすると印を外す。
- 入れ方を書いていない前の版の世帯（その額の時点が前の月）は書き足さない。住み始めを直したとき、時点が前の住み始めと同じだった物だけを新しい住み始め（計算の基準の月より前のとき）に動かす。
- 評価の入れ方の省略の読み方を変える: 評価額が無い家は「買った値段で」（前は今の時価）。評価額があって時点が今か空（前の版の標準の「評価額」）なら今の時価のまま。計算エンジンは `basis` を読まないので、保存済みの世帯の結果は変わらない。
- 買った値段の時点の欄（「その額の時点」）は、買った値段で入れる家には出さない（住み始めについてくる）。今の時価で入れた家で、時点が今月でない前の版の世帯だけ出す。

### 4. 詳細の欄を中枠に分ける（「固定資産税・名義などを入れる」）

- 「▸」の文を「固定資産税・名義などを入れる」に（今住んでいる持ち家）。
- 標準の欄（住まい・買った年月・住み終わり〔住み替えのとき〕・買った値段・修繕の費用）の後に、中枠を3つ並べる（「▸」で開く。物の頭の詳細の欄は無くし、開いた欄が中枠ごとにまとまる）。
- 中枠「建て方・名義など」（見出しの横の1行「マンションか戸建て・住み終わり・修繕の費用の変わり方・家の名義と持分」）: 建て方・住み終わり（住まいが1つのとき）・修繕の伸び率と変化・名義と持分（持分の無い人がいて標準に出るときは物の頭のまま）。
- 中枠「固定資産税・都市計画税」（見出しの横の1行「納税通知書の額。入れなければ持ち家の評価の元から目安（推定）」）: 固定資産税・都市計画税、その伸び率、推定の段（固定資産税の変化）。
- 中枠「持ち家の評価」（見出しの横の1行「資産・相続税の目安に使う家の値段。標準の買った値段から推計（2026年 約…）」）: 評価の入れ方（買った値段で／今の時価で。買った値段を先に）、建物の構造、建物が建った年。今の時価で入れる家だけ、評価額・土地の割合（と前の版の時点）を足す。
- 購入の予定の住宅の購入の詳細は今のまま（土地の値段だけ 5）。相続する家（これから持ち始める家）は今のまま（評価額は相続の見込みの額）。

### 5. 住宅購入の予定の土地は金額で（`purchaseLandField`）

- 住宅の購入の詳細に「うち土地の値段」（物件の価格のうち土地をいくらで買うか）。世帯ファイルには土地の割合（土地÷物件の価格）で書く（2 と同じ12桁の切り上げ）。持ち家の評価の「土地の割合」の欄は、購入の予定には出さない（注文住宅は前からの「土地の代金」。0115）。
- 空欄は目安の割合（「空欄なら物件の価格の30%（約…万円）で計算します」）。物件の価格を直すと同じ割合のまま。土地の値段を直すと、推定のままの固定資産税を入れ直す。

### 6. 固定資産税の自動の目安（0112 の推定を、買った値段から動かす）

固定資産税の自動の計算は、0112（購入の予定）と 0112 の追記 2026-11-03（今住んでいる持ち家）で作ってある。前は評価額（詳細）を入れるまで目安のボタンの値（年12万円）のままだったので、標準で買った値段・買った年月を入れたときから推定に変える（買った値段・土地と建物の値段・買った年月を入れると、未入力か目安のボタンの値か推定のままの固定資産税に推定を入れる）。FP が納税通知書の額を入れれば、その額を使う（今までどおり）。

式（今までどおり）: 土地の評価額＝土地の価格×7割、建物の評価額＝建物の価格×6割（事務所の推定の値）。税＝土地×1/6×1.4%＋土地×1/3×都市計画税率＋建物×1.4%（新築の軽減の間は×1/2）＋建物×都市計画税率。建物は3年ごとの評価替えで古くなった分を下げる（木造・軽量鉄骨30年・ほか60年で下限20%）。

公式の資料で確かめた値（2026-11-08）:

- 固定資産税の標準税率 1.4%、評価替えは3年ごと（総務省「固定資産税」の制度の概要。地方税法 第350条・第341条第6号）。
- 住宅用地の特例: 小規模住宅用地（200㎡以下の部分）は固定資産税の課税標準が評価額の1/6、一般住宅用地は1/3（総務省。地方税法 第349条の3の2）。都市計画税は小規模1/3・一般2/3（東京都主税局「固定資産税・都市計画税（土地・家屋）」。地方税法 第702条の3）。
- 都市計画税の税率は0.3%（東京都主税局。23区。制限税率。地方税法 第702条の4）。かからない市区町村は事務所の推定の値で0にする。
- 新築住宅の減額: 居住部分120㎡相当分までの固定資産税を1/2、3年度分（3階建以上の耐火・準耐火建築物は5年度分）、認定長期優良住宅は5年度分（3階建以上の耐火・準耐火は7年度分）（総務省・東京都主税局。地方税法 附則第15条の6・第15条の7）。推定ではマンションを3階建以上の耐火とみなす。

近似のまま残す所: 土地の評価額の割合（価格の7割）・建物の評価額の割合（6割）・建物の下がり方は統計の出典の無い目安（0112 のまま）。土地の評価額は買った年の価格のまま（負担調整・評価替えの土地の上下を入れない）。200㎡を超える住宅用地・120㎡を超える床面積・都市計画区域の外は入れない。

### 7. 今の時価の評価額の「?」（`MARKET_VALUE_HELP`）

今の時価で入れる評価額の「?」に、先の年の動き方を書く: 建物は建った年から構造の耐用年数（木造22年・軽量鉄骨19年・重量鉄骨34年・鉄筋コンクリート47年）で毎年同じ額ずつ下げ、新築のときの値の20%で止める（今の額は建った年から今までに下がった後の値として読む）。土地は前提条件の「土地の上昇率（年）」で毎年増減（入れていなければ物価上昇率）。例: 2016年に建った木造・今の時価3,500万円（土地の割合50%）なら、建物1,750万円は毎年約146万円ずつ下がり2034年（築18年）に約640万円で止まる。土地1,750万円は年1%なら10年後に約1,930万円（例の建物の数字は計算エンジンの結果と合うことをテストで確かめる）。

## 理由

- 購入の予定と同じ推計にそろえると、FP が分かる数字（売買契約書の値段と時期）だけで、今と先の年の評価額が出る。今の時価の査定を取る FP は少なく、標準で評価額を聞くと、0円か根拠の無い額のどちらかになりやすかった。
- 形式の版を上げずに済む: 土地の値段は割合、買った年月は評価の時点、入れ方は 0136 の `basis` で書ける。割合を12桁で切り上げれば、入れた土地の値段が円まで出る。
- 合計を直したときに割合を保つのは、プランで合計を動かしたときと欄に書いたときの中身を同じにするため（動かす項目の当て方の決まり。0036）。片方だけで入れた途中（割合 1・0）は、先に入れた額を残すほうが自然。
- 中枠に見出しと1行の説明を付けると、開いた欄が何のための物か分かる。標準でしか入れない FP が要らない欄（その額の時点・土地の割合・今の時価の評価額）は、買った値段で入れる家には出さない。

## 影響（計算の結果が変わる所）

- 保存済みの世帯・見本の棚・モデル世帯: 世帯ファイルの値は変わらないので、結果は変わらない（計算エンジンは `basis` を読まない。印の無い時点は動かさない）。
- これから標準の欄だけで持ち家を入れる世帯: 前は評価額を入れないと持ち家が0円（未入力の警告）だった所に、買った値段からの評価額が入る。例: 2015年4月に4,000万円（うち土地1,500万円）で買った木造の家は、2026年に約2,924万円（建物1,250万円〔築11年で半分〕・土地1,674万円〔物価上昇率 年1%で11年〕）。固定資産税は目安のボタンの値（年12万円）から買った値段からの推定（2026年 年22.88万円、評価替えごとに下がる段つき）に変わる。
- 標準の欄の数: 今住んでいる持ち家に4欄増える（買った年月・合計・土地・建物）。代表の世帯の最初の5項目で 39 → 43。
- 購入の予定で土地の割合を入れていた世帯: 欄が「うち土地の値段」に変わるだけで値は同じ。
