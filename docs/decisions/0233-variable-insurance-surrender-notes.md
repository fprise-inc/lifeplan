# 0233. 変額保険を解約するプランの注意と手引き（死亡保険金の最低保証・提案書と入力項目の注意・手で作るプランの手順）

- 状態: 採用（一部未確定）（2026-11-19）
- 固定の強さ: 内部。部品 `insurance.policy` の改訂7（円の目安の形の変額保険の死亡保険金の決まり。約束の版 1.3 は変えない）、注意の文と出す条件、積立の期間の0円の期間を残す読み方は後から変えてよい（変えたら追記に書く）。世帯ファイルの形式の版は変えない（足した入力の欄は無い）
- 前提にする記録: 0009・0016（提案書の作りと必須の記載）、0036・0043（プランの差分・入力画面でプランを直す）、0026（NISA の枠と、枠を超えた分の扱い）、0054・0055（変額保険の円の目安の形・保険の入力項目）、0044（一時所得の特別控除）、0227（画面の操作の手引き）

## 背景

- 変額保険に入っている世帯に、FP が「解約して、保障（掛け捨ての保険）と運用（NISA など）に分けるとこうなる」を見せたい。商品を特定しない・おすすめを出さない方針は変えない（比較の試算として見せる）。
- 経緯: 最初は保険の入力項目に専用の比較の区画（「解約して分けたら」のボタン・年ごとの小さな表・分けたプランを自動で作るボタン）を作ったが、複雑になりすぎるので、利用者の判断で、手動のプランと手引きで支える形にした（2026-11-19）。
- 変額保険の設計書は、運用実績の例（年3%・6%・10% など）ごとの解約返戻金を載せる。高い利回りの例の数字と、NISA を前提条件の利回りで伸ばした数字を並べると、保険と運用の違いではなく利回りの前提の違いで差が出る。

## 決定

### 1. 円の目安の形の変額保険の死亡保険金（`insurance.policy` 改訂7）

- 円の目安の形の変額保険（`insurance.variable` で `simple.estimate`）の契約の被保険者の死亡保険金は、基本保険金額（主契約の死亡保障の額）・数表の死亡保障・その時に解約したときの解約返戻金の多い方。
- 前は、数表の死亡保障の行があればその額（基本保険金額を下回る行でもそのまま）、無ければ基本保険金額のままで、数表の解約返戻金が基本保険金額を超えた年も死亡保険金が基本保険金額だった（変額保険の死亡保険金は基本保険金額と積立金の多い方で、積立金は解約返戻金を下回らない）。
- 外貨建て保険の目安の形・前の入れ方（積立金を伸ばす形）は変えない。

### 2. 注意の4つ

- 健康状態によっては新しい保険に入れないことがある・早い時期の解約には解約控除がかかる・年齢が上がると新しく入る保険の保険料が上がる・保険の募集人が乗り換えを勧めるときには説明の決まりがある。文は `report/src/variableSurrender.ts` に1つだけ置き、提案書と画面の両方が読む。
- **提案書**: 提案か比較のページのプランが、現状では解約の予定が無い変額保険を解約するとき（FP が手で作ったプランでも同じ）、外せない章「前提条件と注意書き」の注に、頭の一文「変額保険を解約するプランを載せています。比較の試算で、特定の商品をおすすめするものではありません。」と注意の4つを載せる（0009 の3・6 の必須の記載と同じ章。帳票の入力を組み立てる部品 `report/src/build.ts` が決め、どの契約かは書かない。0016 の2 の提示層は文を受け取るだけ。帳票の入力の形は変えない）。結果のタブには出さない（利用者の判断）。
- **保険の入力項目**: 変額保険に「解約の月」を入れたとき、その欄のすぐ後に説明の欄（`readLines.ts` の infoNote。折りたためる）「解約するときの注意」を出す。中身は「解約して保障と運用に分けるプランを作るときは、運用の利回りを、続ける場合と同じ前提にそろえて比較してください」と注意の4つ。外貨建て保険・解約の月の無い契約には出さない。

### 3. 手で作るプランで最後まで組み立てられるか（確かめた結果）

今の入力の画面と計算で、次のとおり組み立てられる（`app/test/variable-surrender-manual.test.ts`）。

| 手順 | 入れる所 | 結果 |
|---|---|---|
| (a) 解約の月 | 保険の入力項目の「解約の月」「解約の月の解約返戻金（円）」（数表のその保険年度の行に書く） | その月に解約返戻金を受け取り、保険料が止まる。払込総額を上回る分は一時所得（50万円の特別控除の後の2分の1）で税が増え、下回れば増えない |
| (b) 掛け捨ての保険 | 「＋ 保険契約を足す」で定期保険か収入保障保険、契約年月・保険料・保障の額 | ふつうの契約として計算される |
| (c) NISA の積立を増やす | 貯蓄・運用の NISA のつみたて投資枠の期間（「＋期間を追加」） | 解約の年の年齢から増やせる |
| (d) 解約返戻金をまとめて入れる | NISA の成長投資枠の期間（今の年齢から0円・解約の年の年齢から1年だけ毎月 解約返戻金÷12・次の年齢から0円）。課税口座も同じ形 | **できる（最小限の直しを入れた。下の4）**。ただし年齢の期間なので、その年齢になる月から12か月に分けて入る近似で、解約の月にまとめて入れる形ではない。成長投資枠は年240万円まで |

- NISA の枠を超える積立を入れると、貯蓄・運用のパネルに NISA の枠のお知らせが出て、超えた分の扱い（世帯の前提「NISA の枠を超えた分」: 預金に残す〔既定〕／課税口座で続ける）を FP が選ぶ（0026 の3）。手引きにも書いた。
- 解約の月にまとめて入れる形（年月の一時の積立）は、積立の期間を年齢で持つ今の作り（0026 の2）と別の欄が要り、入力の形・プランの差分・確かめの一覧まで広がるので、作らなかった。

### 4. 積立の期間の0円の期間を残す（`app/src/workspace/input/savings/model.ts` の `writeSteps`）

- 前は、積立の期間を書き戻すときに0円の期間を捨てていた。そのため (d) の「今の年齢から0円・46歳から月20万円・47歳から0円」は、書いた直後は正しく計算されるが、読み直すと「今の年齢から月20万円」（後の期間が今から始まる形）に見え、その口座の期間を次に直すと、積立が今から積立をやめる年齢まで続く形に書き換わっていた。途中で休む期間（「30歳から3万円・40歳から0円・50歳から3万円」）も同じで、休みが消えていた。
- 0円でない期間が1つでもあれば、0円の期間も残す（全部が0円なら今までどおり1つだけ残すか空にする）。計算のエンジンは0円の積立を何もしない積立として読むので、今までの世帯の結果は変わらない。

### 5. 操作の手引き

- 画面の操作の手引き（0227）の結果のタブの章に、節「変額保険を解約して、保障と運用に分けたプランの作り方」（`results.variableSurrender`）を足した: プランを写す → 解約の月と解約返戻金 → 掛け捨ての保険 → NISA の積立 → 解約返戻金をまとめて入れる（3 の近似と年240万円）→ 枠を超えた分の扱い → 利回りをそろえる（費用を引いた後の利回りか、運用の費用の欄）→ プランの比較で並べる。注意の4つも書いた。

## 理由

- **専用の区画をやめて手動のプランに任せる**: 解約・掛け捨ての保険・NISA の積立はどれも今の欄で表せ、FP が自分で入れたほうが前提（利回り・費用・取り崩し）が見える。専用の比較は、そろえる前提が増えるほど画面が複雑になった。
- **注意は提案書と入力項目に出す**: お客さまが見る提案書には必須の記載と同じ章に、FP が入れる場面には入れた欄の近くに出すのが、見落としが少ない。条件を「現状では解約の予定が無い変額保険を解約するプラン」にすれば、どの作り方のプランでも出る。
- **死亡保険金の最低保証を部品で直す**: 続ける場合の亡くなったときの額が、数表の解約返戻金より少なく出るのは、手で作るプランの比較でもゆがみになる。
- **0円の期間を残す**: 今から始まらない積立・ある年齢でやめる積立は (d) に限らず入れられる形で、読み直して形が変わるのは誤り。

## 代案（採らなかったもの）

- **専用の比較の区画とプランを作るボタン**: 上の経緯のとおり、作ったが外した。
- **解約の月にまとめて入れる一時の積立の欄を足す**: 3 のとおり、入力の形から広がるので、年齢の期間での近似と手引きにした。
