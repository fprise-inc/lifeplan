# 0069. 車のカードの中身（下取りの残価の目安・推定の印・維持費の入れ方と名前つきの行・ひな形のボタン・続きの車・今返している自動車ローン）と、世帯ファイルの形式 0.26

- 状態: 採用（一部未確定）（2026-10-27）
- 固定の強さ: 骨格は、車の `upkeepMode`（`total`・`detail`・省略）の意味と `upkeepOther[]`（`id`・`label`・`annual`）の形、入力項目ID `car.upkeepMode`・`car.upkeepOther`、出来事の種類 `carPurchase`・`carRelease`。残価の目安の割合・ひな形の額・欄の並び・簡易と詳細・文言は後から変えてよい

## 背景

- 車の維持費の入れ方（合計／内訳）は、切り替えるともう片方の値を消していた（合計→内訳で合計を捨て、内訳→合計で内訳を捨てる）。内訳には名前つきの行（雪国のタイヤ・防錆など）を入れる所が無かった。
- 目安で入れた周期・ローンの条件・次の買い替えの時期・内訳には推定の印が付かず、下取りは価格・周期にかかわらず50万円の決まった値だった。
- 「次の買い替えまでの年数」と「次の買い替えの時期」の2つの欄が同じ値を持っていた（時点の部品の「今から」で入れられる）。
- 今返している自動車ローンは、車のカードに出すまで住まい・ローンのカードで入れていた（0052）。
- 前提にする記録: 0008（車のひな形）、0035（世帯ファイルの形）、0038（時点の部品）、0041（値の状態）、0044（お金の行）、0052（住まい・ローンのカード）。

## 決定

### 1. 計算（部品 `expense.car` の改訂3）

- 車に **維持費の入れ方** `upkeepMode` を足す（任意）:

| 値 | 計算 |
|---|---|
| `total`（合計で） | 合計 `upkeep` だけを数える。内訳（自動車税・保険・車検・駐車場代・燃料代・名前つきの行）は数えない（値は世帯に残す） |
| `detail`（内訳で） | 内訳だけを数える。合計は数えない（値は世帯に残す） |
| 省略（前の形） | 入っている物を全部数える（今までと同じ） |

- 車に **内訳の名前つきの行** `upkeepOther[]`（`id`・名前 `label`〔表示だけ〕・年額 `annual`）を足す（任意）。年額の12分の1を、持っている間の毎月、表の行「車の維持費」に出す（駐車場代・燃料代と同じ。万一のときの扱いも同じく当てる）。お金の動きの計算式は `expense.car.other`。
- 入力のスキーマに2つの欄、登録簿に入力項目ID `car.upkeepMode`・`car.upkeepOther` を足した。

### 2. 画面（車ごとのまとまり）

| 欄 | 簡易／詳細 | 空欄・足したとき |
|---|---|---|
| 名義（使う人） | 簡易 | 本人 |
| 次の買い替えの時期／購入の時期（時点の部品。既定の入れ方は「今から○年後」） | 簡易 | 3年後（推定。値の状態の行） |
| 買い替えの周期 | 簡易 | 8年（推定） |
| 車両の価格 | 簡易 | 250万円（推定） |
| 買い方（現金／ローン） | 簡易 | 現金。ローンにすると借入8割・5年・年2.5%（推定） |
| 維持費（年額の合計） | 簡易（内訳で入れているときは読むだけ） | 36万円（推定） |
| 手放す時期（名義の人の年齢） | 簡易 | 最後まで |
| 下取り（次の買い替えで引く額） | 詳細 | 価格×周期の残価の目安（推定） |
| 今の車を持っている | 詳細（足すボタンで決まる） | — |
| 維持費の入れ方・内訳・名前つきの行 | 詳細 | — |
| 伸び方・万一のときの扱い | 詳細 | — |

- 「次の買い替えまでの年数」の欄はやめた（時点の部品の「今から」で入れる。今からで入れた時点は年月で持つ）。
- 車を足すボタンは「＋ 今の車」「＋ これから買う車」（`purchase.owned` はボタンで決まる。直すのは詳細の欄）。新しい車は `upkeepMode: "total"` で始める。
- **下取りの残価の目安**（ひな形。原本で確かめた市場の統計ではないので根拠は「ひな形の目安」）: 車両の価格に対して、3年まで50%・5年35%・8年15%・10年以上5%、その間はならす（250万円・8年で38万円）。推定のままの下取りは、価格・周期を直したら目安を入れ直す。FP が打った下取りは変えない。
- 推定の印: 価格・下取り・周期・維持費の合計・内訳（自動車税・保険・車検・燃料の目安）・ローンの条件は画面の側の仮の印、次の買い替えの時期は車の値の状態の行。
- **維持費の入れ方**を切り替えても、もう片方の値は消さない:
  - 合計→内訳（初めて）: 合計を目安の割合で分ける（自動車税・保険・車検は目安、残りを燃料。推定の印）。
  - 内訳→合計→合計を直した→内訳: 内訳は前のまま。合計のほうが多ければ、差を名前つきの行「その他（まだ分けていない）」に置く（推定の印）。差が無くなれば、推定のままのその行を外す。
  - 内訳→合計: 合計が無ければ内訳の合計を入れる。
  - 入れ方の無い古い車は、入っている物から入れ方を読む（合計があれば合計、無ければ内訳）。開いただけでは書き換えない。
- 見出しの説明に **この車の一生の費用（今の値段で）**: 計算の最後か手放す月までの、買い替え（下取りを引いた額）と維持費の合計。ローンの利息・物価の伸びは含まない（見出しの目安）。

### 3. 出来事に結ぶひな形のボタンと続きの車

- 名前つきの出来事の種類に **車の購入** `carPurchase`（車の `purchase.first`）と **車を手放す** `carRelease`（車の `until`）を足した。時点の部品の「出来事から」で選べ、選ぶと出来事になる（0038 と同じ。指している物が全部いっしょに動く）。手放す時期の欄（年齢の整数）を直すと、出来事を指しているときは出来事のほうを動かす。
- 手放す時期を入れた、その名義の最後の車に **「手放した後の移動の費用を足す」**（簡易。自動では足さない）: 車のカードの出るお金の行（種類 車の修理・用品など・表の行 車の維持費・毎月1万円〔ひな形の目安。推定〕）を、出来事「車を手放す」の翌月から作る。
- 周期が10年以上か、手放すまで買い替えない車に **「古くなってからの修理費を足す」**（詳細）: 毎年10万円（ひな形の目安。推定）の行を、出来事「車の購入」から10年後（今の車は、次の買い替えの周期の前に買ったとみなす）から、手放す時期まで作る。車そのものには段階・例外の年を持たせない。
- **「この車の続きを足す」**（詳細。手放す時期を入れた最後の車）: 手放した翌月を購入の時期にした、同じ欄のこれから買う車を足す（周期を途中で変えるため）。推定の印も写す。

### 4. 車のカードの区画

1. 車（車ごとのまとまり。内訳で入れている車は、詳細に名前つきの行のまとまりが続く）
2. 出るお金（車の修理・用品・車を持たない移動の費用）: 0044 のお金の行。空のときは「カーシェア・レンタカー 月1万円」のひな形（推定）。
3. **今返している自動車ローン**: 住まい・ローンのカードから移した（欄はほかのローンと同じ部品）。住まい・ローンのカードの「ほかのローン」には読むだけの1行「自動車ローン（今返している） n件（車のカードで入れます）」。

- 車が無くても、車のカードのお金の行か今返している自動車ローンがあれば、カードは物がある（要約は件数）。

### 5. 世帯ファイルの形式 0.26

- 足すだけの MINOR。0.25 → 0.26 の変換の段は形式の版だけを書き換える（入れ方の無い車は前の形で計算するので、足さない）。0.25 のアプリは知らない欄を読み落として書き戻すので、版を上げて閲覧だけにする。
- 見本 `crates/household-store/tests/fixtures/household-format/0.26/`（0.25 の見本に、内訳で入れる車〔合計の値も残し、名前つきの行が2つ〕と合計で入れる車〔駐車場代も残す〕を足したもの）。
- AI接続口の縮約版の許可リストに `car.upkeepMode`・`car.upkeepOther` を入れ、版を `reduced@17` にした。名前つきの行の名前は決まった形の無い文字列なので縮約版では外れ、持ち帰り用のレポートでも外す。

## 残したもの（計算がまだ無いので出していない欄）

- 手放すときの売却額（手放す月に売却額を入金にする計算が無い）。手放す時期の欄の説明に「まだ計算に入っていない」と書いた。
- 残価設定ローン（最後の回の額・返す／買い取る）とカーリース（月額・期間・含むもの・途中でやめる額）。買い方の欄の説明に、リースは価格0円にしてリース料を出るお金の行で入れる工夫を書いた。
- 車の種類（軽・普通・大きい車・電気自動車）ごとの目安と、今の車の年式（13年を超えた自動車税の重課の判定・残価の元）。
- 買い方を現金に戻したときのローンの条件の保存（今はローンの欄を外す）。
- 車のメニュー「この車が無かったら」（保存しない自動の差分の作りを決めてから）。
- 手放した後の移動の費用の目安を家計調査の交通の値で（原本で確かめてから）。周期の8年の出典。

## 見本の世帯の結果

- 変わらない（見本の車はどれも入れ方を持たず、前の形で計算する）。新しく足す車の下取りの目安だけが変わる（50万円 → 価格×周期の残価の目安。250万円・8年なら38万円）。
