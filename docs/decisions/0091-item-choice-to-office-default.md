# 0091. 入力項目を選ぶから事務所の既定にする・事務所の既定にそろえる・既定を標準に戻す

- 状態: 採用（2026-10-30）
- 固定の強さ: 内部（画面の操作と文言）。事務所データの形（`defaults.items`）と世帯ファイルの形（形式の版）は変えない。「事務所の既定にしても、作った世帯は黙って変わらない」（0083 の6・0073 の3）は変えない。置き場所・文言は後から変えてよい
- 前提にする記録: 0073（事務所の既定値）、0083（入力項目の選び方）、0084（事務所の既定値の持ち方）

## 背景

- 入力のホームの「入力項目を選ぶ ▾」は、**世帯ごと**の選び方（出す入力項目と、開いたときの入れ方）を世帯ファイルの `household.itemChoice` に持つ（0083 の2）。PC ごとの設定ではない。世帯といっしょに2台目の PC・事務所の共有フォルダへ移る。
- 事務所の既定（事務所の既定値のパネルの「新しい世帯で出す入力項目と、開いたときの入れ方」。事務所データの `defaults.items`）は、空の世帯を作るときにだけ写す（0083 の6）。作った世帯・見本の世帯・古い世帯には当てない。
- 使う人から「世帯の画面で選んだ形を、そのまま事務所の既定にしたい」という声があった。今は事務所の既定値のパネルを開き、同じ選び方をもう一度チェックし直す必要がある。
- 0083 の未確定に「一覧の『事務所の既定に戻す』」が残っていた。事務所の既定値の区画には、ほかの区画にある「標準に戻す」が無かった。

## 決定

### 1. 「この選び方を事務所の既定にする」

- 「入力項目を選ぶ」の一覧の下に、事務所の既定との関係を1行で出す: 同じなら「事務所の既定と同じです（新しく作る世帯は、この選び方で始まります）」、違えば「事務所の既定と違います」と2つの操作。
- 「この選び方を事務所の既定にする」: この世帯の選び方（出さない入力項目と、詳細で開く入力項目）をそのまま事務所の既定にする。押すとすぐ事務所データに保存する（確かめの画面は挟まない。下の「取り消す」で戻せる）。
- 置き換えるのは事務所の既定値の**入力項目の選び方だけ**（`withOfficeItems`）。並び・対策・前提条件などほかの既定は変えない。
- **最後に変えた日（`changedOn`）は変えない**: この日は、新しい世帯に写す前提条件などの推定の根拠「事務所の標準（年月）」に使う。見せ方だけの選び方を変えただけで、前提条件の根拠の年月が新しくなると、値は変わっていないのに新しく決めたように見えるため。
- 値が入っているので出している入力項目（0083 の4）も、世帯の選び方で外してあれば、外した形のまま写す（新しい世帯では値が無いので出さない）。
- 事務所データを読めない画面（本体につながっていない、部品だけの確かめ）では、この行を出さない。

### 2. 取り消す（事務所の既定を前に戻す）

- 事務所の既定にした後、知らせ「事務所の既定にしました。これから作る世帯に写します（作った世帯は変わりません）」と「取り消す」を出す。取り消すと、押す前の事務所の既定に戻す。
- 事務所の既定は世帯の物ではないので、世帯の ↶↷ には入れない（↶ で世帯を戻したときに、事務所の設定まで黙って戻ると、ほかの世帯の作り方が変わる）。そのため一覧の中に専用の「取り消す」を置いた。一覧で世帯の選び方を変えると、知らせは消える。

### 3. 「事務所の既定にそろえる」（世帯を事務所の既定と同じにする）

- 一覧の下に「事務所の既定にそろえる」を置く。この世帯の選び方を事務所の既定と同じにする（0083 の未確定の「事務所の既定に戻す」）。世帯の変更なので、ほかの操作と同じく保存・↶↷ の対象になる。入れ方が変わる入力項目は、その場の切り替え（0083 の5）も外す。
- 「戻す」でなく「そろえる」にした: 見本から写した世帯・古い世帯は、事務所の既定から始まっていないので「戻す」と合わない。

### 4. 事務所の既定を標準に戻す

- 事務所の既定値のパネルの区画「新しい世帯で出す入力項目と、開いたときの入れ方」に「標準に戻す（全部出す・全部標準で開く）」を足した（ほかの区画の「標準に戻す」と同じ。保存で効く）。

## 理由

- 依頼主の質問「これは世帯のみに影響する設定か」への答えは「はい、世帯ごと（世帯ファイル）」。世帯の画面で作った形をそのまま既定にできると、事務所の既定値のパネルで同じ選び方を作り直さずに済む。
- その場ですぐ保存して「取り消す」を出す: 確かめの画面を挟むと一覧の上にもう1枚重なる。効くのはこれから作る世帯だけで、作った世帯は変わらないので、すぐ戻せれば十分。
- 一覧の下に置いた: 一覧の中の選び方を既定にする操作なので、選んだすぐ下にあるのが分かりやすい。違うときだけ操作を出し、同じときは1行の知らせだけにして、一覧を短く保つ。

## 代案（採らなかったもの）

- 事務所の既定を世帯から参照し続け、既定を変えるとどの世帯にも効く形: 0083 の代案のとおり、作った世帯の見え方が黙って変わる。対策に最初から出す項目（0084）は見せ方だけで世帯ごとに持たないので参照する形だが、入力項目の選び方は世帯ごとに持つ（0083 の2）。
- 「事務所の既定にする」の前に確かめの画面を出す: 2 の理由。
- 事務所の既定の変更を世帯の ↶↷ に入れる: 2 の理由。
- 事務所の既定にしたときに、最後に変えた日も今日にする（事務所の既定値のパネルの保存と同じ）: 1 の理由。
