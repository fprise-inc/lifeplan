# 0133. 子ども・教育と車の入力項目の手直し（進路の型の比べ方・標準の公立私立・専門学校の学費の目安・子ごとの教育費・学校外の費用の1つの欄・子の行の時期・車の手放す時期の既定・名義の候補）

- 状態: 採用（一部未確定）（2026-11-07）
- 固定の強さ: 内部（画面の欄・選択肢・見出し・足したときの既定。世帯ファイルの形式の版は変えない。計算の決まりは変えない〔変わるのは、これから足す車の手放す時期の既定と、ボタンで入れる値だけ〕。目安の値・言葉は後から変えてよい。変えたら追記に書く）
- 前提にする記録: 0010・0029・0062・0063・0078・0088・0089・0090・0103・0104（子ども・教育）、0069・0101（車）、0041（値の状態・推定の印）、0044（お金の行）、0130（入力項目をまたぐ言葉の決まり）、0131（欄の部品・欄の外の額の書き方）

## 背景

入力項目を通しで入れた見直しで、子ども・教育と車に次の問題が見つかった。

1. 高校のあとが専門学校（私立）の子で、進路の型が「すべて公立（大学は国公立）」と出た（型に無い段階を飛ばして比べていた）。型の名前は欄の幅で切れていた。
2. 標準の公立・私立の選ぶ欄に、どの段階でも「国立」「インターナショナルスクール」が出ていた（子2人で9つの欄）。
3. 専門学校の学費は国の統計が無く、0円で計算中のまま、手がかりの数字が無かった。
4. 標準のどこにも教育費の額が出ず、子の見出しも「第1子」だけ（年齢・学年が無い）。
5. 学校外の費用が、標準の「学校外の費用」と詳細の「学校外の費用の入れ方」の2つの欄に分かれていた。
6. 奨学金・教育ローンを詳細で足して標準に戻すと、見出しも出なかった。見出しの額が「月50,000円」。
7. 子の援助・給付型の奨学金の行の時期が、ご本人の年齢と年月で読まれ（「ご本人47歳」）、子の生年月を直しても動かなかった。足した行の始まりに「今から（今受け取っているお金として…）」の推定の根拠が残っていた。
8. 給付型の奨学金・子が払う分は詳細でしか足せなかった。
9. 子への援助の「贈与する人」に、贈与する人がいなくても「贈与する人を選ばない」の1択が出ていた。
10. 車を手放す時期の既定が「最後まで」（100歳まで運転して買い替え続ける）。利用者の判断で、これから足す車は名義の人の75歳（推定）にすることになった。
11. 車の名義の候補に小さな子まで出ていた。標準でローンを選んでも借り方が見えず、今返している自動車ローンを標準から足せなかった。内訳で入れた維持費の合計が「20.35万円」。

## 決定

### 1. 進路の型の比べ方（`stages/education.ts` の `presetOf`）

- 型に無い段階は、型のどの段階の代わりかで比べる: 高校のあとの短大・専門学校は大学の代わり、高専は高校の代わり。代わりに比べるときは国立と公立を同じ側（国公立）として比べる。大学院は型の外なので比べない。
- 型を選び直しても、短大・専門学校・高専の公立・私立は変えない（今までどおり）。そのことを型の欄の下に「専門学校の公立・私立は型では変わりません（その段階で選びます）」と1行で出す。
- 型の名前「すべて公立（大学は国公立）」を「すべて公立（国公立大）」に短くした（欄の幅で切れないように）。

### 2. 標準の公立・私立は「公立／私立」の2つ

- 標準の欄（`…/stage/<i>/sector`、標準だけの欄）は公立・私立の2つ。国立・インターナショナルスクールは詳細の欄（`…/sectorAll`）で選ぶ。もう選んでいれば標準の欄にも出す（選択肢が同じになるときは1つの欄のまま）。

### 3. 専門学校の学費の目安（`educationCost.ts` の `VOCATIONAL_GUIDE`、`fillVocationalGuide`）

- 専門学校の段階に「学費を目安で入れる（年113.6万円・入学金18.3万円）」のボタン（標準）。押すと、入っていない方の年額・入学金に目安を入れ、推定の印（根拠は業界団体の調査の平均）を付ける。年額が入っていればボタンを出さない。
- 値は公益社団法人東京都専修学校各種学校協会「学生・生徒納付金調査」令和7年度（調査統計資料の調査2）の専門課程・昼間部の総平均（千円。入学金 183・授業料 740・実習費 138・設備費 176・その他 82、初年度の合計 1,318）。年額は入学金を除く4つの和 1,136千円。国の統計（文部科学省）には専門学校の学費が無いので、この調査を使う。東京都内の私立の専門学校の値であることを根拠の文に書く。
- 公立・私立の高専とインターナショナルスクールは、出典を確かめられる目安が無いので、ボタンを出さず「?」と未入力の1行に「学校の案内の額を入れます」とだけ書く。
- 段階の見出しの下の1行は、推定で入れた年額を「（推定）」と書く（FP が入れた額は「（入れた額）」のまま）。

### 4. 子ごとのこれからの教育費（`stageRemainingCost`・`childAgeGrade`、`form.ts` の `summary`）

- 子の区画の見出しの横に「10歳・小4・これからの教育費 約683.6万円（今の値段・統計の平均）」、段階の見出しの横に「6年で約198.5万円」を小さく出す。見出しの名前（探して開く・確かめの一覧に使う）は「第1子」「小学校（6歳から）」のまま。
- 見出しの横の要約は、まとまりと区画の定義の新しい欄 `summary`（見出しの名前ではない）。描くのは `FieldViews.tsx`。
- 額は今の値段の目安（計算エンジンの額とは別）: 計算の基準の月の年度から卒業までの年数×（学校の費用・学費〔入れた額か統計の平均〕＋入れた部活動などの額＋学校外の費用〔幼稚園〜高校。行で入れているときは数えない〕＋自宅外の仕送り）と、まだ入学していなければ入学金・自宅外の初期費用。教育費の上昇率・修学支援・就学支援金・保育料・留学は入れない。学費が未入力（0円）の段階は額を出さない。

### 5. 学校外の費用を1つの欄に（`uniformOutOfSchool`）

- 標準の1つの欄「学校外の費用（塾・習い事など）: 統計の平均／入れない／段階ごとに額で／塾・習い事を行で」（前の形の世帯だけ「統計の平均に行を足す（前の形）」も）。詳細の「学校外の費用の入れ方」の欄はやめた。
- 世帯ファイルは今の2つの値のまま読み書きする: 統計の平均＝段階の額を外す（行で入れていたら入れ方を統計に戻す。行は消さない）、入れない＝段階ごとに「無し」、段階ごとに額で＝額の入っていない段階に統計の平均の月額を推定の印で入れる（その段階の「▸」で直す）、塾・習い事を行で＝初めてなら段階ごとに統計の平均の行（推定）を作って入れ方を行にする（今までの「期間の行で入れる」と同じ）。
- 行で入れているときの説明と行は「塾・習い事の行」のまとまり（標準）。統計の平均のときに使っていない行があれば、詳細にだけ「塾・習い事の行（使っていません）」の説明を出す。

### 6. 奨学金・教育ローン・留学・子への援助

- 貸与の奨学金・教育ローンは、入っていれば標準にも見出しの1行（欄は詳細。「▸ 月額・利率・返す年数などを入れる」）。見出しは「貸与の奨学金（第二種） 月5万円・子が返す」「教育ローン 121万円」（0131 の `amountText`）。期間の欄は「始まり／終わり」（0130）。
- 教育ローンの返す年数の推定 20年は、日本政策金融公庫「国の教育ローン」の案内（ご利用条件・返済期間「20年以内」）で確かめた（2026-11-07。変えない）。
- 留学の「万一のときの扱い」は詳細（「続ける（既定）／やめる」。0130 の言葉）。留学の行は「▸ 万一のときの扱いを入れる」で開く。
- 子への援助の出す人（`giftDonorOptions`）: 世帯の外の贈与する人がいなければ欄を出さず、見出しの下に「出す人: 世帯」。いれば欄の名前を「出す人」、選択肢を「世帯から出す」「（贈与する人の呼び方）から出す」。前に選んだ人が今の候補に無ければ「前に選んだ人から出す」で残す。詳細の「出す人（世帯の中）」は「世帯の中で出す人」に。
- 名前: 「理工農系」→「修学支援の対象の学部（理工農系）」、「部活動などの費用（年額）」→「うち部活動など（年額）」、段階を外すボタンは「外す」（大学は「大学に行かない」のまま）、画面の文の「段」は「段階」（0130）。
- 大学などを自宅外にしたときだけ、仕送り（月額）を標準に出す（初期費用は詳細。利用者の判断）。「▸」の文は「初期費用・受験の費用などを入れる」。

### 7. 子の行の時期は子の物差しで（`higherSchoolYears`、`addChildIncome`・`addScholarship`）

- 子の行（教育資金の援助・給付型の奨学金・子が払う分）と貸与の奨学金を足すとき、始まりを子の年齢の学年の4月（`memberAge` と `ageSwitch: "schoolYear"`。大学などの入学の年齢〔18歳＋浪人の年数〕）で書く。年ごとの行の終わりは最後の年の4月（同じ形）、子が払う分（毎月）の終わりと貸与の奨学金の終わりは卒業の月（年月）のまま。欄の下は「第2子が18歳になった後の最初の4月（2038年4月・令和20年）」と読む。子の生年月を直すと一緒に動く。
- 足した行の始まりには、在学の期間に合わせた既定の推定の印（根拠「既定の値（大学の4年間。在学の期間に合わせました。時期が違えば直してください）」）を付ける（お金の行の「今から」の根拠を残さない）。
- 受け取るお金は1つの「＋ 援助・給付型の奨学金を受ける」で、押すと「祖父母などの援助」「給付型の奨学金・学費の助成」「子が払う分」を選ぶ（0040 の追記の1つのボタンの選択肢。標準）。

### 8. 車

- **手放す時期の既定**（`RELEASE_AGE`・`releaseAt`）: これから足す車（今の車・これから買う車・リース）は、手放す時期を名義の人が75歳になる月（推定の印。根拠「既定の値（名義の人が75歳で手放す。運転免許の更新で認知機能の検査が始まる年齢の目安…）」）で入れる。名義の人がもう75歳以上なら、次の年齢。前に足した車・見本の世帯の車は書き換えない（利用者の判断: 入れなかったときの初めの値で、これから足す物だけ）。
  - 名義を変えたとき、手放す時期が既定の推定のままなら新しい名義の人の年齢にする。
  - 既定のままの車を「この1台だけ」にしたら、この1台だけの目安（買ってから13年・今の車は今から5年）に入れ替える。この1台だけの目安のまま買い替える形に戻したら、既定（75歳。推定）に戻す（前は「最後まで」に戻していた）。空欄にすると「最後まで」（FP が選んだこととして印は付けない）。
  - 手放す時期の欄の当て先を物の値の状態の行（`car.until`）にし、「この値にする」で推定の印が外れるようにした（前はこの1台だけの目安の印が「この値にする」で外れなかった）。
- **名義**（0130 の名義の決まりと部品）: 欄の名前は「名義」、「?」に「使う人で選びます」。候補は今の車・リースは今18歳以上、これから買う車は買う月に18歳以上（`holderOptions(wh, "age18", …)`）。
- 見出しに「今の車」「これから買う車」（「車 1（ご本人・今の車）」）。詳細のチェックの名前は「今の車（外すと「これから買う車」）」。
- 標準で「ローン」を選んだら、買い方の欄の下に借り方の1行（`loanLine`。「借入: 下取りを引いた額の8割・5年・年2.14%（▸ で変えられます）」）。
- 今の車があれば、標準にも「＋ 今返している自動車ローン」を出す。
- 内訳で入れたときの維持費の合計（読むだけ）は「年20.4万円」（0131 の `amountText`）。決まった率の伸び方の欄の名前は「伸び率（年）」（0130）。

## 理由

- 進路の型を「大学の代わり」で比べるのは、型の名前（「大学だけ私立」など）が高校のあとの学校の公立・私立を含めて決まっているため。飛ばして比べると、私立の専門学校の子が「すべて公立」と読めた。型で専門学校を変えないのは、今までの動き（型を選び直しても専門学校の公立・私立は残す）を変えないため。
- 専門学校の目安に東京都の業界団体の調査を使うのは、国の統計（子供の学習費調査・私立大学等の学生納付金等調査）に専門学校が無く、分野をまたいだ平均を毎年公表している調査がこれだけだったため。都内の値で地方より高めになりうるので、根拠に書き、ボタンでだけ入れる（空欄の推定にはしない。0円のままの未入力の警告は残す）。
- 子の行を子の年齢の学年の4月で書くのは、在学の期間（学年の4月から）と同じ物差しで読め、子の生年月を直しても在学と一緒に動くため（年月で書くと、生年月を直しても受け取りの年が残る）。
- 車の既定を75歳にしたのは、入れ忘れると100歳まで買い替え続けて甘く出るため（利用者の判断）。推定の印なので、確かめの一覧から FP が確かめられる。前の世帯を書き換えないのは、入れ終わった世帯の結果を黙って変えないため。

## 代案（採らなかったもの）

- 子ごとの1行の表（「小学校｜中学校｜高校｜大学」に公立・私立を並べる）: 欄の描き方（入力のパネルの部品）を大きく変えるので β 後に回した。見出しの横の要約と標準の2択で、縦の長さと迷いを先に減らした。
- 車の大きさ（軽自動車／普通車／大きめ）: 利用者の判断で足さない（入力項目を増やさない）。
- 専門学校の目安を空欄の推定にする: 都内の値で、地方の学校ではずれやすいので、押して入れる形にした。
- 見出しの名前に年齢・教育費を入れる: 探して開くの「どこ」と確かめの一覧の名前が長くなるので、見出しの横の要約（`summary`）に分けた。
