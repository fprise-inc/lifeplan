# 0155. 事業所得のある人の確定申告の入れ場所（申告の仕方・青色申告特別控除を働き方と収入にも出す・入れないときは白色の推定）と、詳細のヒアリングシートの版4

- 状態: 採用（一部未確定）（2026-11-07）
- 固定の強さ: 内部（欄の置き場所・標準か詳細か・推定の印の付け方・画面の言葉。後から変えてよい。変えたら追記に書く）。世帯の欄 `members[].taxReturn` の名前と値は 0081 のまま（骨格）で、世帯ファイルの形式の版は変えない。計算エンジン・制度データは変えない。ヒアリングシートは `full` 版4 を足し版3 を廃止（0018 の決まりどおり。項目キー `hs.income.taxReturn` は変えない・使い回さない）
- 前提にする記録: 0081（青色申告特別控除・純損失の繰り越し・`members[].taxReturn`）、0078（標準の欄は「必要十分」で決める）、0041・0150（値の状態の操作・確定は明示の操作だけ）、0018・0135（ヒアリングシートの版）、0152（書類を読む AI 向けの手引き・欄の一覧）、0131（空欄の意味・欄の部品）

## 背景

- 申告の仕方（青色・白色）と青色申告特別控除の区分の欄（`members[].taxReturn`）は、0081 で収益不動産の入力項目の「申告（物件の持ち主ごと）」にだけ作った。事業所得だけの自営業の人には入れる場所が無かった。働き方の事業所得の欄（`employment.business.income`）は「青色申告特別控除の前の額」と決めてある（0081 の4）。
- エンジン（`tax.totalIncome`）は、`taxReturn` が青色なら事業所得からも控除を引く（0081 の4。確かめた: 下の1）。欄が無いので、事業所得だけの世帯は青色申告をしていても白色（控除なし）で計算され、所得税・住民税・国民健康保険料（所得割）・介護保険料・子ども・子育て支援金が多めに出ていた。
- 書類の読み取りの確定申告書の手引き（0152）では、事業所得だけの人の申告の仕方の候補は「この世帯に、この値を入れる欄がありません」になり、FP が入れないにするしかなかった（0152 の未確定）。

## 決定

### 1. エンジンは変えない（今の計算が税法どおりかを確かめた）

- `tax.totalIncome` は、申告の仕方が青色の人の年ごとに、**不動産所得と事業所得の黒字の合計（損益通算の前。赤字の所得は0として数える）を上限に、不動産所得・事業所得の順に**引く。55万円・65万円は、不動産所得が事業的規模（5棟10室の目安）か事業所得がある年だけで、当たらなければ10万円（知らせ `N_LIMIT_APPLIED`〔`taxReturn.blueDeduction`〕）。事業所得には自営の働き方の期間・課税の扱いが事業所得の入るお金の行・事業所得の民泊・宿を含む。
- 国税庁 No.2072（青色申告特別控除。根拠は措置法25条の2・措通25の2-1）と突き合わせた: 55万円・65万円の上限は「不動産所得と事業所得の黒字の合計額（損益通算前）。赤字の所得はないものとして計算」、控除の順は「不動産所得、事業所得の順」、10万円は「不動産所得、事業所得、山林所得の順」で上限も山林所得を含む。エンジンはこのとおり（山林所得は扱わないので、10万円も不動産所得・事業所得の2つ）。直す所は無かった。
- 住民税・国民健康保険料・介護保険料・後期高齢者医療の保険料・子ども・子育て支援金の所得割は、どれも控除の後の総所得金額（`tax.totalIncome` の `total`）から計算するので、控除が効く。個人事業税は計算していない（事業所得の民泊・宿と事業的規模の物件は知らせ `N_NOT_SUPPORTED`。個人事業税には青色申告特別控除が無いが、計算していないので食い違いは無い）。

### 2. 働き方と収入に「〇〇の確定申告」のまとまりを足す（収益不動産の「申告」と同じ値）

- 働き方と収入の人ごとの区画に、**事業所得のある人**（自営の働き方の期間、課税の扱いが事業所得の入るお金の行〔受け取る人。空ならご本人〕、事業所得の民泊・宿のどれか）だけ、まとまり「ご本人の確定申告」を出す（今の働き方・働き方 1・2… の後、定年後の予定の前）。欄は申告の仕方と、青色のとき青色申告特別控除（65万円・55万円・10万円）。
- 欄の定義は `app/src/workspace/input/taxReturn.ts` の1か所（`taxReturnFields`）にして、収益不動産の「申告」と働き方と収入の「確定申告」の両方がこれを使う。当て先は同じ（構成員の `member.taxReturn` の `["method"]`・`["blueDeduction"]`）なので、**1人の人に値は1つで、どちらから入れても両方に同じ値が出る**。説明（「?」）に「収益不動産の『申告』と働き方と収入の『確定申告』は同じ値です」と書いた。
- 事業所得があるかの見方（`hasBusinessIncome`）も同じファイルの1つにし、収益不動産の側の「10万円で計算しています」の知らせも同じ見方にした（入るお金の行の事業所得を見ていなかったのを、エンジンと同じに直した）。民泊・宿の所得の区分の既定（`lodgingIncomeKind`）も同じファイルに移した（収益不動産の側からは今までの名前で読める）。
- 事業所得の欄の説明に「青色申告なら、控除は下の『確定申告』で選ぶと計算で引きます」を足した。

### 3. 標準の欄にする（0078 の決め方）

- 0078 の「推定の当たり外れで90歳の資産が500万円以上動く世帯が複数ある欄で、顧客が答えられるもの」に当たる: 見本の自営業の世帯（事業所得 年850万円）で、白色と青色65万円の差は90歳（2073年末）の金融資産で +1,505万円（55万円で +1,287万円、10万円で +242万円）。モデル世帯 `selfEmployed`（表は2060年まで）で表の最後の年に +454万円。自営業の人は自分の申告の仕方と控除の額を答えられる（確定申告書の第一表・青色申告決算書にある）。
- 申告の仕方・青色申告特別控除とも標準（`level: simple`）。**出すのは事業所得のある人だけ**なので、代表の世帯（会社員の夫婦と子2人。最初の5項目で 39）の標準の欄の数は変わらない。事業所得のある人のいる世帯だけ、働き方と収入の標準の欄が1つ（青色なら2つ）増える。
- 収益不動産の「申告」は今までどおり詳細（物件の入力項目の中で持ち主ごとにまとめる欄。働き方と収入で標準に入れられる）。

### 4. 入れないときは白色（控除なし）の推定

- 欄が無い（入れていない）ときの計算は今までどおり白色（控除なし）、青色で区分が無ければ10万円（エンジンの省略の読み方。0081）。結果が甘く出ない側。
- **55万円・65万円を使える人**（事業所得があるか、不動産所得が事業的規模の目安に当たる人）には、欄に推定の印を付ける: 根拠「既定の値（白色。青色申告特別控除なしで計算しています。青色申告なら選んでください）」、青色で区分が空なら「既定の値（10万円。55万円・65万円の要件に当たるなら選んでください）」。確かめの一覧・「推定で計算中」に数え、「この値にする」で確定（白色・10万円と書く）、「推定に戻す」で空に戻せる（`blankIsEstimate`）。見せている値を書き戻しても世帯は変えない（0041）。
- 10万円までしか効かない人（物件だけで事業的規模でない人）は、今までどおり推定の印を付けない（省略の既定として見せる）。動くのは10万円の控除の分だけで、物件のある見本の世帯の「推定で計算中」を増やさないため。
- **白色を選んだら `{"method":"white"}` と書く**（前は欄ごと外していた）。入れていない（推定の白色）と、FP が白色と決めたことを見分けるため。エンジンは前から `white` を読む（0081）。青色から白色に変えたら区分は外す。欄を空にしたら申告の欄ごと外す。

### 5. 書類の読み取り（0152）

- 確定申告書の手引き（`sdk/skills/read-documents/guides/tax-return.md`）の「申告の仕方の欄は収益不動産の持ち主の画面にだけ」を、事業所得のある人の働き方と収入の確定申告と収益不動産の申告の両方にあり、同じ値なので `member.taxReturn` に書けばよい、に直した。どちらの欄も無い人（給与・年金だけの人）は今までどおり「欄がありません」。
- 当て先は同じなので、欄が2か所に出ても書類の候補の当て先は1つ（`fieldPlaces` が当て先で1つにまとめる）。入力の欄の一覧（`fields.md`。`npm run gen:document-fields`）は作り直したが、欄の名前・選択肢・人の欄は同じなので中身は変わらない。
- 手引きの見本の答え（青色65万円の個人事業主）は、事業所得だけのモデル世帯 `selfEmployed` でも全部の候補が入るようになった（テストの「欄の無い候補」を外した）。

### 6. 詳細のヒアリングシートを `full` 版4 に（版3 は廃止。0018 の1・7）

- 版3 の項目はキーを変えずにそのまま残し、区画「3. お仕事と収入」の事業の所得の次に、問い「確定申告の仕方」`hs.income.taxReturn` を足した（繰り返しの軸は大人）。選択肢: 青色申告（65万円の控除）・青色申告（55万円の控除）・青色申告（10万円の控除）・白色申告。状態は「わからない」「該当なし」。説明: 自営業・フリーランスの方だけ、確定申告書の第一表の「青色」の印と青色申告決算書の青色申告特別控除額でわかる。
- 取り込み: 働き方が自営業の人の答えを、その人の `taxReturn` に確定で入れる（白色は `{"method":"white"}`）。空欄・わからない・該当なしは入れない（入力の画面で白色の推定）。働き方が自営業でない人の答えは取り込まずに知らせる（事業の所得の欄と同じ）。前回の値の書き出し（見直し）は、入れてある自営業の人だけ記入する。
- Web で答えるヒアリングは、働き方が自営業の人にだけ聞く。
- 簡易の票（`basic` 版2）には足さない（年収の1問で答える短い票。欄を増やさない）。
- 見本 `hearing/samples/full-4-sample.{json,xlsx}` を足した（版3 の見本の配偶者の方をフリーランス・青色申告65万円にした例）。版1〜3 は同梱し続けて取り込める。

### 7. 探して開く

- 入力のホームの言い換えの辞書で、「確定申告」「青色申告」「白色申告」「65万円控除」を働き方と収入の「申告の仕方」（無ければ事業所得）に当てる。

## 理由

- 申告は人ごと（不動産所得と事業所得の全体）なので、値は人に1つ（0081 の代案のとおり）。入れる場所を人の働き方と収入にも出し、定義を1か所にすれば、2か所に別々の値が入ることは起きない。
- 事業所得だけの世帯で税・社会保険料が多めに出る（見本で90歳の金融資産が1,500万円ほど少ない）のは、標準だけ入れる FP が気づけない差。自営業の人なら答えられる。
- 初めの値を青色（65万円）にすると、白色の人の結果が甘く出る。白色（控除なし）は甘く出ない側で、推定の印で FP が確かめられる。

## 代案（採らなかったもの）

- 働き方と収入では1つの選ぶ欄（白色・青色65万円・55万円・10万円）にまとめる: 欄は1つ減るが、書類の候補の当て先（`["method"]`・`["blueDeduction"]`）と収益不動産の欄と形が変わり、同じ値を2通りの形で見せることになるので採らなかった。
- 働き方の期間ごとに欄を置く: 申告は人ごとで、自営の期間が2つある人に2か所出るので採らなかった。
- 物件だけの人にも推定の印を付ける: 物件のある見本の世帯の「推定で計算中」が増えるが、結果は10万円の控除の分しか動かないので採らなかった。
- 簡易のヒアリングシートにも聞く: 簡易の票は年収の1問にした短い票なので、増やさない。

## 影響

- **計算の結果**: エンジン・制度データ・見本とモデル世帯のファイルは変えていないので、**どの見本・モデル世帯の数字も変わらない**（入れていない人は今までどおり白色で計算する）。変わるのは FP が青色を入れたときで、そのときの差（青色65万円・55万円・10万円にしたとき、白色との差。2028年の分は計算基準年の翌々年で、控除が所得の年の翌年度の住民税・国民健康保険料にも効く年）:

  |---|---|---|---|
  | 見本の自営業の夫婦と子2人（`sampleSelfEmployedFamily`。事業所得 年850万円） | 13.25万円・6.5万円・0円（上限）・0円 | 663万円／563万円／104万円 | 2073年末 +1,505万円／+1,287万円／+242万円（運用益を含む） |
  | `selfEmployed`（表は2060年まで） | 9.54万円・5.64万円・6.83万円・1.63万円 | 444万円／380万円／67万円 | 2060年末 +454万円／+389万円／+69万円 |

- **画面**: 見本の自営業の世帯と、事業所得のある人のいる世帯で、働き方と収入が「推定で計算中（1か所）」になる（申告の仕方の推定）。収益不動産で事業的規模の目安に当たる人・事業所得のある物件の持ち主は、収益不動産の「申告」にも同じ推定の印が付く。物件だけの人は今までどおり。
- 前に「白色」を選んで欄ごと外れていた世帯は、事業所得のある人なら推定の白色に見える（計算は同じ）。「この値にする」で確定にできる。
- **形式**: 世帯ファイルの形式の版は変えない（`members[].taxReturn` は 0.33 から、`white` は前から書ける値）。ヒアリングシートは `full` 版4（書き出せる詳細の票）。
- テスト: `app/test/tax-return-input.test.ts`（出る人・標準・推定と確定・2か所で同じ値・副業の事業所得・計算に効く・標準の欄の数・ヒアリングシートから入る）、`app/test/card-rental.test.ts`（白色を書く・空で外す）、`app/test/documentGuides.test.ts`（事業所得だけの世帯で手引きの見本が全部入る）、`hearing/test/taxReturn.test.ts`（版4 の定義・取り込みの4つの答え・入れない答え・自営業でない人・前回の値・見本の往復）、`hearing/test/web.test.ts`（自営業だけ聞く）、通しの入力のテストの世帯②（自営業のひとり親が働き方と収入で青色65万円を入れ、白色より所得税・住民税が下がる）。

## 追記
