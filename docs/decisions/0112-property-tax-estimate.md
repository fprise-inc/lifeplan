# 0112. 固定資産税・都市計画税の推定（購入の予定の持ち家の最初の年の額と、新築の軽減・評価替えの段）

- 状態: 採用（一部未確定）（2026-11-03。同日に今住んでいる持ち家の推定を追記）
- 固定の強さ: 推定は画面の側で世帯に入れる（最初の年の額は固定資産税の欄の推定、変化は「今の額に対する割合」の段の推定）こと、計算エンジンは固定資産税を計算しないこと（今の `residence.propertyTax` の読み方のまま）、法令で決まる値を事務所で変えられないことは骨格。式・目安の値・根拠の文・段の置き方は後から変えてよい（変えたら追記に書く）
- 前提にする記録: 0008 の2（推定）、0040（段階と例外の年）、0041（値の状態）、0049（推定の段階の決まり）、0052（住まい・ローン。2026-11-03 の追記の購入の種類）、0111（事務所の推定の値）

## 背景

- 購入の予定の持ち家の固定資産税は、目安のボタンの値（年12万円）の1つの額で、物件の価格にも新築か中古かにもよらなかった。新築の軽減（建物の分が半分）が終わる年に上がり、3年ごとの評価替えで建物の分が下がっていく動きは、FP が「＋ 固定資産税の変化」で手で入れるしかなかった。

## 決定

### 1. いつ入れるか

- 購入の予定の持ち家で、固定資産税の欄が推定のまま（目安のボタンの値か、この推定）のとき。「＋ 住宅購入の予定」で足したときと、購入の種類（0052 の 2026-11-03 の追記）を選んだときに入れ、その後は推定のままの欄と推定の段だけを、入力を直すたびに入れ直す（`refreshEstimates`。0008 の追記 2026-10-26 の3）。
- 今住んでいる持ち家は推定しない（今の目安のボタンの値のまま）。納税通知書があるはずで、建物の価格・建った年が分からないことが多く、推定のほうが外れやすい。
  - 改めた（2026-11-03 の追記）: 今住んでいる持ち家も、固定資産税の欄が未入力か推定のままなら、持ち家の評価の欄から推定する。
- FP が固定資産税の欄に額（納税通知書・販売会社の試算の額など）を入れたら、その額が優先（入れ直さない）。推定の段は「今の額に対する割合」なので、その額を元に同じ形で動き、割合は入れ直し続ける。FP が直した段・足した段は変えない。FP が外した推定の段は覚えて足し直さない（0049 の推定の段階と同じ決まり。「該当なし」の行）。

### 2. 式

- 土地の評価額 L＝物件の価格×土地の割合（持ち家の評価の土地の割合。空なら前提条件の値か目安の30%）×土地の評価額の割合。建物の評価額 B＝物件の価格×（1−土地の割合）×建物の評価額の割合。
- その年の税＝L×1/6×1.4%＋L×1/3×都市計画税率＋B(年)×1.4%×（新築の軽減の間は1/2）＋B(年)×都市計画税率（100円に丸める）。
- B(年)＝B×g(その年に効いている評価替えの年−建った年)÷g(最初の年の同じ年数)。g(a)＝max(下限, 1−(1−下限)×a÷下限まで下がる年数)。評価替えの年は2024年から3年ごと。
- 最初の年は購入の翌年（1月1日の持ち主にかかる）。計算エンジンは住み始めの年から欄の額を払うので、購入の年もこの額（引き渡しの精算の目安）。
- 新築の軽減は、建った年の翌年から、戸建て3年・マンション5年（長期優良住宅は戸建て5年・マンション7年）。新築は建った年を入れていなければ購入の年に建ったとみなす。中古は建った年を入れていれば、その年からの残りの軽減を当て、入れていなければ購入の年に建ったとみなして軽減を当てない（根拠の文に書く）。
- 段: 最初の年の次の年から、住み終わりの年と計算の最後の年の早いほうまで、税の額が前の年と変わる年に「この年から先」の割合の段（最初の年の額に対する割合）を置く。軽減が終わる年は上がり、評価替えの年は下がり、下限に届いたら止まる。土地の分は横ばい。
  - 割合は小数1桁の％（0.001 刻み。例 97.7%）にそろえて入れ、計算もその値で行う（根拠の文の％と同じ値）。そろえた割合が前の段と同じ年は段にしない。FP が打つ割合の桁は今のまま。
  - 固定資産税の変動率は空のまま（0）にする。計算は段の額に、計算の基準の年からの年数分の変動率を掛ける（`housing.residence`）ので、変動率を入れると段に加えて毎年動く。推定の段があるときは、変動率の欄の説明と欄の下の一言でこの関係を知らせる（評価替えの下がり方は段に入っているので、ふつうは入れない）。
- 長期優良住宅か: つながる住宅ローンに控除の条件があれば、その住宅の種類が認定住宅（長期優良住宅・低炭素住宅）か。ローンを組まない人（控除の条件が無い）は、住宅の購入の詳細の「長期優良住宅（認定）」（`residence.purchase.longLife`。表示と推定の元だけで計算に使わない。形式 0.53）。

### 3. 目安と法令の値

- 目安（事務所の推定の値。`hearing/src/presets.ts`。0111）: 土地の評価額の割合 70%（公示価格の7割程度）・建物の評価額の割合 60%（建築の価格の5〜7割）・都市計画税の税率 0.3%（上限で止める）・建物の評価額の下限 20%・下限まで下がる年数（木造・軽量鉄骨造 30年、重量鉄骨造・鉄筋コンクリート造 60年）。
- 法令の値（`app/src/workspace/input/propertyTax.ts` の `PROPERTY_TAX_LAW`。事務所で変えられない。`docs/estimates-review.md` の「一覧に入れていない値」）: 固定資産税の標準税率 1.4%、都市計画税の上限 0.3%、小規模住宅用地の特例（固定資産税 1/6・都市計画税 1/3）、新築住宅の減額（建物の固定資産税の1/2、戸建て3年・中高層の耐火のマンション5年、認定長期優良住宅は5年・7年）、評価替えの3年ごと。
- 根拠の文は「固定資産税の推定（…）」で始め、最初の年の額には価格・土地の割合・種類・評価額の割合・特例と軽減を、段には理由（軽減が終わる・評価替えで築何年の分だけ下がる・下限で止まる）と、固定資産税の欄の額に対する割合を書く。

## 理由

- 画面の側で世帯に入れる: 推定の値は FP が見て直す物（0008 の2）で、根拠の文を欄に出せる。計算エンジンに式を持たせると、FP が直す口が無くなり、一致テスト・制度データの手続きも要る。今の段の部品（0040）だけで表せる。
- 割合の段: FP が実際の額を入れたときに、軽減の終わり・評価替えの形をそのまま残せる（額の段だと、FP の額と食い違う）。
- 法令の値を制度データ（`data/regulation/`）に置かなかった: 計算エンジンが固定資産税を計算しないので、パックに置いても読む部品が無い。画面の側の法令の値（耐用年数・自動車税など）と同じく、コードの1か所に条文の番号を添えて置き、見直しの一覧に載せる。

## 代案（採らなかったもの）

- 計算エンジンで固定資産税を推定する: 上の理由。
- 段を毎年の少しずつの下げ（「何年かけて移すか」）で表す: 評価替えは3年ごとに変わるので、実際の動き（3年ごとの段）に合わせた。
- 今住んでいる持ち家も推定する: 上の1。（2026-11-03 に改めて採った。追記の1〜3）

## 追記（2026-11-03）: 今住んでいる持ち家の推定と、未確定の残りの決定

### 1. いつ入れるか

- 今住んでいる持ち家（購入の予定でない持ち家）で、持ち家の評価の評価額（`valuation.value`）が入っているとき。推定の元は、評価額・その額の時点（`valuation.asOf`。空欄は計算の基準の月）・土地の割合（空なら前提条件の値か目安の30%）・建物の構造（空なら建て方から）・建った年（`valuation.builtYear`）・建て方（`style`）と、この家につながる住宅ローンの控除の住宅の種類（認定住宅なら長期優良住宅）。どれも既にある欄で、世帯ファイルの形式は変えない。
- 入れる時:
  - 持ち家の評価の欄（評価額・時点・構造・建った年・土地の割合）か建て方を直したときに、固定資産税の欄が未入力（欄が無い・空）か推定のまま（目安のボタンの値を含む）なら入れる（FP が推定の元を入れた時。購入の予定の「足したとき・種類を選んだとき」に当たる）。
  - 固定資産税の欄を空にしたとき（「推定に戻す」を含む）。評価額が無ければ、今までの目安のボタンの値（年12万円）。
  - その後は、この推定のままの欄（書類で確かめるにしたときの代わりの値がこの推定のままのものを含む）と推定の段だけを、入力を直すたびに入れ直す（`refreshEstimates`）。
- 目安のボタンの値（ひな形）は、評価の欄を直すまで変えない（ほかの入力を直したときの入れ直しで、保存した世帯の結果が変わらないように）。
- FP が入れた額（納税通知書の額）が優先。推定の段があれば、購入の予定と同じく割合の段として入れ直し続ける。FP が先に額を入れていた家には、評価の欄を入れても段を足さない。FP が外した推定の段は足し直さない（同じ印。2 の「段」）。
- 評価額を消したら、この推定のままの欄は目安のボタンの値に戻し、推定の段を外す（FP が直した段は残す）。
- ヒアリングシートの取り込みは変えない（シートに評価額の欄が無い。空欄・「わからない」は今までどおり欄を作らず「固定資産税が未記入」の確かめ。画面で評価の欄を入れたときに推定で埋まる）。

### 2. 式（購入の予定の推定との違い）

- 式・目安の値（事務所の推定の値 0111 の6値）・法令の値（`PROPERTY_TAX_LAW`）・段の置き方・割合のそろえ方・根拠の文の頭（「固定資産税の推定」）・段の印は、購入の予定と同じ。
- 最初の年は計算の基準の年（欄の額はその年の額。計算エンジンは計算の基準の年から欄の額を払い、段を当てる）。段は次の年から、住み終わりの年と計算の最後の年の早いほうまで。
- 評価額は、その額の時点の土地と建物の合計（多くは購入の価格と購入の年月。欄の説明のとおり）。L＝評価額×土地の割合×土地の評価額の割合、B＝評価額×(1−土地の割合)×建物の評価額の割合を、その額の時点の評価額とする。
  - 建物: B(年)＝B×g(その年に効いている評価替えの年−建った年)÷g(その額の時点に効いている評価替えの年−建った年)。評価替えの年は2024年から3年ごとの並びを前にも延ばす（2009・2012・…・2021年）。
  - 土地: その額の時点の価格のまま（伸ばさない）。
- 建った年が空欄なら、持ち家の評価と同じくその額の時点の年に建ったとみなし、新築の軽減は当てない（根拠の文に書く）。建った年が入っていて、計算の基準の年が軽減の間（建った年の翌年から戸建て3年・マンション5年、長期優良住宅は5年・7年）なら軽減を当て、終わる年に上がる段を置く。
- マンションか: 建て方（空なら建物の構造が鉄筋コンクリート造か）。
- 根拠の文: 「固定資産税の推定（○年の額。評価額○万円（○年）・土地の割合○%・戸建て（木造）・○年に建った（築○年）。評価額は土地が価格の70%・建物が価格の60%の目安で、建物は評価替えごとに古くなった分だけ下げた（下限は20%）。土地は○年の価格のまま。住宅用地の特例〔・新築の軽減（…年まで）〕を当て、都市計画税0.3%を含む〔。建った年が分からないので…〕）」。

### 3. 決めたこと（理由）

- **評価の欄を直した時に入れる（入力を直すたびには、目安のボタンの値を推定に変えない）**: 目安のボタンの値はひな形（0111 の2回目の「効く所」）で、ほかの入力を直しただけで額が変わると、保存した世帯の結果が知らないうちに変わる。FP が評価額などを入れた時は、推定の元を渡した時なので、そこで入れる（購入の予定で、足したとき・種類を選んだときに入れるのと同じ考え）。
- **土地は時点の価格のまま**: 持ち家の評価（0025）は土地を前提の上昇率（空なら物価上昇率）で伸ばすが、土地の評価額は3年ごとの評価替え（公示価格の7割程度）と負担調整でなだらかにしか動かず、昔の購入の価格を物価上昇率で伸ばすと税を多く見すぎることがある。購入の予定の推定も土地を横ばいにしている。地価が大きく動いた家は、FP が今の評価額と時点を入れるか、納税通知書の額を入れる。
- **建った年が空欄なら軽減を当てない**: 中古の購入の予定と同じ。分からない軽減で税を少なく見せない（支出を少なく見るほうが計画では危ない）。
- **その額の時点の評価額に評価額の割合を当てる**: 中古の購入の予定（購入の価格に割合を当てる）と同じ形にした。中古で買った家は、建物の売値が評価額より早く下がるので、建物の分を少なめに見る傾向がある（根拠の文に元の額を書き、FP が納税通知書の額で直せる）。
- **計算の基準の年を最初の年にする**: 今住んでいる家の欄は「今の額」で、計算エンジンは計算の基準の年から欄の額を払う（`housing.residence`）。

### 4. 推定の値の見直し・事務所の推定の値

- 新しい目安の値は足さない（購入の予定と同じ6値を読む。`docs/estimates-review.md` の2章の行に「今住んでいる持ち家にも」と書いた）。事務所の推定の値で上書きすれば、どちらの推定にも効く（0111）。

### 5. 未確定の残りの決定（推測で決められるもの）

- **床面積**: 欄を足さない。住宅用地の特例は1戸あたり200㎡以下（小規模住宅用地）、新築の軽減は120㎡以下の部分とみなす（多くの家に当てはまる）。広い家は、FP が納税通知書の額を入れる（根拠の文に元の数を書いている）。
- **負担調整**: 入れない。住宅用地の多くは、今は本則の額（負担水準100%）に届いているため。
- **市区町村ごとの税率**: 世帯ごとの欄は足さない。都市計画税の税率は事務所の推定の値（地域に合わせて事務所で変えられる。かからない所は0）、固定資産税の税率は標準税率1.4%（超える税率の市町村は少ない）。違う所は FP が額を入れる。
- **新築の軽減の期限**: 延長が続くとみなす（今までどおり）。法令の値の見直し（`docs/estimates-review.md` の「一覧に入れていない値」）で、改正のたびに確かめる。
- **低炭素住宅**: 見分けない（認定住宅は長期優良住宅とみなす）。認定住宅の多くは長期優良住宅で、違いは建物の軽減の2年分（建物の分の半分）だけ。見分けるには住宅ローン控除の住宅の種類の選択肢を分ける（世帯ファイルの形式が変わる）必要があり、見合わない。低炭素住宅の家は、軽減が終わる年の段を FP が直す。
- 声を聞かないと決められないもの（再建築費の見直し・ヒアリングシートの欄・収益不動産）は未確定に残した。

### 影響

- `app/src/workspace/input/ownedHomeTax.ts`（新）、`propertyTax.ts`（目安・丸め・文の作りを書き出すだけ。式は変えない）、`estimates.ts`（入れ直し）、`stages/housing.ts`（固定資産税の欄を空にしたときの推定・評価の欄と建て方を直したときに入れる）、`app/test/owned-home-proptax.test.ts`（新）、`docs/estimates-review.md`。
- 計算エンジン・世帯ファイルの形式・見本の世帯の結果は変わらない（推定は評価の欄を直したときと、固定資産税の欄を空にしたときだけ）。今住んでいる持ち家で、評価額を入れていて固定資産税が目安のボタンの値の世帯は、評価の欄を直すと固定資産税の額と段が変わる。
