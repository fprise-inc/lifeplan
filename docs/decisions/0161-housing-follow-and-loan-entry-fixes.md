# 0161. 住まい・ローンのつなぎ目の直し（購入の予定を外したときの住み終わり・空き家の持ち始めと毎年の費用・入れ方を変えたときの推定の残高・今の残高だけのローン・購入にローンが無いときの知らせ・返せない返済額）

- 状態: 採用（一部未確定）（2026-11-08）
- 固定の強さ: 内部（入力の画面の決まりだけ。世帯ファイルの形式の版・計算エンジンの部品は変えない）
- 前提にする記録: 0008（世帯のデータモデル。購入とつながる住宅ローンの借入額の知らせ）、0041（値の状態）、0052（住まい・ローンのカード・入れ方の区分）、0123（貸していない不動産の毎年の費用）、0129（ありえない結果の見張り）、0136（住み替えの初めの値）

## 背景

バグの調査（つなぎ目のコードレビューと、開発中のアプリを触る探索）で、住まい・ローンの入力項目に、結果を誤らせる物がまとまって見つかった。

1. 住宅購入の予定を外しても、住み替えで画面が入れた今の持ち家の住み終わり（購入の前の月）と「住み終わりの月に売る」が残り、家を売ってその後の住居費0円で計算していた。賃貸の住み終わりも同じ。
2. 「空き家として持ち続ける」で作った空き家は、購入の時期を直して今の家の住み終わりが動いても、持ち始める時点がついてこなかった（同じ家を二重に数える・つながりが切れて「空き家として持ち続ける」がまた出る）。住み終わりの欄を直接直したときはついてきていた。
3. その空き家に毎年の費用（固定資産税の目安）の行が入らず、ずっと0円だった。推定・未入力の印も出なかった。
4. 「＋ 住宅ローン」（入れ方の既定は「今の残高から」）で足し、入れ方を「借入額から」に変えると、画面が置いた推定の今の残高（3,000万円）と残高の時点が残り、借りた年からの返済が無かったことになっていた。
5. 入れ方が「今の残高から」でないローン（収益不動産のローンなど）で今の残高だけを入れると、残高の時点が空のままで、計算は残高を使わないのに、一覧には残高が出ていた。
6. 住宅購入の予定にローンを付けないと、物件の価格から頭金を引いた額が、払いにも借入にも出なかった（家は資産に入るので純資産が膨らむ）。知らせも無かった。
7. 今の残高から入れた住宅ローンで、完済の年月を直して入れた返済額では返せなくなると、黙って返済額が書き換わった。返せない返済額を打つと「入れました」と出て、値は前のまま。

住み替えの初めの値「今の持ち家を、住み終わりの月に売る」は利用者の判断（0077・0136 の追記）で、変えない。

## 決定

### 1. 住宅購入の予定を外すと、その購入のために住み終わりにした今の住まいを戻す

- 「＋ 住宅購入の予定」は、今の持ち家と同じく、住み終わりにした今の賃貸（家賃なしを含む）にも住み終わりの仮の印（`MOVE_OUT_RENT_ASSUMED`。「住み替え: 購入の前の月で住み終わるとみなしています（直してください）」）を付ける。
- 購入の1件の「外す」は、住み終わりの仮の印（`MOVE_OUT_ASSUMED`・`MOVE_OUT_RENT_ASSUMED`）が残っていて、住み終わりが外す購入の前の月の住まいを、住み終わり空（最後まで住む）に戻し、初めの値で入れた「住み終わりの月に売る」（中身の空の `sale`）と仮の印（住み終わり・住み終わりの後）を外す（`undoMoveOut`）。
- 戻さない物: FP が住み終わりを直した住まい（仮の印が外れている）、売却価格などを入れた家、空き家を作った家（FP が先へ進めた物として残す。住まいの無い期間の知らせが出る）。

### 2. 空き家の持ち始める時点は、どの道で住み終わりが動いてもついてくる

- 購入の時期を直したときに前の住まいの住み終わりをついてこさせる所（`followPurchaseMonth`）でも、その家から作った空き家（`heldFromHome`。持ち始め＝住み終わりの翌月で見分ける）を先に引き、持ち始める時点と評価額の時点を新しい住み終わりの翌月にする。住み終わりの欄を直したときと同じ関数（`moveHeldStart`）を使う。
- つながりを月の一致でなく空き家の側に元の住まいの ID で持つ形は、形式の版に触れるので取らなかった（未確定）。

### 3. 「空き家として持ち続ける」でも毎年の費用の目安を入れる

- 作ったときに、貯蓄・運用で中身「空き家」を選んだときと同じく、固定資産税の目安を推定の行で入れる（0123 の `applyHeldEstateCost`。行が無ければ入れる）。持ち始めが動けば、推定のままの行は入れ直しで追う。

### 4. 入れ方を「借入額から」「毎月の返済額から」に変えたら、推定の今の残高を外す

- 「今の残高から」から変えたとき、今の残高が画面の置いた推定（出どころ auto の推定）なら、今の残高と残高の時点を外す。借入額・借入の年月・金利・期間から返す。FP が入れた残高は消さない（入れ方を変えても値は消えない決まりのまま）。「今の残高から」に戻すと、今までどおり借入額から計算した残高を推定で置き直す。

### 5. 今の残高を入れたら、残高の時点が空なら計算の基準の月にする（どの入れ方でも）

- 今までは「今の残高から」の欄だけがそうしていた。収益不動産のローン・「借入額から」の住宅ローンの今の残高の欄でも同じにする（欄の説明「入れなければ借入額と金利から計算します」は、入れれば使うと読めるため）。今の残高を空にしたら、残高の時点も外す（残高の無い時点は計算に効かない）。
- 借入額の推定が残高より小さいときに借入額を合わせ直すことはしなかった（計算は残高の時点からの残高で返すので、結果には効かない）。

### 6. 購入の予定にローンが無いときは知らせる（自己資金で払う形にはしない）

- 決めたこと: 計算を変えて残りを預金から払う形にはせず、**知らせを出す**。0008 で、購入とつながるローンの借入額の合計が「物件の価格−頭金」に足りないときは「足りない分は預金からも払わず計算に入らない」と知らせる決まりにしてあり、ローンが1本も無いときも同じ扱いにそろえる（ローンの足し忘れが多く、黙って預金から払うと、足し忘れに気づけないまま結果が大きく変わるため）。自己資金で払うなら、頭金を物件の価格と同じ額にすれば知らせは消える。
- 見分け方: 購入の予定の持ち家に、つながる住宅ローン（控除の条件の住まいがその家か、借入の年月が購入の月。注文住宅は土地の決済の月も。`purchaseLoans`）が無く、物件の価格−頭金が0円より大きい。
- 出す所: 物件の価格の欄の下（`warn`）と、確かめの一覧の確かめの注意（物件の価格が推定のままでも出す）。「＋ 住宅ローンを足す（物件の価格−頭金を借りる）」のボタンを添える（「＋ 住宅ローン」は最後に足した購入の予定とつなぐので、その購入が最後のときだけ）。
- ありえない結果の見張りに決まり `purchaseUnfunded`（購入の予定にローンが無いときは知らせが出ている）を足した（0129 の決まりは17個になった）。

### 7. 返せない返済額は入れずに理由を出す

- 欄の定義に `refuse`（読めた値でも、ほかの入力と合わず書けないときの理由）を足した。入力の画面は、打っている間と離れたときに理由を欄の下に出し、書かない（「入れました」にしない）。
- 今の残高から入れたローンの毎月の返済額: 住宅ローンは、今の残高・完済の年月までの回数で金利を解けない（金利がマイナスになる）とき、ほかのローンは利息にも足りず返し終わらないときに、理由を出して書かない。
- 入れた返済額から金利を逆算した後に、完済の年月・残高を直してその返済額では返せなくなったときは、今までどおり前の金利のまま返済額を計算し直し、返済額の欄に「入れた毎月の返済額（○円）では、完済の年月までに返せません（金利がマイナスになります）。今は金利 年○% のまま、返済額を計算し直しています。返済額か完済の年月を直してください」と出す（入れた返済額は、逆算の金利の行の根拠の文から読む）。返せる組み合わせなら、今までどおり入れた返済額のまま金利を解き直す。

## 理由

- 画面が自分で入れた物（住み終わり・売る・空き家・推定の残高）は、元になった操作を取り消したり動かしたりしたときに追わないと、FP の知らないうちに結果がずれる。追うのは仮の印・推定のまま（FP が直していない）の物だけにして、FP の入れた値は変えない（0041）。
- ローンの無い購入を黙って自己資金で払う形にすると、ローンの足し忘れが見えなくなる。0008 の「足りない分は計算に入らない・知らせる」とそろえた。

## 影響

- 計算の結果が変わる所（見本の棚・モデル世帯の結果そのものは変わらない。どれも画面の操作の後だけ）:
  - 持ち家の世帯で「＋ 住宅購入の予定」を足して外すと、足す前と同じ結果に戻る（`dualAssetsTwoKids` で、表の最後の年の金融資産が約1.83億円 → 約6,120万円。前は外しても家を売った形のままだった）。
  - 空き家として持ち続けた後に購入の時期を後ろへずらした世帯: 家を二重に数えなくなる（`dualAssetsTwoKids` で1年ずらすと、2028年に数えていた空き家の分 約3,758万円が無くなる）。
  - 「空き家として持ち続ける」を押した世帯: 毎年の費用の目安が入る（`dualAssetsTwoKids` で年 18.73万円）。
  - 「＋ 住宅ローン」の後に「借入額から」に変えて借入額・借入の年月を入れた世帯: 借りた年からの返済で計算する（3,000万円・2015年4月・年0.85%・35年で、2027年の住宅ローン残高が約2,874万円 → 約2,016万円）。
  - 今の残高だけを入れた収益不動産のローン: 残高から返す（調査の例で、返済が年約100万円多く、残高が約1,900万円多くなる）。

## 追記

- 2026-11-08（0175）: 6 の「購入の予定にローンが無いときは知らせる」を、利用者の判断で改めた。物件の価格の次に「どう買うか」（現金で買う・住宅ローンを使う）の欄を置き、まだ選んでいない世帯（つながるローンが無く、頭金が物件の価格より少ない）はその欄の未入力の印と確かめの一覧で知らせる（物件の価格の欄の知らせと「＋ 住宅ローンを足す」のボタンはやめた）。現金で買うはつながるローンを外して頭金＝物件の価格、住宅ローンを使うはこの購入とつないだ住宅ローンを足し、その欄を住宅の購入の中に続けて出す。世帯ファイルには持たず、今の形から読む。詳しくは 0175 の2。
