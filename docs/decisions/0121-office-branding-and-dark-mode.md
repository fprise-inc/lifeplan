# 0121. 事務所の見た目（基調の色・事務所の名前とロゴ）と、暗い画面（画面の明るさ）

- 状態: 採用（一部未確定）（2026-11-05。同じ日に、暗い画面を画面から選べなくする・資産と負債の図の科目の色を変えない・左上の名前のかざしたときの説明を外すを利用者の判断で決めた。追記）
- 固定の強さ: 内部（事務所データの任意の欄 `branding` と画面の作り）。事務所データの形式の版（`0.1`）・世帯ファイルの形式の版は上げない（足すだけの欄。世帯には何も写さない）。ロゴの画像を PNG と JPEG だけにすること・画面で画像を URL にしないこと（CSP の `img-src 'self'` を変えない）は 0016 の決定に従う物で、変えるときは 0016 と一緒に変える。意味を持つ色（不足の赤・注意〔推定〕の橙・済みの緑・グラフの複数のプランの色）を基調の色で変えない決まりは、変えるときは追記に書く。色の導き方・見本の色・文言・並べ方は後から変えてよい
- 前提にする記録: 0009（提案書の帳票）、0011 の6（事務所データ）、0016（CSP・画像は PNG と JPEG だけ・提示層）、0023（事務所での共有）、0030（持ち帰り用のレポート）、0073（事務所の既定値）

## 背景

- FP 事務所ごとに見た目を変えたいという利用者の判断（3つ）: (1) 画面（特に結果）の基調の藍を、事務所の設定で変えられるようにする。(2) 暗い画面（明るい・暗い・OS に合わせる）を選べるようにする。(3) 左上の「ファイナンシア」とその印を、事務所の名前・ロゴに差し替えられるようにする。
- 色は `app/src/styles/*.css` の色の決め事（`--prop` など）にまとまっていたが、白（`#fff`）・薄い灰・藍の薄い塗り（`rgba(43, 76, 140, …)`）が各所に直書きで約 270 か所あり、暗い画面にも別の基調の色にもそのままでは追いつかなかった。
- 0016 は「ロゴなどの画像は PNG と JPEG だけ・大きさに上限・SVG は受けない」と決め、帳票のロゴの置き場所はカスタム層の `settings/` と書いていたが、作ってはいなかった。画面の CSP は `img-src 'self'` で、`data:`・`blob:` の画像は表示できない。

## 決定

### 1. 置き場所と共有のとき

- 事務所データ（暗号化。0011 の6）に任意の欄 `branding` を足す: 事務所の名前（40文字まで）・基調の色（選んだ色 `#rrggbb`）・画面の明るさ（`light`・`dark`・`system`。`dark` のときだけ暗い画面。画面からは選べない。追記）・ロゴの画像（種類・縦横の画素・バイト。JSON では base64 の文字）。欄の無い古い事務所データは「決めていない」（今の見た目）と読む。全部空なら欄を外す。
- 事務所の既定値（0073 の `defaults`）とは別の欄にした。画像のバイトを持つので大きく、PNG・JPEG かどうかを本体が確かめるため（`defaults` は形を画面が確かめる JSON）。
- 本体の命令 `office_branding_get`・`office_branding_put`（確かめて整えた値を返す）・`office_logo_pick`（本体のダイアログで PNG・JPEG を選ばせ、確かめた画像を返す。保存はしない。パス・ファイル名は返さない）。
- **事務所で共有しているとき（0023）も、この PC の設定**（共有フォルダには置かない）。事務所の既定値（0073）と同じ作りに合わせた。メンバーには伝わらないので、各 PC で決める（画面にもそう書く）。
- 世帯には写さない（見せ方だけ。変えるとどの世帯にもすぐ効く）。計算の結果は変わらない。

### 2. 基調の色（`presentation/theme.ts`）

- 選んだ色1つから、明るい画面と暗い画面の `--prop`・`--prop-ink`・`--prop-bg` を導き、画面が `html` の style に CSSOM で入れる（CSP の `style-src` に触れない）。基調の色の薄い塗り（`--prop-area`・`--sel-bg`、表の差の行・選んだ案の地など）は CSS の中で `--prop` から `color-mix` で作る。標準の藍のままなら何も入れない（明るい画面は今までと同じ見た目）。
- **見やすさ**: 色相と彩度を保ち、明るさ（OKLCH の L）だけを直す。明るい画面は白地とのコントラスト比 4.5:1 以上（白抜きの文字も同じ比）、暗い画面はカードの地で 5.5:1 以上（暗い文字を重ねても同じ比）。足りない色は自動で濃く（暗い画面では明るく）して、画面に「少し濃くして使います（#…）」と知らせる。黒に近い色は少し明るくする。
- **意味を持つ色と紛れる色は使えない**（直さずに断り、「この見た目にする」を押せなくする）: 不足の赤（`--short`・`--short-ink` との OKLab の距離 0.09 未満）、推定の印の橙（`--est`・`--est-ink` と 0.06 未満）、彩度の低い灰（現状のプランの灰と見分けにくい）。「済み」の緑に近い色（0.05 未満）は使えるが知らせる（✓ の印で見分けられる）。
- **変えない色**: 不足・注意・済み・グラフの複数のプランの色・資産と負債の図の科目の色（箱の色と、図の外の純資産の金額の文字の色。画面の `--bs-netWorth-ink`・提案書の `bs-net-ink`）は、基調の色を変えても変わらない（追記）。
- **見本の色**（どれも上の確かめを通る落ち着いた色）: 藍（標準 `#2b4c8c`）・青緑 `#24606b`・緑 `#2d5a46`・茶 `#5c4033`・えんじ `#7a2a4f`・紫 `#4a3b72`。ほかに自由に選べる（色の選び方と番号の欄）。
- **提案書（PDF）**: 見出しの番号の箱・見出しの線・グラフの提案の線などのアクセントの色（帳票の `accent`）に、明るい画面の基調の色を使う。画面が `proposal_render` に `accent` として渡し、本体は `#rrggbb` で白地に 4.5:1 以上のときだけ使う（そうでなければ帳票の標準の色）。帳票の部品は Typst の `sys.inputs` の `lifeplan-accent` から読む（無ければ標準の `#1d5fa8`。標準の藍のままの事務所は今までと同じ PDF）。
- **持ち帰り用のレポート（0030）**: 中身に任意の欄 `accent`（明るい画面の色）を足し、画面の部品が `.tk` の style に入れる。後から足した任意の欄なので版は 1 のまま（無ければ藍）。

### 3. 暗い画面（画面の明るさ）

- ~~右上の文字の大きさの右に、画面の明るさのボタンを置き、明るい・暗い・OS に合わせるを選べる。既定は OS に合わせる~~（追記で改めた: 画面には選ぶ所を出さず、標準は明るい画面だけ。OS の設定でも暗くしない。暗い画面は個別のカスタマイズで `branding.appearance` に `dark` を入れたときだけ）。
- `html.dark` の class で色の決め事を入れ替える（`app.css` の「暗い画面」の区切り）。地を暗く・文字を明るくし、塗りの強い色（基調の色・墨・不足・注意・済み）は同じ色相のまま明るくして、その上の文字（`--on-fill`）を暗くする。白の直書きはすべて `--card`（地）か `--on-fill`（塗りの上の文字）に、薄い灰・暖色・桃色の地は `--wash`・`--wash-warm`・`--wash-short` に置きかえた（明るい画面では元の値のまま）。
- グラフ: 複数のプランの色は、暗い画面だけ同じ色相の明るい色にする（意味の割り当ては変えない）。不足の面は、明るい桃色の面のままだと暗い地でまぶしいので、暗い赤の地に赤の斜線にする。資産と負債の図の不足の箱は暗い赤の地にする。
- **提案書と持ち帰り用のレポートは明るいまま**: 提案書の見本はページ（白い紙）をそのまま出す。持ち帰り用のレポートは `html.dark` の class を持たない別のファイルで、アプリの中の見本（`.tk`）も明るい色の決め事に戻す。

### 4. 左上のロゴと事務所の名前（`header/TopBar.tsx`）

- 事務所の名前・ロゴがあれば、「ファイナンシア」とその印の代わりに出す。ロゴがあればロゴ（高さ 24px・幅 132px まで）と名前、ロゴが無ければ名前だけ、両方無ければ今のまま。帯が狭いとき（`fit.ts` の段 2・3）は、ロゴがあれば名前を隠し、ロゴが無ければ名前を短く切る。
- **ソフトの名前の残し方**: 左上には事務所の物だけを出し、「ファイナンシア」は FP のメニューの「ファイナンシアへ」（要望・不具合を送る）に残す。名前にかざしたときの説明は出さない（追記で利用者の判断。見た目を設定しない事務所には今までどおり「ファイナンシア」と出るので、それで足りる）。
- **画像の出し方**: 画面は画像を `img` の URL（`data:`・`blob:` を含む）にしない。本体から受けたバイトを `createImageBitmap` で絵にして、キャンバスに描く（`presentation/LogoCanvas.tsx`）。CSP の `img-src 'self'` は変えない。読めない画像は名前だけにする。
- **提案書の表紙**: 本体が事務所データから事務所の名前とロゴを読み、表紙の上（題名の上）に出す（帳票の外枠の値 `frame.office` と、外枠の文書が読み込む `/logo.bin`。種類は `frame.logo` の `png`・`jpg`）。各ページのヘッダーには出さない（刻印の帯と同じく、帳票の外側の決まりを増やさない）。提案書の見本（SVG）の中の画像は、同じ場所に置いたキャンバスに描く（0016 の CSP のまま）。
- 持ち帰り用のレポートには、事務所名（今までの欄）を事務所の名前から最初に入れる。ロゴは入れない（残したこと）。

### 5. ロゴの画像の確かめ（0016）

- 本体（`household-store` の `branding.rs`）が、PNG（印と IHDR）・JPEG（SOI と SOF）の見出しから種類と縦横の画素を読む。256KB まで・縦横 8〜2000 画素。SVG・GIF などは `E_STORE_LOGO`、大きすぎは `E_STORE_LOGO_TOO_LARGE`。
- 保存の前に、アプリ本体が帳票の部品（Typst）で組んで PDF にしてみて、絵にできるかも確かめる（見出しだけ合っていて中身の読めない画像を、提案書を作るときまで持ち越さない）。

## 理由

- 色を1つだけ選ばせて導く: 事務所に色の決め事を全部決めさせると、見やすさと意味の色との区別を事務所が負うことになる。1色から導けば、確かめの決まりを1か所（`theme.ts`）に置ける。
- 断る色を作った: 不足の赤・推定の橙は、結果を読み違えさせる色。直して使うと選んだ色と違う色になるので、直さずに断り、別の色を選んでもらう方が分かりやすい。
- この PC の設定にした: 事務所の既定値（0073）と同じ。共有フォルダの名簿（0023 の骨格）に足すと、誰がいつ変えたかの扱いが要る。
- 明るさを事務所データに持った: 画面の側には保存しない決まり（0016）。この PC の設定の置き場所は事務所データしかない。

## 代案（採らなかったもの）

- 事務所の既定値（`defaults`）の中に入れる: 上の理由（画像の確かめを本体でしたい・大きさ）。
- `img-src` に `blob:` を足してロゴを `img` で出す: CSP を広げることになる（0016）。キャンバスで足りる。
- 暗い画面を CSS の `filter: invert()` で作る: グラフの色の明るさが逆になり、意味の色が崩れる。

## 追記

### 2026-11-05: 暗い画面は画面から選べなくする・資産と負債の図の科目の色を変えない・左上の名前の説明を外す（利用者の判断）

1. **暗い画面の切り替えは画面に出さない**: 右上の画面の明るさのボタンを外した。標準は明るい画面だけで、OS の設定（暗い画面）に合わせて自動で暗くすることもしない。暗い画面の色の決め事（`app.css` の `html.dark`）は残し、使えるのは個別のカスタマイズ（カスタム層・AI 経由で設定する形）からだけにする。今は事務所データの `branding.appearance` が `dark` のときだけ `html.dark` を付ける（`resolveMode`。`system`・`light`・無しは明るい画面）。画面のどこにも選ぶ所を出さない（開発の確かめ用の URL の `#look=dark` だけ残す）。入れる道（カスタム層の設定の名前・AI の道具）は未確定。
2. **基調の色の変更はそのまま**。資産と負債の図の科目の色は事務所の色を選んでも変えない: 箱の色はもとから固定。図の外の純資産の金額の文字（画面の `--bs-netWorth-ink`。前は `--prop-ink`）と、提案書の資産と負債の図・合算BS の章の純資産の金額の文字（前は `accent`）を、標準の藍の固定の色にした。
3. **左上の名前にかざしたときの説明（「○○事務所（ファイナンシア）」）は出さない**。FP のメニューの「ファイナンシアへ」はそのまま。見た目を設定しない事務所には、今までどおり「ファイナンシア」と出る。
