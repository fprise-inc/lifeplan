# 0032. お金の3つの分け方（使うお金・貯めるお金・増やすお金。説明用の図）

- 状態: 採用（一部未確定）（2026-10-21）
- 固定の強さ: 内部（画面と帳票の見せ方・言葉は、理由を残せば変えてよい）。ただし、計算の決まり（下の2: ふだんの支出とできごとの支出の分け方・数える年・賄えない分の出し方・「ほぼ同じ」の幅）と、世帯ファイルの表示の設定の欄（`display.balance.moneyThree`。形式の版 0.13）は骨格

## 背景

- FP は面談で「お金を、すぐ使う・近いうちに使う・しばらく使わない、の3つに分けて置きましょう」とよく説明する。これまでは FP が手で数字を出しており、世帯のライフプラン（これからの支出の予定）とつながっていなかった。
- ライフプランの計算には、毎年続く支出と、教育費・車・住まいの取得のような一時的・期間限定の支出の両方が年ごとに入っている。今の金融資産をこの2つと残りに分けて、今の置き場所（預金・NISA・iDeCo など）と並べれば、「預金が多すぎる／足りない」を数字で示せる。
- ただし、これは説明のための分け方で、計算の結果（キャッシュフロー表・資産が尽きる年）とは別のもの。0027（資産と負債のタブ）・0030（持ち帰り用のレポート）・0031（黒字のうち貯まる割合・運用しない分）が前提。

## 決定

### 1. 呼び方と置き場所

- 3つの呼び方の既定は「使うお金」「貯めるお金」「増やすお金」。資産と負債のタブの表示の設定で「すぐ使うお金」「近いうちに使うお金」「しばらく使わないお金」に変えられる。
- 置き場所は3つ（どれも同じ値・同じ並び・同じ言葉）:
  1. 資産と負債のタブのバランスシートの図の下の区画（主の置き場所）。何か月分・何年先までの欄はここに置く。
  2. 結果のタブの、グラフの下の一行の知らせ（ずれがあるときだけ）。「資産と負債で見る →」で 1 の区画へ移って光らせる。
  3. 持ち帰り用のレポートの1ページ（載せる画面で選べる。既定は載せる）と、提案書の1章「お金の3つの分け方（説明用の図）」（章の選択で外せる）。何か月分・何年先までは FP が決めた値を文で書き、顧客は変えられない。
- 計算するプランは、画面で選んでいるプラン（提案書は提案のプラン）。時点は「今の時点」（計算基準年。資産と負債のタブの「今」と同じ、その年の年末の残高）。

### 2. 計算の決まり（計算エンジンの側の関数 `engine/src/explain/moneyThree.ts`）

- 計算の結果の表（年ごとのマス）から出すだけの関数にする。`runEngine` の結果には入れず、計算エンジンのまとめた JS（`engine/dist/engine.js`）にも入れない（3つの実行環境のそろいのテストの対象は変わらない）。画面・持ち帰り用のレポート・提案書の側が同じ関数を呼ぶ。
- **ふだんの支出**: 毎年続く支出。基本生活費（車の維持費を含む）・住まいの費用（家賃・ローンの返済・固定資産税・修繕・管理費）・保険料・その他の支出（奨学金の返済・FP顧問料・使途不明金など）。
- **できごとの支出**: 一時的・期間限定の支出。教育費（`cf.expense.education`）・車の購入（`cf.expense.lumpSum.car`）と車のローンの返済（`cf.expense.debt.car`）・住まいの取得（`cf.expense.housing.purchase`）と繰り上げ返済・介護・一時的な支出（結婚・贈与・葬儀・その他）。周期的な支出（0008 の追記）は、2年以上ごとならできごと、毎年ならふだんの支出（載せる行に関係なく）。
- どちらにも数えない: ゆとりの支出（`cf.expense.living.surplus`。黒字から出る支出で、できごとのある年の黒字から決まるため。0031）と、取り崩しの計画で使うお金（`cf.expense.living.drawdown`。0026）。器の間の移動（積立）は支出ではないので数えない。
- **使うお金** ＝ ふだんの支出の月額 × 何か月（既定 6、1〜24）。ふだんの支出は計算基準年の値。計算基準月が年の途中なら、その年は数か月分しかないので翌年（1年分）の値で見る（資産と負債のタブの「生活費の○か月分」と同じ）。月額は年額 ÷ 12、使うお金は年額 × 月数 ÷ 12（どちらも円未満切り捨て。丸めの規則ID `conv.moneyThree.monthly`）。
- **貯めるお金** ＝ 今後 N 年（既定 10、1〜30）の各年について「できごとの支出 − 収入の残り」を出し、プラスの年だけを足す。収入の残り＝手取り収入（収入 − 税・社会保険料）− ふだんの支出。黒字の年の残りは次の年に繰り越さない。数える年は今の時点の翌年から（今の時点の残高は、その年のお金の動きの後の年末の値なので）。N 年がプランの最後の年を超えるときは、最後の年までで止め、そう書く。
- **増やすお金** ＝ 金融資産の合計 − 使うお金 − 貯めるお金。マイナスなら箱は 0 にし、「金融資産より○万円多い」と書く（足りない側の表示）。
- **今の置き場所**: 資産と負債のタブの「今」と同じ分け方（`report/src/bsGroups.ts`）の金融資産。「預金など」はすぐ使えるお金（預金・財形貯蓄）。合計の入れ方（まとめた金融資産）の運用しない分（0031 の3）は預金などに数える。
- **差** ＝ 預金など −（使うお金＋貯めるお金）。差の大きさが、ふだんの支出の1か月分より小さいときは「ほぼ同じ」とし、結果のタブの知らせは出さない。

### 3. 見せ方（3つの箱は同じ形。貯めるお金を基準にそろえる）

- どの箱も、額だけでなく「何が入っているか」をいつも見せる。形は3つとも同じ: 名前と額 → 中身の一文 → いつも見える中身の一覧 → まとめ（ほか○件）→ ひと言。
  - 貯めるお金: 一覧の各行は「年・できごと・賄えない分」。賄えない分が 0 の年は一覧に出さず、「収入で賄える年は入れていません」と添える。6件を超えるときは、賄えない分の大きい順に5件（年の順に並べる）と「ほか○件 ○万円」。全部の年の表（年・できごと・支出・収入の残り・賄えない分）は「内訳を見る」で開く（提案書は章の下に表で載せる）。
  - 使うお金: 「ふだんの支出 月○万円 × ○か月」と、中身の月額（基本生活費・住まい・保険料・その他）。
  - 増やすお金: 「金融資産 ○万円 − 使うお金 ○万円 − 貯めるお金 ○万円」の引き算を一覧で。
- できごとの名前は、構成員の呼び方（0012）と学校の入学の年（入学の年は「長男の大学入学」、大学の2年目からは「長男の大学2年目」、ほかは「長男の教育費」）、車の購入・買い替え、周期的な支出の見出し（無ければ載せる行の名前か「○年ごとの支出」）から作る。同じ年に複数あれば大きい順に「・」でつなぐ（4つ目からは「ほか」）。
- 図: 左＝使う時期で分けた3つの箱（上ほどすぐ使う。説明用なので薄い色＋同じ色相の枠）、右＝今の置き場所（バランスシートの図と同じ色のベタ塗り）。左右は同じ縮尺。左の「使う＋貯める」の下端を右の列まで点線でのばし、ずれている分に斜線と点線の枠と札を付ける。入りきらない箱の名前は図の下に一覧で出す（狭い幅でも読める）。
- 文は事実だけ。「『増やすお金』○万円のうち、○万円が預金のままです」「預金だけでは、『使うお金』と『貯めるお金』の分が○万円足りません」（足りないときは、その範囲に入っている置き場所と、金融資産の合計でも足りない分を添える）。勧める言葉（運用しましょう、など）は書かない。区画には「説明用の図です。キャッシュフロー表・結果の計算には混ぜません」と書く。
- 部品の置き場所: 提示用の値を作る部品は提案書と共用（`report/src/moneyThree.ts`。0027 の2と同じ考え方）で、アプリの側の入口は `app/src/workspace/moneyThree.ts`。画面の部品は提示層（`app/src/presentation/MoneyThree.tsx`）、帳票は `report/typst/report-core/pages/money3.typ`。持ち帰り用のレポートの画面が読める作業の層の部品に `moneyThree` を足す（0030 の2の lint）。

### 4. 設定の持ち方と形式の版

- 何か月分・何年先まで・呼び方は、資産と負債のタブの表示の設定として世帯ファイルの本文に持つ（`display.balance.moneyThree` ＝ `months`・`years`・`wording`（`use`・`time`）。キャッシュフロー表・結果の計算には使わない）。欄の名前は持たない情報の検査（0012 の3）に当たらないものにする。
- 形式の版を 0.13 に上げる（足すだけの MINOR。無ければ既定の 6か月・10年・使う／貯める／増やす。0.7 と同じ考え方: 0.12 までのアプリは知らない欄を読み落として書き戻さないので、閲覧だけにする）。変換の段（0.12 → 0.13）は版を書き換えるだけ。
- 持ち帰り用のレポートの中身（0030 の2）には、載せるときだけ `views.moneyThree` と `moneyThree`（同じ3つの値）を足す。画面の部品は同じファイルに入るので、中身の版（`financia.takeaway` の 1）は変えない。
- 提案書の入力（`lifeplan.proposalInput` 0.1.0。試験版）に任意の `moneyThree` と章 `moneyThree` を足す。

## 理由

- 計算エンジンの側の関数にしたのは、丸めと分け方の決まり（ふだんの支出とできごとの支出の境）を1か所にし、単体テストで固めるため。`runEngine` の結果に入れないのは、説明用の図をキャッシュフロー表・結果の計算と混ぜないため（入れると計算の結果の形と、3つの実行環境のそろいの対象が変わる）。
- 黒字を繰り越さないのは、年ごとの「その年の収入で賄えない分」の合計にすると、FP が顧客に1行ずつ説明でき、手で検算できるため。繰り越すと前の年の残りの使い道まで決めることになる。
- 数える年を今の時点の翌年からにしたのは、今の時点の残高（その年の年末）にその年のできごとの支出がすでに入っているため（二重に数えない）。
- 「ほぼ同じ」をふだんの支出の1か月分にしたのは、使うお金の単位（○か月分）と同じ物差しで、世帯の規模に合わせて自然に幅が変わるため。
- 3つの箱の中身をいつも見せるのは、額だけだと「なぜその額か」を聞かれたときに画面を探す必要があるため。貯めるお金の一覧は賄えない分の行だけにして、収入で賄える年は表に回す（一覧が長くなりすぎない）。

## 影響

- 世帯ファイルの形式の版が 0.13 になる（本体の `household-store` の変換の段と見本 `tests/fixtures/household-format/0.13/`）。
- 計算エンジンのまとめた JS・計算の結果は変わらない。持ち帰り用のレポートのファイルは、載せるときだけ1ページ増える。提案書は章が1つ増える（材料が無いときは省く）。

## 未確定（11月以降に決めること）

- ふだんの支出とできごとの支出の境の細部: 車のローンの返済・介護の費用をできごとに入れたが、長く続くものをふだんの支出に寄せるか（現場の FP の使い方を見て決める）。周期的な支出を毎年かどうかだけで分けてよいか。
- 退職金・満期金などの一時金の収入も「その年の収入」に入れている（その年のできごとの支出を賄える）。一時金を外すか（0031 の黒字の決め方とそろえるか）。
- 預金などの範囲（財形貯蓄・外貨預金をどちらに数えるか）と、預金が無い世帯（合計の入れ方で運用しない分も無い）での文の出し方。
- 提案書の章を既定で載せるか（今は載せる）。持ち帰り用のレポートで「FP からひとこと」の欄を設けるか。
- 何か月分・何年先までの既定を事務所の設定として持つか（今は世帯ごと）。

## 追記

- 2026-10-22（図をすっきりさせる）: 図は FP が指しながら口頭で説明する前提にし、分け方と置き場所のずれ（預金などのままの分・足りない分）を図に描くのをやめた。右の柱の「預金などのまま ○万円」の札、左右をつなぐ点線、ずれている分の斜線と点線の枠、凡例（左＝分け方・右＝置き場所・ずれている分）はなくした。ずれは区画の上の一文と、結果のタブの一行の知らせで示す（変えていない）。柱の見出しは「いつ使うお金か」「今どこにあるか」にし、見出しの行と合計の額の行を分けた（文字「大」・狭い幅でも重ならない）。持ち帰り用のレポート・提案書の図も同じにした（提案書の図の下の文は「今どこにあるか：」と置き場所の一覧だけ）。
  - 箱にカーソルを合わせる・キーボードで選ぶ・押す（タッチ）と、名前・金額・一言の札を出す（バランスシートの図と同じ札）。薄くて名前を書けない箱も読めるので、画面では図の下の「入りきらない箱の一覧」をやめた。持ち帰り用のレポートは一覧も残す。
  - 画面の「貯めるお金」のカードは、できごとの一覧を最初は出さず、額・「今後○年（○〜○年）の できごと ○件」・「内訳を見る」だけにした。「内訳を見る」は小窓（カードの横に重ねる。外を押す・Esc・× で閉じる）で、年・できごと・賄えない分の一覧と、全部の年の表を出す。図の「貯めるお金」の箱の札も同じ一覧。使うお金の内訳と増やすお金の引き算は短いので出したまま。持ち帰り用のレポート・提案書は一覧のまま。上の「決定」の「いつも見える中身の一覧」は、画面の貯めるお金についてはこの形に変えた。
- 2026-10-22（結果のタブの知らせをなくす）: 結果のタブのグラフの下の一行の知らせ（「『増やすお金』のうち ○万円 が預金のままです」「資産と負債で見る →」）はなくした。分け方と置き場所のずれは、資産と負債のタブの区画の上の一文だけで示す（変えていない）。上の「決定」の1の置き場所の 2 と、2の「結果のタブの知らせは出さない」は使わなくなった。提示用の値（`report/src/moneyThree.ts`）からも知らせの文（`notice`）を外し、提案書の入力（試験版 0.1.0）の `moneyThree` の欄からも外した。
