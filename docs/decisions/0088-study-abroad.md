# 0088. 留学（教育の目標の中に1回ずつ・在学が延びる形と延びない形・推定の額の根拠）と、世帯ファイルの形式 0.40

- 状態: 採用（一部未確定）（2026-10-30）
- 固定の強さ: β公開から変えない（骨格）。教育の目標の `abroad[]` の欄（`stage`・`grade`・`kind`〔`leave`・`credit`・`short`〕・`amount`・`onContingency.mode`〔`continue`・`stop`〕）の意味と、計算式ID `education.cost.abroad` は骨格。推定の額・既定の学年・払う月・画面の見せ方は後から変えてよい（変えたら追記に書く）

## 背景

- 留学は、子ども・教育のカードの「＋ 留学」で、出るお金の行（種類 教育費。0044）を足す形だった。行には時期（年齢）・払う人・伸び方・万一のときの扱い（割合・該当する万一も）・表の行の欄があり、進路（何年生のときか）とつながっていなかった。推定の額 350万円には根拠が無かった。
- 休学して1年留学すると在学が1年延びる（卒業・独立も1年うしろ）。単位が認められる留学（大学の交換留学・認定留学、高校の留学）や短期の留学は延びない。延びるかどうかで、学費・仕送り・独立の時期が変わる。
- 前提にする記録: 0010（教育費）、0035（世帯ファイルの形）、0041（値の状態）、0044（お金の行）、0062（子ども・教育のカード）。

## 決定

### 1. 形（教育の目標の `abroad[]`。1回ずつ）

| 欄 | 意味 |
|---|---|
| `stage` | 在学中の学校の段（高校・大学・短大・専門学校） |
| `grade` | 何年生のときか（1〜在学年数） |
| `kind` | `credit`: 1年（単位が認められ、在学は延びない）。`leave`: 1年（休学して留学し、在学が1年延びる）。`short`: 短期（1か月ほど） |
| `amount` | 1回の額（渡航・滞在・留学先の学費などの合計。計算基準年の価格） |
| `onContingency.mode` | 万一のときの扱い。`stop` は世帯の万一の想定（死亡）の月の翌月より後の留学を払わない。省略は続ける |

- 回数を増やすときは、もう一度「＋ 留学」で足す（1回ずつ）。時期の欄は持たず、段と学年で決める: その学年の4月（短期はその年の8月）に1回の額を払う。
- 表の行は「教育費」（`cf.expense.education`）で決め打ち。払う人は世帯（欄を出さない）。額は今の値段で入れ、教育費の上昇率で伸ばす（ほかの教育費と同じ。伸び方の欄は出さない）。
- 万一のときの扱いは「続ける」「やめる」の2択。該当する万一は死亡だけ（ほかのお金の行の既定と同じ）。

### 2. 計算（`education.cost` の改訂6）

- 留学の額: 上の月に表の行「教育費」へ（計算式 `education.cost.abroad`）。
- 休学して1年（`leave`）: その段の在学年数を1年延ばし、留学の年は在籍する学校の学費・学校の費用・学校外活動費・仕送りを計算しない（休学中の在籍料は入れない。文部科学省の通知「学生の休学中の在籍料等に関する留意事項について」〔令和3年3月23日〕は、休学中に授業料の名目で費用を取るのは適当でないとしている）。後の学年の学費と後の段（高校で休学すれば大学）の入学は1年ずつうしろにずれる。在学の記録（修学支援の計算が読む `enrollments`）の年度の学費からもその年を外すので、休学の年は修学支援（減免・給付）も計算しない。
- 単位が認められる1年（`credit`）・短期（`short`）: 在籍する学校の学費は払い続け、卒業の時期は変わらない。
- 子の独立（最後の学校の終わり。0062 の追記 2026-10-30）も、休学の年の数だけうしろにずれる。
- 万一のときの扱いが `stop` なら、世帯の万一の想定（`contingency.event`。構成員のうち最初に見つかった万一）の死亡の月の翌月より後の留学を払わない。

### 3. 推定の額（足したときの値。値の状態の推定の行。0041）

- 留学の費用の平均を出す公的な統計は見つからなかった（日本学生支援機構の「日本人学生留学状況調査」は人数だけ、日本政策金融公庫「教育費負担の実態調査」〔令和3年度〕に留学費用の項目は無い）。そこで、国の留学の支援制度の支給の上限から目安を作った。
- 文部科学省「官民協働海外留学支援制度 トビタテ！留学JAPAN」（高校生等 第12期・大学生等 第19期の募集要項。2026年10月）: 月額の奨学金は北米・シンガポール・欧州・中近東 160,000円（そのほか 120,000円）、留学準備金はアジア以外 250,000円（円安・物価高で100,000円を増額）、大学生等は留学先の授業料 300,000円。

| 学校 | 留学の形 | 推定 |
|---|---|---|
| 高校 | 1年（延びる・延びない） | 16万円×12か月＋準備金35万円 ＝ 227万円 |
| 大学など | 1年（単位が認められる。交換留学で留学先の授業料は免除が多い） | 16万円×12か月＋準備金35万円 ＝ 227万円 |
| 大学など | 1年（休学して留学） | 16万円×12か月＋準備金35万円＋留学先の授業料30万円 ＝ 257万円 |
| 高校・大学など | 短期（1か月ほど） | 16万円×1か月＋準備金35万円 ＝ 51万円 |

- 照らし合わせ: 日本政策金融公庫「国民生活事業のご案内2026」p.23 の、国の教育ローン（教育一般貸付）の令和7年度の進学先別の1件当たりの平均融資額は「外国の大学等」261万円で、休学して留学する1年の推定（257万円）とほぼ同じ。
- 学校か留学の形を変えたとき、額が推定のまま（値の状態が推定）なら新しい推定に入れ直す。FP が入れた額は変えない。
- 限界: 支援の上限の額で、地域（アジアなどは月額12万円・準備金21万円）・期間・寮か下宿かで大きく変わる。「?」にそのことを書いた。

### 4. 単位・在学年数の根拠（「留学の形」の「?」）

- 高校: 校長は外国の高校への留学を許可でき、外国での履修を36単位まで高校の単位として認定でき、学年の途中でも卒業を認められる（学校教育法施行規則第93条。36単位への拡大は平成22年の省令の改正）。1年の留学でも3年で卒業できることが多いので、既定は「延びない」。
- 大学: 他の大学（外国の大学への留学を含む）で修得した単位は60単位まで自分の大学の単位とみなせる（大学設置基準第28条）。交換留学・認定留学なら卒業は延びず、休学して留学すると在学が延びる（休学・在学年数の扱いは各大学の学則）。

### 5. 古い世帯と形式 0.40

- 足すだけの MINOR。0.39 → 0.40 の変換の段は形式の版だけを書き換える。前の版で足した留学（出るお金の行・種類 教育費）は書き換えず、今までどおり「この子の出るお金」に出る（払う人・伸び方などの欄もそのまま）。
- 見本 `crates/household-store/tests/fixtures/household-format/0.40/`（0.39 の見本の大学の段がある子に、単位が認められる1年と、休学して1年〔やめる〕の留学を足した物）。
- 入力の欄の当て先の表（`laterFields.ts`）に留学の欄を足した。

## 理由

- **教育の目標の中に置く**: 留学は進路（何年生のときか・延びるか）とつながる。延びる留学は在学・学費・仕送り・独立をずらすので、教育費の計算の部品が段と一緒に計算するのがいちばん確か。お金の行のままだと、行と段の両方を FP が合わせることになる。
- **欄を絞る**: 払う人（世帯の財布は1つ）・表の行（教育費）・伸び方（教育費の上昇率）は留学ではほかに選ぶ意味が無い。万一のときは続けるかやめるかが分かればよい。
- **推定を支援制度の上限から作る**: 費用の平均の統計が無い中で、国の制度の公表した額から作り、作り方を書いておけば FP が顧客に根拠を説明できる。少なく見積もらないよう、高いほうの地域の額を使った。

## 代案（採らなかったもの）

- 出るお金の行に段・学年への参照を足す: 教育費の計算の部品は教育の目標だけを読む（`memberScope`）ので、在学の延びを計算できない。行と段の二重の持ち方になる。
- 休学の年も在籍する学校の学費を全額払う: 休学中に授業料を取らないのがふつうで、1年分の学費（私立大学で約100万円以上）を多く見積もる。
- 留学の費用の推定を、民間の留学の会社の数字で: 出典の調べ方・範囲が確かめられない。
