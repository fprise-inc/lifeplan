- 固定の強さ: 打った値の状態の決まり（1）は 0041 の骨格の読み方（0041 の追記 2026-11-07）。ほかは内部（画面の欄の出し方・言葉・既定の値の選び方。後から変えてよい。変えたら追記に書く）。世帯ファイルの形式の版・計算エンジンは変えない

## 背景

入力項目の見直しの後、3つの世帯（会社員の夫婦と子2人・自営業のひとり親・60代の夫婦）を画面のキー入力で入れ直して確かめたところ、住まい・ローンのほかに次のことが分かった。

- 推定の値と同じ値を打っても「推定」のままだった（自営業の働く最後の年齢に「70」、貸与の奨学金の月額に「5」、国民年金の加入月数に「480」）。欄の部品は「入ったときと同じ文字のまま離れたら書かない」、欄の書き方は「同じ値なら世帯を変えない」（0041）ので、打っても確かめの一覧の推定に残った。「38歳」と年齢で入れた生年月は仮の値の印のままで、確かめの一覧の未入力に残った。
- 独立した子（34歳・31歳）にも子ども・教育の「進路の型 推定」が出て、推定に数え、ホームは「2人・公立 推定で計算中」だった。
- 確定給付企業年金を年金で受け取るとき、「受け取る時期（勤め先を辞めた翌月・過去）」と「年金の始まり」の2つの時点が並んだ。足した企業年金の勤め先の既定が今の再雇用の期間で、正社員の期間を選び直す必要があった。
- 介護の期間の欄は、亡くなる見込みで費用が止まっても「55か月」のままで、止まることが欄から分からなかった。プランで施設に変えても、違いの一覧・見出しが「母の介護（在宅）」のままだった。
- 書類から入れた年金の見込みと書類の額の差の内訳が「?」の中にしかなかった。
- 結果の対策: 63歳・今は再雇用の人に「60歳から再雇用（年収399万円）」（過去の定年の文）。生活費の基準の札が「月209,000円」（ほかは万円）。
- 入力のホームの札の1行が、書類から入れた後も「働き方の期間から推計して計算中です」「目安の退職金で計算中です」のままだった（残っている推定は加入月数・年金の年数）。
- 年収を入れても欄の名前の横に「推定」の札が残った（賞与の内訳が推定のため）。パネルの頭は「推定で計算中（34か所）」、帯のボタンは「見えている 8か所」で数が食い違って見えた。
- iDeCo の積立の行は「42 歳〜 加入できる年齢まで」で、終わりの年齢が無かった。受け取りの推定の文は「65歳（iDeCo に入れる年齢の上限）」だが、加入できる年齢の上限は制度データで2026年12月から70歳になる前の月まで。
- あげる贈与の相手の既定は、子のいる世帯でも「その他の人（贈与税は計算しません）」だった。
- 確かめの一覧に、値の無い「標準報酬月額 根拠 ▾」や、どの働き方の期間にも「辞めた後に失業給付を受け取る おまかせ（推定）」が並んだ。
- 入力項目をまたいだそろえの残り: 「外す」が7通り（外す・この家族を外す・この契約を外す・この期間を外す・進路を外す・推定の変化を外す・この変化を外す）。年金の受け取り開始・保険の保障の終わり・車の手放す時期・預金の引き出せない期間の終わりの「誰の年齢で」に小さな子が出た。お金の3つの分け方の「保険料 月0万円」。小規模企業共済の受け取り方が「（選ぶ）」のまま（空欄は受け取らない）。

## 決定

### 1. 推定と同じ値を打っても確定にする（0041 の読み方）

- 推定・書類待ちの欄に FP が値を打って欄を離れたら（Enter・Tab も）、推定と同じ値でも確定にする。打つのは明示の操作（0041 の「確定は明示の操作だけ」に合う）。確定は打って入れた確定（推定の根拠を残さない。「この値にする」の確定と見分ける）。
- 欄の部品は「欄に入ってから文字を打ったか」を持つ（`FieldViews.tsx` の `Field`・`WhenField`、貯蓄の表の数の欄）。打っていれば、入ったときと同じ文字でも書く（`shouldCommitOnBlur` の3つ目の引数）。打っていなければ今までどおり何も書かない（欄に入って離れる・Tab で通る・パネルを開いて最初の欄に入るでは値も状態も変えない）。
- 書く道は `valueState.ts` の `typeValue`（数・選択・年月などの欄）と `confirmTyped`（時点の欄。時点の部品で書いても推定のままなら）。中では「この値にする」と同じ道（`applyStateOp` の confirm）で確定にしてから根拠を外す。仮の値（生年月）と「この値にする」を持たない推定は、値を書き直して仮の印・推定の行を外す。
- 欄の書き方（`form.ts` の `field` の `set`）は今までどおり同じ値なら世帯を変えない。0041 の「推定の値と同じ値を書き戻しても確定にしない」は、画面や部品が自分で書き戻すとき（欄に入って離れる・同じ文字のまま離れる・関連する値の入れ直し）に限ると読む（0041 の追記 2026-11-07）。

### 2. 年齢で入れた生年月は確定（確かさは「年齢から」）

- 生年月の欄に「38歳」と打ったら、生まれた年月の幅のまん中（0131 の3）を確定で入れる（前は仮の値の印）。根拠「年齢から（38歳と聞いて出した生年月）」を残した確定の行（「この値にする」の確定と同じ形）を構成員の生年月の値の状態の行に書く（`typeFromAge`。生年月の欄は当て先を持たないので、仮の印の読み替え表の当て先）。
- 欄の読みに「・年齢から」を添える（「42歳（昭和59年5月）・年齢から」）。確かめの一覧の未入力・推定には出ない。月まで打ち直すと、入力のパネルの書き方（値が変わった所の前からの行を外す）で印が外れる。

### 3. 教育の段が全部過ぎた子

- 進路が入っていてどの段も終わっている子、進路が無くこの年齢でこれからの段が無い子（`educationFinished`）は、子ども・教育の区画を見出しの横の「34歳・教育は終わっています」だけにする（進路の型・推定の欄を出さず、推定に数えない）。奨学金・教育ローン・援助・留学・習い事の物がある子は今までどおり（返済などが続くため）。
- どの子もそうなら（この子のお金の行も無ければ）入力のホームの子ども・教育は「教育は終わっています」・該当なし。

### 4. 企業年金の受け取る時期と既定の勤め先

- 確定給付企業年金を年金だけで受け取るときは「受け取る時期」を出さない（入れてあれば残して見せる）。時点は「年金の始まり」の1つで、空欄の意味は「勤め先を辞めた翌月（2023年4月）」。
- 足した退職金・企業年金の既定の勤め先（`benefitPeriod`）: 今の働き方の期間が正社員・公務員・役員ならその期間。今が再雇用・パートなどなら、正社員・公務員・役員の期間のうち最後に始まった期間（無ければ今の期間）。国民年金基金は今の期間のまま。

### 5. 介護の期間と見出し

- 介護の期間の欄は、亡くなる見込みで費用が止まるとき、欄の下に「亡くなる見込みで止まり、2029年5月まで（費用は19か月分）」（`careDeathCut`）。欄の数（入れた値か統計の推定）と計算は変えない。期間の空欄の意味を「亡くなる見込みまで」に変える案は、計算の決まりが変わるので取らなかった。
- 介護の物の見出しは「母の介護」（在宅か施設かを入れない）。在宅か施設かは見出しの下の1行の頭（「施設・2027年4月から60か月・月…」）。違いの一覧の名前も「母の介護: 在宅か施設か 在宅 → 施設」になる。

### 6. 年金の見込みの内訳・対策の文・カードの1行・推定の札と数

- 書類から入れた人の年金の見込みは、書類の額と違えば、見込みの行のすぐ下に「内訳: 書類の額 年204.6万円＋これからの加入・加給年金など 年40.4万円」（「?」の中から出した）。
- 対策の「ご本人が働く最後の年齢」の説明: もう定年の後の働き方の期間にいる人は「今の働き方（再雇用・年収350万円）のまま」（過去の定年の文を出さない）。生活費・NISA の額は万円の小数1桁（「基準（A）: 月20.9万円」）。
- 入力のホームの推定で計算中のカードの1行は、推定のまま残っている欄の名前（「推定のまま: 年金の年数」「推定のまま: 協会けんぽの支部・賞与・勤め先の従業員数 ほか4か所」）。欄の名前の無い推定（年金の記録が無い人の推計）があるときだけ、その項目の決まった文。
- 欄の値は確定で内訳の一部が推定（年収〔賞与込み〕の賞与など）のときは、欄の名前の横に札を出さない（札は欄の値そのものが推定のときだけ）。内訳の行（「うち賞与 51.3万円（推定）」）の後ろに小さな「推定」の印（押すと根拠）。
- パネルの頭は、詳細・閉じたまとまりに「この値にする」にできる推定が隠れているとき「推定で計算中（見えている 8か所・詳細を含め 34か所）」。

### 7. iDeCo の積立の最後

- 積立の表の iDeCo の行の最後の期間は「〜64歳（65歳で受け取りを始める前の月まで）」。終わりは受け取りを始める年齢（入れた値か推定）と、加入できる年齢の上限（制度データ `ideco.enrollment.untilAge`。2026年12月から70歳）の早いほう（`idecoStop`。受け取りを始めた月からは掛金を出さない、計算と同じ決まり）。上限が先なら「（70歳になる前の月まで・加入できる年齢の上限）」。行の注は「国民年金に入っている月など、加入できる月だけ（計算で判定）」。
- 受け取りを始める年齢の推定の文は、iDeCo もほかと同じ「65歳（推定は65歳までにしています）」（65歳は加入の上限ではないため）。

### 8. あげる贈与の既定の相手

- 候補（世帯の子〔上から〕・離れて暮らす子と孫）が1人ならその人。2人以上なら、離れて暮らす子・孫（前からの既定）、いなければ第1子に推定の印（「相手の候補が2人以上のため、既定で選んでいます」）。選び直すか「この値にする」で印が外れる。候補がいなければ今までどおり相手なし。空（「選ぶ」）にする案は、選ぶまで贈与税を計算しない形になるので取らなかった。

### 9. 確かめの一覧に並べない推定・値を出す推定

- 標準報酬月額の空欄の目安（給与から毎年決め直す）と、失業給付・高年齢雇用継続給付の「おまかせ（推定）」（期間の形から決め、期間を変えると入れ直す）は、数えない推定（`quietEstimate`）にする。確かめの一覧・推定の数・まとめての確定に入れない。欄の「推定」の印と「この値にする」は今のまま。
- 確かめの一覧の推定の行は、空欄のまま推定で計算する欄（`blankEstimate`）でも推定の値を見せる（値の無い「根拠 ▾」だけの行にしない）。

### 10. 入力項目をまたいだそろえ

- 「外す」: 物を外すボタンは「外す」だけ（この家族を・この契約を・この期間を・進路を・この変化を・推定の変化を、を付けない。何を外すかは位置で分かる。0130 の追記 2026-11-07）。FP顧問料の契約の見出しの「この契約を外す」は、単発の料金の「外す」と同じまとまりに並ぶので残す。
- 時点の欄の「誰の年齢で」: 年金の受け取り開始・企業年金の年金の始まりはその人だけ（`who: "fixed"`）。保険の保障の始まり・終わり・払込の終わり・解約・更新、車の手放す時期・買い替える年齢、預金の引き出せない期間の終わりは大人（ご本人・配偶者）と欄の人（被保険者・名義の人）だけ（`ADULTS_WHO`）。今入っている人はいつも出す。
- お金の3つの分け方の一覧の月額・年額は、10万円未満なら万円の小数1桁（「保険料 月0.5万円」）。
- 小規模企業共済の受け取り方は、空欄の意味の選択肢「受け取らない（残高のまま持つ）」を先頭に置いて見せる（「（選ぶ）」のままにしない）。

### 確かめて直さなかった物

- 「その他の資産」の種類の既定が「外国株式」: 画面で見たのは同じパネルの課税口座の資産の配分の行（NISA・課税口座は足したときに外国株式100%の配分を入れる）で、その他の資産の種類は「貸していない不動産／その他の資産」の2つ（0145 のまま）。直す所は無い。
- 利回りが費用の前か後か: 口座の利回りと前提条件の運用利回りは「費用を引いた後」、資産の種類ごとの利回りは「信託報酬を引く前」と、それぞれの「?」に書いてあり、計算（口座の運用の費用・資産配分の信託報酬を引く）と合う。直さない。
- 相続・贈与の「額の入れ方」（ほかは「伸び方」）: 1回の額の値段の基準で、伸び方とは別の物なので言葉は残す。養育費の伸び方の既定（物価に合わせる）は、既定を変えると全部の世帯の結果が動くので変えない（見直しの計画で決めたとおり）。

## 理由

- 打った値が推定のまま残ると、FP は確かめたのに確かめの一覧から消えず、何度も同じ欄を見ることになる。打つのは明示の操作なので確定にしてよい。欄に入って離れるだけで確定にする前の形（0041 で止めた）とは違い、文字を打ったかで分ける。
- 年齢で入れた生年月も、FP が聞いて入れた値。仮の値（推定が成り立たない欄に計算のために置いた値）とは違う。確かさが年齢までなことは根拠に残して欄に見せる。
- 終わった教育・過去の受け取りの時点・効かない推定の行は、見る所を増やすだけで結果に効かない。
- 見出しや一覧の名前に変わりうる値（在宅か施設か）を入れると、プランの中で前の値のまま残る。
