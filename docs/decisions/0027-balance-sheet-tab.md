# 0027. 資産と負債のタブ（家計のバランスシートを図で見せる・合算BSの差し込み口）

- 状態: 採用（一部未確定）（2026-10-20）
- 固定の強さ: 内部（画面と帳票の見せ方。理由を残せば変えてよい）。資産の4つの分け方（器の種類と分け方の対応。`report/src/bsGroups.ts`）と、合算BSの差し込み口の形（提示用の値 `BsCustomViewModel`）は試験版（カスタム層から使うようになったら、3か月前に予告して変える。0001 の5）

## 背景

- 0025 で全資産・全負債のバランスシート（BS）を計算できるようにし、結果の画面に「資産と負債の推移」のグラフと、その下にその年の BS の表を置いた。表は数字の並びで、顧客に「家計の全体の形」が伝わりにくかった。
- 経験のある FP が BS を重視するのは、(1) 今の BS は入力した事実で、先の年は見込み（毎年の見直しで答え合わせができる）、(2) すぐ使えるお金と、引き出せない・換金しにくい資産の区別、(3) ローンの返済は手元のお金は減るが純資産として残る（キャッシュフロー表では支出にしか見えない）、を説明できるから。
- 結果の画面のグラフの切り替えに「資産と負債の推移」があると、結果の画面が重くなり、BS の説明に要る部品（図・年のつまみ・解説・体力の目安）を置く場所がなかった。

## 決定

### 1. 置き場所

- 上の帯のタブを「入力／結果／資産と負債／万一のとき／提案書」にする。
- 結果の画面のグラフは「資産の推移」「収支の推移」の2つにする（`ChartMode` から `balance` を外す）。グラフの下のその年の BS の表は外す。全部のプランを重ねる表示の純資産の線（`PlanLineModel.netWorth`）と、提示用の値の `balance`・`baseCharts.balance`・`baseLines.netWorth` も外す（資産と負債の推移は新しいタブの部品が描く）。
- 画面の確かめ用の `#chart=balance` は、資産と負債のタブを開く（`#bsview=one|three|plans|prev`・`#bsyear=2046`・`#bsopen=combined`・`#bstable`）。

### 2. 分け方（アプリと提案書で同じ部品）

- 資産を使いやすさで4つに分ける。上の3つを金融資産としてまとめて示す（金融資産の合計 `cf.balance.financial` と同じ範囲）。

| 分け方 | 器の種類 |
|---|---|
| すぐ使えるお金 | `deposit`（預金）・`zaikei`（財形貯蓄） |
| 値動きのある運用 | `nisa`・`legacyNisa`・`childNisa`・`juniorNisa`・`taxable`・`fxDeposit`・`esop`・`pooled`（まとめた金融資産） |
| 引き出せないお金 | `ideco`・`corporateDc`・`smallBusinessMutualAid` |
| 換金しにくい資産 | `realEstate`（住まいの持ち家は「持ち家（土地・建物）」、ほかは「その他の不動産」）・`car`・`insurance`（解約返戻金）・`otherAsset` |

- 負債は「住宅ローン」（`cf.balance.debt.mortgage`＋`unpaidInterest`）と「その他の負債」（`cf.balance.debt.other` を負債の種類で「車のローン」「奨学金」「その他の借入」に分ける。金融資産の器のマイナスは「資金の不足」としてここに置く）。
- 純資産＝資産の合計−負債の合計（0025 の1 と同じ足し算）。どの年も資産の合計＝負債の合計＋純資産（テストで確かめる）。
- 部品は `report/src/bsGroups.ts`（`bsSeries`）。提案書の帳票の入力と、アプリの作業の層（`app/src/workspace/balanceTab.ts`）の両方がこれを使う。

### 3. 今は事実、先は見込み

- タブの年は計算基準年から表の最後の年まで（結果の画面の表は計算基準月が年の途中なら翌年からだが、BS の「今」は計算基準年の年末の値。提案書の「今」と同じ）。今の年は「事実（今・入力した値）」の札・はっきりした色・実線の枠、先の年は「見込み（○年）」の札・少し薄い色・点線の枠。
- 計算基準年が年の途中から始まるとき、その年のお金の動きは数か月分しかないので、「生活費の何か月分」と返済額は翌年（1年分）の値で見る。

### 4. 図の縮尺

- 1年ずつ見るときは、その年がいっぱいの高さになる縮尺。年を動かすと、箱と縮尺が前の形から行き過ぎなく動く（`tween.ts` の `useTween`）。大きさの変化は、図の右の目盛りと「資産の大きさの推移」の小さなグラフで見せる。
- 並べるとき（3時点・プラン・前回）は、並べたものの中のいちばん大きい額を共通の縮尺にする。
- 額のある箱は読める最低限の高さを持つ（30万円より小さい箱は額に応じて小さく）。残りの高さをほかの箱で額に比例して分け、左右の高さは必ずそろえる。比例からずれた年は図の下に目立たない注記を出す（`bsLayout.ts` の `allocHeights`）。
- 純資産がマイナスの年は、資産の側の一番下に点線の「純資産のマイナス（足りない分）」を置き、左右をそろえる。

### 5. 前回と比べる（控え）

- 入力ホームの「控え」（0009 の2）があるときだけボタンを出す。選んだ控えの現状の入力（`inputs.request`）を今の計算エンジンで計算し、今の年（今の計算基準年）の年末の見込みと、今の実際を並べ、純資産の差を1文で、差の大きい項目（最大4つ）を添える。
- 控えでは BS を出せないときは、理由を出して今の実際だけを見せる: 控えに資産・負債の入力が1つも無い（口座・持ち家・車・負債のどれも無い）、今の年が控えの計算の期間に入っていない、計算できない（控えの時点が古く今の制度データで計算できないなど）。
- 控えのメモは FP のメモなので提示用の値に入れない（0016 の2）。控えは日付ときっかけ（手動・PDF書き出し）で呼ぶ。

### 6. 家計の体力の目安

- すぐ使えるお金が生活費（その年の基本生活費。取り崩して使うお金を除く）の何か月分か、資産のうち値動きのある運用の割合、負債の重さ（負債の合計 ÷ 資産の合計）、純資産の4つ。
- 目安の幅は事務所の設定（表示の設定 `DisplaySettings.bsGuide`）で FP が変えられる。最初の値は 6〜12か月分・10〜40%・50%未満（根拠のある公的な基準ではなく、説明の目安。事務所で直す前提）。
- 赤で煽らない。「目安の幅の中です」「目安より少なめです」「重めです。ローンの返済とともに軽くなっていきます」のような落ち着いた言葉にする。

### 7. 提案書

- 資産と負債の推移のページに、今・退職の年・75歳の3時点の BS の図を足す（帳票の入力 `balanceSheet.figure`。アプリと同じ分け方・色・共通の縮尺。今は実線、先は点線と少し薄い色）。年の抜粋の表は図の下に残す。

### 8. 合算BS の差し込み口（カスタマイズで追加）

- タブの上の「見るもの」に「家計のバランスシート」と、点線の札の「合算BS（カスタマイズで追加）」を置く。押すと考え方の説明（会社と経営者個人を並べ、貸し借りと自社株は相殺して合わせる）だけを出す。会社の数字の計算は作らない。
- 差し込み口の形: 提示用の値 `BalanceTabModel.customViews`（`BsCustomViewModel`: 名前・並べる図の列（列ごとに `BsYearModel` の形の BS）・注記）。値が入れば、同じ図の部品で共通の縮尺で並べて描く。値を作るのはカスタム層の計算部品（0016 の5 の `extend`。会社の BS の入力はカスタム層の入力欄 `fields/` と世帯ファイルの拡張領域。0011 の4）で、画面にコードは入れない（0016 の4）。今は公式の画面から値を作らない（`customViews` は空）。

## 理由

- **タブに分ける**: BS の説明には、図・年のつまみ・解説・体力の目安・比べ方が要り、結果の画面に入れると主役（足りるか）がぼやける。見本で「結果のタブに置いた場合」と比べ、新しいタブにした。
- **使いやすさの4つで分ける**: 「金融資産・不動産・その他」の分け方では、iDeCo のように金融資産でも引き出せないお金と、預金の区別がつかない。FP が説明したいのは「今日使えるお金がどれだけあるか」。
- **その年がいっぱいの縮尺**: どの年も同じ縮尺にすると、今の年の図が小さく潰れて見にくい（見本の第1版）。大きさの変化は目盛りと小さなグラフで補う。
- **分け方の部品を1つに**: アプリと提案書で分け方がずれると、顧客に見せた画面と PDF の数字が合わなくなる。
- **合算BS は形だけ**: 会社の BS は会計の入力と計算が要り、家計のソフトの最初の版の範囲を超える。差し込み口の形を先に決めておけば、会社の経営者を顧客に持つ FP 向けのカスタマイズで、画面を変えずに足せる。

## 影響

- 結果の画面の「資産と負債の推移」と、その下の BS の表（`presentation/BalanceSheet.tsx`）はなくなる。全部のプランを重ねる表示は、資産と収支の2つで比べる。
- 表示の設定に `bsGuide` が足される（世帯ファイルの本文の `display`。読めない値は最初の値）。

## 未確定

- 保険の解約返戻金を「換金しにくい資産」に、まとめた金融資産（`pooled`）を「値動きのある運用」に入れてよいか。

- 土地と建物を分けて見せるか（エンジンの表は持ち家の評価額の合計だけを出す。分けるなら行を足す。0025）。
