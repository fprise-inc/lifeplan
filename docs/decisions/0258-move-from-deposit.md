# 0258. 貯蓄・運用に「預金から移す」を足す（時期と額を1行ずつ・NISA は成長投資枠・年の枠を超えた分は預金に残す）と、形式 0.91

- 状態: 採用（一部未確定）（2026-11-24）
- 固定の強さ: 骨格は、口座の欄 `accounts[].fromDeposit`（`{id, at, amount}` の並び。入力項目ID `account.fromDeposit`）の名前と意味（決済口座からその月に移す器の間の移動で、年間収支に入れない）と、形式 0.91 の変換の段（版だけ）。使える口座の種類・NISA の枠を超えた分の扱い・同じ年の積立との順番・画面の言葉と並びは後から変えてよい（変えたら追記に書く）
- 前提にする記録: 0026（資産運用の入れ方・NISA の枠を超えた分）、0004 の6（積立は器の間の移動）、0255（口座の表の列）、0254（推定の欄の並び）、0223 の追記（口座の名前のキャンセル）、0252（資産配分・形式 0.90）、0036（プランの差分）、0011・0035（形式の版の上げ方・並びの要素の ID）

## 背景

- 一括で投資するのが怖い人が、手元の預金（例 5,000万円）を、今1,000万円・2年後2,000万円・7年後2,000万円のように、何回かに分けて投資に移す形を入れたい。
- 今の積立は「期間と月額」だけで、1か月だけの期間を作れば代用できるが分かりにくい。NISA の年の枠を超えた分がどうなるかも見えない。

## 決定（利用者の判断）

### 1. 入れ方

- 名前は「預金から移す」。運用する口座ごとに「時期」と「額」を1行ずつ入れ、行は何行でも足せる。行ごとに「外す」。時期の右に「今月」「2年後・ご本人47歳」のような説明（計算基準月からの隔たりと、名義の人のその月の年齢）。
- 出す口座: 課税口座・NISA・財形・持株会・外貨預金・暗号資産（預金から入れられる口座）。iDeCo・企業型DC は掛金の決まりがあるので出さない（小規模企業共済も同じ）。収支が入る口座（決済口座。預金から出す元）にも出さない。
- 標準でも詳細でも出す。何も入れていない口座は、積立の「＋期間を追加」の下に「＋預金から移す」の1行だけ（NISA は「＋預金から移す（成長投資枠）」）。行を足した口座は、見出し「預金から移す」（NISA は「預金から移す（成長投資枠）」）と行と「＋預金から移す」を出す。
- 「？」の文: 「預金から、この口座へまとまった額を移します（時期ごとに1行）。何回かに分けて投資に移すときは、行を足します。NISA は年の枠を超えた分を預金に残すので、超えるときは年を分けて入れてください。」
- 行を足すと、1行目は今月・0円、2行目からは時期のいちばん後の行の1年後に同じ額で入る（足した行へ画面が移る。`revealAdded`）。行は時期の順に並べる（同じ時期は入れた順）。
- 口座の表の列の見出しは、出せる口座が1つでもあれば「毎月の積立・預金から移す」（0255 の列の並び・縦線はそのまま）。収支が入る預金の行には、ほかの口座に移す行があるときだけ「ほかの口座へ「預金から移す」額は、この口座から出します」を添える。
- 欄: 時期は年月の欄（「2028-12」「2028/12」「令和10年12月」などで読める。読めない文字・空は前の値に戻して理由を出す）。額は万円の数の欄（0254 の並びのとおり、欄の中は数字だけで単位は欄の外）。計算基準月より前の行には「計算基準月より前なので、計算に入れていません（今の残高に入れてください）」、表の最後の年より後の行には「表の最後の年（2081年）より後なので、計算に入れていません」を行の下に出す。

### 2. 計算（`plan.cashflow` の改訂30）

- その月に、決済口座からその口座へ移す（器の間の移動。年間収支に入れない。今の積立 `account.contribution` と同じ扱いで、移動の行 `cf.transfer.*` に出る。計算式は `plan.cashflow.fromDeposit`、根拠の名前は「預金から移す」）。
- 計算基準月より前・表の最後の年より後の行は使わない（計算基準月ちょうど・最後の年の12月は使う）。
- NISA は成長投資枠に入れる。その年の成長投資枠（年240万円）・生涯の枠（1,800万円）・成長投資枠の生涯の枠（1,200万円）の残りを超えた分は預金に残す（つみたて投資枠との合計 年360万円は、成長投資枠が年240万円までなので超えない）。前提の「NISA の枠を超えた分」（`investment.nisaOverflow`）が「課税口座で続ける」でも、移す行の超えた分は預金に残す（移す額は FP が年を選んで入れる物なので、黙って課税口座へ回さない）。計算の知らせは積立の超えた分と同じ（N_LIMIT_APPLIED の `nisa.annualLimit`）。画面は行の下に「この年の枠を超える 260万円は、預金に残しています（成長投資枠は年240万円）」（生涯の枠のときは「生涯の枠を超える 60万円は、預金に残しています（生涯の枠は1,800万円、うち成長投資枠は1,200万円）」）。画面の額は目安（`nisaMoveOvers`。その口座の積立と移す行を月の順に数える。計算はエンジンの制度データ）。
- 同じ年の積立と移す行は、月の順に枠を使う（同じ月は積立が先）。移す行の無い年の積立の順番は今までどおりなので、移す行の無い世帯の結果は1円も変わらない。
- 預金が足りないときは、ほかの不足のときと同じ（年末に取り崩しの順番で補い、補えなければ資金の不足〔`cf.balance.shortfall`〕と、その知らせ）。移す額を預金の残りで止めることはしない。
- 資産配分の入れ方（0252）の口座でも同じに働く（移した額に配分の利回りをかける。移した年は半年分〔0003 の3〕）。
- 使えない器（iDeCo・企業型DC・小規模企業共済・預金・こどもNISA・旧NISA など）に書いた行は使わない。

### 3. 世帯ファイルの形式 0.91（形を変える MINOR。0252 の 0.90 の後）

- 足した欄: 口座の `fromDeposit`（任意。行は `id`〔並びの要素の ID。0035 の5〕・`at`〔時点〕・`amount`〔円〕）。前の版のアプリは計算の入力の検査で知らない欄を通さないので、版を上げて閲覧だけにする。
- 変換の段（`crates/household-store/src/migrate.rs` の `v0_90_to_0_91`）は版だけを書き換える（前の版の世帯は欄が無い＝移す行なし）。控え・自分で作った見本の最初の状態の中身は変えない。
- 見本 `0.91/`（課税口座に3行〔今月・2年後・7年後〕と NISA に1行）。並びの要素の ID は画面が開くときに振る（`elementIds.ts`。新しい並びなので変換の段で振る古い要素は無い）。

### 4. プラン・AI接続口・手引き

- プラン（差分。0036）: プランを直している間に行を足す・時期や額を変える・外すと、入力項目 `account.fromDeposit` の差分（足す・値を変える・外す）になり、現状は変わらない。欄（時期・額）は行の ID の中の `at`・`amount` を当て先に持つので、違いの一覧・動かす項目の一覧（欄から作った項目）にも出る。
- AI接続口: 入力の形の案内（`get_input_guide` の口座の区分の書き方）に `fromDeposit` の書き方を足した。縮約版の許可リストに `account.fromDeposit` を入れた（計算に要る。`reduced@34`）。`docs/ai-connector.md` に書き方・使える口座・NISA の枠・答えの移動の行を書いた。
- 入力のホームの「探して開く」に「預金から移す」「一括投資」「分割投資」「時間分散」などの言葉を足した。画面の操作の手引き（`docs/app-guide/02-input.md` の `input.moveFromDeposit`）と、対応範囲の一覧（`docs/coverage/investment.yaml` の `investment.fromDeposit`）を足した。
- 結果の表: 移した額は今の移動の行（課税口座への移動・NISA の成長投資枠への移動など）に入り、数字の根拠に「預金から移す」と出る。

## 確かめ

- エンジン（`engine/test/fromDeposit.test.ts`）: 3回に分けて移す・年間収支が変わらない、時期の境目（基準月の前の月・基準月ちょうど・最後の年の12月・その後。基準月が3月の世帯）、NISA の年の枠（ちょうど・1円超え・課税口座で続ける前提でも預金に残す・同じ年の2行）、生涯の枠と成長投資枠の生涯の枠（ちょうど・1円超え）、同じ年の積立との順番、預金が足りないとき（取り崩して補う・引き出せない口座だけなら資金の不足）、資産配分の口座、使えない器。
- 画面（`app/test/move-from-deposit.test.ts`）: 「＋預金から移す」の出し方（標準・詳細・出さない口座）、行を足す・直す・外す、時期の説明（基準月が1〜3月の年をまたぐ説明を含む）、計算に入れない行の知らせ、NISA の枠の知らせ（ちょうど・1円超え・生涯の枠）と計算の一致、資産配分の口座、欄の当て先、プランの差分。
- 世帯ファイル: 形式 0.91 の見本と変換の段のテスト。
