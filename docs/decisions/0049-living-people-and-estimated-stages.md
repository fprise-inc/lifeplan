# 0049. 生活費の人数の数え方と、推定の段階（人数の変化と年齢から作る段）

- 状態: 採用（一部未確定）（2026-10-26）
- 固定の強さ: 内部（推定の作り方）。世帯ファイルの形は変えない（段は `livingExpenses[].stages`、推定の印は物の値の状態の欄 `valueStates` の行）。人数の目安の表・退職と年齢の目安の割合・段にする出来事の種類は後から変えてよい（変えたら追記に書く）

## 背景

- 生活費の目安の人数に、生まれる予定の子（`expected`）は入れていなかったが、生年月が計算基準月より後の子は数えていた。自宅外で在学中の子・施設に入る人も数えていた。
- 子の独立・退職・70歳・80歳の節目はボタンを押さないと入らず、押すと印の無い割合（85%・80%・75%・70%）が入った。何も押さない新しい世帯では、老後も子の独立の後も生活費が減らなかった。
- 0041 の「推定で埋める」に生活費の段階が残っていた。0035 の11（古い世帯を開いても黙って書き換えない）と、新しく入れる物は最初から推定で入れる決まり（0041）。

## 決定

### 1. 生活費の人数（`livingStages.ts` の `countAt`。目安の `householdSize` もこれ）

その月に世帯で暮らしている人を数える:

- 生まれている（生年月がその月まで）。今の人数（計算基準月）では予定の子は数えない。加わっている（`joins`）・離れていない（`leaves` の月から数えない）。
- 大学・短大・専門学校の自宅外（`living: "away"`）の在学の間は数えない（入学は学年の4月＋浪人の年数、在学年数は段の年数か標準）。
- 施設の介護（`careExpenses[].place: "facility"`）の始まりの月から数えない（月数があればその間だけ）。在宅は数える。
- 世帯の外の家族（0035 の4）は、家計を1つにする期間のうち「生活費の人数に入れる」（`living`。既定 true）の期間だけ数える。

### 2. 推定の段階

- 段を作る月: 子の誕生（今より後に生まれる子）・加わる・独立（離れる）、世帯の外の家族と家計を1つにする期間の始まりと終わりの翌月、自宅外の在学の始まりと終わり、施設の介護の始まり（と終わり）、本人の退職（働き方の期間の最後の翌月。期間が無いか終わりが空なら65歳）、本人の70歳・80歳。今より後で、表の最後の年までの月だけ。同じ月は1つの段にまとめる。
- 割合 ＝（その月の人数の目安 ÷ 今の人数の目安）×（その月の年齢の水準 ÷ 今の年齢の水準）。人数の目安は家計調査の世帯人員別（`living.statistics.basicMonthly`。1人は仮の値）。年齢の水準は退職後 0.8・70歳から 0.75・80歳から 0.7（前のボタンと同じ目安。年齢階級別の統計で確かめる前）。小数第2位に丸める。人数が0なら0。前の段と同じ割合になる月は段にしない。
- 段の節目（`label`）: 退職・70歳・80歳・子の独立のどれかを含む段はその名前、ほかは「その他の節目」。見出しは理由から作る（「長女の誕生」「長男の自宅外の在学」「ご本人の施設の介護」など。保存しない）。
- 段の ID は生活費の ID と理由から決まる値（同じ理由の段はいつも同じ ID。差分・値の状態の行が同じ段を指し続ける）。
- 時点は、元の物の時点の形を写す（子の独立が年齢・出来事なら同じ形、年齢の段は本人の年齢）。

### 3. 推定の印と入れ直し

- 推定の段は、割合の当て先（`livingExpense.stages/<段の ID>/ratio`）に推定の行（出どころ `auto`、出し方 `derived`、根拠「推定の段階（人数の変化と年齢から。…）」）を持つ。時点には行を持たない（家族・進路・働き方の物から決まる）。
- 元の入力が変わったら（推定の入れ直し `refreshEstimates`）、推定のままの段だけ、時点と割合を入れ直し、要らなくなった段は外し、新しく要る段を足す。
- FP がその段の割合・時点・入れ方・節目を直すと、その段の行を外す（その段だけ確定。ほかの推定の段は入れ直し続ける）。FP が外した推定の段は「該当なし」の行（`livingExpense.stages/<段の ID>`。値の無い場所の該当なしは 0035 の12 の検査で許す）で覚え、入れ直しで足し直さない。FP が足した段（節目のボタン・その他）は推定の段と別に残る。
- 入れ直すのは、推定の段か外した推定の段の印がある生活費だけ。**新しい世帯**（空の世帯・「目安で入れる」「推定で埋める」で作る生活費）は最初から推定の段階を入れる。**古い世帯**は入れない（開いても、ほかの欄を直しても）。段が無い生活費にはカードの簡易に「子の誕生・独立・退職などで、生活費の段階を推定で入れる」、FP が入れた段がある生活費には詳細に「推定の段階に入れ替える（今の段階を外します）」を出し、押したときだけ入れる。
- 生活費の額を確定にしていても、推定のままの段は入れ直す（段の割合は額に対する割合なので、額を直しても段の意味は変わらない）。

### 4. 費目の按分の統計

- マスタデータ `master.living.statistics` を 2026.2.0 にし、同じ家計調査の表（2025年 二人以上の世帯 第3-1表 世帯人員別）から、食料・光熱・水道・家具・家事用品・被服及び履物・保健医療・交通・通信（自動車等関係費を除く）・教養娯楽・その他の消費支出（仕送り金を含む）の8値（`categoryMonthly.*`）を足した。8費目の合計は `basicMonthly` と同じ（表の丸めで1円違う世帯人員がある）。原本と照らし合わせた（表の値と、10大費目の合計が消費支出に合うこと）。
- 総額を費目に分けるときの割合と、費目の欄の横の「同じ人数の世帯の平均」に使う（0048 の2）。1人の世帯は表に無いので2人の世帯の割合。

## 理由

- 割合を人数の目安の比にした: 統計の表が人数ごとなので、どの変わり目も同じ表の比で出せ、根拠を1つの文で見せられる。予定の子・自宅外の在学・施設の介護・同居の親の扱いも同じ決まりで済む。
- 年齢の水準を人数の比に掛けた: 退職・高齢で減る分と、人数で減る分は別の理由なので重ねる。前のボタンの割合を年齢の水準として残し、統計で確かめるまで推定の根拠に「確かめる前」と書く。
- 段ごとの印にした: 1段を直しても、ほかの段は家族の変化に合わせ続けられる。外した段を覚えないと、入れ直しのたびに戻ってくる。
- 古い世帯に入れない: 開いただけで結果が変わるのを避ける（0035 の11）。

## 代案（採らなかったもの）

- 段の印を生活費の物に1つだけ持つ: 1段を直すと全部の段の入れ直しが止まるか、直した段が戻る。
- 時点にも推定の行を持つ: 1段に推定の欄が2つになり、確かめの一覧とカードの数が倍になる。時点は物から決まる。
- 人数の比を使わず、節目ごとに決まった割合: 子の多い世帯・同居の親・自宅外の在学を表せない。

- 画面: `app/src/workspace/input/livingStages.ts`（新）、`estimates.ts`（人数の数え方・入れ直し）、`household.ts`（空の世帯）、`fill.ts`（推定で埋める）、`stages/living.ts`（段の欄・ボタン）。
