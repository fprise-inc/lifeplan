# 0058. 退職金・企業年金の受け取りの並びと、退職所得控除の重なりの知らせ

- 状態: 採用（一部未確定）（2026-10-27）
- 固定の強さ: 内部（画面の作り）。世帯ファイルの形は変えない。並べる物・知らせの文言・列は後から変えてよい。決まりの年数を制度データから読むこと（画面に数を書かない）は保つ
- 前提にする記録: 0003（退職所得の分離課税）、0007（制度データの写し）、0026（iDeCo・企業型DC の受け取り）、0039（相続税の目安）、0057（退職金・企業年金のカード）

## 背景

- 退職金・iDeCo・企業型DC・小規模企業共済の一時金は、どれも退職所得で、受け取る年が近いと退職所得控除を分け合う（勤続期間の重なる分の控除が引かれる）。前の一時金を見る年数は種類で違い、令和8年からは「DC の一時金の後の退職金」が前年以前9年内に延びた（前は4年内）。5年空ければよいと思い違えやすい。
- 計算エンジンは受け取りを集めて税を計算する（`retirement.receipts`・`tax.retirementIncome`）が、入力の画面には、退職給付（退職金・企業年金のカード）と DC・共済（貯蓄・運用のカード）の受け取りを並べて見る所が無かった。

## 決定

- 退職金・企業年金のカードのパネルの下に「受け取りの並び」を人ごとに出す（読むだけ。簡易でも出す）。並べる物: このカードの退職給付（一時金・年金の始まりと年数）と、貯蓄・運用の iDeCo・企業型DC の受け取り・小規模企業共済の共済金（「→ 貯蓄・運用で直す」）。
- 列: 時期・もの・額・退職所得の税。時期と額は入力から読み、入力に額の無い物（公務員の退職手当・役員退職慰労金の見込みの計算、DB の年金の年額の既定、DC の残高から出る額）は計算の結果から読む。税の列は計算の結果があるときだけ出す（その物の所得税と住民税の退職所得の分）。
- 結果は、今の世帯の写しの要求（万一の想定・必要保障額の推移を外す）で1回計算する（相続税の目安と同じ計算の道。0045）。計算の道が無いとき（画面の確かめなど）は入力だけで並べ、税の列を出さない。
- 一時金を年の順に並べ、隣り合う2つの間隔で決まりを知らせる（所得税法施行令70条1項2号）。年数は制度データの写しから読む:
  - 退職手当等どうし: 前年以前 `incomeTax.retirementIncome.overlap.lookbackYears` 年内 →「前の退職金から（年数＋1）年空けないと、勤続の重なる分の控除が引かれます」
  - DC の一時金の後の退職手当等: 前年以前 `incomeTax.retirementIncome.overlap.lookbackYearsAfterDc` 年内（前の一時金の年と今の年の値の小さい方。令和8年以後に受けた一時金は9年）→「2026年以後は、DC の一時金の後は10年空けないと…」
  - 退職手当等の後の DC の一時金: 前年以前 `incomeTax.retirementIncome.overlap.lookbackYearsForDc` 年内 →「DC の一時金は、前の退職金から20年空けないと…」
  - 同じ年: 「勤続期間を合わせて、退職所得控除を1回で計算します（重なる期間は1回だけ数えます）」
- 知らせは間隔だけで出す（勤続期間が本当に重なるかは見ない。重ならなければ控除は引かれないが、確かめる手がかりとして出す）。税の差は、プランで時期・受け取り方を変えて比べる。

## 理由

- 受け取りの順番と間隔は、退職金・DC・共済をまたいで1か所で見ないと気づけない。物はそれぞれのカードに置いたまま（1つの物は1つのカード。0045）、並びだけを見せる。
- 年数を制度データから読む: 改正（令和8年の9年内）で変わる値で、画面に書くと食い違う。

## 代案（採らなかったもの）

- 並びを段階の定義の読むだけの欄にする: 計算の結果（見込みの計算の額・税）を段階の定義から読めない。
- 勤続期間の重なりまで画面で判定する: 計算エンジンと同じ判定を画面に二重に持つことになる。

## 影響

- 画面: `input/retirementLineup.ts`（並びと知らせ・計算の要求）、`input/RetirementLineup.tsx`、`input/InputPanel.tsx`（退職金・企業年金のパネルに出す）、`styles/app.css`。
- 統計の写し（`hearing/src/statistics.generated.ts`）に、重なりの年数3つを足した。
- 計算エンジン・世帯ファイル・見本の世帯の結果は変わらない。
- テスト: `app/test/card-retirement.test.ts`（DC の一時金の5年後の退職金で10年の知らせ・退職金の後の DC で20年・退職金どうしで5年・同じ年・結果が無いと税の列を出さない・見込みの計算の額を結果から）。
