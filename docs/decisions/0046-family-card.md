# 0046. 家族のカードの中身（関係の形と期間・これから生まれる子・子の独立の標準・家族のお金の行）

- 状態: 採用（一部未確定）（2026-10-26）
- 固定の強さ: 内部（画面の作り）。世帯ファイルの形は変えない（関係を期間で分けて持つ形・年齢の時点・入るお金の行は形式 0.17〜0.20 にある）。子の独立の標準（22歳になった後の最初の3月末の翌月）とその根拠の文、これから生まれる子の推定の時期（2年後）、欄の名前・説明の文・並びは後から変えてよい

## 背景

- 家族のカードは、続柄・生年月・1日生まれ・性別・子の独立と、出来事の区画だけだった。配偶者は「＋ 配偶者を足す」で法律婚として足すだけで、関係の形（法律婚・事実婚）・始まり・終わりは入れられなかった。エンジンは関係の形で税（配偶者控除・配偶者特別控除・扶養控除・住民税の非課税・相続の配偶者）を分け、同じ2人の配偶者の関係を期間で分けて持てる（0035 の5。`engine/test/relations-periods.test.ts`）。
- これから生まれる子は、子を足してから詳細の「これから加わる」と「加わる時期」を入れるしかなく、生年月と加わる月を別々に入れていた。
- 子の独立の標準は「22歳になる月」を年月で持ち、生年月を直したら標準のままの値だけ追いかけていた（0008 の追記 2026-10-25 の仮の直し）。生活費の「末子独立後」の目安は、エンジンでは「22歳になった後の最初の3月31日の翌月」（`expense.living`・万一の遺族の生活費の独立の年齢と同じ決まり）で、画面の標準と1年近くずれることがあった。
- 家族のお金の行（養育費・手当・財産分与・同居の家族が入れるお金・離れて暮らす子への仕送り）は、お金の行の土台（0044）で種類だけがあり、区画は詳細にだけ出ていた。仕送りの行は相手のいない行・親が相手の行が介護・親のカードの行になるので、家族のカードの「＋ 仕送り」で足した行が家族のカードから消えた。

## 決定

### 1. 足すボタン

- 配偶者がいないとき「＋ 配偶者（法律婚）」「＋ パートナー（事実婚）」の2つ。押したボタンで関係の形を決める（推定にしない）。配偶者の関係には要素の ID を振って足す。
- 「＋ 子」「＋ これから生まれる子」。どちらも進路を推定（標準の進路の型）で入れる（0041 の決まりのまま）。

### 2. 関係の形と期間（詳細の区画「夫婦の関係」）

- 本人と配偶者の配偶者の関係（`relations[]` の `type: spouse`）を、始まりの順に段として並べる。段ごとに「関係の形」（法律婚・事実婚）・「始まり」・「終わり（最後の月）」。空欄の始まりは「最初から」、最後の段の空欄の終わりは「今も続いている」。
- 「＋ 関係の段階を足す（事実婚 → 入籍など）」: 最後の段を今から1年後の前の月で終え（終わりがあればその翌月から）、翌月から別の形の段を始める。段の始まりを直すと前の段の終わりをその前の月に、段の終わりを直すと次の段の始まりをその次の月に合わせる（期間は重ならない）。「この段階を外す」は前の段の終わりを外した段の終わりにする。
- **最後の段の終わり（離婚・別居）を入れると、配偶者はその翌月に世帯を離れる**（構成員の `leaves`）。離れる月が前の関係の終わりの翌月に合っていた（同じ月に解ける）ときだけ直し、人が別に入れた離れる月は変えない。終わりを空にすると、合っていた離れる月も空にする。終わりを出来事（離婚）から決めたときは、離れる月を同じ出来事の1か月後にする（出来事を動かすと両方動く）。
- 時点の部品（0038）の「出来事から」に、関係の始まり（結婚）と最後の段の終わり（離婚）を、まだ出来事でない物として出す（選ぶと出来事にする）。
- 関係が終わった段に、注意（配偶者の名義の口座・保険・住まい・車は、各カードで外すか名義を直すまで世帯の物として計算する）と「＋ 財産分与（入るお金）を足す」「＋ 養育費を受け取る」「＋ 養育費を払う」（関係が終わった翌月から。相手は前の配偶者）。名義の物を1件ずつ「外す・残す・分ける」で選ぶ画面は作らない（物を時点で外す形がまだ無い）。
- 配偶者のまとまりに、関係の読むだけの1行（「法律婚」「事実婚（2027年9月まで） → 2027年10月から法律婚」）。
- 関係の欄の当て先は関係の要素（`{object: 関係の ID}`、入力項目ID `relation.marriage`・`relation.from`・`relation.to`）。プランで「離婚する案」「入籍する案」を作ると、その関係の値の差分になる。

### 3. これから生まれる子

- 足すと、生年月と加わる月を今から2年後の同じ月にし（推定。仮の印「今から2年後」）、予定の印（`expected`）を立て、性別は「わからない（男性を代わりの値）」の仮の印にする。
- 簡易に「生まれる予定」の欄（時点の部品。年月・今から・本人の年齢で入れられ、年月にして持つ）。書くと生年月と加わる月を同じ月にする。
- 「生まれました」: 予定の印と加わる月を外す（生年月はそのまま。性別の仮の印は「生まれたら確かめる」に）。

### 4. 子の独立の標準

- 新しく足す子の独立は、**22歳になった後の最初の3月末の翌月**（大学を出る年度末の翌月）を年齢の時点（`{memberAge: {years: 22, ageSwitch: schoolYear}}`。22歳になった後の最初の4月と同じ月）で持つ。生年月・1日生まれを直すと合わせて動く（追いかけが要らない）。仮の印「標準（22歳になった後の最初の3月末の翌月）」。
- 年月などで入れ直した子は「独立を標準に戻す」で年齢の時点の標準に戻せる。
- 年月で持つ古い世帯の子は変えない（黙って書き換えない）。今までどおり、22歳になる月のままなら生年月を直したときに追いかける。

### 5. 本人と配偶者の入れ替え（詳細）

- 続柄の `self`・`spouse` だけを入れ替える。物は構成員の ID で指すので、働き方・年金・口座・保険の名義・呼び名・定年後の予定は人に付いたまま。

### 6. 家族のお金の行

- 家族のカードの「入るお金」（養育費を受け取る・財産分与・同居の家族が家計に入れるお金・手当・給付金）と「出るお金」（養育費を払う・離れて暮らす子への仕送り）は、家族のカードの段階の定義が作り、簡易に出す（ほかのカードの区画は今のまま）。行の欄は 0044 のまま。
- 相手は簡易にも出し、選べる人に本人のほかの世帯の人（前の配偶者・子）を足す。
- 足すときの既定: 養育費（受け取る・払う）と手当・給付金の終わりは、いちばん下の子の18歳の年度末（年齢の時点。子の生年月で動く）。離れて暮らす子への仕送りは、相手を子（世帯の外の子、無ければ独立の早い子）にして足す。子がいなければ仕送りのボタンを出さない（相手のいない仕送りは介護・親のカードの行になるため）。
- 1日生まれの欄は詳細に移した（結果の差は1か月）。

### 7. 出さない欄（計算がまだ無い）

計算に入らない欄は出さない。次は計算を足す回に欄を出す: 年金分割（離婚のとき）、人ごとの想定の寿命、税の障害者・寡婦とひとり親の区分、子の収入（アルバイト・就職後）、表の最後の年を「誰が何歳」の決まりで持つこと。

## 理由

- **関係の形は押したボタンで決める**: 法律婚か事実婚かは聞けば分かる事実で、推定にすると税の結果が黙って変わる。
- **離れる月は関係の終わりから作る**: エンジンは、世帯を離れていない配偶者の収入・生活費の人数をそのまま世帯に入れる。関係だけを終えると、離婚した後も配偶者の給与が家計に入って見える。人が入れた離れる月を残すのは、別居の後に離婚するような順番の違う入れ方を壊さないため。
- **子の独立を年齢の時点で持つ**: 生年月を直すたびの追いかけ（標準のままかの見分け）が要らなくなり、エンジンの末子独立の決まりと同じ月になる。卒業・就職の4月に合う。
- **名義の物の選び方は作らない**: 物を時点で世帯から外す形が無く、今の物を外すと離婚の前の年の結果まで変わる。注意と財産分与の行で、分ける額だけは入れられる。

## 影響
