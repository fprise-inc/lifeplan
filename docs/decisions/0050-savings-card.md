# 0050. 貯蓄・運用のカードの中身（お金の行き先・預金に残しておく額・口座ごとの詳細・値の状態の操作）

- 状態: 採用（一部未確定）（2026-10-26）
- 固定の強さ: 内部（画面の作り）。世帯ファイルの形は変えない（使う欄はどれもエンジンの入力の形にあり、形式 0.20 のまま）。取り崩す順番を口座ごとに書くときの決まり（選んだ口座を物の ID で並べ、その後に「取り崩さない」口座の無い器の種類を標準の順で足す）と、預金に残しておく額の目安のボタンが押した時の額で止まる（生活費を追いかけない）ことは、結果の数に効くので変えるときは追記に書く。文言・並び・目安のボタンの月数・利回りの選び方の値（仮の値）は後から変えてよい

## 背景

- 貯蓄・運用のカードは、口座の表・期間を分けた積立・資産配分・受け取り方を専用の部品で描く（0026）。エンジンには、取り崩す順番を物の ID でも書けること（書かなかった器は取り崩さない）、決済口座の印、決済口座に年末に残す額、引き出せない期間、年金で受け取る年数と併用の一時金の割合、加入の始まり、運用の費用、旧NISA・ジュニアNISA の買付の年ごとの内訳、小規模企業共済の受け取り、不動産を持ち始める時点（0039）があったが、画面に無かった。取り崩す順番は資産配分の入れ方のときだけ、器の種類の3つのまとまりでしか並べられなかった。
- 値の状態の操作（0041）は欄の部品に付いているが、このカードは専用の部品なので、欄の横の操作が無かった（確かめの一覧には出る）。専用の部品の数の欄は、欄に入って離れるだけで同じ値を確定の箱で書き直していた。
- 生活防衛資金は前の回でなくした（0031 の追記）。取り置きに使えるのは、残しておく額と、合計の入れ方の「運用しない分」。
- 前提にする記録: 0026（資産運用の入力と取り崩し）、0031（黒字の貯まり方）、0039（不動産を持ち始める時点）、0040（段階と例外の年）、0041（値の状態の操作）、0043（入力画面でプランを直す）、0044（お金の行）、0045（カード）。

## 決定

### 1. 区画「お金の行き先」（口座・資産配分の入れ方の詳細だけ）

- **取り崩す順番**を口座ごとに並べる（▲▼）。決済口座はいちばん上に「収支が入る口座」として出し、並べ替えない。iDeCo・企業型DC・小規模企業共済・まとめた金融資産の器は並べない（受け取りの決まりで預金に入る・まだ分けていない分は決済口座の次）。
  - 見え方はエンジンの取り崩しと同じ決まりで作る（`savings/model.ts` の `withdrawViewOf`。順番の要素を上から読み、種類の要素はその種類の口座を世帯の並び順で、書かれなかった口座は「取り崩さない」）。
  - 口座を動かす・「取り崩さない」を付け外しすると、選んだ口座を物の ID（`{object}`）の順に書き、その後に、「取り崩さない」口座の無い器の種類を標準の順（預金・外貨預金・財形・課税口座・持株会・旧NISA・NISA）で足す。後から足した口座と、エンジンが作る器（NISA の枠を超えた分の課税口座・旧NISA の移し先）を最後に取り崩すため。標準と同じ並びで取り崩さない口座が無ければ、順番を消す（標準に戻る）。「標準の順番に戻す」でも消せる。
  - 器の種類で書いた古い順番（資産配分の入れ方の3つのまとまり）は、開いても書き換えず、口座ごとに展開して見せる。FP が口座を動かしたときだけ物の ID で書く。
  - こどもNISA・ジュニアNISA は標準では取り崩さない（エンジンの標準の順番に無い）。「取り崩さない」を外すと順番に入る。
  - 資産配分の入れ方の3つのまとまりの並べ替えは、この区画に移した（課税口座の税・リバランスはそのまま）。
- **収支が入る口座**（決済口座）: 預金が2つ以上のとき、預金から選ぶ。選んだ口座に印を付け、ほかの印を外す（今の決済口座を選び直したら何も変えない）。
- **預金に残しておく額**（1欄）: エンジンの「決済口座に年末に残す額」をそのまま出す。省略は0円（預金を使い切ってからほかの口座を取り崩す）。その年の年末の額（今の値段ではない）。
  - 目安のボタン「生活費の6か月分」「生活費の1年分」: 押した時の基本生活費の月額（最初の生活費の物。費目の入れ方は費目の合計）×6・×12 を1万円に丸めて入れる。値は**押した時の額で止まり、生活費を変えても追いかけない**。根拠つきの推定（要求の入力の値の状態の欄の行。出し方 `standard`、根拠に月額と月数）にし、「✓ この値で確定」で根拠を残した確定にできる。打ち直すと行は外れる。
  - 生活防衛資金のような別の器は作らない。
- 簡易では、区画を開かずに見出しの「詳細あり」と1文（「取り崩す順番: 預金（ご主人）［収支が入る口座］ → 課税口座（ご主人） → NISA（ご主人）（標準）。取り崩さない: …。預金に残しておく額 …」）だけを出す。
- 合計の入れ方では区画を出さず、「合計の入れ方では使いません（口座の入れ方に戻すと効きます）」と出す。値は残す（計算では使われない。器が1つのため）。

### 2. 口座ごとの詳細（詳細だけ）

- 口座の表で入れる欄（種類・名義・残高・積立・利回り・取得価額・受け取り方）を除いた欄を、口座ごとのまとまりで並べる: 残高の時点、運用の費用、積立の終わり、引き出せない期間の終わり、旧NISA・ジュニアNISA の買付の年ごとの内訳、口座ごとの資産の配分。
  - **運用の費用**（器の `fee`）: 口座の入れ方の運用する口座だけ。資産配分の入れ方は配分の信託報酬を使うので出さない。口座の表の利回りは「費用を引く前」と書き、費用は計算で引く。
  - **引き出せない期間の終わり**（時点。その月まで取り崩さない）: 預金・課税口座など。iDeCo・企業型DC・小規模企業共済には出さない（受け取りの決まりで預金に入る）。ずっと取り崩さない口座は、お金の行き先の「取り崩さない」で決める。
  - **積立の終わり**: いちばん後の期間の終わりを指す（前は最初の期間の終わりを見せていた）。NISA で成長投資枠の積立もあるときは枠ごとに終わりが違うので出さない（積立の表の期間で直す）。
  - **旧NISA・ジュニアNISA の買付の年ごとの内訳**（年・制度・取得価額・時価）: 足す・外す。無ければ全部を残高の時点の年に買ったとみなす（エンジンの読み方のまま）。
- 「＋ 口座を足す」の主な4つ（預貯金・NISA・iDeCo・課税口座）は簡易、ほか（財形・企業型DC・外貨預金・持株会・小規模企業共済・旧NISA・ジュニアNISA・こどもNISA）は「そのほか ▾」で簡易からも開ける。こどもNISA・ジュニアNISA は子がいれば最初の子の名義で作る。

### 3. 受け取り（iDeCo・企業型DC・小規模企業共済）

- iDeCo・企業型DC の受け取り方の名前を「一時金・年金・併用」にし、詳細に**年金で受け取る年数**（5〜20年。空欄は10年）と**一時金で受け取る割合（併用）**（空欄は半分）、**加入者期間の始まり**（年月）を出す。受け取る額の概算は併用の割合を使う。年金から併用に変えたとき・併用の割合を入れた後に年金と併用を行き来したとき、入れた年数と割合は残す（年金に変えると併用の割合だけ外す）。
- **小規模企業共済**（エンジンの部品のとおり）: 受け取り方（一括・分割・併用）、受け取りを始める時期（廃業・退職など。時点。空欄なら受け取らずに残高のまま持つ）、分割で受け取る年数（10年か15年）、一括で受け取る割合（併用）、加入した年月（一括の退職所得の勤続期間の近似）。

### 4. 足した口座の残高と、入れていない合計

- 「＋」で足した口座・不動産・その他の資産の残高（評価額）は、**未入力（0円で計算中）**の印の0円（出し方 `standard`、根拠が「未入力」で始まる推定の箱）で始める。打つと確定になる。前は印の無い確定の0円だった（計算の結果は同じ）。
- 口座の無い世帯を合計の入れ方にしたとき（合計が0円）も、金融資産の合計を同じ印で始める。

### 5. 合計の入れ方の利回りの選び方

- 「控えめ（1.0%）・ふつう（2.0%）・積極的（3.0%）・率で入れる」のボタンで平均の利回りを入れる。値は事務所の標準の仮の値で、商品のおすすめではないと書く。選び方は保存しない（平均の利回りの値がボタンの値と同じならそのボタンを押した状態で見せ、ほかの値なら「率で入れる」）。詳細と「率で入れる」では率の欄を出す。
- 「運用しない分」は詳細に移した。

### 6. 不動産（住まい以外）

- 土地と建物に分けた不動産の「土地と建物」に、**持ち始める時点**（詳細。これから相続・贈与で受け取る不動産）を出す（0039 の `holdFrom`）。分けていない不動産には持たせない（中身を作ると土地と建物の計算に変わるため）。分ける欄の説明に、分けると入れられることを書く。
- お金の行（0044）の「不動産の一時の経費（大規模修繕・原状回復など）」の区画を、このカードのパネルにも出す（不動産があるか行があるとき）。行は家計の支出として出る。不動産所得の経費にはまだ入れていないと区画に書く。
- 家賃と経費の年額の段階・例外の年（0040）は今のまま。

### 7. 専用の部品の欄の値の状態の操作（0041）

- 入力のパネルは、貯蓄・運用のパネルにも値の状態の操作（現状なら `applyStateOp`、プランを直しているなら `planStateOp`）を渡す。区画の部品（`Section`）で描く欄（口座ごとの詳細・お金の行き先・受け取りの詳細・不動産・利回りの段階）は、ほかのカードと同じ4つの操作と印を持つ。
- 専用の部品の欄（口座の表の残高・取得価額・利回り、金融資産の合計・平均の利回り・運用しない分、積立をやめる年齢）には、状態の印と根拠の1行・操作・プランの「現状と違う」印を添える（`input/FieldStateLine.tsx`。状態は `fieldStatus`、操作は渡された関数で、欄の部品と同じ決まり）。表の中では確定のほかの操作を「…」の後ろにたたむ。押しても世帯が変わらない「確定」（推定の値を書く所が無い欄）は出さない。
- 専用の部品の数の欄は、入ったときと同じ文字のまま離れたら書かない（欄の部品と同じ `shouldCommitOnBlur`）。打ったときは欄の定義の書き方で書く（同じ値でも書く。未入力の0円に0を打つと確定になる。打った操作のため）。
- 確かめの一覧から「開く」で来たとき、専用の部品の数の欄にも移れるように、欄の DOM の ID（`fieldDomId`）を付けた。

### 8. そのほか

- 取り崩しの計画を予定なしから定額・定率にしたときの始める年齢の初めの値を、65歳か退職の遅い方（過ぎていれば次に迎える年齢。0026 の追記 2026-10-25）にした（前は65歳のまま）。
- 入力のホームのカードの要約（金融資産の額）は、入れ方のとおりに数える（合計の入れ方で残した口座の値と、まだ分けていない分を二重に足さない）。

## 理由

- **物の ID の後に器の種類を足す**: 物の ID だけで書くと、後から足した口座とエンジンが作る器が取り崩されず、黙って資金不足になる。「取り崩さない」口座がある種類を足さないのは、種類の要素がその口座も取り崩してしまうため。
- **残しておく額を1欄に**: 生活防衛資金は複雑になりすぎてなくした。エンジンの1つの値をそのまま出せば、計算の決まりを増やさずに「手を付けないお金」を表せる。目安が生活費を追いかけると、生活費の段階や推定の入れ直しで黙って変わり、FP が決めた額と違ってしまう。
- **専用の部品のまま印と操作を添える**: 口座の表・期間を分けた積立は欄の部品では描けない。欄の定義（確かめの一覧が使う物）を同じ所から引けば、状態の決まりは1つのまま。
- **足した口座を未入力の印で始める**: 0円のまま黙って計算する所を作らない（0041・0045 の決め）。値は同じなので計算は変わらない。

## 代案（採らなかったもの）

- **取り崩す順番を器の種類のまとまりのまま全部の入れ方に出す**: 名義ごと・取り置きの口座ごとに決めたい、という要望に届かない。
- **目安のボタンの額を生活費に連動させる**: 上の理由。連動させたい FP は生活費を変えた後にもう一度押せばよい。
- **利回りの選び方を画面の側に保存する**: 世帯ファイルの形が変わる。値から見せ方が決まるので保存しなくてよい。
- **口座の利回りの空欄（前提から計算した値）を推定の印にする**: 「✓ この値で確定」で書く値が無く（前提・配分に追いかける値）、押しても変わらない推定の欄がカードと確かめの一覧に残り続ける。今の薄い文字（前提から計算した値）のままにした。

## 未確定

- 口座の間の移し替え（`transfers`。入れ物だけ）の画面: 計算を入れる回まで出さない。取り置きを使う年に戻す・決めた年に売る・黒字の行き先・支出を払う口座は、移し替えの計算と一緒に作る。
- 配当・分配金の受け取り（利回りを値上がりと受け取る分に分ける）、取り崩しの計画の段階、口座の名前・満期の年月（表示だけの欄。形式の版を上げる回）、金融資産の合計の目安（統計の原本で確かめてから）、逆算の条件（○歳の年末に○円残す）: 計算か形が入る回まで欄を出さない。
- 不動産の一時の経費を、貸している不動産の不動産所得の経費に入れる（修繕費と資本的支出の選択）: 計算を入れる回まで、家計の支出として出るだけ。
- 取り崩す順番を器の種類のまとまりで並べ直す操作（口座ごとの順番を消して種類の順にする）。今は「標準の順番に戻す」だけ。
- 欄の部品（`FieldViews.tsx` の `Field`）でも、未入力の0円の欄に0を打ったときに確定にするか（今は同じ値なので何も変えない）。
- 口座の利回り・iDeCo の受け取り方の空欄（推定）を、「✓ この値で確定」で値として書けるようにするか（今は押しても変わらないので、専用の部品では出さない。確かめの一覧には出る）。
