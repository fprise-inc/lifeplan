# 0029. 保育料の自動の計算と、学校給食費の負担軽減

- 状態: 採用（一部未確定）（2026-10-20）
- 固定の強さ: β公開から変えない（骨格）。計算部品ID（`education.nurseryFee`）、制度の値ID（`educationSupport.nursery.*`・`educationSupport.schoolLunch.*`・`education.statistics.{elementary,juniorHigh}.public.schoolLunch`）、教育の目標の欄（保育所の段の `hours`・`feeRatio`、目標の `schoolLunch`）、計算式ID（`education.nurseryFee.auto`・`education.nurseryFee.input`・`education.cost.schoolLunchRelief`）は骨格。自治体の水準の割合の既定値（目安 0.8）、きょうだいの数え方・ひとり親世帯等の見分け方の近似、画面の見せ方は後から変えてよい（変えたら追記に書く）

## 背景

- 保育園（0〜2歳）の保育料は、教育の目標の保育所の段に月額を入れる形だった。月額は市区町村の保育料表と世帯の住民税で決まり、FP が顧客ごとに調べて入れるのは手間がかかる。簡易の入力でも出したい。
- 保育料は、市区町村が「市町村民税の所得割額」（父母の合計）の階層で決める。国は階層ごとの上限（利用者負担の上限額）を政令で定め、多くの市区町村はそれより低い額にしている。エンジンは住民税（所得割）を計算できる（`residentTax.annual`）。
- 小学校・中学校の学校の費用は「子供の学習費調査」の学習費総額−学校外活動費（＝学校教育費＋学校給食費）で計算していて、給食費が入っている。国の「学校給食費の抜本的な負担軽減」が令和8年4月から公立小学校で始まった。
- 0003（年度・月）、0006（部品・約束の版）、0007（制度データの形式・出典・承認）、0008（教育の目標）、0010（学費データと公的支援を分ける）が前提。

## 決定

### 1. 保育料の部品 `education.nurseryFee`

- 保育所の段（`stage: nursery`）は、新しい部品 `education.nurseryFee`（子ごと。入力は `member`）が計算する。`education.cost` は保育所の段を数えない（月額の入力も、この部品に移した）。`plan.flows` と `protection.need` はこの部品の出力も集める。行は今までどおり `cf.expense.education.nursery`（保育料）。
- 部品を分けたのは、多子の軽減できょうだいの教育の目標を読むため（`education.cost` は子の目標だけを読む `memberScope` にしてあり、1人の目標を変えてもほかの子の教育費を計算し直さない形を崩さない）と、住民税の部品を呼ぶため。
- 月額（`monthly`）を入れた段は、その月額を教育費の上昇率で伸ばして毎月計上する（計算式 `education.nurseryFee.input`）。`0` は「保育料なし」（自治体が独自に無償化している場合など）。
- 月額を入れていない段は、2〜5 のとおり世帯の収入から自動で計算する（計算式 `education.nurseryFee.auto`。知らせ `N_ESTIMATED`。画面では「保育料（自動計算・目安）」）。
- 期間は、通い始め（`from`）から、3歳になった後の最初の4月の前の月まで（満3歳に達する日以後の最初の3月31日までは3号認定の額。施行令4条1項2号・2項。3歳の学年の4月からは幼児教育・保育の無償化で0円）。
- 通い始めの省略は、その子の育児休業（働き方の期間の `leave`・`childcare`）の終わりの翌月。対象の子を書いていない育児休業は、休業の始まりの2か月後までに生まれた子のうち、いちばん遅く生まれた子のものとみなす。育児休業の入力が無ければ1歳の学年の4月（今までの既定）。

### 2. 国の基準の上限（制度データ）

- 子ども・子育て支援法施行令4条2項（満3歳未満保育認定子どもの利用者負担の上限）を、e-Gov法令検索の条文とこども家庭庁の公表資料（「幼児教育・保育の無償化 利用者負担」の表）で照らし合わせて入れた（`regulation.educationSupport` 2026.5.0。`reviewed`）。
  - `educationSupport.nursery.fee.standard`・`.short`（段階表。保育標準時間・保育短時間）: 市町村民税所得割合算額 48,600円未満 19,500円（19,300円）／97,000円未満 30,000円（29,600円）／169,000円未満 44,500円（43,900円）／301,000円未満 61,000円（60,100円）／397,000円未満 80,000円（78,800円）／それ以上 104,000円（102,400円）。令和元年10月1日の版と令和8年10月1日の版で額は同じ。
  - `educationSupport.nursery.fee.specified.limit`・`.amount`: ひとり親世帯等（特定教育・保育給付認定保護者）は所得割合算額 77,101円未満なら 9,000円（4条2項6号・7号ただし書）。
  - `educationSupport.nursery.multiChild.secondRatio`（0.5）・`.lowIncomeLimit`（57,700円）: 多子の軽減（13条・14条。下の4）。
- 市町村民税世帯非課税者（4条2項8号）と、生活保護の世帯は0円。部品の決まりとして持つ（値は持たない）。生活保護は扱わない。
- 上限は「給付単価（公定価格）を限度とする」（4条2項の「いずれか低い額」）が、公定価格は持たないので、表の額をそのまま上限とする。

### 3. 市町村民税所得割合算額と、どの年度の住民税か

- 父母（関係 `parentOf` の親。無ければ本人と配偶者）の市町村民税の所得割を足す。所得割は、調整控除の後・住宅借入金等特別税額控除の前の額（施行令4条2項2号の「附則第五条の四第五項その他の内閣府令で定める規定による控除をされるべき金額があるときは、当該金額を加算した額」）で、100円未満を切り捨てる。寄附金税額控除・配当控除などはエンジンが計算していないので、もともと引いていない。
- **年度は施行令のとおりにする**（年単位の近似にしない）: 4〜8月分は前年度、9〜3月分はその年度の住民税（4条2項2号。こども家庭庁の資料の「８月以前は前年度分、９月以降は当年度分」）。エンジンは年度ごとの住民税を計算できるので、近似にする理由が無い。育児休業の翌年度に所得割が下がり、保育料が9月に切り替わるのを表せる。
- 父母がみな住民税（均等割も）を課されない年度は0円（市町村民税世帯非課税者）。所得割が0円でも均等割がかかれば一番下の段（19,500円）。
- 住民税の決定額だけを入れた年度（`residentTaxAssessment`）は、所得割の内訳が無いので、決定額の10分の6（市町村民税の標準の割合）を所得割とみなす（均等割の分だけ多め。知らせ `N_APPROXIMATED`）。
- 所得割は全国一律の標準税率で計算する（住民税の部品と同じく、指定都市の税率の配分・超過課税は扱わない）。父母以外の同居の家族（祖父母が家計の主宰者の場合など）の所得は足さない。

### 4. 多子の軽減とひとり親世帯等

- 多子の軽減（施行令13条）: 小学校就学前で保育所・幼稚園・認定こども園などに通う子（負担額算定基準子ども）の年長の順で、2番目は国の基準の額×0.5、3番目以降は0円。
  - きょうだいが通っているかは、そのきょうだいの教育の目標で見る: 幼稚園の段があれば3歳の学年の4月から、保育所の段があればその通い始めから、小学校に入る前の月まで通っているとみなす（保育所の段だけで幼稚園の段が無い子は、3歳からも保育所に通うとみなす）。教育の目標が無いきょうだいは数えない。
  - 生まれた月が同じきょうだい（双子など）は、構成員の並びの順を年長とする。
- 所得割合算額が 57,700円未満（ひとり親世帯等は 77,101円未満）の世帯は、年齢と通っているかを問わず、世帯にいる子の年長の順で数える（14条。ひとり親世帯等は2番目から0円）。
- ひとり親世帯等: その月に世帯にいる子の親が1人のとき（万一の想定で親が亡くなった月からを含む）。在宅障害児（者）のいる世帯・要保護者等の世帯は扱わない。

### 5. 自治体の水準（国の基準に対する割合）

- 自動の計算では、2〜4 で求めた国の基準の額に「国の基準に対する割合」（保育所の段の `feeRatio`。省略は **0.8**）を掛ける（円未満切り捨て）。FP は自治体の保育料表に合わせて割合を変えるか、月額を入れる。
- 既定値 0.8 は**目安**で、公的な資料に全国の平均の割合を直接示すものは見つからなかった。根拠にしたのは、内閣府の令和4年度子ども・子育て支援調査研究事業「幼児教育・保育の無償化の効果等の把握に関する調査研究」（令和5年3月。こども家庭庁が掲載）の自治体アンケート:
  - 回答した自治体の 55.7% が「国基準に対する保育料（0〜2歳）の独自軽減」をしている（図表11）。
  - その軽減率（「国基準に対する％」）は「61〜70％」が最も多く（20.95%）、41〜80% に約7割が入る（図表14、611件）。
  - 「軽減率」が国の基準から下げた割合か、国の基準に対する水準かは表から読み切れない。どちらに読んでも、独自軽減をしない自治体（約44%）を国の基準のまま（1.0）とした自治体の単純な平均は国の基準のおよそ 0.66〜0.78 になる。
  - ライフプランでは支出を少なく見積もるほうが危ないので、この幅の上の端を丸めた 0.8 を既定にした（保育料を多めに見る側）。
- 限界: 自治体の数の平均で、人口では重みづけしていない（大きな市ほど独自軽減をしている割合が高い。図表12）。調査は令和4年度で、その後の都道府県・市区町村の独自の無償化（第1子からの無償化など）は入っていない。自治体ごとのデータは持たない（独自の無償化は FP が月額 0 を入れるか割合を変える）。

### 6. 学校給食費の負担軽減

- 確かめた結果（文部科学省「学校給食費の抜本的な負担軽減」の案内、給食費負担軽減交付金実施要領（令和8年3月24日決定・5月29日一部改正）、文部科学省・総務省・財務省「三党合意に基づくいわゆる教育無償化に向けた対応について」（令和7年12月19日））:
  - 令和8年（2026年）4月から、給食を実施する公立の小学校（義務教育学校前期課程・特別支援学校小学部を含む）の児童に、保護者の所得によらず、食材費を国と都道府県が2分の1ずつ自治体に支援する。法律（学校給食法）は改正せず、予算補助（給食費負担軽減交付金）として実施する。
  - 基準額は完全給食で児童1人あたり月 5,200円（令和5年の実態調査の平均に物価を加味）、年間は11か月分。基準額を超える部分は、引き続き保護者から学校給食費を徴収できる（自治体によっては保護者の負担が残る）。基準額は毎年の調査と物価で見直す。
  - **中学校は対象外**。三省の対応方針では「中学校給食についても…課題の整理を行った上で検討」で、決まっていない。私立の小学校も対象外。
- 制度として確定している公立小学校の分だけを制度データに入れた（`educationSupport.schoolLunch.elementary.public.monthly` 5,200円・`educationSupport.schoolLunch.months` 11。令和8年4月1日から。`reviewed`）。中学校の値は入れない（未確定・見直し待ち）。
- 統計の学校給食費（「子供の学習費調査」令和5年度・訂正版の表1「うち学校給食費」）を `master.education.statistics` に足した（公立小学校 35,774円・公立中学校 35,671円。2026.3.0。表の内訳の合計を計算し直して照らし合わせた `reviewed`）。
- `education.cost`（改訂3）: 公立小学校の段で、制度の値がある年度（令和8年度から）は、統計の学校給食費（教育費の上昇率で伸ばした額）と基準額×月数（名目額）の小さい方を学校の費用から引く（計算式 `education.cost.schoolLunchRelief`）。基準額を超える分は保護者の負担として残す。統計の給食費は既に自治体が無償化していた子も含む平均で、今の値（約3.6万円）は上限（5.72万円）より小さいので、当面は全額が引かれる。
- 教育の目標の `schoolLunch`（「詳細」の欄「公立の小学校・中学校の給食費」）で子ごとに変えられる: 省略は制度データどおり、`free`（自治体が無償化）は公立の小学校・中学校の全年度で統計の学校給食費の全額を引く、`paid`（全額を払う）は引かない。学校の年額を直接入れた段（`annualOverride`）と、学費データの行（学校が決まっている段）は引かない。
- 交付金は保護者への給付ではないので、収入（公的支援）ではなく、学校の費用を減らす形で表す（0010 の5 の「支援を引く前の額」は学費データ（学校別の学納金）の決まりで、統計の平均の学校給食費には当てない）。
- 「授業料など／給食費／習い事・塾」の内訳を画面で分けて見せることは、今回は作らない（保留）。

### 7. 世帯ファイルの形式

- 世帯ファイルの形式の版を `0.9` に上げた（足した欄 `hours`・`feeRatio`・`schoolLunch` はどれも任意。0011 の追記）。保育所の段の空の月額は、古い版では0円、`0.9` からは収入から自動で計算する読み方で、データは書き換えない。

## 理由

- **国の基準を制度データ、自治体の水準を割合で**: 国の基準は政令で全国一律に決まり、出典をたどれる。自治体ごとの保育料表を全国分持つことはできないので、割合という1つの数で近づけ、FP が直せるようにする。
- **年度を施行令のとおりに**: 育児休業の年の所得の落ち込みが保育料に効く（休業の翌年度の9月から下がる）。年単位の近似では、この切り替えを表せない。
- **部品を分ける**: きょうだいの教育の目標と住民税を読む計算を `education.cost` に入れると、1人の入力の変更でほかの子の教育費まで計算し直すことになる。
- **給食費は確定した分だけ**: 中学校は政府の文書でも「検討」で、時期も額も決まっていない。決まっていない制度を見込むと、FP が顧客に誤った説明をしてしまう。

## 影響

- 後から変えると: 世帯ファイルの教育の目標の欄（`hours`・`feeRatio`・`schoolLunch`）と計算部品の約束の作り直しになる。
- 守るべき決まり:
  - 保育料の自動の額は制度の名目額で、教育費の上昇率を当てない（月額を入れた段は当てる）。
  - 自動の額には「目安」であることを画面で示す（計算式の名前「保育料（自動計算・目安）」と、入力の欄の「推定あり」）。
  - 中学校の給食費の負担軽減は、制度が決まるまで制度データに入れない。
- テストで確かめること（CI）: 所得割合算額の段階ごとの額、保育短時間の表、4〜8月と9〜3月の年度の切り替え、非課税の世帯、3歳の4月からの無償化、多子の軽減（2番目半額・3番目0円、所得の上限未満の数え方）、ひとり親世帯等、割合、月額の上書きと 0、育児休業からの通い始め、表への計上。給食費は公立小学校の令和8年度からの差し引き、私立・直接入れた年額・中学校は引かないこと、`free`・`paid`。

## 未確定（11月以降に決めること）

- 中学校の学校給食費の負担軽減（国が検討中。決まったら制度データの値を足し、`education.cost` の対象の段に中学校を足す）。
- 学校給食費の基準額の毎年の見直し（新しい額が決まったら行を足す。それまでは令和8年度の額のまま続くものとする）。
- 自治体の水準の割合の既定値の見直し（人口で重みづけした全国の水準の資料が見つかれば、その根拠で直す）。事務所の標準値（0025・0026）で事務所ごとに既定を変えられるようにするか。
- 保育標準時間・短時間の既定を、父母の働き方（短時間勤務など）から決めるか（今は省略を標準時間とする）。
- 在宅障害児のいる世帯などの軽減、3〜5歳の副食費（給食の材料費。無償化の対象外）を足すか。
- 万一の想定で、遺族の所得による保育料の変化を必要保障額に入れるか（今は万一なしの額）。

## 追記

- 2026-10-25（計算基準月より前の年度の住民税）: 3 の「年度は施行令のとおりにする」の例外として、計算基準月に払っている住民税の年度より前の年度の住民税は使わない。計算基準月が6〜8月の年の、その月から8月までの分は、計算基準月に払っている年度の住民税で決める（前の年度の住民税は表に載らず、その所得の年の制度の値が制度データに無いことがある。0003 の追記（2026-10-25））。
