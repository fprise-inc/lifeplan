# 0075. 結果の表の行の足し（プランの比較の年金の見込み・世帯の外の家族の収入の行・扶養の境目の参考の行）

- 状態: 採用（一部未確定）（2026-10-27）
- 固定の強さ: 内部（画面の作り）。世帯ファイルの形・エンジンの入力と出力は変えない（計算の結果を読むだけ。お金の流れは変えない）。行の名前・並び・説明の文は後から変えてよい（変えたら追記に書く）
- 前提にする記録: 0035（世帯の外の家族と家計を1つにする期間）、0042（世帯の外の家族のお金）、0059（介護・親のカードと扶養の境目の1行）、0067（年金のカードの年金の見込み）。

## 背景

- 年金の見込み（今の水準の65歳からの額。0067）は年金のカードにだけ出ていて、プランの比較の表には年金の行が無かった。働き方を変えたプランどうしで年金の月額を比べるには、表の年金の行を2つのプランで見比べて月額に直すしかなかった。
- 世帯の外の家族（家計が別の親など）の年金・給与は、家計を1つにする期間のうち「収入を世帯に入れる」月の分だけ世帯の表に入る（0035 の4）。表の行の見出しは「ご家族の年金」で、誰の分か・どの期間の分かが表から分からなかった。年齢の行も「ご家族」だった。
- 扶養していると入れた親・祖父母の扶養控除は、計算がその年のその人の所得で年ごとに判定し、境目を超える年は黙って外す。入力の側の扶養の境目の1行（0059 の4）は、今の年の境目と、親のお金に入れた年金の額との比べだけで、計算が判定に使う額（年金の推計）と年ごとの差は見えなかった。

## 決定

### 1. プランの比較の表の年金の見込みの行

- 比較の表を開いている間だけ、帯のプランごとに、年金のカードの年金の見込みと同じ写しの要求（`pensionEstimateRequest`。賃金上昇率・物価上昇率・マクロ経済スライドを外した今の水準、万一の想定などを外す）を求める。プランの要求は、保存していない変更を含む今の中身（万一のときの画面と同じ `cgRequestOf`）。
- 行「65歳からの年金（夫婦の月額・今の水準）」: 受け取り開始を外した写しの、人ごとの老齢年金の年額（受け取り開始の年の次の年）の合計÷12。年金のカードの要約（「夫婦で月24.1万円（65歳から・推定）」）と同じ額・同じ丸め。全員もう受け取っていれば「年金（夫婦の月額・今の水準。受け取り中）」。1人の世帯は「夫婦の」を付けない。
- 受け取り開始を変えたプランが1つでもあれば、行「受け取り開始からの年金（夫婦の月額・今の水準。繰下げ・繰上げを含む）」も出す（変えたままの写し。変えていないプランは65歳からと同じ額）。
- 差は「そのプラン−基準」の月額（「+1.4万円」）。年金が少ないことは「注意」にしない（働き方の違いの結果で、悪いとは限らない）。求めている間の列は「計算しています…」、求められなかった列は「—」。

### 2. 世帯の外の家族の収入の行

- 世帯の外の家族の給与・年金の行の見出しを「お母さまの年金（家計を1つにする間）」にする（行の中身は今までと同じ。その人の分だけ）。見出しに説明「世帯の外の家族（家計が別）の収入は、家計を1つにする期間のうち『収入を世帯に入れる』月の分だけ、世帯の収入に入れています」を付ける。年齢の行の見出しも同じ呼び方にする。
- 呼び方は、親はお父さま・お母さま（性別が無ければ親御さま）、祖父母はおじいさま・おばあさま、ほかはご家族。同じ呼び方の世帯の外の家族が2人以上いれば、誰の家族かを前に付ける（「奥様のお母さま」）。世帯の外の家族のお金が尽きるできごとの文も同じ呼び方にした。

### 3. 扶養の境目の参考の行

- 扶養していると入れた、生年月のある世帯の外の親・祖父母がいるときだけ、表の最後に参考のまとまり「参考（世帯のお金の流れに入らない）」を出し、人ごとに2行を置く。
  - 「お母さまの年金（扶養の判定に使う額）」: 計算がその人の所得の判定に使う年金の額（年ごと・額面）。家計が別の年の年金は世帯の表に出ないので、写しの要求（その人の家計を1つにする期間を、全部の期間で「収入を世帯に入れる」1つの期間にしたもの。年金の額は家計の扱いで変わらない）の結果から読む。親のお金に入れた年金の額ではなく、計算が判定に使う推計の額。
  - 「税の扶養の境目まで」: 税の扶養の境目（年金だけなら、合計所得の上限＋その年の12月31日の年齢の公的年金等控除の最低額。0059 の4 と同じ制度の値）−その年金。境目を超える年は▲（その年は扶養控除を入れていない）。
- いる年（生まれていて、亡くなる見込みの年まで）だけ出す。結果のタブを見ている間、表に出しているプランの要求で1回求める（計算し直している間は前の結果を見せておく）。
- 健康保険の扶養と、年金のほかの所得（給与・事業など）は見ない（見出しの説明に「年金のほかに収入がある人は、合計所得で確かめてください」）。

### 4. 扶養している・同居している・仕送りの額の欄の直し

- 介護・親のカードで、扶養している・同居している・仕送りの額のどれか1つだけを入れると、構成員の `support` に片方の印が無いまま残り、計算の要求の形に合わず計算できなかった。書いた後に、無い方の印を既定（false）で埋める。

## 理由

- **年金の見込みを写しの要求で求める**: 年金のカードと同じ求め方にしないと、カードと比較の表で額が食い違う。結果の表の額（物価・賃金で伸ばした額）は30年先の額で、プランどうしの月額の比べに向かない。
- **比較の表を開いている間だけ求める**: プランごとに1〜2回の計算が要る。開いていないときに求めると、帯のプランを動かすたびに計算が増える。
- **扶養の境目を参考の行にする**: 判定に使う額は年ごとに変わり（年金の改定・65歳の境）、計算が黙って扶養控除を外す年がある。表の年の並びで差を見せると、外れる年が分かる。世帯のお金の流れに入らない額なので、収入のまとまりには入れず、表の最後に分けて置く。
- **計算が判定に使う額を出す**: 親のお金の年金の額は親のお金の見通しにだけ使い、扶養の判定は推計の年金で行う（0042）。画面が判定と違う額で境目を見せると、結果と食い違う。

## 代案（採らなかったもの）

- **エンジンに扶養の判定の結果（年ごとの所得と境目・数えたか）を出力として足す**: 判定そのものを読めるが、出力の約束が増える。まずは写しの要求の結果と制度の値から作り、要るなら後で足す。
- **世帯の外の家族の収入を収入のまとまりの外に出す**: 家計を1つにする期間の分は世帯の収入なので、収入合計と年間収支に入る。見出しで分かるようにするだけにした。
- **年金の見込みの行を帯のプランのカードにも出す**: カードが混む。比較の表だけにした。

## 追記（2026-10-31: グラフの札の呼び方・説明モードの収入の段）

- グラフの年を指したとき・固定したときの札の家族の年齢（主画面のグラフ・万一のときのグラフの `ChartModel.family`）と、年の詳しい数の家族の年齢も、結果の表の年齢の行と同じ呼び方にする（世帯の外の家族は「お母さま」、同じ呼び方の人が2人なら「ご本人のお母さま」。`workspace/present.ts` の `personLabel`）。前は「ご家族」と呼び、表の呼び方と違っていた。
- 説明モードの収入の段の一文は、収支の推移のグラフの「給与」（給与と事業の収入）と同じ範囲で言う: 事業の収入だけなら「事業の収入」、両方あれば「給与・事業の収入」。最後の年には、その年に働いて得る収入がある人（本人を先に）の年齢を添える。「いちばん多い年」は働いて得る収入だけの額で、棒（給与・退職金など）の額がそれより多い年があれば「退職金などを合わせると、いちばん多い○年は…」を続ける。前は退職金を含めた額を「いちばん多い年」と言い、事業の収入も「給与」と呼んでいた。
