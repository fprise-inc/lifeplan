# 0177. プランを重ねて写すときの打ち消し・FP顧問料の料金の段階と対策の値・資産の配分の割合の按分・範囲の無かった率の欄

- 状態: 採用（一部未確定）（2026-11-08）
- 固定の強さ: 内部（計算エンジンの部品 `expense.advisoryFee` の改訂3・`plan.cashflow` の改訂26・`account.ideco` の改訂7・`account.mutualAid` の改訂5・`asset.heldSale` の改訂4、プランの差分のまとめ方、対策「FP顧問料」の値の読み方、入力の欄の範囲と知らせ。世帯ファイルの形式の版・差分の形・エンジンの入力の形は変えない）
- 前提にする記録: 0008（FP顧問料の入力・案の土台）、0026（資産の配分・相場の下落）、0036（プランの差分の型・当てる順・土台を外す）、0070（料金の段階）、0073（事務所の料金表）、0098（率の欄の範囲）

## 背景

まとめて調べた不具合（顧問料とプランの回）のうち、次の7つを直した。

1. **プランを消すと、別のプランの中身が変わる**: 土台のプランBで足した物（車・顧問料の契約など）を、Bを土台にしたCで外しているとき、Bを消す（帯の × も同じ）と、外した物がCに戻った。Cの値から土台なしで新しいプランを保存しても同じ。プランを消すときは土台の差分をCに写して1つのプランにまとめる（0036）が、1つのプランの中は「外す → 足す → 値を変える」の順に当てるので、Cの「外す」が先に空振りし（要確認「外す物がもうありません」）、Bから写した「足す」が後から物を戻した。例: 会社員の世帯で、Bで車を足しCで外すと、Bを消した後のCの支出の合計が約2,242万円増えた。
2. **顧問料の払い方を月額⇄年額に変えると、料金の段階が前の払い方のまま残る**: 継続の額だけを直し、段階は直していなかった。段階の欄は継続の払い方の額を読むので空に見え、そこに打つと段階が年額と月額の両方を持ち、エンジンは両方を払った（例: 月1.5万円と年18万円で、年36万円）。打たなくても、提案書の注は月の額に「年」を付けて「年15,000円」と書いた。
3. **年額の顧問料で、料金の段階の月を払う月からずらすと、その年に年額を2回払う**: 段階の月に新しい年額を払い、その月を以後の払う月にしていた（例: 1月払いの年12万円・段階「2029年7月から年15万円」で、2029年は27万円）。
4. **料金の段階を始まりと同じ月（か前）にすると、計算は段階を無視するのに、提案書の注には段階の額が出る**: 段階を当てる条件が「始まりより後」だけだった。
5. **提案の側だけの契約を、どのプランにも入れられない（仕様の穴）**: 対策「FP顧問料」の今の値は「現状にも入れる」の契約が1つでもあれば「入れる」だった。今の顧問契約（現状にも入れる）と提案の側だけの契約があると、結果の画面で「入れる」にしても現状と同じ値として差分にならず、提案の側だけの契約はどのプランにも入らなかった（0008 の追記の「ON はすべての契約を入れる」が当たらない）。
6. **口座ごとの資産の配分の割合が、合計100%でなくても知らせが出ず、利回りがそのまま増減する**: 合計120%なら利回りが1.2倍、合計50%なら半分（残りは0%）。1行だけのときは割合を見ずに100%として扱い、2行以上では割合をそのまま掛けていた。リバランスしない設定のときだけ合計で割っていた。
7. **健康保険料率（本人負担分）・生活費の段の割合・住まいの費用（家賃・修繕や管理の費用・固定資産税）の段の割合が、マイナスと大きすぎる値を受け付ける**: 欄は「-100%」のまま計算は0%、999% も知らせなしで通った（0098 で範囲を付けた欄の外。0098 が名前を挙げた借入の金利・解約返戻率・予定利率・教育の欄とは別の欄）。

## 決定

### 1. 土台の差分を写して重ねるときは、足してから外した組を打ち消す（`plans/stack.ts`）

- プランを消すとき（`deletePlan`。帯の × も）と、別のプランの値から新しく保存するとき（`savePlan` の持ち越し）は、土台の差分に上のプランの差分を重ねる部品 `stackDiffs(下, 上)` でまとめる。持ち越しが何段にもわたるときは、土台のいちばん下から順に重ねる。
- 打ち消し方は、入力画面で同じプランの中で足した物を外したとき（`planEdit.ts` の `applyChanges`）と同じ:
  - 土台で足した物を上のプランで外す: 両方とも捨てる（土台で足した物の中への差分も捨てる）。置き換えの組（外す＋足す）なら、土台の足す物を組の足す物にし、組は捨てる。
  - 土台で足した物の中の並びの要素を外す: 土台の足す物から、その要素を除く。
  - 土台で足した並びの要素を外す: 両方とも捨てる（その要素の中への差分も捨てる）。
  - 土台で値の全体を変えた所（ID を持たない並びの全体など）の中の並びに、要素を足す・外す: 土台のその値に入れる・その値から除く（1つのプランの中は「足す → 値を変える」の順なので、そのままだと全体の値が上書きする）。
- 打ち消すのはオンの差分だけ。**オフにしてある上のプランの外す**は打ち消さずに残し、当てるとき（`applyDiffs`）に、外す物がまだ無い外す（置き換えの組でないもの）は、同じプランの足すを当てた後でもう一度外す（後でオンにしても、物が戻らない）。
- **性質のテスト**（`app/test/plan-stack-delete.test.ts`）: 3つの見本の世帯で、B ← C ← D の3段のプランに、物を足す・外す・置き換える・並びの要素を足す外す・値を変える・払い方を変える、をばらばらに入れ（各40通り）、土台をどの順で消しても（Bだけ・Cだけ・B→C・C→B）残ったプランの計算の要求が変わらないこと、Dの値から土台なし・Bを土台にして保存し直しても同じことを確かめる。空の並び（物を全部外した集まり）と、足さなかった集まりは同じ中身とみる。

### 2. FP顧問料の料金の段階は、契約の払い方の1つの額（エンジン・入力・提案書で同じ読み方。0070 の追記）

- **段階の額**: 年額と月額の両方があれば、契約の払い方（継続の顧問料が年額か月額か）の額だけを使う。片方だけならその額（前の版で払い方だけを変えた世帯は、段階の払い方のまま。計算も今までと同じ）。
- **年額の段階の月**: 年額で払う契約の年額の段階は、段階の月からの最初の払う月（始まりと同じ月。年に1回の前払い）から当てる（**決めたこと**: 「その年は前の額＋差額の月割り」ではなく「次の払う月から新しい額」。年額の前払いは1年に1回で、月割りの差額の精算は事務所ごとに違うため。料金表から作る段階〔○年目から〕はいつも払う月と同じ月なので、既定の契約は変わらない）。
- **始まりと同じ月か前の段階**: 始まりから段階の額（始まりより前の段階は、始まりの時点の額として当てる。いちばん後の物）。
- 入力: 払い方を変えると、段階も同じ払い方に直す（月額×12・年額÷12〔円未満は四捨五入〕）。段階の額の欄は、段階が持っている払い方で出し（両方あれば契約の払い方）、打つともう片方の額を外す（段階は年額か月額のどちらか1つ）。
- 提案書の注（`report/src/build.ts` の `stepsText`）: 段階ごとに、その段階の払い方で「年」「月」を付け、月はエンジンが当てる月（始まりより前なら始まりの月、年額の段階は次の払う月）で書く。
- エンジン: `expense.advisoryFee` の改訂3。

### 3. 対策「FP顧問料」の今の値は3つ（「入れる」「入れない」「今の契約だけ」）

- 対策の今の値（`advisoryFeeState`）: すべての契約を入れていれば「入れる」（true）、どれも入れていなければ「入れない」（false）、一部だけ（「現状にも入れる」の契約と提案の側だけの契約がある）なら「今の契約だけ」（null）。
- プランの値の意味は今までどおり（0008 の追記）: 「入れる」はすべての契約を入れ、「入れない」はどの契約も入れない。値が無い（現状のまま）・「今の契約だけ」は「現状にも入れる」の契約だけ。今の値が「今の契約だけ」の世帯では、「入れる」も「入れない」も現状と違う値なので差分になり、提案の側だけの契約をプランに入れられる。
- 結果の画面の対策の行は、契約が両方の側にある世帯だけ「入れない／今の契約だけ／入れる」の3つの選び方にする（ほかの世帯は今までどおり2つ）。土台が「入れる」のプランで「今の契約だけ」を選ぶと、今の契約だけに戻す差分になる。
- FP顧問料の一文の比べ方: 顧問料を入れている案（今の契約だけを含む）は入れない案と、入れない案は入れる案と比べる。提案書の「顧問料なし」の比べ方も、今の契約だけの案を顧問料を入れている案として扱う。
- **決めたこと**: 対策を「今の契約」と「提案の契約」の2つの項目に分ける案は採らなかった（2つの切り替えで4通りになり、今の契約を外して提案の契約だけを入れる組み合わせは「契約を解約する」に近く、入力の画面で直す方が自然。保存した差分の `lever:fee` の意味も変わる）。3つ目の値は値の無い状態（現状のまま）と同じなので、保存の形も前のプランの意味も変わらない。
- 持ち帰りのつまみ（`takeaway`）は、今までどおり「入れる契約が1つでもあれば入れる」で見せる（下の未確定）。

### 4. 口座の資産の配分の割合は、合計で割って按分する

- エンジン（sdk の器の利回り `accountReturnRate`・相場の下落の割合 `shockShare`）: 割合の合計が100%でなくても、合計で割って按分する。1行だけなら割合にかかわらずその資産クラスが100%（今までと同じ）、合計が0なら資産の配分が無いのと同じ。リバランスしない設定のとき（今までも合計で割っていた）と同じ扱いになる（**決めたこと**: 計算を止めるより按分の方が自然。結果のタブの資産配分のつまみ・資産配分の入れ方も、割合の合計で割った配分を作っている）。画面の利回りの目安（`plans/allocation.ts` の `expectedReturn`）も同じ按分にする。
- 入力: 合計が100%でないときは、最初の行の「割合」の欄の下と確かめの一覧に「資産の配分の割合の合計が120%です。計算では合計を100%として按分しています（国内株式75%・国内債券25%）。合計が100%になるように直してください」を出し、「合計を100%にする」で按分した割合に書き直せる（押したときだけ。小数第4位までにし、端数は最後の行で合わせる）。1行だけで100%でないときも同じ知らせを出す。
- 割合の欄の 0〜100% の範囲（入力の残りの直し）とは別の知らせで、両方が出るときは範囲の知らせを先に出す。
- エンジン: `plan.cashflow` の改訂26・`account.ideco` の改訂7・`account.mutualAid` の改訂5・`asset.heldSale` の改訂4（sdk の部品を使う部品）。

### 5. 範囲の無かった率の欄に範囲を付ける（0098 の追記）

- 健康保険料率（本人負担分。健康保険組合・共済の料率の欄）: 0%〜10%（`HEALTH_RATE_RANGE`。労使合わせた料率の上の端は13%ほどで、本人はその半分。介護保険料を含めても10%に届かない）。
- 段の「今の額に対する割合」（基本生活費の段・退職後の生活費の段、家賃・修繕や管理の費用・固定資産税の段）: 0%〜500%（`STAGE_RATIO_RANGE`。修繕積立金の段階の増額や、新築の軽減が終わった後の固定資産税も入る大きさ）。
- 範囲の外は 0098 と同じく打った時点で止め（「0%より小さい値は設定できません。」）、古い世帯に入っていた範囲の外の値は値を変えずに欄と確かめの一覧に知らせ、押したときだけ範囲の端にする。
- 住宅ローンの金利の範囲は 0098 の未確定のまま（ここでは付けない）。

## 理由

- プランを消す・保存し直すのは中身を変えない操作（0036）で、FP は結果の数字が変わったことに気づきにくい。打ち消しを入力画面の同じプランの中の扱いと同じにしたので、差分の一覧の見え方も、同じプランで足して外したときと同じになる。
- 料金の段階の欄の説明は「この月から、継続の顧問料をこの額にします」で、額は1つ。払い方は継続の顧問料の欄で選ぶので、段階もそれに合わせるのが自然。
- 「現状にも入れる」は契約ごとの事実、対策は提案の比べ方。事実が混ざっている世帯でも、両方の比べ方（提案の契約を入れる・どれも入れない）ができる必要がある。

## 影響

- 計算の結果が変わる世帯:
  - プランを重ね、土台で足した物を上のプランで外している世帯で、土台を消した・上のプランの値から保存した後のプラン（外したはずの物の額がまるごと戻っていたのが、戻らなくなる）。すでに消して写した後のプランは、保存してある差分のまま（下の未確定）。
  - 料金の段階に年額と月額の両方がある契約（払い方を変えた後に段階に打った契約。段階の後の毎年の顧問料が、両方の合計から契約の払い方の額だけになる）、年額の契約で段階の月を払う月からずらした契約（その年の年額1回分が減り、段階の額は次の払う月から）、段階を始まりと同じ月か前にした契約（始まりから段階の額）。
  - 「現状にも入れる」の契約と提案の側だけの契約があり、プランで「入れる」にしていた世帯（提案の側だけの契約が入る。今までは入っていなかった）。
  - 口座の資産の配分を2行以上入れ、合計が100%でない世帯（例: 国内株式90%・国内債券30%の課税口座の2050年の残高が 8,112,993円 → 6,278,243円）。1行だけの口座と、合計が100%の口座は変わらない。見本の世帯（54件）は変わらない。
- 画面: 顧問料の段階の欄の払い方、対策「FP顧問料」の3つ目の選び方、資産の配分の合計の知らせ、3つの率の欄の範囲。提案書の顧問料の段階の文。
- 世帯ファイルの形式の版・差分の形・エンジンの入力の形は変えない。

## 未確定

- すでにプランを消して写した後のプラン（直す前に作った物）に残っている「足す＋外す」の組は、開いたときに直さない（当てるときにもう一度外すので、中身は正しくなる。差分の一覧に両方の行が残る）。
- 持ち帰りの FP顧問料のつまみを3つの値にするか（今は「入れる契約が1つでもあれば入れる」。今の契約だけの案を「入れる」と見せ、押し直すとすべての契約を入れる）。
- 置き換えの組の要素（並びの中の置き換え）と、ID を持たない並びの中の要素をまたいで打ち消す場合（今は当てるときにもう一度外すことで中身を合わせている）。
- 年額の段階で、差額を月割りで精算する事務所の料金の入れ方（今は単発の料金で入れる）。
