# 0076. 表の行を開くと出る子の行と、年間収支の赤字の出どころ（口座から払った分・家計の赤字）

- 状態: 採用（一部未確定）（2026-10-27）
- 固定の強さ: 内部（画面の作り）。世帯ファイルの形・エンジンの入力と出力は変えない（計算の結果を読むだけ）。子の行の名前・並び・見た目は後から変えてよい（変えたら追記に書く）
- 前提にする記録: 0016（提示層は提示用の値だけを受け取る）、0026（取り崩し）、0031（黒字のうち貯まる割合）、0050（貯蓄・運用のカードとお金の行き先）。

## 背景

- 目的ごとに口座を分けて積み立てている世帯では、車や学費のような大きな支出の年に年間収支が赤字になり、その赤字を目的の口座から払う。結果の表では年間収支の赤字しか見えず、「目的の口座から払った分」と「家計の赤字」が分からなかった。
- 計算は、決済口座の年末の残高が下回ると、取り崩しの順序の口座から年末に売って補う（0026。お金の動き `cf.transfer.withdrawal` は口座の物の ID を持つ）。目的の口座を取り崩しの順序の先にしておけば、その年の赤字はその口座から払われているが、表にその内訳が無かった。
- 口座の間の移し替え（移す行）は、まだ計算に入れていない（計算の知らせ「口座の間の移し替えは、計算に入れていません」）。支出と移す行を結ぶ形は、移し替えを計算に入れる回に決める。

## 決定

### 1. 表の行を開くと出る子の行

- 生涯キャッシュフロー表の行（値・合計の行）は、子の行（`children`。名前と年ごとの額）を持てる。子の行を持つ行は見出しの左に「▸」を出し、押すとその行の下に子の行を開く（「▾」で閉じる）。開いた行は表の中だけで覚える（世帯に保存しない）。表は閉じた形で出す。
- 子の行は小さい字・薄い背景で、根拠（押すと出る計算の式）は出さない。提示層の鍵に物の ID を入れない（`net:from1` のような並びの番号）。0円の年は空。
- 行の見出しに説明（押さずに見る短い文）を付けられる（`note`）。

### 2. 年間収支の赤字の出どころ

- 年間収支の行の子の行:
  - 「うち ○○から払った分（取り崩し）」（口座ごと。○○は FP が付けた口座の名前か、名義人と種類「ご主人のNISA」）: その年に取り崩した口座の手取り（売った額−その口座の譲渡益の税）のうち、赤字を払った分。
  - 「うち 家計の赤字（決済口座の預金から）」: 残り（赤字−口座から払った分）。払いきれない資金不足も含む。ある年があるときだけ出す。
- 子の行はマイナスで出し、その年の合計は年間収支と同じ。黒字の年は出さない（積立のために取り崩した年の取り崩しは、赤字を払った分ではない）。取り崩しの手取りが赤字より多い年は、表に出た口座の順に赤字の額までを割り当てる。
- 取り崩しで赤字を払った年が1つも無い表では、子の行を持たない（今までの表のまま）。
- 見出しの説明「▸ で開くと、赤字の年の赤字を、口座から取り崩して払った分（口座ごと・税を引いた手取り）と、家計の赤字（決済口座の預金から払った分。払いきれない資金不足も含む）に分けて見られます」。

## 理由

- **年間収支の行を開く形にした**: 赤字を分けて見たいのは大きな支出の年だけで、いつも行を足すと表が長くなる。開く形なら、ふだんの表は今のまま。
- **取り崩しの手取りで分けた**: 年間収支は譲渡益の税を引いた後の額で、赤字を払ったのは売った額から税を引いた手取り。手取りで分けると、子の行の合計が年間収支とそろう。
- **黒字の年は出さない**: 年間収支の行の子の行は「赤字を何で払ったか」。黒字の年の取り崩しを出すと、赤字の内訳と読み違える。

## 代案（採らなかったもの）

- **取り崩しの行を収入か支出のまとまりに足す**: 取り崩しは器の間の移動で、収入でも支出でもない。収入合計・支出合計に入れると年間収支の意味が変わる。
- **支出の行ごとに払った口座を出す**: 支出と口座の結び付き（移す行の結んだ支出）は、移し替えを計算に入れるまで無い。今ある計算の結果（年の赤字を何で補ったか）から出せる所だけにした。

## 影響

- **画面**: `presentation/model.ts`（子の行の型 `TableChildRow`・行の説明 `note`）、`presentation/MainView.tsx`（「▸」と子の行）、`workspace/resultRows.ts`（`deficitSources`）、`workspace/present.ts`（年間収支の行に子の行を付ける）、`styles/app.css`。
- **持ち帰り用のレポート**: 提示用の値には子の行が入るが、持ち帰り用のレポートの表の部品は子の行を出さない（今の表の形のまま）。
- **世帯ファイル・エンジン・見本の世帯の計算の結果**: 変わらない。
