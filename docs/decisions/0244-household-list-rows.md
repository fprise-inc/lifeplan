# 0244. 世帯の一覧の行を1行にそろえる（行には「開く」だけを見せ、ほかの操作は「ほかの操作」にたたむ。見本の「アプリ」の印をなくし、「写して手直しする」を「複製する」に）

- 状態: 採用（一部未確定）（2026-11-22）
- 固定の強さ: 内部（画面の見せ方と言葉）。世帯ファイルの形・保存される値・計算・本体の命令・見本番号の決まり・見本を保存しないで開く動きは変えない。決まりとして残すのは「世帯の一覧（顧客・見本）の行に見せる操作は『開く』（見本は『この見本をもとに顧客を作る』も）と『ほかの操作』だけ」「開いている行は『開く』の場所に『開いています』」「『ほかの操作』は一覧の中で1つだけ開き、Esc（重ねた順の上の1つ。0239）と外側を押すと閉じる」の3つ。どの操作を外に出すか・「ほかの操作」の中の並び・見た目の細部は後から変えてよい（変えたら追記に書く）
- 前提にする記録: 0033（顧客番号の区分と通し番号・見本の棚）、0182（見本にするときはメモと面談の履歴を外す）、0239（閉じ方と Esc の重ねた順）、0240（ボタンの4段と大きさ2つ）

## 背景

- 世帯を選ぶ画面の顧客の一覧は、行ごとに「開く・区分を変える・顧客番号を変える・（通し番号を付ける）・（お客さまの世帯にする）・見本に登録・完全削除」の7つまでのリンクが横に並んでいた。幅が足りないと操作の欄が2〜3行に折れ、行の高さがそろわなかった。いちばん右の「完全削除」が、よく押す「見本に登録」のすぐ隣にあった。
- 見本の一覧は「開く・この見本をもとに顧客を作る・写して手直しする・（名前と項目を直す・完全削除）」が縦に積まれ、1行が4行ぶんの高さになっていた。
- 開いている見本の行では、見本番号の右の「アプリ」「開いています」の印が、隣の名前の列に重なっていた（番号の列が折り返さない決まりのまま、印が列の幅を超えたため）。
- 見本の一覧の「アプリ」の印は、番号（01〜09）と行の操作（直せる見本だけに「名前と項目を直す」が出る）で分かるので、無くても困らない。見本の一覧の上の説明も「01〜09 はアプリに入っている見本」と、アプリの中で「アプリ」と言っていた。
- 「写して手直しする」は、押しても手直しの画面に移るわけではなく（同じ家族の形・年代の次の空き番号に新しい見本を作るだけ）、何が起きるかが言葉から分かりにくかった。
- 試しの版で、行に「開く」だけを見せて残りを「ほかの操作」にたたむ形を画面で確かめ、利用者の判断（2026-11-22）で採用した。言葉（「アプリ」の印をなくす・「複製する」「（複製）」・説明の文から「アプリ」を外す）も利用者の判断。

## 決定

### 1. 行に見せる操作と、「ほかの操作」にたたむ操作

| 一覧 | 行に見せる | 「ほかの操作」の中（並びの順） |
|---|---|---|
| 顧客 | 「開く」（小さいボタン）か「開いています」 | 区分を変える（区分を使っているとき）・顧客番号を変える・通し番号を付ける（自由な番号の世帯）・お客さまの世帯にする（架空の世帯）・見本に登録・**完全削除**（危ない段） |
| 見本（はじめから入っている見本） | 「開く」か「開いています」・この見本をもとに顧客を作る | 複製する |
| 見本（自分で作った見本） | 同上 | 複製する・名前と項目を直す・**完全削除**（危ない段） |

- 保存の部品を使えないとき（「この見本をもとに顧客を作る」「複製する」が出ないとき）は、はじめから入っている見本の行は「開く」だけで、「ほかの操作」も出さない。自分で作った見本は「ほかの操作」に「名前と項目を直す」「完全削除」（今までどおり、保存の部品が使えなくても出していた物）。
- 前の版でたどれた操作は、どれも同じ条件で残る（操作の一覧を前後で突き合わせた。下の「確かめたこと」）。顧客番号・見本番号を押しても開くのも今までどおり。
- 操作を選んだときの動き（その行に出るフォーム・確かめの流れ）は変えない。完全削除の確かめ（顧客番号・見本番号を打つまで「完全に削除する」を押せない）も今までどおり。取り消しのボタンの言葉（「キャンセル」）は変えない。
- ボタンの段は 0240 のとおり: 「開く」はふつうの段の小（`.btn.small`）、「この見本をもとに顧客を作る」と「ほかの操作」の中の操作は控えめ（下線のリンク）、「完全削除」は危ない段（赤い文字のリンク）。「ほかの操作」は閉じているときは灰の文字（行の中で目立たせない）で、開いているときは藍の太字（0240 の4: 開いている状態は藍）。

### 2. 「開いています」は「開く」の場所に

- 開いている世帯・開いている見本の行は、「開く」の代わりに同じ幅の場所へ「開いています」（藍の太字）を出す。番号の右の印としては出さない（名前の列に重ならない）。
- 開いている行の色（薄い藍の地。`tr.sel`）と、番号を太字にするのは今までどおり。
- 顧客番号の右の印（「架空」「自由な番号」）は、番号と同じ行に並べたまま（折らない）。「同期の衝突の写しがあります」も番号の欄のまま。

### 3. 「ほかの操作」の開き方と閉じ方

- 「ほかの操作」はボタン（`aria-expanded`・`aria-controls`）。押すと、すぐ下に中の操作が縦に並ぶ（行の高さはそのぶん伸び、行のほかの欄は上にそろえる）。キーボードでは Tab で「開く」の次に止まり、Enter か Space で開く。開いたら Tab で中の操作へ移れる。閉じている間の中の操作には Tab で止まらない（`hidden`）。
- 開くのは一覧の中で1つだけ（別の行の「ほかの操作」を押すと、前の物は閉じる）。閉じるのは、もう一度押す・Esc・外側を押す・中の操作を選ぶ・タブを切り替える・一覧を閉じるとき。一覧を閉じて開き直すと、閉じている。
- Esc は 0239 の重ねた順に入れる（`useEscClose`）。開いている間は「ほかの操作」がいちばん上なので、1回目の Esc で「ほかの操作」だけを閉じ、選択を「ほかの操作」のボタンに戻す。次の Esc で世帯の一覧が閉じる。外側を押したときは、押した所の動きもそのまま起きる（暗い所を押せば、一覧も閉じる）。
- 開いた状態で描く指定（`initialMore`。画面の確かめ用）を足した。

### 4. 見本の言葉

| 所 | 前 | 後 |
|---|---|---|
| 見本の行の操作・見本の帯のボタン | 写して手直しする | **複製する** |
| 複製した見本の名前の後ろ | （写し） | **（複製）** |
| 「複製する」の説明（乗せたときの文。帯のボタンにも付けた） | 同じ家族の形・年代の次の空き番号（10〜）で、新しい見本を作ります。メモと面談の履歴は写しません | 同じ家族の形・年代の次の空き番号（10〜）に複製します。メモと面談の履歴は複製しません |
| 複製した後の知らせ | 見本 1-2-10 を作りました（メモと面談の履歴は写していません）。手直しは自動で保存します | 見本 1-2-10 として複製しました（メモと面談の履歴は複製していません）。手直しは自動で保存します |
| 見本の一覧の番号の印 | アプリ | （出さない） |
| 見本の一覧の上の説明 | 01〜09 はアプリに入っている見本（直せません） | 01〜09 ははじめから入っている見本（直せません） |
| 見本の一覧の下の案内 | 「顧客」の一覧の「見本に登録」から | 「顧客」の一覧の行の「ほかの操作」の「見本に登録」から |

- 「（複製）」を付けるのは画面の側（`copyRequest`）。本体（`crates/household-store`）は名前を受け取るだけで、名前に何も足さない。
- **すでに「（写し）」の付いた見本の名前は変えない**（保存した名前を書き換えない。直すときは「名前と項目を直す」）。「（写し）」の付いた見本をもう一度複製すると「…（写し）（複製）」になる。
- 見本番号の決まり（01〜09 ははじめから入っている見本・10〜 は自分で作った見本）と、見本を保存しないで開く動き（`sampleNotSaving`）は変えない。番号を作る・読むコード（`store/numbering.ts`・`crates/household-store/src/numbering.rs`）にも触らない（別の変更で扱う）。

### 5. 変えないもの

- 一覧の足元の口（復元キー・保存先・事務所の共有・事務所の既定値・AI との接続）。試しの版では口と今の状態を1組にして組ごとに折る形も試したが、この記録の外（別に決める）。
- 一覧の列（顧客番号・区分・家族・最後に保存・最後に直した人・開いている人）と、番号で探す・区分で絞る・見本の絞り込み。

### 6. 幅が足りないときに折る所

- 行の操作の欄は折らない（「開く」「ほかの操作」は1行のまま）。代わりに、幅が足りないときは **顧客の「家族」「開いている人」、見本の「名前」** の欄で折る（`.hh-wrap`）。前は操作の欄が狭められ、事務所で共有して列が増えると、操作のリンクが1字ずつ縦に並んで行が 490〜830px の高さになっていた。
- 顧客番号の右の印（「架空」「自由な番号」）は、幅が足りないときだけ番号の下へ送る（番号そのものは折らない）。「同期の衝突の写しがあります」は番号の下に置く（番号の欄を広げない）。
- 見本の「項目」の印は、今までどおり印ごとに次の行へ送る（5つ以上の見本は、幅 1440px でも2行になる。未確定）。

## 確かめたこと

見えないブラウザで、前（今の main）と後を同じ手順で流して数えた（開発用のサーバーの世帯の置き場に、見本から作った顧客1件＋作った顧客20件〔区分 A・B・C、枝番 `A0002-1`・`C0002-C`、5桁の `B12345`、自由な番号 `K-2019-42`・16字の `ABCDEFGHIJ-12345`・数字だけの `0099`、Web のヒアリングの印、同期の衝突の写し〕と自分で作った見本2つ〔40字に近い名前・短い名前〕。事務所で共有した状態〔最後に直した人・開いている人の列、ほかの人が開いている行〕と、その行を閲覧だけで開いた状態も）。文字 中・大 × 幅 1440・1000・600px × 明るい・暗い画面の 12 通り。

| 一覧（文字 中） | 幅 | 前: 操作が2段以上の行 / 行の高さ | 後: 操作が2段以上の行 / 1行に収まった行 / 行の高さ |
|---|---|---|---|
| 顧客21件 | 1440 | 21/21 / 57.7px | 0 / 20/21（残る1行は同期の衝突の写しの知らせを番号の下に置いた行） / 45〜56.7px |
| 顧客21件 | 1000 | 21/21 / 82〜106px | 0 / 16/21（家族の欄で折れる） / 45〜57.7px |
| 顧客21件（事務所で共有。列が6つ） | 1440 | 21/21 / 493〜704px（表が横に 52px はみ出す） | 0 / 12/21（家族・開いている人の欄で折れる） / 45〜57.7px（横のはみ出し 0） |
| 見本18件 | 1440 | 18/18 / 102〜151px | 0 / 6/18（名前・項目の欄で折れる） / 45〜82.8px |
| 見本18件 | 1000 | 18/18 / 143〜212px | 0 / 3/18 / 45〜82.8px |

- 文字「大」も同じ傾向（顧客21件・1440px: 前は 21/21 の行で操作が2段・65.3px、後は 20/21 が1行・51〜64.4px）。暗い画面は、どの見え方でも明るい画面と行の高さが同じ。
- 幅 600px は、前も後も表が横に動く（顧客 265 → 203px、見本 260 → 244px、事務所で共有 552 → 420px）。ページそのものの横のはみ出しは、どの見え方でも 0。
- 「開いています」が名前・ほかのボタンに重なっている所: 前は開いている見本の行で 1（12 通りのすべて）、後は 0。「開いています」は、どの見え方でもその欄の中に収まった。
- 行ごとの操作の一覧（「ほかの操作」の中も含める）を前後で突き合わせ、顧客21行・見本18行のすべてで同じだった（「写して手直しする」→「複製する」の言い換えだけ）。
- 「ほかの操作」の動き（19 項目すべて合格）: 「開く」の次に Tab で止まる・Enter と Space で開く・開いたら Tab で中の最初の操作へ移り、中の操作を順にたどれる・Esc で「ほかの操作」だけ閉じて選択が「ほかの操作」に戻る（一覧は開いたまま）・もう一度の Esc で一覧が閉じる・閉じているときは中の操作に Tab で止まらない・別の行の「ほかの操作」を押すと前の物は閉じる・同じ物をもう一度押すと閉じる・外側を押すと閉じる・タブを切り替えると閉じる・一覧を閉じて開き直すと閉じている・「顧客番号を変える」を選ぶとたたんでその行にフォームが出る。完全削除の確かめ（番号を打つまで押せない・1字違うと押せない・合えば消える）は前後で同じ。見本を複製すると次の空き番号（1-2-11）に「単身・20代の会社員（複製）」ができ、「見本 1-2-11 として複製しました（メモと面談の履歴は複製していません）。…」と出る。画面のエラーは前後とも 0。
- 試しの版で「ほかの操作」を押し始め（pointerdown）で閉じていたのを、押し終え（click）で閉じるようにした。押し始めで閉じると、上の行の「ほかの操作」がたたまれて下の行が上がり、別の行の「ほかの操作」や「開く」を押しても外れることがあった（見えないブラウザで再現した）。
