# 0083. 入力項目の選び方（世帯ごとに出す入力項目と開いたときの入れ方・事務所の既定値）と、最初の5枚をなくす・世帯ファイルの形式 0.34

- 状態: 採用（2026-10-29。一部未確定）
- 固定の強さ: 内部（画面の見せ方）。世帯ファイルに足した欄 `household.itemChoice`（形式 0.34。足すだけの MINOR）と、事務所データの `defaults.items` は足すだけの形。「非表示は見せ方だけで値も計算も変えない」「値が入っている入力項目は隠さない」「事務所の既定値は新しい世帯に写す（作った世帯は黙って変わらない）」の3つは、変えるときは追記に書く。入口の置き場所・文言・並びは後から変えてよい
- 前提にする記録: 0011（世帯ファイルの形式と変換）、0035（形式の表）、0045（入力のホームの入力項目）、0073（事務所の既定値）、0077（標準／詳細）、0078（標準の欄は必要十分）

## 背景

- 入力のホームには15の入力項目がいつも並ぶ。お客さまによっては使わない入力項目（収益不動産・車など）も並び、どこを入れればよいかが見えにくい。
- 標準／詳細の切り替えは入力項目ごとにパネルの見出しで変えるが、世帯を開き直すと標準に戻る。収益不動産のように、いつも詳細で入れたい入力項目でも毎回切り替えていた。
- 事務所の既定値（0073）の未確定に「カードごとの既定の段」が残っていた。
- 最初の5枚（ざっくり入れる人に最初に案内する入力項目）は、FP がアプリを分かったうえで自分の順に入れるので要らない、という使う人の判断があった。並びは事務所の既定値で変えられる。

## 決定

### 1. 世帯ごとの選び方（出す入力項目と、開いたときの入れ方）

- 入力のホームの2行目（編集の対象の行）の右端に、入口を1つだけ置く: 「入力項目を選ぶ ▾」（非表示の項目があれば「入力項目を選ぶ（非表示 2）」）。プランの有無で上部の配置は変わらない（行はいつも出す）。
- 押すと、入口の下に小さな一覧を重ねて出す（画面は動かさない）。並びはホームと同じ（事務所の既定値の並び）。1行に、出すかのチェックと、開いたときの入れ方（標準／詳細の小さな切り替え）。見出しの「?」に決まりを書く。Esc・外を押す・「閉じる」で閉じる。
- 選ぶとその場で世帯に入る（保存と ↶↷ はほかの操作と同じ）。選び方は世帯全体の物で、プランごとには持たない（プランの編集中に選んでも、現状の世帯に入る）。

### 2. 置き場所: 世帯ファイル（形式 0.34）

- 世帯ファイルの `household.itemChoice` に持つ（任意。決めていなければ欄を作らない）:
  - `hidden`: 入力のホームに出さない入力項目（段階の ID。標準の順）。家族・前提条件は入らない（読むときに捨てる）。
  - `levels`: 開いたときの入れ方（`"detail"` の入力項目だけ。無い入力項目は標準）。
- 理由: 出す入力項目は「このお客さまは収益不動産を持つか」などお客さまの事実に結び付く。世帯といっしょに2台目の PC・事務所の共有フォルダへ移り、誰が開いても同じに見えるべき。PC の設定に置くと、別の PC で開くと全部が出て、同じ世帯の見え方が人と PC で違う。
- 前の版のアプリは知らない欄を読み落として書き戻すので、形式の版を上げて閲覧だけにする（0011 の5。足すだけの MINOR）。変換の段 0.33 → 0.34 は形式の版だけを書き換える。読むときは形を確かめ、知らない ID・標準の入れ方・家族と前提条件の非表示は捨てる（`itemChoice.ts` の `readItemChoice`）。計算の要求には入れない。

### 3. 非表示と「当てはまらない」は別の物

| | 非表示 | 当てはまらない |
|---|---|---|
| 意味 | この世帯の入力のホームに出さない（見せ方だけ） | この世帯には無いと FP が決めた |
| 値・値の状態・保存した項目の印 | 変えない | 入っていない物を「該当なし」にし、保存した項目の印を付ける |
| 計算 | 今までどおり（入れていない物は推定か「無し」） | 該当なしで計算 |
| 進み具合 | 数えない（「12項目中」） | 「当てはまらない」に数える |
| 確かめの一覧 | 「まだ入れていない」の行を出さない（ほかの行は出す） | 行は出ない（入っていない物が無い） |

### 4. 値が入っている入力項目は隠さない

- 値が入っている入力項目（項目に属する物がある、または欄に FP が入れた印がある。`items.ts` の `entered`）は、非表示にしてあってもホームに出す。一覧ではチェックを外せない（「値が入っているので出します」。非表示にしてあれば注記を出す）。家族・前提条件はいつも出す（「いつも出します」）。
- 黙って値を隠すと、計算に入っている物が画面で見えなくなるため。警告を出して隠す形にはしなかった（警告を見落とすと、0円や見えない値で誤る）。
- 非表示にした入力項目に後から物が入れば（取り込み・プランで足したなど）、その時からホームに出る。プランの編集中は、そのプランの中身で決め、プランで直した所のある入力項目も出す。
- 非表示の入力項目のパネルは、確かめの一覧の行・ピンからは今までどおり開ける。

### 5. 開いたときの入れ方と、パネルの切り替え

- パネルを開いたときの入れ方は、(1) パネルの見出しで切り替えた入れ方（世帯を開いている間だけ）、(2) 世帯の選び方の入れ方、(3) 初め（標準。画面の確かめ用の `#level=detail`）の順で決める。ピンは物が属する入力項目の入れ方。
- **パネルで最後に使った入れ方は世帯ファイルに書かない**（0077 のとおり、その場だけ）。お客さまの前で詳細を一度見せただけで世帯が書き換わり、保存・↶↷・共有の変更の印が増えるのを避け、決める所を一覧の1か所にした。一覧で入れ方を変えると、その入力項目のその場の切り替えは外す（すぐに効く）。
- 詳細で開いても、標準の欄と詳細の欄の決まり（0077・0078）は変えない。

### 6. 事務所の既定値（新しい世帯で出す入力項目と、開いたときの入れ方）

- 事務所の既定値のパネルに区画を1つ足す: 「新しい世帯で出す入力項目と、開いたときの入れ方」。並びは入力項目の並びと同じで、1行に出すかのチェックと標準／詳細（家族・前提条件はチェックを外せない）。
- 事務所データの `defaults` の中の足すだけの欄 `items`（形は世帯の `itemChoice` と同じ）。読むときに形を確かめる（`office/settings.ts`）。
- 写し方は 0073 の3と同じ: **空の世帯を作るときだけ写す**（見本・古い世帯・見本から写した世帯には当てない）。後で事務所の値を変えても、作った世帯は黙って変わらない。写した後は世帯ごとに直す。

### 7. 最初の5枚をなくす

- 入力のホームの「まず最初の5項目を入れてください」の案内（と閉じる操作）、入力項目の「最初の5項目」の印、事務所の既定値の「最初の5項目」のチェックと数を外した。並び（↑↓）と「標準の並びに戻す」は残す。
- 並びの形 `CardLayout` は `order` だけにした。古い事務所データの `layout.first` は読まない（あっても誤りにしない）。
- 前は最初の5枚に出さなかった1行の案内と「目安で入れる」「当てはまらない」の1押しを、どの入力項目にも同じ決まりで出す。ただし「当てはまらない」は家族・基本生活費・前提条件には出さない（どの世帯にもある物）。

### 8. 画面の言葉

- 画面では「入力項目」と呼ぶ（0077 の追記）。この回で見つけた残り: 取り込むの「?」の「基本生活費のカードの見出し」→「基本生活費の項目の見出し」。

## 理由

- 入口を1つにした: 入力のホームの上部は2行にまとめてある（0077）。チェックや切り替えをカードごとに置くと、カードの見た目が増える。
- 世帯ファイルに置いた: 2 のとおり。事務所の既定値は写すだけにして、世帯ファイルは事務所データに頼らない決まり（0011 の6・0073）を守る。
- 値が入った入力項目は出したまま: 見えない値で計算するのを防ぐ。非表示は「使わない入力項目を片付ける」ための物で、値を隠す道具にしない。
- 最初の5枚をなくした: どの入力項目から入れてもよく、並びは事務所で変えられる。特別な5つを残すと、案内・印・事務所の設定の3か所が要る。

## 代案（採らなかったもの）

- 世帯ごとの選び方を PC の設定に置く: 2 のとおり、同じ世帯の見え方が PC で違う。
- 事務所の既定値を参照し続ける（写さない）: 事務所の値を変えると、作った世帯の見え方が黙って変わる。0073 の写し方とそろえた。
- 値が入った入力項目も隠し、ホームに警告を出す: 警告を見落とすと誤る。
- パネルで最後に使った入れ方を世帯に覚える: 5 のとおり。
- 非表示を「当てはまらない」で兼ねる: 「無い」と決めたことと「画面から片付けた」ことを分けられず、進み具合と確かめの一覧が誤る。

## 追記（2026-11-01）: 「標準」「詳細」「既定」の使い分け

- 「標準」は入れ方の切り替え（標準／詳細）の名前にだけ使う。新しい世帯に入れる初めの値・事務所の設定の値は「既定の値」「事務所の既定値」（ボタンは「既定に戻す」「既定の並びに戻す」、推定の根拠は「既定の値（…）」「事務所の既定値（年月）」）。制度・一般の言い方（標準報酬月額・保育標準時間・標準の税率・学校の種類の標準の年数など）はそのまま。
- 切り替えの「詳細」を文の中で指すときは、かぎかっこで「詳細」と書く（「詳細」で直せます／「詳細」の「働き方 1・2…」）。前の名前「詳しく入れる」は使わない。
- まとまりの中の欄を開くリンクは「▸ 続きを見る」「▾ 閉じる」（切り替えの「詳細」と紛れないように）。
