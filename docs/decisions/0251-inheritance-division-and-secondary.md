# 0251. 相続税の試算の次の回: 遺産の分け方、特例の減額を土地を取得する人に寄せる、一次と二次の相続税の推移、二次の取得する人の選び直しと、世帯ファイルの形式 0.88

- 状態: 採用（一部未確定）（2026-11-23）
- 固定の強さ: β公開から変えない（骨格）。要求と世帯の設定の欄（`input.inheritanceTax.division`〔`spouseShare`・`shares[]`〕・`lands[].primary.member`・`lands[].secondary.member`、要求だけの `timeline`〔`alternatives`・`step`〕の名前と意味）、出力の任意の欄（`timeline`・`points[].division`・`points[].successiveCredit`・`byHeir[].landReduction`・`byHeir[].successiveCredit`・`lands[].special.member`。約束の版 1.3）、形式 0.88 は骨格。既定（法定相続分どおり・先に亡くなる人は年上の人・二次の時点は表の最後の年の12月・比較する分け方の4通り・一次で取得したお金は二次まで増減しない）、画面の並び・言葉・表の間引きは後から変えてよい（変えたら追記に書く）
- 前提にする記録: 0005・0170（計算の速さ）、0011・0035（世帯ファイルの形式の版の上げ方）、0036・0043（プランの差分・入力画面でプランを直す）、0039（相続税の目安）、0060・0061（相続・贈与の入力項目と世帯に保存する設定）、0231（土地の評価と小規模宅地等の特例。「次の回への申し送り」と「未確定」をこの記録で受ける）

## 背景

- 0231 は、相続税も試算する世帯（`detailed`）の土地の評価と特例を1つの時点の関数（`evaluateLands`）にし、年ごとの一次・二次と分け方を次の回に回した。分け方は法定相続分どおりだけで、特例で減った額は遺産の全体から引いていたので、自宅を配偶者が取得しても子の税が下がって見えた（実際は配偶者の取得が減るだけで、配偶者は軽減で0円のまま、子の税は下がらない）。
- 二次の相続（二人とも亡くなった後）は、表の最後の年に夫婦の財産を合わせて見る目安（0039 の `bothAfter`）だけで、「いつ一次が起きたら、一次・二次・合計がいくらか」「配偶者が多く取得すると二次が重くなる」を見る所が無かった。
- 0231 の未確定「配偶者が自宅を取得するとみなす既定を、二次（同居の子がいる世帯）にも広げるか」が残っていた。

## 決定

### 1. 相続税も試算する世帯だけ

- 分け方・推移・取得する子は、どれも `detailed` の世帯だけ読む。チェックしない世帯の入力（区画は詳細の1つの欄だけ）・計算・注意・含めていない一覧は変えない（エンジンと画面のテストで固定）。
- 試算する世帯でも、分け方を入れず特例の減額も無ければ、人ごとの額は法定相続分どおり（改訂6と同じ数）。

### 2. 遺産の分け方（`input.inheritanceTax.division`）

- `spouseShare`: 一次の相続（配偶者がいる人の相続）で配偶者が取得する割合。省略は法定相続分。
- `shares[]`（`member`・`share`）: 配偶者のほかの相続人の分け方。配偶者の分を除いた残りのうちの割合（配偶者のいない相続・二人とも亡くなった後・二次は全体のうち）。入れていない人は、入れた人の残りを法定相続分の比で分ける。**合計が1を超える・全員入れて合計が1でないときは、黙って補わず、入れた割合を使わない**（法定相続分の比。注意 `divisionSharesInvalid`。画面は1人目の子の欄と確かめの一覧に知らせを出し、「子の割合を消す」の1押しを置く）。
- **割合は財産の評価額（小規模宅地等の特例の前。債務と葬式の費用を引く前）のうち**で、債務と葬式の費用は取得する割合で負担する。額で入れる形は作らない（年ごとの推移では遺産の額が年で変わり、額の分け方は年をまたいで意味が保てない）。
- **土地は取得する人の分に入れる**: 一次は `lands[].primary`、二次（二人とも亡くなった後・推移の二次）は `secondary` の取得する人。配偶者なら配偶者、`member`（0.88 で足した欄）を選んでいればその子、選んでいなければ配偶者のほかの相続人で割合どおり。取得する人を選んでいない土地は全員で割合どおり（自宅で配偶者が取得するとみなした土地〔0231 の6〕は配偶者）。
- **特例で減った額は、その土地を取得する人の取得から引く**（出力 `byHeir[].landReduction`）。各人の課税価格＝取得する分−負担する債務と葬式の費用−取得した土地の特例で減った額。各人の税＝相続税の総額×各人の課税価格÷課税価格の合計（相続税法17条・No.4152）。配偶者の軽減は、配偶者の課税価格と「1億6,000万円か法定相続分の額の多い方」の小さい方で（相続税法19条の2。条文の本文〔e-Gov の法令 API。令和8年4月1日の版〕で読んだ）。
- **相続時精算課税で贈与した財産は、受け取った人の分に置く**（割合で配偶者などに分けない。受け取った人が取得する分は、その額を下回らない）。
- 取得する土地の評価と贈与の合計が割合の分より大きい人は、その人の分をその額まで増やし、ほかの人の分を割合の比で減らす（出力 `division.adjusted`、注意 `divisionAdjusted`）。
- 相続税も試算する世帯は、いつも取得する分を配分する（推移の二次に足す配偶者の分にも使う）。人ごとの税に配分を使うのは、分け方を入れたか、特例の減額を寄せるか、割合を直したときだけで、ほかは法定相続分どおりの額と同じ。
- 未成年者控除は財産を取得した人だけ（19条の3第1項。分け方で取得しない子は受けない）。
- 分け方を入れたか、特例の減額を取得する人に寄せたときは、時点の出力に `division`（`entered`・配偶者が取得した割合 `spouseShare`・`adjusted`）を出す。内訳の文は「入れた分け方（配偶者 80%）で分けたとして」「法定相続分どおりに分け、特例で減った額は土地を取得する人の分から引いたとして」と、人ごとの取得と納める額。

### 3. 一次と二次の推移（要求の `timeline`。出力 `timeline`）

- 求めるのは、`detailed` で、要求に `timeline` があり、万一の想定の無い、法律婚の夫婦の世帯だけ。画面は相続・贈与の入力項目の中の目安を求めるときだけ入れる（ホームの要約・結果のタブのポイントの要求には入れない）。世帯には保存しない。
- **先に亡くなる人**（出力 `first`）は、二人とも亡くなった後の後に亡くなる人（`lastSurvivor`。省略は分け方の欄 `division.first` で選んだ人でない方、それも無ければ年下の人）でない方。画面の欄「先に亡くなる人（一次の相続）」は `division.first` に書く（`lastSurvivor` には書かない。相続税も試算する世帯だけ読むので、チェックを外すと二人とも亡くなった後の亡くなる人は今までの決め方に戻る）。
- **一次**: 先に亡くなる人が、計算基準年はいまの時点（計算基準月・初めの姿。0039 の追記の改訂4。「いま亡くなったら」と同じ額）、ほかの年はその年の12月に亡くなるとして、その年の年末の財産で出す。計算基準年から表の最後の年まで毎年（`step` で間引ける。計算基準年と表の最後の年はいつも出す）。計算基準年より後の年は、まだ払っていない所得の税を債務に入れない（年ごとに死亡の想定の表を作ると重いので。二人とも亡くなった後と同じ）。
- **二次**: 後に亡くなる人（`second`）が表の最後の年の12月に亡くなるとして、その人の名義の財産（表の年末の残高。名義の無い財産は先に亡くなった人の分の残り）に、一次で取得した財産を足す。
  - 土地・建物: 一次で後に亡くなる人が取得した分（一次の配分と同じ決まり: 配偶者を選んだ土地と、取得する人を選んでいない自宅は全部、子などを選んだ土地は無し〔配偶者のほかの相続人がいなければ全部〕、選んでいない土地は配偶者の割合）を、二次の年の評価で足し、二次の取得する人（`secondary`）で特例を見る。**表の最後の年に無い土地・建物**（二次の前に売る・手放す物）は、一次の時点の評価のまま、下のお金の分に残す（売った代金は表では先に亡くなった人の名義の口座に入り、後に亡くなる人の財産に乗らないため）。
  - ほか（金融資産など）: 一次で取得した額（非課税の分を含む。土地・建物と、精算課税で前にもらった財産を除く）−負担した債務と葬式の費用−一次で納めた額を、**一次の時点の額のまま**足す（`inherited`）。二次までに使う・増える分は、後に亡くなる人の名義の資産の推移に入っている分だけ（画面の表の上に「一次で取得したお金は、二次まで使わない（増えも減りもしない）として出しています」と出す）。
  - 死亡保険金: 後に亡くなる人が被保険者の契約は、先に亡くなった人が契約者の契約（一次で受け継いだ契約）も数える。
  - 相次相続控除（相続税法20条・No.4168）: A（一次で後に亡くなる人が納めた額）×（C÷(B−A)。1を超えれば1）×（D÷C）×（10−経過年数）÷10。経過年数は1年未満を切り捨て（条文は「10年から引いた年数の端数は1年」で同じ）。10年を超えれば無し。控除の順は未成年者控除の後、精算課税で払った贈与税の前。
  - 未成年者控除は、一次で受けた分（扶養義務者の税から引いた分を含む）があれば、最初の額の残りまで（19条の3第3項）。
  - 相続人は「二人とも亡くなった後」と同じ（夫婦の子）。相続人がいない（子のいない夫婦で兄弟姉妹などを入れていない）ときは二次を計算せず、出力に `secondaryStatus: "noHeirs"`、画面の二次の欄は「計算していません」と、足す人の手がかり（いちばん少ない分け方の文は出さない）。
- **比較する分け方**（`alternatives`）: 入れた分け方（`entered`）のほか、配偶者の割合だけを替えた分け方を同じ年ごとに出す。画面は「法定相続分どおり」（`legal`。入れた分け方が法定相続分どおりなら出さない）・「配偶者が全部取得する」（`spouseAll`。100%）・「配偶者は取得する土地だけ」（`spouseLandsOnly`。0%で、取得する土地の評価まで増やす）の3通りを求める。子の分け方は入れたまま。
- 年ごとの行: 一次・二次・合計の納める額、一次と二次の課税価格、一次の配偶者の課税価格と納めた額、二次に足した額、二次の相次相続控除と未成年者控除。

### 5. 二次の取得する人の選び直し（0231 の未確定を解く）

- **配偶者が自宅を取得するとみなす既定は、二次に広げない（選ぶまで使わない）を既定のまま**にし、二次の取得する人の欄で選び直す形にした（利用者の判断を受けたおすすめ）。一次で配偶者が取得した自宅も、二次は `secondary` の取得する人で特例を見る。
- 二次の取得する人の説明に、表の最後の年の家族の手がかりを書く: 子ごとに、独立している（年）・独立する見込み（年）・同居の見込み（入力の家族の世帯から抜ける時点から）。持ち家の有無（いわゆる家なき子）はソフトでは分からないので確かめてもらう。

### 7. 別の目の点検（2026-11-23）で直した所

- 分け方を入れていない世帯の推移の「入れた分け方」の行で、特例の減額が0円の年は配分を作らず、不動産を二次に二重に数えていた（預金2億円＋自宅の評価4,800万円で二次の課税価格 1億7,200万円。正しくは 1億2,400万円）。相続税も試算する世帯はいつも配分する（2）。
- 子の割合の合計が届かないと配偶者の割合が黙って増えていた → 使わずに法定相続分どおりにして知らせる（2）。精算課税の贈与まで割合で分けていた → 受け取った人に置く（2）。二次の前に売る土地・建物が二次から抜けていた → 一次の時点の評価で残す（3）。子のいない夫婦の推移が 0円 と出ていた → 計算していないと出す（3）。先に亡くなる人の欄が `lastSurvivor` に書き、チェックを外しても残っていた → `division.first`（3）。言葉（4）。
- 「試算しない世帯は今までと同じ」のテストを、0231 の版（main）で計算した見本の世帯6件×3通り（要求の時点だけ・世帯の設定のまま・不動産の評価の割合などを入れた設定）の数（`engine/test/fixtures/inheritance-main-snapshot.json`）と比べる形にした。0251 の欄（分け方・推移の要求）を足しても同じ。

## 理由

- **割合を評価額（特例の前・債務の前）のうちにした**: 「遺産の何割を配偶者が」という言い方にそのまま合い、特例と債務は取得した物に付いて動くので、割合を入れ直さずに土地を取得する人を替えられる。特例の後の額で割合を決めると、特例を使う人を替えるたびに分け方の意味が変わる。
- **特例の減額を取得する人に寄せた**: 実際の計算と同じで、「配偶者が自宅を取得すると特例の効果が子に及ばない」「同居の子が取得すると一次の税が下がる」を数字で見られる。0231 の申し送りの主題。
- **二次は表の最後の年の12月**: 「二人とも亡くなった後」の目安と同じ時点で、一次と二次が同じ年の境目も表に入る。
- **一次で取得したお金を二次まで動かさない**: 表は二人とも生きている姿なので、亡くなった後の暮らしで使う額は表から決まらない。よく使われる「配偶者の固有の財産＋一次で取得した財産−一次の税」の形で、目安として読みやすい。
- **間引かない**: 速さの計測で推移の分が小さく、年ごとの抜けが無い方が「いつ」の答えに使いやすい。

## 代案（採らなかったもの）

- 分け方を額で入れる: 年ごとの推移で意味が保てない（1の決定）。額で確かめたいときは、税理士などが出した額を入れる（0039 の6）。
- 二次の財産を「夫婦の財産を合わせた表の年末の残高から、一次で子が取得した分を引く」で出す: 表の死亡保険金・死亡退職金が入らず、先に亡くなった人の収入（表では生きている）も残るので、一次で取得した分の数え方が分け方で崩れる。
- 二次の時点を一次の何年後に固定する（10年後など）: 表の最後の年の目安と時点がずれ、相次相続控除の年数が分け方の比較で動かない。
- 配偶者が自宅を取得するとみなす既定を二次にも広げる（同居の子がいるとみなす）: 二次の要件（同居・家なき子）は二次の時点の家族と持ち家で決まり、ソフトが決めると誤った安心を与える（0231 の要件を自動で判定しすぎない決まり）。
- 分け方の欄を動かす項目に出す: 配偶者の割合と子の割合の組で1つの分け方なので、1つの欄だけを動かす対策は分かりにくい。入れるなら、配偶者の割合だけの合成の対策を足す（未確定）。
