# 0255. 貯蓄・運用の口座の表の列をそろえる（見出しを入力の左端に・列の間に縦線・積立の行を途中で切らない）

- 状態: 採用（2026-11-23）
- 固定の強さ: 内部（画面の見せ方）。入力の欄・保存される値・世帯ファイルの形・計算は変えない。線の色・余白は後から変えてよい（変えたら追記に書く）
- 前提にする記録: 0026（資産運用の入力）

## 背景

- 貯蓄・運用の入力項目の「口座ごとの残高・積立額」の表で、「残高」の見出しが右寄せ、「毎月の積立」の見出しが左寄せだったため、2つの見出しがくっついて1つの言葉に読めた。列の境目も分かりにくかった。
- 積立の行「45〜59歳（60歳になる前の月まで） 月 [1] 万円」は、狭い幅で途中が切れて、数の欄と「万円」が離れることがあった。

## 決定（利用者の判断。見本の3案のうち案A）

- 見出し「口座」「残高」「毎月の積立」は、その列の入力の欄の左端にそろえる（残高の列は欄も見出しも左寄せ。合計の行の残高も左寄せ）。「利回り（年）」は数字が右寄せのままなので、見出しも右寄せで列にそろえる。
- 列の間に細い縦線を引く（枠線の色 `--line-2`。ダークでは同じトークンの暗い色）。
- 積立の行は「45〜59歳（…まで）」と「月 [1] 万円」をそれぞれひとかたまりにし、途中で切らない。狭い幅では、かたまりごと次の行へ回す（`.sv-st-age`・`.sv-st-amt`）。期間の始まりの年齢（1行目の数字）は列の左端から書く（前は幅をとって右寄せで、少し字下げして見えた）。
- 資産の種類の割合の表（`.sv-cls`）は変えない。

## 確かめたこと

- 幅 1300・960・760、ライトとダークで、表の見出しと欄の位置、縦線、積立の行の回り方を画面で確かめた。幅 760 では、前と同じく表が横に送れる（利回りの列は横送りの先）。
