# 0171. 社会保険の切り替わりの月と判定の直し（任意継続の家族・特定同一世帯所属者と特定世帯・給与所得者等・被扶養者であった人の後期・介護の所得の指標・高額介護サービス費の課税所得・亡くなった月の保険料・亡くなる前の扶養・出生後休業支援給付の母）

- 状態: 採用（一部未確定）（2026-11-08）
- 固定の強さ: 内部（部品の計算の決まり）。世帯ファイルの形式の版・エンジンの入力は変えない。`socialInsurance.employeeStatus` の出力に任意の欄 `continuation` を足した（約束の版 1.0 → 1.1。0006 の4 の MINOR）。制度データ `regulation.socialInsurance` に値を8つ足した（2026.12.0。原本での確認待ち）
- 前提にする記録: 0003（月が最小単位・死亡は「その月に亡くなる」。追記 2026-10-09）、0006（約束の版）、0007（制度データ）、0008（4 の健康保険の種類を導く・追記 2026-10-25 の1 の扶養と4 の任意継続）、0037（雇用保険の給付と扶養）、0165（亡くなった後の世帯主と払う人の名義）

## 背景

社会保険料・給付・介護の計算を、条文（e-Gov の本文）と公式の資料から作った答えと突き合わせた検算（独立の検算と、切り替わりの月を見る点検）で、次の食い違いが見つかった。

1. 任意継続の被保険者の家族を被扶養者にせず、国民健康保険に入れていた（扶養する人を「勤め先の健康保険に入る人」に限っていた）。
2. 国民健康保険で、75歳で後期高齢者医療に移った人（特定同一世帯所属者）を軽減の判定の所得と人数に入れず、残った1人の世帯（特定世帯・特定継続世帯）の平等割を減らしていなかった。
3. 国民健康保険・後期高齢者医療の軽減の判定の「給与所得者等の数」を、給与・公的年金が少しでもある人で数えていた（法令は給与等の収入55万円超・公的年金等の収入60万円超〔65歳以上は125万円超〕）。
4. 後期高齢者医療で、資格を取る前に被用者保険の被扶養者だった人の扱い（所得割をかけない・均等割を2年は5割）が無かった。
5. 介護の自己負担割合・高額介護サービス費・第1号保険料の第1〜5段階の所得の指標で、給与所得・公的年金等の所得から10万円を引いていなかった。
6. 高額介護サービス費の上限を、所得税の課税所得で判定していた（法令は住民税の課税所得。令和7・8年の基礎控除の引き上げで所得税の方が低い）。
7. 万一の想定で亡くなった月の保険料を、亡くなった月の分までかけていた。遺された家族の国民健康保険・第1号への切り替えは翌月からだった。
8. 亡くなる想定を入れると、亡くなる前の数か月から扶養の配偶者が国民健康保険になっていた（扶養の判定の「その月からの1年の見込み」に、亡くなった後の遺族年金と止まる給与が入った）。
9. 出生後休業支援給付を、産後休業をした母に出していなかった（母の対象期間は出生から16週間）。

## 決定

### 1. 任意継続の被保険者の家族（`socialInsurance.healthStatus` 改訂8・`socialInsurance.employeeStatus` 改訂4）

- 任意継続被保険者も健康保険の被保険者（健康保険法3条1項）なので、任意継続の月の人を扶養する人の候補にする。家族は被扶養者（同条7項）のまま、国民健康保険に入れない。国民年金は、任意継続の人が第2号でないので、配偶者は第1号のまま（変えない）。
- 扶養する人の働き方の期間は、家族の部品からは読めない（`memberScope`）。`socialInsurance.employeeStatus` の出力の月に任意の欄 `continuation`（その月の期間に `healthInsurance.kind: continuation` を書いた）を足し（約束の版 1.1）、2年の上限（`socialInsurance.health.continuation.maxMonths`）は家族の部品の側で数える。欄の無い差し替えの部品なら、今までどおり任意継続の人は扶養する人にならない。
- 収入の見込みが0の家族は、扶養する人の収入が0でも「2分の1の未満」を満たすとみなす（昭和52年の通知のなお書き: 扶養する人の収入を上回らず、生計維持の中心が扶養する人なら被扶養者としてよい）。辞めて任意継続にした月の夫（給与0）に、収入の無い妻・子が扶養される。育児休業の月などで扶養する人の給与が0のときも同じ。

### 2. 特定同一世帯所属者・特定世帯（`socialInsurance.nationalHealth` 改訂12）

- 特定同一世帯所属者: 国民健康保険から75歳で後期高齢者医療に移り、その年度に同じ世帯にいる人（国民健康保険法施行令29条の7第2項8号イ）。移る前の月の健康保険の種類（`socialInsurance.healthStatus`）が国民健康保険なら当たる。移る前の月が表の前（計算基準月の2年前の1月より前）で分からないときは、その月に勤め先の健康保険（任意継続を含む）の期間が無ければ、国民健康保険から移ったとみなす。別居の親・祖父母（`member.support.cohabiting` が true でない）は同じ世帯でないとみなす。世帯から離れた月・亡くなった月からは当たらない。
- 軽減の判定（同6項）: 判定の所得に特定同一世帯所属者の前の年の所得を入れ（世帯主でなくても）、5割・2割の基準の人数を「被保険者の数と特定同一世帯所属者の数の合計」にする。給与所得者等の数も、世帯主・被保険者・特定同一世帯所属者の中で数える。
- 平等割（同2項8号ロ・ハ、3項7号ロ・ハ、子ども・子育て支援納付金賦課額の同じ号）: 世帯の国民健康保険の人がその月に1人で、特定同一世帯所属者がいる月は、特定同一世帯所属者が移った月から5年（60か月）は2分の1（特定世帯）、その後3年（96か月まで）は4分の3（特定継続世帯）。医療分・後期高齢者支援金等分・子ども・子育て支援金分に当て、介護分には当てない（介護納付金賦課額の号には特定世帯の定めが無い）。特定同一世帯所属者が2人以上いれば、最も近く移った人の月から数える。
- 平等割は、その区分に入る人がいる月（世帯の月）ごとに割合を掛けて足す（前は加入の月数の最も多い人の月数）。加入の月が人によって重ならない形でだけ前と変わる。

### 3. 給与所得者等の数（`socialInsurance.nationalHealth` 改訂12・`socialInsurance.lateElderly` 改訂9。sdk の `isEarner`）

- 前の年の給与等の収入金額（賞与を含む。通勤手当は含まない）が55万円を超える人と、公的年金等の収入金額が60万円（その年の12月31日に65歳以上は125万円）を超える人を数える（国民健康保険法施行令29条の7第6項1号・附則5条、高齢者の医療の確保に関する法律施行令18条5項1号・附則3条。本則の65歳以上の110万円を附則で125万円に読み替える）。給与の人は公的年金で重ねて数えない。
- 基準は制度の値（`<区分>.reduction.earnerSalaryRevenue`・`earnerPensionRevenue`・`earnerPensionRevenueElderly`）。値が無いときは、収入が少しでもあれば数える（前の近似）。

### 4. 後期高齢者医療の被扶養者であった被保険者（`socialInsurance.lateElderly` 改訂9）

- 資格を取った月（75歳の誕生日の月）の前の月の健康保険の種類が扶養（`dependent`。勤め先の健康保険・任意継続の人の扶養）なら、被扶養者であった被保険者とする（高齢者医療確保法99条2項）。
- 所得割はかけない（施行令18条1項2号ただし書・8号ただし書。医療分・子ども・子育て支援金分とも。期間の限りなし）。
- 均等割は、資格を取った月から2年を経過する月まで（24か月）、7割・5割の軽減がかからなければ5割を減らす（同6項。5割は制度の値 `reduction.ratioHalf`）。年度の月を2年の中と外に分けて按分し、区分ごとに100円未満を切り捨てる。
- 資格を取る前の月が表の前の人（計算基準月の2年前より前に75歳になった人）は分からないので当てない。

### 5. 介護保険の所得の指標（`care.expense` 改訂7・`socialInsurance.careFirst` 改訂7。sdk の `careIncome`）

- 介護保険法施行令22条の2第1項・第4項（と、令和6年1月の厚生労働省の事務連絡「介護保険制度における所得指標の取扱いについて」）のとおり、
  - 自己負担割合の本人の合計所得金額: 給与所得と公的年金等の雑所得の合計を、そこから10万円を引いた額（0円が下限）に置き換える。
  - 「公的年金等の収入金額＋その他の合計所得金額」（2割・3割の世帯の判定、高額介護サービス費の個人の上限、第1号保険料の第1〜5段階）: その他の合計所得金額の給与所得を、そこから10万円を引いた額（0円が下限）に置き換える。
  - 給与所得は、所得金額調整控除（租税特別措置法41条の3の11。子ども等の分と、給与と年金の両方がある分）の前の額（所得税法28条2項で計算した額）で数える。
- 10万円は制度の値 `socialInsurance.care.incomeIndicator.salaryPensionDeduction`。第6段階以上の保険料（合計所得金額の段階）には当てない（事務連絡）。

### 6. 高額介護サービス費の課税所得（`care.expense` 改訂7）

- 世帯の65歳以上の人のいずれかの、その所得の年の翌年度の住民税の課税所得（市町村民税の総所得金額等から所得控除をした後の額。施行令22条の2の2第5項1号）で、上限の段（44,400円・93,000円・140,100円）を決める。`residentTax.annual` の `taxable` を使う。
- 住民税の決定通知書の額を入れた年度（途中の値が無い）は、所得税の課税所得で近似する（前と同じ）。

### 7. 亡くなった月（`socialInsurance.employeeStatus` 改訂4・`socialInsurance.healthStatus` 改訂8・`pension.category` 改訂5・`socialInsurance.careFirst` 改訂7、sdk の `insuranceEndMonth`）

- 0003 の「その月に亡くなる」を、社会保険では「その月の途中で亡くなり、翌日に資格を失う」と読む。保険料は資格を失った日の属する月の前の月までなので、亡くなった月の分はかからない（国民健康保険法8条・高齢者医療確保法53条・介護保険法11条・健康保険法36条・厚生年金保険法14条・国民年金法9条1号と11条）。月末に亡くなる形も同じに扱う近似（月末の死亡を選ぶ欄は作らない）。
- 3つの部品で、亡くなった人をその月から加入なしにする:
  - `socialInsurance.employeeStatus`: 亡くなる月は健康保険・厚生年金に入らない（月の途中で辞めた月と同じ）。雇用保険はその月の給与にかかるので変えない。期間・勤め先・働き方は残す。
  - `socialInsurance.healthStatus`: 亡くなる月から、どの保険にも入らない（`none`）。扶養する人の候補からも、亡くなる月から外す。
  - `pension.category`: 亡くなる月から、どの種別でもない。
- これで、国民健康保険・後期高齢者医療・国民年金の保険料（健康保険の種類・年金の種別を読む）は亡くなった月の前の月まで、勤め先の健康保険料・厚生年金保険料は前の月の分まで（亡くなった月の給与から引くのは前の月の分の1回）になる。介護保険の第1号の保険料は、世帯から離れる月と亡くなる月の早い方の前の月まで数える。
- 遺された家族: 扶養していた人が亡くなる月から、子は国民健康保険、第3号だった配偶者は第1号になる（配偶者が第2号でなくなるので）。その月の国民健康保険料・国民年金保険料は遺族にかかる。
- 遺族年金（sdk の `survivorBasis`）: 亡くなった人の加入の月は死亡の月の前の月まで数える（被保険者期間は資格を失った月の前の月まで）。亡くならない世界で「この月に亡くなったら」を見るときも同じに数える。短期要件（死亡の当時に厚生年金の被保険者）は、死亡の月の記録が厚生年金か、前の月まで厚生年金に入っていて死亡の月も同じ勤め先の期間にいれば満たす（死亡の月は記録に入らないため、`socialInsurance.employeeStatus` の勤め先で見る）。

### 8. 亡くなる前の扶養の判定（`socialInsurance.healthStatus` 改訂8）

- 被扶養者の認定はその時の状況での今後1年の見込みなので、その月より後に世帯の人が亡くなる月から先は、その月の見込みに入れない。表の外の月と同じく、亡くなる月から先の見込みの月は、その1年前の月とみなす（その月にはまだ分からない死亡で出る遺族年金と、止まる給与を数えない）。扶養する人・扶養される人の両方の見込みに当てる。
- 0008 の追記 2026-10-25 の1（扶養される人の見込みに遺族年金・障害年金を入れる）は、亡くなった後の月（その死亡がもう分かっている月）では今までどおり。

### 9. 出生後休業支援給付の母（`benefit.employment` 改訂6）

- 対象期間は子の出生から8週間（2か月の近似）。子の出生の月に自分が産前産後休業だった人（産後休業をした人）は16週間（4か月の近似。制度の値 `employmentInsurance.postBirthBenefit.withinMonthsAfterMaternity`。雇用保険法61条の10、厚生労働省のリーフレット「母親は産後休業後８週間以内」）。配偶者の育児休業の要件で見る配偶者の期間は8週間のまま（配偶者が産後休業中なら要件を見ないのは前と同じ）。

## 理由

- どれも条文に書いてある決まりで、利用者の判断の要る所は無い。条文は e-Gov の本文（国民健康保険法施行令・高齢者の医療の確保に関する法律施行令・介護保険法施行令）を取り直し、指紋（sha256）が制度データに記録した版と一致することと、引用の文言があることを機械で確かめた。
- 亡くなった月の扱いは、万一の重ねで働き方の期間を「月の途中で終わる」にする案もあったが、自営・無職の人（国民健康保険・第1号）にも同じ決まりが要るので、加入を導く3つの部品で亡くなる月を見る形にした（死亡の月を知る判定の部品 `contingency.event` は、ほかの部品にも読まれている小さな部品）。
- 亡くなる前の見込みは、「その月にはまだ分からない」ことを、表の外の月と同じ「1年前の月とみなす」で表した（新しい決まりを作らず、0003 の追記の考え方にそろえた）。
- 平等割の月ごとの割合は、特定世帯が年度の途中で始まる（75歳の誕生日の月から）ので、月の単位で掛ける。

## 影響

- 計算の結果が変わる（見本の世帯。直す前と後の全期間の合計）:
  - 年金暮らしの夫婦の片方が75歳になり、もう片方が国民健康保険に残る世帯（特定同一世帯所属者・特定世帯）: 国民健康保険料が、移った後の年度に年 約1.1万円（平等割の2分の1）〜約2.1万円（人数で5割軽減に入る年）少なくなる。`pensionCouple` −3.6万円、`sampleSeniorCouple` −2.9万円、`sampleSeniorRental` −5.1万円、`workingSixties` −6.2万円、`salariedCoupleTwoKids`・`investmentCouple`・`surplusSaving` −3.8万円、`executiveOwner` −4.1万円、`marketDropAtRetirement`・`nisaWithdrawal` −3.0万円、`dualAssetsTwoKids` −2.4万円、`rentalSample` −2.4万円、`sampleParentsCare` −2.5万円、`idecoPayout` −1.1万円（社会保険料控除が減る分、所得税・住民税が数百〜数千円増える）。
  - 亡くなる想定の世帯: `pairLoanDeath`（会社員が亡くなる）は亡くなった月の健康保険料・厚生年金保険料など 約16.4万円（賞与の月だったので賞与の保険料を含む）が減る（社会保険料控除が減る分、所得税が 約0.8万円増える）。`survivorEmployeeLoan` は亡くなった月の保険料 約7.5万円が減り、亡くなる前の年度の妻の国民健康保険料 約1.9万円が減り（亡くなる前の扶養）、亡くなった月の遺族の国民健康保険料・国民年金保険料 約2.6万円が増える。遺族厚生年金は年 約500〜760円増える（平均標準報酬額から、賞与の無い死亡の月が外れるため）。`survivorSelfEmployed` は亡くなった人の亡くなった月の国民健康保険料 約6.1万円と国民年金保険料 1.96万円が減る。
  - `protectionNeed`: 必要保障額（死亡の想定の表から組み立てる。0170）が、亡くなる年によって 約2.8万円減る〜約6.0万円増える（亡くなった月の保険料が減る、遺族の国民健康保険・国民年金がその月から増える、亡くなる前の扶養、遺族厚生年金の平均標準報酬額から死亡の月が外れるの合わせた分）。
  - `parentalLeave`: 母に出生後休業支援給付 42,679円が出る。
  - 給与所得者等の数・被扶養者であった人の後期・介護の所得の指標・高額介護サービス費の課税所得は、見本の世帯には当たる形が無く変わらない（テストの世帯で確かめた）。
- 遺族年金の加入月数: 亡くなった人の厚生年金の被保険者期間が、死亡の月の分だけ1か月少なくなる。短期要件（在職中の死亡）で300月に満たない人は300月のみなしなので額はほぼ変わらない（平均標準報酬額の分だけ動く）。長期要件の人は1か月分の報酬比例が減る（標準報酬41万円で年 約1,700円の遺族厚生年金）。受給資格期間の25年の境目にいる人は、1か月で長期要件を満たさなくなることがある。短期要件は、死亡の月も同じ勤め先にいれば満たす（前と同じ人が満たす）。
