# 0063. 学校外の費用の入れ方（統計の平均で／行で入れる）・行の種類と、世帯ファイルの形式 0.23

- 状態: 採用（一部未確定）（2026-10-27）
- 固定の強さ: β公開から変えない（骨格）。教育の目標の `outOfSchoolMode`（`statistics`・`rows`・省略）の意味と、`lessons[].kind`（`cram`・`lesson`・`other`。計算に使わない）の名前と値の一覧は骨格。初めて「行で入れる」にしたときに作る統計の平均の行の名前・額の出し方は後から変えてよい

## 背景

- 幼稚園〜高校の学費の統計（文部科学省「子供の学習費調査」の学習費総額）のうち、学校外活動費（塾・習い事・家庭での学習・体験を含む平均）を既定で数えている。塾・習い事の月謝の行（`lessons`）は、その上に足していた。塾の月謝を実際の額で入れると、統計の平均の中の塾の分と二重になる（子1人で年に数十万円多く出る）。前は説明の文で「平均より多くかかる分だけを入れる」と頼んでいた（0008 の追記）。
- 前提にする記録: 0010（教育費）、0035（世帯ファイルの形）、0041（値の状態）、0062（子ども・教育のカード）。

## 決定

### 1. 形

- 教育の目標に **学校外の費用の入れ方** `education.outOfSchoolMode` を足す（任意）:

| 値 | 計算 |
|---|---|
| `statistics`（統計の平均で） | 段の学校外活動費（統計の平均か、段の `outOfSchool`）だけを数える。**塾・習い事の行は数えない**（行は世帯に残す） |
| `rows`（行で入れる） | 塾・習い事の行だけを数える。**段の学校外活動費（統計の平均・段の月額）は数えない** |
| 省略（前の形） | 段の学校外活動費に行を足す（今までと同じ） |

- 学校の費用（学習費総額−学校外活動費）は、どの入れ方でも同じ。
- 行に **種類** `lessons[].kind` を足す（任意。塾 `cram`・習い事 `lesson`・その他 `other`）。表示と既定の名前だけで、計算には使わない。
- 計算エンジンの部品 `education.cost` の改訂4。入力のスキーマに2つの欄を足した。

### 2. 画面（0062 の学校外の費用のまとまり）

- 入れ方の選択は簡易。新しく入れる進路（推定の進路・子を足したとき）は `statistics` で始める。
- **初めて「行で入れる」にしたとき**: 幼稚園〜高校の段ごとに、統計の平均の学校外活動費を12で割った月額の行（名前「学校外活動費（中学校・平均）」、種類 その他、期間はその段の在学の期間）を作る。額は推定（値の状態の行。根拠に統計の名前）。段に学校外活動費の月額を入れていればその額（確定）。学校外活動費を「無し」にした段・もう終わった段・同じ名前の行がある段は作らない。結果は切り替える前とほぼ同じ（月額に丸めた分だけ違う）で、FP は塾の段の行だけを実際の額に直せばよい。
- 「統計の平均で」に戻しても**行は消さない**（隠して使わない）。もう一度「行で入れる」にすると同じ行が戻る（作り直さない）。
- 入れ方の無い古い世帯: 行が無ければ「統計の平均で」と同じ計算なので、そう見せる（書き換えない）。行があれば3つ目の選択「統計の平均に行を足す（前の形）」で見せ、「二重になっていないか確かめ、どちらかに切り替えてください」と出す。黙って書き換えない（0035 の11）。
- 行の欄は名前・種類・月額・始まり・終わり（詳細）。足すボタンは塾（月2万円）・習い事（月8,000円）・その他（月5,000円）。入れ方が「統計の平均で」のときは行を出さない。

### 3. 世帯ファイルの形式 0.23

- 足すだけの MINOR。0.22 → 0.23 の変換の段は形式の版だけを書き換える（入れ方の無い目標は前の形で計算するので、足さない）。0.22 のアプリは知らない欄を読み落として書き戻すので、版を上げて閲覧だけにする。
- 見本 `crates/household-store/tests/fixtures/household-format/0.23/`（0.22 の見本の教育の目標を「行で入れる」にし、行に種類を付けたもの）。
- 入力項目ID は足さない（どちらも `goal.education` の中の欄）。AI接続口の縮約版の許可リストは変えない。

## 理由

- **統計の平均と行のどちらか一方だけを数える**: 統計の平均は塾・習い事を含む平均なので、行を足すと二重になる。差額だけを入れてもらう前の頼み方は、FP が平均を知らないと誤る。
- **切り替えの初めに統計の平均の行を作る**: 段ごとに平均の額が見え、塾の段だけ直せる（粗い→細かいの入れ直し）。結果が切り替えた瞬間に大きく変わらない。
- **戻しても行を消さない**: 入れ方を試し比べても FP が入れた額を失わない（形式を切り替えても値は隠すだけで消さない決まり）。
- **省略を前の形のままにする**: 古い世帯の結果を黙って変えない。

## 代案（採らなかったもの）

- 「行で入れる」のときに全部の段の `outOfSchool` を `none` に書き換える: 統計に戻すときに段の値を戻せず、段の月額を入れていた世帯の値が消える。入れ方の1つの欄で計算が決まる方が当て先が1つで済む。
- 行の種類で計算を変える（塾だけ統計から差し引く など）: 統計に塾だけの内訳が無い区分がある。種類は表示と名前だけにした。

## 追記
- 2026-10-30（学校ごとの学校外の費用・部活動の費用。0062 の追記）: 学校外の費用（塾・習い事など）を、学校（段）の中で入れる形にした。
  - 標準: 進路のまとまりに1つの選択「学校外の費用（塾・習い事など）」（統計の平均／入れない。段ごとに違う額が入っていれば「学校ごとに入れた額（詳細）」）。選ぶと幼稚園〜高校のすべての段を一律にする（段の `outOfSchool` を外すか `none`）。
  - 詳細: 幼稚園〜高校の各段に「学校外の費用（月額）」（塾・習い事など）。空欄は推定（統計の平均の学校外活動費÷12）で、入れると段の `outOfSchool: {monthly}`（前からある形。計算は変えていない）。入れ方が「塾・習い事を期間の行で入れる」（`rows`）のときは段の額を数えないので出さない。
  - 前からの入れ方の選択（`outOfSchoolMode`）と行は、まとまり「学校外の費用の入れ方（塾・習い事の行）」（詳細）に残した（選択肢の名前を「学校ごとの額で（統計の平均か入れた額）」「塾・習い事を期間の行で入れる」に）。塾の期間がはっきりしているときだけ行で入れる。
  - **部活動などの費用**（段の `clubAnnual`。中学校・高校の段だけに出す）: 子供の学習費調査では部活動の費用は学校教育費の「教科外活動費」（クラブ活動〔課外の部活動を含む〕・学芸会・運動会・林間学校など）に含まれ、学校の費用（統計の平均）に入っている。そこで推定は教科外活動費の統計の平均（公立中学校 年27,316円・私立中学校 65,131円・公立高校 49,499円・私立高校 63,440円。令和5年度・訂正版の図3-2・図4-2）を見せ、額を入れると学校の費用の中の教科外活動費をその額に入れ替える（`education.cost` の改訂5。学校の年額を入れた段はその年額に足す）。統計の平均は部活動をしていない生徒も含む。「?」に目安として、中学生の運動部の家庭の支出の平均 年50,857円（公益財団法人笹川スポーツ財団「中学生のスポーツ活動と保護者の関与に関する調査」2025年11月12日発表。中学生の保護者 3,136名）を書いた。
  - 依頼の数字「運動部で年約8.4万円・文化部で年約4.4万円（2026年の調査）」は、民間の会社の調査（2026年6月のインターネット調査。部活動に所属する中高生214名・保護者300名ほか）の発表資料にあったが、費用の範囲（学校に払う部費を含むか）と平均の出し方が書かれていないので、推定にも目安にも使わなかった。
  - 統計の値は `master.education.statistics` の 2026.4.0 で足した（幼稚園〜高校の公立・私立の教科外活動費 `education.statistics.<段>.<公私>.extracurricular`。原本の指紋と図の内訳の合計＝表1の学校教育費で照らし合わせた）。
