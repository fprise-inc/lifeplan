# 0059. 介護・親のカードの中身（世帯の外の家族の欄・扶養の境目・亡くなる見込みの推定・本人と配偶者の介護は自動で入れない・介護の段階・親のお金は開いて見る）

- 状態: 採用（一部未確定）（2026-10-26）
- 固定の強さ: 内部（画面の作り）。世帯ファイルの形・エンジンの入力は変えない（今ある欄 `members[].kind`・`outside`・`support`・`leaves`・`wallet`、`careExpenses[]` の `growth`・`onContingency` を画面に出しただけ）。推定の目安に、統計の写し（介護の費用の統計・簡易生命表）と制度の値（扶養の境目）を足した。欄の並び・文言・推定の決め方・事務所の設定の既定は後から変えてよい（変えたら追記に書く）

## 背景

- 0045 で介護・親のカードの枠を作り、世帯の外の家族のまとまり・介護の費用・親とのお金の行・介護休業の読むだけの1行を集めた。中身は家族のカードの構成員のまとまり（家計を1つにする期間・親のお金の小さな形。0035 の4・0042）と、ライフイベントの介護の費用のまとまりをそのまま使っていた。
- 本人・配偶者の介護の費用は、入れなければ0円のまま気づかずに計算される。目安で入れると1人数百万円の額が黙って入る。外れると大きく誤る物は、自動で入れず未入力の警告にする決め方（推定と既定の値の決まり）に当たる。
- 親（世帯の外の家族）の「扶養に入れるか」は、親の年金の額で決まる。FP が面談で毎回確かめる境目なのに、画面に無かった。
- 世帯の外の家族の亡くなる見込み（`leaves`）は、親のお金の見通し（0042）と相続人の数え方（0039）が読むのに、入れる欄が無かった。
- 前提にする記録: 0008（世帯のデータモデル）、0035 の4（世帯の外の家族）、0038（時点の部品）、0039（相続税の目安）、0041（値の状態）、0042（世帯の外の家族のお金）、0044（お金の行）、0045（14枚のカード）。

## 決定

- 家族のカードの構成員のまとまりから、世帯の外の家族の欄（家計を1つにする期間・親のお金・扶養・同居・仕送りの額）を外した（世帯の外の家族はこのカードにだけ出すので、家族のカードには残らない欄だった）。
- 仕送りの額の欄（`member.support.allowance`）は、健康保険の扶養の判定（別居の親）にだけ使い支出に入らないので、「仕送りの額（月額。扶養の判定に使う）」と名前を直し、扶養の欄の下に置いた。値があって相手の行が無ければ「＋ 仕送りを出るお金の行にする」（押したときだけ。0035 の11）。

- 親・祖父母は性別と誰の家族かで「父・母・義父・義母・祖父・祖母」と呼ぶ（`labels.ts`）。性別が仮の値のあいだは「親」「祖父母」のまま。兄弟姉妹は「兄弟姉妹」、孫は「孫」。

### 4. 扶養の境目の1行（親・祖父母。詳細の扶養の欄の下）

- 税の扶養: 年金だけなら「合計所得の上限（`incomeTax.dependentIncomeLimit`）＋公的年金等控除の最低額（その年の12月31日の年齢で65歳以上・未満の表の最初の段）」まで（2026年は65歳以上で年172万円）。
- 健康保険の扶養: 年収の基準（60歳以上は180万円）未満で、同居なら扶養する人の年収の半分未満、別居なら仕送りの額より少ないこと。後期高齢者医療の年齢（75歳）からは入れない。
- 親のお金の年金の額を入れていれば、その額が税の扶養の範囲かを添える。
- 制度データの値（`socialInsurance.dependent.*`・`socialInsurance.health.lateElderlyAge`・`incomeTax.dependentIncomeLimit`・`incomeTax.publicPensionDeduction.*.tier1`・`incomeTax.publicPensionDeduction.elderlyAge`）を推定の目安の写しに足して読む。表示だけで、計算は変えない。

## 理由

- **本人・配偶者の介護を警告にした**: 目安の額が大きく（在宅の平均で1人 約333万円）、外れると大きく誤る。気づかないまま0円にもしない。
- **親のお金を開いて見る形にした**: 親を足すたびに未入力の欄が2つ増え、入れない FP も多い（入れなくても子の世帯の計算はできる）。空の欄で警告を出すより、要る人が開く。
- **亡くなる見込みを年齢の時点にした**: 生年月を直すと一緒に動く（推定の入れ直しが要らない）。介護の目安の始まり・相続の受け取りの時期の推定が、この時点から決まる。
- **欄のキーを変えなかった**: 保存した差分・仮の印・動かす項目に影響しない。

## 代案（採らなかったもの）

- 続柄を「父・母・義父・義母」の1つの選択にする: 1つの欄で種類・性別・誰の家族かの3つの値を書くことになり、当て先が1つにならない。3つの欄のまま、呼び方で見せる。
- 本人・配偶者の介護を新しい世帯に最初から入れる: 外れると大きく誤る物は警告にする決め方に合わない。事務所の設定で選べる形だけ置いた。
- 介護休業を作るボタン: 働き方の期間は重ならない決まりなので、休業を差し込むには今の期間を分ける操作が要る。働き方と収入のカードの操作に任せ、ここは読むだけ。

- 2026-11-08（0164）: 在宅か施設かが空の介護の費用は、額の目安を在宅の平均にした（`care.expense` 改訂6。前は在宅と施設を合わせた平均で、欄の「在宅」・表の行と食い違っていた）。
