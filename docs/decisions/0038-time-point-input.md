# 0038. 時点の部品（「いつ」の欄の入れ方・読み取り・出来事が正本）

- 状態: 採用（一部未確定）（2026-10-26）
- 固定の強さ: 画面の部品（内部）。世帯ファイルの形は変えない（形式 0.17 のまま。部品が書く値は 0003 の6 の時点の型そのもの）。部品が書く値の形（年齢・出来事で入れた時点は年齢・出来事で持つ、今からは年月で持つ）と、出来事が正本の欄で出来事を動かす決まりは、プランの差分（0036）が当て先にする値なので変えるときは追記に書く。読み取る言い回し・見せ方・欄ごとの既定の入れ方・例の文は後から変えてよい

## 背景

- 入力の画面の「いつ」の欄は、年月の文字だけの欄（始まり・終わり・購入の年月など）と、年齢の整数の欄（定年・働く最後・年金の受け取り開始・車を手放す年齢・保険料の払込の終わり）に分かれていた。年齢・出来事で決めた時点は年月で見せ、書き換えると年月の形になった（0003 の追記 2026-10-11）。
- エンジンの時点の型（0003 の6）は、年月・構成員の年齢（年齢の切り替えの規則 `ageSwitch` つき）・名前つきイベントからのずらしを持つ。名前つきイベントを指す時点はエンジンで解けるのに、画面から入れられなかった（今ある見本の世帯では、持ち家の住み始めと住宅ローン控除の入居だけが使う）。
- 現場では「本人が60歳になったら」「妻が65歳」「入居から10年後」「5年後」「令和23年6月」のように時点を言う。欄ごとに入れ方が違うと、FP が欄ごとに書き方を覚えることになり、年齢で決めた時点が生年月を直しても動かない。
- 「独立」「入居」のように、ほかの物が付いて動く時点は、1か所を直せば付いている物が全部動いてほしい。プランでも、その時点を変える差分1件で済ませたい（0036 の3 の、合成の対策を当て先に寄せる方針）。

## 決定

### 1. 入れ方は4つ。書く値はエンジンの時点の型そのもの

| 入れ方 | 打つ例 | 書く値 |
|---|---|---|
| 年月 | `2041年6月`・`2041/6`・`令和23年6月`・`R23.6` | `{"at": "2041-06"}` |
| 人の年齢 | `60歳`・`妻65歳`・`60歳3か月`・`長男22歳の年度末` | `{"memberAge": {"member": ID, "years": 60, "months": 3, "ageSwitch": …}}`（0 の `months`・`reachMonth` の `ageSwitch` は省く） |
| 出来事から | `入居から10年後`・`入居の翌月`・`入居の2年前` | `{"event": ID, "offset": {"years": 10, "months": 0}}`（ずらしが0なら `offset` を省く。年と月の符号はそろえる） |
| 今から | `5年後`・`今から3か月後`・`来年4月` | 計算の基準の月から数えた年月 `{"at": …}`（「今から」は持たない。欄の下に「今から○年後」を添える） |

- **年齢・出来事で入れた時点は、年齢・出来事のまま持つ**（年月に直さない）。生年月を直すと年齢で決めた時点が、出来事を動かすと出来事から決めた時点が、一緒に動く。
- 欄の値（画面の部品の `value`）は年月に解いた `"YYYY-MM"`（ほかの読み手・要約のため）。入っている形のままの時点は欄の状態の `when.raw` に持つ。
- 画面の側で時点を年月に解く関数（`app/src/workspace/timepoint.ts`）は、エンジンの `time/ageSwitch.ts`・`time/timepoint.ts` と同じ決まりで解く（6つの年齢の切り替えの規則すべて。テストで生まれ月12通り×1日生まれか×年齢×規則を突き合わせる）。

### 2. 欄ごとの決まり

- **既定の入れ方**は人の年齢。書類に年月で書いてある欄（購入・借入・保障の始まり・金利の段・繰上返済・受け取る年月・住み始め・FP顧問料・家族が加わる時期）は年月、車の買い替えは今から。
- **既定の人**は欄ごとに決める（働き方・年金・退職給付は本人か配偶者のその人、子の独立・教育はその子、介護は介護を受ける人、車は名義の人、保険は被保険者、生活費・ライフイベント・住まいは本人）。人を書けば（`妻65歳`）その人の年齢になる。人の呼び方は、本人・夫・妻・配偶者・続柄（長男・長女…）・上の子・下の子・末子・第n子・親・父・母・FP が付けた呼び名。
- **「○歳」がどの月か**（欄の決まり `ageMeans`）:

| 決まり | 「65歳」の意味 | 欄 |
|---|---|---|
| `reach`（既定） | 65歳になる月（年齢に達する月。1日生まれは前の月。0003 の4） | ほとんどの欄 |
| `before` | 65歳になる前の月まで | 働く最後・定年・働き方の期間の終わり・積立の終わり（「○歳まで」の欄） |
| `after` | 65歳になった翌月から（`ageSwitch: monthAfterReach`） | 年金の受け取り開始（0003 の追記 2026-10-11） |

  打った言葉が決まりより先に効く: `60歳の前月`・`60歳になる前の月`・`60歳の翌月`・`60歳になる月`・`3歳の誕生月`・`3歳の誕生月の翌月`・`22歳の年度末`（`firstMarch31AfterReach`）・`6歳の4月`（`schoolYear`。その年齢になって最初の4月）。
- **終わりの欄**は「n年間」「nか月間」でも入れられる。始まりの月を含めて n か月目の月を、始まりと同じ形で持つ（年月なら年月、年齢なら年齢、出来事からなら同じ出来事からのずらし。始まりが学年・年度末の規則の年齢なら年月）。**空欄は欄ごとの意味**（最後まで・終身・終わりを決めていない など）を欄の下に出す。
- **使える入れ方**を欄ごとに絞れる（使えない入れ方で打ったら、使える入れ方を知らせる）。出来事そのものの時点は年月・年齢・今からだけ（出来事から出来事は作らない）。
- **範囲の確かめ**も欄ごと: 年金の受け取り開始は60歳になった翌月から75歳になった翌月まで、定年は40〜80歳、働く最後は40〜90歳。

### 3. 打った文字の読み取り

- 全角は半角に、空白は除き、「ヶ月・カ月・ケ月・ヵ月」は「か月」、「才・さい」は「歳」、数字の間のダッシュ・波線は「-」にそろえる。
- 年月: `2041-06`・`2041/6`・`2041.6`・`2041年6月`・`204106`（後ろの「から・まで・頃」は読み飛ばす）。和暦は元号（漢字・頭文字の大文字小文字）＋年（元年も）＋月で、年は元号の初めの年からの足し算で読む（`平成31年5月`・`令和元年4月` のような改元をまたいだ書き方もそのまま足す）。年だけ（`2041`・`令和23年`）は「月も入れてください」と返す。年月の欄（`kind: ym`。生年月・書類の年月）も和暦を読む。
- 年齢: `60歳`・`60`（数だけは既定の人の年齢。今からの形を見せているときは年数）・`60歳3か月`・人の呼び方＋年齢（`妻65歳`・`妻が65歳`・`長男の18歳`）と、2 の言葉。130歳まで、か月は0〜11。0歳より前の月・分からない人・家族のいない世帯は理由を返す。
- 今から: `5年後`・`今から3か月後`・`1年6か月後`・`今月`・`来月`・`今年／来年／再来年n月`。
- 出来事から: 出来事の名前（「入居」「長女の独立」「下の子の独立」「本人の年金の受け取り開始」など）＋`の翌月`・`の前月`・`の翌年`・`の前年`・`からn年後`・`のn年m か月後`・`のn年前`。出来事の形を見せている欄では、名前を書かずに `10年後`・`翌月` と打てばその出来事から読む（`今から10年後` は今から）。
- 読めないときは、欄の下に1行で理由と、その欄で使える例を出す。打っている間は世帯を変えず、読み替えた形（「→ 長女が22歳になった後の最初の3月（2038年3月）」）を出し、欄を離れたとき（Enter）に入れる。読めないまま離れたら前の値のままにして知らせる。
- 欄に見せる文字は、打ち直すと同じ時点に読める形（`65歳`・`妻65歳`・`入居から10年後`・`2041年6月`）。年月の形でも、欄の既定の入れ方に合えば年齢・今からで見せる（`60歳`・`3年後`。形は変えない）。欄の下には読み替えた形（「ご主人が60歳になる月（2046年5月）」「入居から10年後（入居は2028年4月・2038年4月）」「2041年6月（令和23年・今から14年8か月後・ご主人55歳）」）を出す。
- 横の「入れ方」の選び直しは、同じ月のまま形を変える（年齢 ⇄ 年月 ⇄ 出来事から。年齢に直せない月は理由を出す）。年齢の形では「誰の年齢か」も選べる。

### 4. 欄の種類と、整数の欄

- 時点そのものの欄（`kind: "when"`。年月の文字だけだった時点の欄をすべてこれにした）と、年齢・年数の整数の欄に時点の部品を付けた欄（定年・働く最後・年金の受け取り開始〔基礎・厚生とも／別々〕・車を手放す年齢・保険料の払込の終わり）がある。どちらも欄の定義の `time`（決まり・状態・書き方）を持ち、入力の画面の区画の中では時点の部品で描く。
- 整数の欄は、結果のタブの「動かす項目」では整数のまま描き、値も整数で持つ（動かす項目の鍵の意味は読み替え表で決まっているため。0035 の9・0036）。欄のキーは変えていない。
- **働き方の期間の始まり・終わりは年月にして持つ**（年齢・今からで入れても、その年月を書く。欄の下に知らせる）。定年・再雇用の期間の見つけ方・標準報酬月額の目安などが、働き方の期間を年月で読むため。出来事からは選べない。
- **働く最後**は年齢（○歳になる前の月まで）のほか、○歳になる前の月でない年月（`60歳の年度末` など）も入れられる。年齢なら結果の打ち手「働く最後の年齢」と同じ当て方、それ以外の月は同じ決まりで働き方の期間を終え・足し、退職の段階の生活費はその翌月から、働く最後の月を終わりにしていた積立はその月に合わせる。同じ月を入れ直したときは何もしない。
- **定年**は「○歳になる前の月まで」に当たる時点だけ（今の勤め先の期間と定年後の予定を年齢で持つため）。月まで決めるときは働き方の期間の終わりで入れる。
- 年金の受け取り開始は、標準（65歳になった翌月）と同じ月の出来事でない時点は省く（省略は標準）。基礎と厚生をまとめた欄は、別々の時点のときは知らせ、直すと両方そろえる。

### 5. 出来事が正本（今の世帯の形でできる所）

- **正本の欄**: 子の独立（`member.leaves`、出来事の種類 `independence`）・持ち家の住み始め（`residence.from`、`moveIn`）・年金の受け取り開始（`pensionRecord.claim`、`pensionStart`。基礎と厚生が同じ時点のとき）・介護の始まり（`care.from`、`careStart`）。
- **出来事から選べる一覧**: 世帯の出来事（`household.events`）と、まだ出来事でない正本の欄（「長女の独立（2038年4月・選ぶと出来事にします）」）。後者を選ぶと、画面が出来事（種類・構成員・時点＝元の欄の時点の写し）を作り、元の欄をその出来事に向け（`{"event": ID}`）、選んだ欄もその出来事を指す。作っても計算の結果は変わらない。
- **正本の欄が出来事を指している間**（ずらしが0で、出来事の種類が欄の種類と同じ）は、欄に出来事の時点を見せ、打って直すと**出来事の時点を書く**（指している物が全部動く）。欄の下に「「長女の独立」の出来事の時点です。ここを直すと出来事が動き、この出来事を指すほかの n 件も一緒に動きます」と出す。入れ方・人の選び直しは出来事の時点の形を変える。別の出来事を選んだときだけ、この欄を切り離す。ほかの欄（出来事を指しているだけの欄）に年月・年齢を入れたら、その欄だけを変える。
- 出来事の時点は年月か人の年齢だけ（出来事から出来事は作らない。連鎖させない）。画面の側で解くときも、循環は解けないとして止める。
- **家族のカードの「出来事」の区画**（詳しく）: 出来事ごとに時点の欄（年齢・年月・今から）と、指している物の数。FP が足せる出来事の種類は 結婚・離婚・転職・開業・住み替え・移住・親との同居・出産・その他（`marriage`・`divorce`・`jobChange`・`startBusiness`・`relocation`・`parentMoveIn`・`birth`・`other`）で、誰のかも選べる。指されている出来事は外せない。住宅ローン控除の仮の条件のために置いた入居は、借入の年月に合わせて入れ直すので、ここでは直さない（0008 の追記 2026-10-25）。
- **家族を外したとき**: その人の年齢で決めた時点と、その人の出来事から決めた時点を、外す前の年月に直し、その人の出来事を外す（解けない時点を残さない。今まではその人の年齢で決めた時点が残ることがあった）。
- 子の独立が出来事を指していても、出来事の時点が標準（22歳になる月）のままなら、生年月を直したときに標準に合わせる（0008 の追記 2026-10-25 の標準の値の追いかけ）。
- 生活費の段階の「末子独立」の目安を置くときは、いちばん遅い子の独立が年齢・出来事の形なら、その形を写す（独立が動くと節目も動く）。
- 画面の側で時点を読む所（打ち手の今の値・世帯の人数・独立の年・目安の区切り・要約の文・提案書のカード・一時的支出か）は、時点を解いてから読む（年齢・出来事の形でも同じ月に読む）。打ち手の今の値（働く最後の年齢・受け取り開始の年齢・積立の終わり）は、これまで年月の形の時点しか読まなかった。

### 6. プランの差分との関係（0036）

- 時点の欄の当て先は、欄の入力項目ID と場所のまま。値は入っている形のままの時点（値の箱の `value` に時点をそのまま入れる）。
- 出来事が正本の欄で出来事を動かしたときの当て先は、出来事の時点（向き先 `{"object": 出来事}`・`event.at`・`[]`）の `set` 1件。まだ出来事でない物を選んだときは、出来事を足す `add` と、元の欄・選んだ欄の時点の `set` になる（プランの編集で使うときに、この形で差分を書く）。
- この記録では差分の当て方（`plans/`）を変えていない。結果のタブの動かす項目は今のまま（整数の欄は整数）。

## 理由

- **1つの部品にする**: 欄ごとに書き方が違うと、FP が欄ごとに覚え、取り込み・AI の候補・ヒアリングも欄ごとに読み方を持つことになる。読み取りを1か所にすれば、例の文・知らせの文もそろう。
- **年齢・出来事のまま持つ**: 年月に直すと、生年月の修正・出来事の移動で付いて動かなくなる。エンジンはもともとこの形を読むので、形式を変えずにできる。
- **今からは年月で持つ**: 「今から5年後」は計算の基準の月が変わると意味が変わる。見直しのたびに黙って動かないよう、入れた時点の年月で持ち、今からの言い方は見せ方だけにする。
- **「○歳」の意味を欄ごとに決める**: 働く最後・年金の受け取り開始は、制度・現場の言い方で「○歳」が指す月が違う（○歳になる前の月まで働く、○歳になった翌月から受け取る）。言葉で書けば上書きできるので、言い回しの違いで別の月にならない。
- **欄を離れたときに入れる**: 年齢の「6」と「60」のように、打っている途中の文字も読めてしまう。途中の値で計算し直したり、出来事を作ったりしないため。
- **整数の欄は整数のまま**: 動かす項目の鍵の意味は読み替え表で凍結しており、差分の値を整数で持つ。時点の値を流すと、古い差分の読み方と食い違う。差分を当て先で書けるようになってから、時点の欄から動かす項目を作る。
- **働き方の期間を年月で持つ**: 定年・再雇用の期間の見つけ方、給与・標準報酬月額の目安の年齢、住民税の判定など、働き方の期間を年月で読む所が多い。年齢で持つと、それらを全部解いて読むように直す必要がある（未確定の1）。
- **出来事が正本を、選んだときに作る**: 物を作るたびに出来事も作ると、今の世帯（見本の世帯を含む）を開いただけで世帯が書き換わる。選んだとき・正本の欄を直したときに作れば、開いた世帯を黙って書き換えない（0035 の「古い世帯は黙って書き換えない」）。
- **家族を外したときに年月へ直す**: 外した人の年齢・出来事を指したままの時点は解けず、計算が止まる。

## 影響

- **世帯ファイルの形**: 変えない（形式 0.17 のまま。新しい欄は無い）。出来事の種類の名前を足した（`independence`・`pensionStart`・`careStart` と FP が足す種類）。エンジンは出来事の種類を、辞め方の推定（`retirement`。0037）と制度の値の基準の出来事でだけ読み、これらの名前は読まない。
- **計算の結果**: 見本の世帯の結果は変わらない（開いただけでは形を変えない）。モデル世帯すべてで、時点の欄を年齢・出来事の形に直しても（同じ月のまま）キャッシュフロー表が同じことをテストで確かめる。
- **画面**: 時点の欄はすべて時点の部品で描く。打ち手の読み方（`levers.ts`）は時点を解いて読む。働く最後を年齢の整数でない月にする当て方（`applyRetireMonth`）を足した（打ち手「働く最後の年齢」の当て方は同じ）。
- **テスト**: 読み取りの例（年月・和暦の境・境目の年齢・1日生まれ・学年と年度末・今から・出来事から・n年間・読めない理由）、見せ方と読み直しの往復、年齢の切り替えの規則のエンジンとの突き合わせ、欄の読み書き（出来事が正本・出来事にする・家族を外す・受け取り開始・働く最後・定年・働き方の期間）、モデル世帯の往復（時点の欄は形のままの時点で往復）。

## 未確定

形を変えないとできないこと・この記録の後にすることの案。

1. **定年・働く最後を出来事にする**: 働き方の期間を年月で読む所（定年・再雇用の期間の見つけ方、給与・標準報酬月額の目安、住民税の判定、加入歴の作り方）を、時点を解いて読むように直してから、働き方の期間の終わりを `retirement`（定年）・`lastWork`（働く最後）の出来事に向ける。打ち手「働く最後の年齢」はその出来事の時点の `set` に寄せ（0036 の3）、退職後の生活費の節目・積立の終わり・退職給付の受け取りは出来事を指す。`retirement` はエンジンが辞め方の推定に読む（0037）ので、定年の出来事だけに使う。
2. **「出来事の年の n 月」**（「下の子の独立の年の4月」）: 時点の型の出来事からの形に「その年の n 月」を足す（例: `{"event": ID, "month": 4}`。形式の変更）。それまでは人の年齢の学年の規則（`長女22歳の4月`＝22歳になって最初の4月）で代える。
3. **出来事に名前を持たせる**: 出来事の形に名前の欄が無いので、FP が足す「その他の出来事」に名前を付けられない（`label` を足す。形式の変更）。
4. **時期の幅**（「55〜65歳のどこか」で年ごとにずらして比べる）: 時点の欄の「幅で並べて見る」から、保存しない自動の差分（時点の `set` を幅の中の年ごとに。0036 の6）で作る。この記録では入れていない。
5. **生年月を年齢で入れる**（「36歳」と打つと仮の生年月と「仮」の印）: 生年月の欄は年月の欄（時点の型でない）なので、この部品の外。仮の印の置き場所（0035 の3）と合わせて決める。
6. **結果のタブの動かす項目を、時点の欄から作る**: 差分を当て先で書けるようになってから（0036 の8）、時点の欄・整数に時点の部品を付けた欄を、時点の値のまま動かせるようにする。そのとき整数の欄（定年・受け取り開始など）を時点の欄にまとめ、車の「次の買い替えまでの年数」は「今から」にまとめる。
7. **まだ時点の部品にしていない欄**: 万一の前提の時点の欄（働き方を変える時期など）、黒字の貯まり方の割合の区切り（年齢の整数）、積立をやめる年齢・受け取りを始める年齢（貯蓄・運用の整数の欄）、書類の年月の欄（契約年月・残高の時点など。年月の型で持つので和暦は読む）。
8. **出来事を自動で作るか**: 物を作るときに出来事も作る（独立・入居・受け取り開始・介護の始まり）かは、古い世帯を開いたときに書き換えない決まりと合わせて決める（今は選んだときに作る）。
