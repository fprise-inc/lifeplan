# 0181. 固定資産税の目安の見直し（建物の下がり方を固定資産評価基準の経年減点補正率・再建築費評点補正率に寄せる・新築の評価額の割合・土地の扱い）

- 状態: 採用（一部未確定）（2026-11-09）
- 固定の強さ: 内部（画面の側の推定の式・目安の値・根拠の文。世帯ファイルの形式の版・計算エンジン・書く値の形は変えない。法令の値〔経年減点補正率・再建築費評点補正率〕を事務所で変えられないことは 0112 のまま）
- 前提にする記録: 0111（事務所の推定の値）、0112（固定資産税の推定）、0123（貸していない不動産の毎年の費用）、0176（今住んでいる持ち家を買った値段から推計する）

## 背景

0112 の推定は、建物の評価額を「建物の価格×6割」とし、建物の下がり方を「木造・軽量鉄骨造30年・ほかは60年で、まっすぐ下限20%」の目安（事務所の推定の値）で置いていた。築10年前後の木造で実際の納税額より高く出やすく、0176 の例（2015年4月に4,000万円〔土地1,500万円〕で買った木造）では2026年 年22.88万円になった。利用者の判断（2026-11-09）で、総務省の固定資産評価基準のやり方に寄せて見直す。入力の欄は増やさない（推定の元は今までどおり、買った値段・土地の値段・買った年月・建て方・構造・建った年）。

## 決定

### 1. 建物の評価額の下がり方（`propertyTax.ts` の `buildingValueRatio`）

固定資産評価基準の家屋の評価（評価額＝再建築費評点数×経年減点補正率×評点一点当たりの価額）に寄せる。

- 推定の元の時点（購入の予定は最初の年、今住んでいる持ち家はその額の時点の年）に効いている評価替えの年の経過年数の経年減点補正率を元にし、その後の評価替えの年（2024年から3年ごと）ごとに、その年の経過年数の補正率×再建築費評点補正率（累積）に置き換える。前の額より上がる年は前の額のまま（在来分の家屋の価額の据え置き）。評価替えの間の年は前の評価替えの額のまま。
- 経過年数＝評価替えの年−建った年（1年未満は1年。新築の翌年の最初の評価は1年の0.80）。
- 経年減点補正率（法令の値。`KEINEN`）:
  - 木造: 別表第9「木造家屋経年減点補正率基準表」1（専用住宅、共同住宅、寄宿舎及び併用住宅用建物）の、延べ床面積1.0㎡当たり再建築費評点数 95,820点以上147,770点未満の区分（0.80・0.75・0.70・0.68・0.65・0.63・0.61・0.59・0.56・0.54・0.52・0.50・0.47・0.45・0.43・0.40・0.38・0.36・0.34・0.31・0.29・0.27・0.25・0.22、築25年以上0.20）。
  - 非木造: 別表第13「非木造家屋経年減点補正率基準表」2（住宅、アパート用建物）。鉄筋コンクリート造（鉄骨鉄筋コンクリート造）は築60年、重量鉄骨造は鉄骨造（骨格材の肉厚4mm超）の40年、軽量鉄骨造は鉄骨造（3mm超4mm以下）の30年で0.20。築3年まで0.80・0.75・0.70、その後は0.20までまっすぐ下がる（表の小数4桁の値と同じ。テストで照らす）。
- 再建築費評点補正率（法令の値。`REBUILD_FACTOR`）: 確かめた2024年度（令和6基準年度）の木造1.11・非木造1.07だけを置き、ほかの年は1にする。
- 購入の予定（0112）・今住んでいる持ち家（0112 の追記 2026-11-03）・貸していない不動産の空き家と別荘（0123。評価額の建物の分を新築の評価額とみなし、建った年からの比を当てる）の3つの推定に同じ関数を使う。新築の軽減・住宅用地の特例・税率・段の置き方・割合のそろえ方は 0112 のまま。

### 2. 新築の評価額の割合（事務所の推定の値 `preset.housing.propertyTax.buildingRatio`）

- 意味を「新築の評価額（経過年数1年の補正率0.80を当てた後）の、建物の価格に対する割合」とし、60% → 40% にする（版 2。事務所の値で上書きしている事務所には「公式の値が新しくなりました」と出る。0111）。中古で買った家・今の時価の家は、今までどおり、その額の時点の建物の価格にこの割合を当てた額をその時点の評価額とする。
- 統計の出典は無い（推定の値）。照らした数（2026-11-09）: 総務省「固定資産の価格等の概要調書」令和6年度の新増分家屋（木造・戸建形式住宅・全国計）は1㎡あたり87,664円。建物の価格が1㎡あたり20〜25万円なら3.5〜4.4割、住宅金融支援機構「2025年度フラット35利用者調査」の注文住宅の平均（所要資金4,262万円÷住宅面積118.4㎡＝約36万円/㎡）なら約2.4割。価格に設計・販売・設備の分が入るほど割合は下がる。高めの側の40%を目安にした（支出を少なく見すぎないため。0112 の追記 2026-11-03 の3 と同じ考え）。

### 3. 土地（変えない）

土地の評価額は今までどおり、その額の時点（買った年）の土地の価格×7割（事務所の推定の値 `landRatio`）のまま、伸ばさない。

- 総務省は宅地の評価額を地価公示価格等の7割を目途とする（平成6年度の評価替えから）。買った値段は実際の売買の価格で、地価公示価格より高いことが多い（買った値段×7割は評価額をやや高めに読む）。買った後の地価の上がりを入れないことと、おおよそ打ち消し合う。
- 土地を上昇率で伸ばすと、評価替えと負担調整でなだらかにしか動かない土地の評価額を、昔の買った値段から多く見すぎることがある（0112 の追記の3 のまま）。地価が大きく動いた家は、FP が納税通知書の額を入れる。

### 5. 0176 の例の家の目安

2015年4月に4,000万円（うち土地1,500万円）で買った木造（建った年は空欄＝買った年の新築）の2026年の額:

| | 前（0112） | 後（この記録） |
|---|---|---|
| 土地 | 1,050万円 → 年3.50万円 | 同じ（年3.50万円） |
| 建物の評価額 | 2,500万円×60%×(1−0.8×9÷30)＝1,140万円 | 2,500万円×40%＝1,000万円（新築）×(0.56×1.11÷0.80)＝777万円 |
| 建物の税（1.4%＋0.3%） | 年19.38万円 | 年13.21万円 |
| 合計 | **年22.88万円** | **年16.71万円** |

段は 2027年 年15.29万円（築12年 0.50×1.11）・2030年 13.64万円・2033年 12.00万円・2036年 10.34万円・2039年 8.69万円・2042年 8.22万円（築27年で下限0.20×1.11）で止まる。年15万円前後の見込みより少し高いのは、2024年度の再建築費評点補正率（1.11）を当てたため（当てなければ年15.4万円）。実際の評価替えで当たった率なので、そのまま採る。

## 理由

- 経年減点補正率は法令の値で、評価替えのたびに納税通知書の額がこの表で動く。目安の年数（事務所の推定の値）より、FP が納税通知書と照らしやすい。木造の初めの数年の下がり（0.80→0.70）と、下限に届く年（木造25年）が実際に近くなる。
- 再建築費評点補正率は、2024年度のように1.1倍を超えると、築10年前後の家の評価額がほとんど下がらない（据え置き）。確かめた年だけ入れ、決まっていない先の年は1にして、推定の元にない値を作らない。
- 新築の評価額の割合は家ごとの再建築費評点数で決まり、価格からは出せない。概要調書の1㎡あたりの価格と、建物の価格の1㎡あたりの目安から、高めの側の値にした。
- 事務所の推定の値の、建物の評価額の下限と下限まで下がる年数（木造・非木造）の3値は、経年減点補正率の表に置き換わるので外した。事務所で地域に合わせるときは、建物の評価額の割合（と都市計画税の税率）で合わせる。

## 代案（採らなかったもの）

- 木造の区分を事務所の推定の値で選べるようにする: 区分の違いは築15年・20年・25年・35年で下限に届く差で、多くの新築の家は今の区分に入る（概要調書の1㎡あたりの価格）。選ぶ口を足すほどの差か、FP の声を聞いてから決める。
- 先の評価替えの再建築費評点補正率を物価上昇率から見込む: 率は工事原価の3年の動きから決まり、物価上昇率と同じではない。見込みの値で建物の評価額を上げると、推定の元にない値で税が増える。
- 土地を前提条件の上昇率で伸ばす: 3 のとおり。

## 影響（計算の結果が変わる所）

- 推定のままの固定資産税（根拠の文が「固定資産税の推定」の欄と段）は、入力を直したときの入れ直し（`refreshEstimates`）で新しい式の額になる。FP が入れた額・目安のボタンの値（年12万円のひな形）は変わらない（入れ直さない）。
  - 購入の予定（新築の木造の戸建て4,000万円・土地30%・2028年購入）: 最初の年 年19.60万円 → 14.00万円。軽減が終わる年は 29.84万円 → 20.65万円。
  - 購入の予定（中古の戸建て・建った年が空欄）: 年31.36万円 → 21.84万円。
  - 今住んでいる持ち家（2018年築のマンション5,000万円・土地30%）: 2026年 年36.34万円 → 24.32万円。（2005年築の木造3,500万円・土地30%）: 年14.78万円 → 10.31万円。
  - 0176 の例の家: 上の5（年22.88万円 → 16.71万円）。
- 貸していない不動産の空き家・別荘の毎年の費用の目安（推定のままの行）: 建物の分が、価格×40%×（建った年からの経年減点補正率の比）になる（前は価格×60%×目安の下がり方）。例: 1,000万円（土地30%）の1980年築の木造の空き家は、建物の評価額 84万円 → 70万円。
- 見本の棚・モデル世帯: 固定資産税はどれも FP の額（確定）で、貸していない不動産の推定の行も無いので、結果は変わらない。
- 事務所の推定の値: `preset.housing.propertyTax.buildingFloor`・`buildingYears.wood`・`buildingYears.nonWood` を外した（上書きしていた事務所の値は読まれなくなる）。`buildingRatio` は版 2。
- 世帯ファイルの形式の版・計算エンジンは変えない。

## 未確定

- 評価替えの年（2027年度）の再建築費評点補正率と、令和9基準年度の経年減点補正率基準表の改正（区分の評点数）。決まったら `REBUILD_FACTOR` と `KEINEN` を直す（`docs/estimates-review.md` の「一覧に入れていない値」）。
- 在来分の家屋の価額の据え置きは、各基準年度の経過措置として置かれてきた。先の年も続くとみなしている。
- 新築の評価額の割合（40%）は統計の出典の無い目安。概要調書の新増分の価格と建物の価格の統計（建築着工統計の工事費予定額など）を組み合わせて、統計から出す道を探す。マンションの割合（共用部分・販売の分が大きい）を分けるか。
- 中古で買った家（建った年が前）は、売値の建物の分に同じ割合を当てるので、評価額を低めに読むことがある（中古の建物の売値は評価額より早く下がる）。中古の家の推定の元を「新築の時の価格」に寄せるか。
- 軽量鉄骨造を肉厚3mm超4mm以下（30年）とみなした（3mm以下なら20年）。積雪地域・寒冷地域の補正（別表第9の2）は入れていない。
- 木造の区分（95,820〜147,770点）を事務所で選べるようにするか（代案）。
