# 0066. 年金のカードの中身（入れ方の区分と書類の種類・前の記録を残す・加入月数のわからない・受け取っている遺族年金と障害年金・外国の年金）

- 状態: 採用（一部未確定）（2026-10-27）
- 固定の強さ: 骨格（入れ方の区分は画面の側で、記録の型 `pensionRecord.kind` の値を変えないこと、推計に戻しても前の記録を消さずに画面の側に残してエンジンへ渡さないこと、加入月数のわからないの代わりの値の決まり、受給中の遺族年金・障害年金の種類 `incomeFlow.pensionType` の値の一覧と計算に使わないこと、古い世帯を黙って書き換えないこと）。欄の並び・簡易と詳細の分け方・文言・書類の種類の既定の年齢・終わりの推定の文は後から変えてよい（変えたら追記に書く）
- 前提にする記録: 0003（年金の決まり・受け取り開始）、0008（世帯のデータモデル・値の箱・年金の記録）、0035（世帯ファイルの形式。足すだけの形）、0038（時点の部品）、0041（値の状態の操作・確かめの一覧・推定で埋める）、0043（入力画面でプランを直す）、0044（お金の行）、0045（カード）。年金の見込みの見せ方と形式 0.28 は 0067。

## 背景

- 計算エンジンの年金の記録（`pensionRecords`。1人1件）は5つの型（ねんきん定期便の50歳未満・50歳以上、受給中の通知、加入歴、見込額だけ）を持ち、記録の無い人は働き方の期間から加入歴を推計する。受け取り開始は基礎と厚生を別々に時点で持てる。
- 画面は6つの選択肢（5つの型と「入れない」）を1つの欄で選んでいた。「入れない」を選ぶと記録を消し、写した数字が無くなった。定期便の加入月数が0か月のままのときは知らせだけで、「分からない」を選ぶ道が無かった。
- 受け取っている遺族年金・障害年金と外国の年金は、お金の行（0044）の種類 `survivorPension`・`foreignPension` で額を入れられたが、年金のカードの後ろの詳細の区画にあり、遺族年金の種類（遺族基礎年金・寡婦年金など）で決まる終わりを推定しなかった。
- これからの国民年金（付加年金・任意加入・これからの免除と猶予・追納・子の学生納付特例）、加給年金を受けない前提、制度の境目までの額は、計算エンジンにまだ無い。

## 決定

### 1. 入れ方の区分（推計／書類から／加入歴から）と書類の種類

| 区分 | 中身 | 記録の型 |
|---|---|---|
| 推計（既定） | 書類が無い。働き方の期間から計算する | 記録なし |
| 書類から | 書類の種類を選んで数字を写す | `statementUnder50`・`statementOver50`・`receiving`・`projection` |
| 加入歴から | 加入の期間と平均標準報酬額の表 | `history` |

- 区分は画面の側（記録の型から決まる）。記録の型の値は変えない。書類の種類は「ねんきん定期便（50歳未満）」「ねんきん定期便（50歳以上）」「年金額改定通知書（受給中）」「ねんきんネットの見込額・見込額だけ」の4つ（後の2つはどちらも `projection`）。
- 書類からを選んだときの書類の種類の既定は年齢から: 65歳以上は改定通知書、50歳以上は定期便の50歳以上、それより下は定期便の50歳未満。推計のままのまとまりには「書類の額で置き換える」を出す（書類からにする1押し）。
- 書類の種類を変えるときは、同じ意味の欄（作成年月・加入月数）と値の状態の行を引き継ぎ、額の欄の名前・説明・未入力の文を新しい書類のものにする（前から）。
- 改定通知書の額の欄の説明に「加給年金・振替加算は計算で足すので、除いて写す」を書く（二重にしない）。
- 受け取り開始の欄の説明に「制度の変更で受け取り開始が遅くなる場合を試す欄ではない」を書く（ここで変えると繰上げの減額・繰下げの増額が付く）。

### 2. 区分を変えても前の記録を消さない

- 区分を変える（書類から→推計、書類から⇄加入歴から）ときは、今の記録を画面の側の `pensionKept`（構成員の ID → 区分ごとに1件）に残し、計算の要求からは外す（1人1件の決まり）。行き先の区分に残した記録があれば、それを戻す。無ければ、今の記録の作成年月・受け取り開始を引き継いで新しく作る（別の ID）。
- 推計のまとまりには「前に入れた記録（…）を残しています。入れ方を戻すと戻ります」と出す。
- 残した記録は画面の側の値で、計算・AI接続口の縮約版・持ち帰り用のレポートには渡さない。プランの中で区分を変えたときは、プランの差分（記録の外す・足す）になり、残した記録は作らない。

### 3. 定期便の加入月数（わからない・代わりの値）

- 加入月数が国民年金・厚生年金とも0か月のまま（値の状態の行も無い）の定期便は、欄を空欄で見せ、まとまりに「加入月数がわからない（代わりの値で計算する）」を出す。押すと2つとも代わりの値にし、値の状態の行を「わからない」（出し方 `derived`、根拠に月数）にする。欄の「わからない」の操作も、その欄だけ同じ代わりの値にする。
- 代わりの値: 国民年金は20歳の月から書類の作成年月まで（60歳になる前の月まで。最大480か月）、厚生年金は作成年月までの働き方の期間のうち厚生年金に入る月（最大900か月）。
- 写した値を打つと、わからないの行は外れて確定になる（0041 の4）。加入月数の知らせ（パネル・カード・結果のタブ）は、わからない・推定の行があれば出さない。

### 4. 推定で埋める（入っていない物）

| 物 | 入っていないとき | 推定で埋める |
|---|---|---|
| 書類からで、老齢基礎年金・老齢厚生年金の額が2つとも未入力 | 年金0円 | 推計に戻す（書類の記録は 2 のとおり残す）。根拠「働き方の期間から推計」 |
| 額はあるが定期便の加入月数が0か月のまま | 少なく（50歳以上は0円で）計算 | 代わりの値を推定（出どころ `auto`）で入れる |

- 古い世帯を開いても自動では入れない（確かめの一覧のいちばん上とカードのパネルの上に出す。0041 の6）。0041 の未確定の「年金の見込額」は、この2つと 0067 の見込みの表示で行った。

### 5. 受け取っている遺族年金・障害年金

- 年金のカードに区画「受け取っている遺族年金・障害年金」を置き、お金の行（種類 `survivorPension`。非課税・年金の行）で1件ずつ入れる。簡易の欄は 受け取る人（本人・配偶者・子）・種類・年額（通知書の額）・計算に入れる始まり・終わり。詳細は前からのお金の行の欄（課税の扱い・伸び方・万一のときの扱い・表の行・段階と例外の年）。
- 種類は入るお金の行に足した `pensionType`（`survivorBasic` 遺族基礎年金・`survivorEmployee` 遺族厚生年金・`widow` 寡婦年金・`disabilityBasic` 障害基礎年金・`disabilityEmployee` 障害厚生年金）。表示と終わりの推定だけで、計算には使わない。
- 終わりの推定（今の制度）: 遺族基礎年金はいちばん下の子が18歳になった年度の末、寡婦年金は65歳になった月、30歳未満で子のない人の遺族厚生年金は始まりから5年、ほかは続く（終わり無し）。推定の終わりは値の状態の行（推定・出どころ `auto`）で持ち、種類・受け取る人を変えると入れ直す。FP が終わりを入れたら入れ直さない。続く（終わり無し）の推定は行を書かない（値の無い場所に行を書かない。0035 の12）。
- 足す1押しは「＋ 遺族年金を受け取っている」（子がいれば遺族基礎年金、いなければ遺族厚生年金）と「＋ 障害年金を受け取っている」（障害基礎年金）。年額は未入力（0円で計算中）で始める。
- 受け取る人に、始まりより後で終わりより前に始まる配偶者の関係（再婚）があれば、終わりの欄に知らせを出し、「終わりを再婚の月に合わせる」の1押しを出す（自動では合わせない）。
- まとまりに「額だけで計算する（非課税）。65歳からの自分の老齢厚生年金との調整・再婚などでの失権・障害年金と老齢年金の組み合わせは計算に入っていない。65歳から額が変わるときは段階で」と書く。

### 6. 外国の年金と区画の置き方

- 外国の年金（お金の行の種類 `foreignPension`。雑所得）は区画「外国の年金（円の額で）」に置き、簡易で足せる。この区画からは遺族年金・障害年金を足さない（5 の区画で足す）。
- 年金のカードはお金の行の区画を自分の中に置く（カードの後ろに区画を足すカードの一覧から外した）。
- 人の区画に、読むだけの1行「退職金・企業年金・基金 n件（退職金・企業年金のカードで入れます）」。

### 7. 人の範囲

- 年金のカードに出すのは世帯の中の本人・配偶者（生まれる予定・世帯の外の家族を除く）。世帯の外の家族（親など）の年金は介護・親のカード（0042）で、混ぜない。受給中の遺族年金・障害年金の受け取る人には子も選べる。

## 理由

- **区分を3つにする**: 書類の種類は「どの書類を持っているか」の1問で選べ、選び直しても書類の欄の形はほぼ同じ。最初の問いを「書類があるか」にすると、書類の無い人は何も入れずに済む。
- **前の記録を画面の側に残す**: 1人1件の記録を計算に渡す形のまま、推計と書類からを比べ直せる。計算の要求に入れないので、残した記録が結果を変えない。
- **代わりの値を20歳から作成年月まで**: 定期便を持つ人の多くは20歳から加入していて、0か月のままより実際に近い。わからないの印で確かめの一覧に残る。
- **遺族年金の種類を計算に使わない**: 65歳からの調整・失権を計算に入れるまで、種類は終わりの推定と見せ方にだけ使う。計算に入れる回に、同じ値をそのまま読める。

## 代案（採らなかったもの）

- **区分を4つ（定期便の版・通知書・加入歴・入れない）**: 書類の種類で欄の形はほぼ変わらず、選ぶ数が増えるだけ。
- **推計に戻すときに記録を消す（前のまま）**: 写した数字が戻らない。
- **残した記録を計算の要求の中に持つ**: 1人1件の決まりと合わず、エンジンが使う記録を選ぶ決まりが要る。
- **遺族年金・障害年金をお金の行でなく年金の記録の新しい物にする**: 計算（65歳からの調整・扶養の判定・失権）が入るまで、入れても結果に出ない欄が増える。お金の行の額で始め、計算を入れる回に物の形を決める。

## 影響

- **画面**: 年金のカード（`input/stages/pension.ts`）、推定で埋める（`input/fill.ts`）、区画の置き方（`input/stages/index.ts`）、区分と書類の種類の選択肢（`input/labels.ts`）、画面の側の残した記録（`input/household.ts` の `pensionKept`）。
- **エンジン**: 入るお金の行に `pensionType`（任意。表示と終わりの推定だけ）を足した。計算は変えない。
- **計算の結果**: 見本の世帯・モデル世帯は変わらない（世帯の物は変えず、開いただけでは書かない）。FP が「推定で埋める」を押した世帯は、年金の額・加入月数の分だけ変わる。
- **テスト**: `app/test/card-pension.test.ts`、`app/test/screen-fixes.test.ts`（区分と書類の種類に合わせた）。

## 未確定（残した欄）

- 受給中の遺族年金・障害年金の記録の物（等級・受け始めた時期・うち中高齢寡婦加算・65歳からの老齢厚生年金との調整・障害年金と老齢年金の組み合わせ・健康保険の扶養と住民税の非課税への算入・再婚での失権）。計算が入るまでは額と段階で入れる。
- これからの国民年金（付加年金・任意加入・これからの免除と猶予・未納・追納・子の学生納付特例）。エンジンは働き方の期間どおりに納めるとして計算する（第1号の期間の免除・猶予は、加入歴とこれまでの免除の欄で過去の分だけ入れられる）。
- 加給年金・振替加算を受けない前提（生計維持が認められない場合）と、事実婚の配偶者の加給年金の扱いの確かめ。
- 制度の境目までの額（住民税が非課税になる年金の額・年金生活者支援給付金の対象）の読むだけの1行。
- 年金分割の読むだけの1行（家族のカードに年金分割の欄ができてから）。

## 追記

- 2026-10-29（推計のしかたを出す・受け取り開始の欄を標準と詳細で分ける・繰上げは両方同時）:
  - **推計のしかた**: 入れ方が「推計（書類なし）」のとき、入れ方の欄の横に「推計のしかた: 生年月と、働き方と収入の項目の働き方の期間（働き方・始まりと終わり・年収）から、国民年金・厚生年金に入る月数と平均の報酬を出して、老齢基礎年金と老齢厚生年金を計算します。過去の報酬は今の年収の水準とみなします」を出す（計算エンジンの年金の加入の記録の推計 `pension.record` に合わせた文）。前は同じ趣旨の文をまとまりの「?」の中に入れていて見えにくかった。まとまりの説明は、前に入れた記録を残しているときの文だけにした。
  - **受け取り開始の欄**: 標準では「受け取り開始（基礎・厚生とも）」だけを出し、詳細（と標準の「▸ 詳しく」を開いたとき）では、その代わりに「老齢基礎年金の受け取り開始」「老齢厚生年金の受け取り開始」を出す（3つを同時に出さない）。繰下げは基礎と厚生を別々にできる（例: 加給年金を受けるために厚生は65歳から、基礎だけ繰下げる）ので、別々の欄は残す。基礎と厚生で違う時期のときは、標準の欄に「基礎と厚生で違う時期にしています（別々の欄は「詳細」で見られます）。ここを直すと両方そろえます」を出し、標準の欄を直すと両方そろう（前からの動き）。欄の決まりに「標準だけの欄」（`simpleOnly`。詳細の欄が見えている間は出さない）を足した。欄のキーは変えないので、対策の「年金の受け取り開始」（`pensionAge`。本人の基礎と厚生を両方動かす）と、動かす項目の一覧から推計の区分の受け取り開始の欄を外す決まり（0078）はそのまま。
  - **繰上げは両方同時**: 繰上げ（65歳になった翌月より前）は老齢基礎年金と老齢厚生年金を同時に請求する決まり（国民年金法附則9条の2第2項）。計算エンジンは片方だけ早めた入力を早い方の月にそろえて知らせる（`N_ASSUMED`）が、入力の画面でも片方だけの繰上げを作らない: 別々の欄で片方を直したとき、直した方かもう片方が繰上げなら、もう片方も同じ時点にそろえる（65歳に戻せば両方65歳）。繰下げどうしは別々のまま。別々の欄の説明にこの決まりを書いた。
  - テスト: `app/test/card-pension.test.ts`（推計のしかたの文・標準だけの欄・違う時期の知らせとそろえ直し・繰上げのそろえ方・時点の部品で入れたとき）。
