# 0179. 運用と保険の器の直し（旧NISA の内訳の無いとき・移し先の利回り・変額と外貨建の前の払込・年金の税・資産が尽きる年）

- 状態: 採用（一部未確定）（2026-11-08）
- 固定の強さ: 内部（計算エンジンの部品 `plan.cashflow` の改訂25・`insurance.policy` の改訂6〔約束の版 1.3。受け取りの種類 `annuityRight` を足した〕、制度データ `regulation.tax` 2026.20.0 の5値、エンジンの目安1つ、画面と提案書の「資産が尽きる年」の決め方。世帯ファイルの形式の版は変えない）
- 前提にする記録: 0002（丸めは規則IDつき）、0007（制度データの形式）、0026（資産運用・取り崩し・「金融資産は○歳まで持ちます」）、0054・0055（保険の受け取りと税の区分・アカウント型）、0111（事務所の推定の値）

## 背景

運用・NISA・保険の器を調べて、次の7件が見つかった。

1. **旧NISA・ジュニアNISA に買付の年の内訳を入れないと、非課税期間が終わらない**（R4-001）: 非課税期間の終わりは内訳（`accounts[].lots`）の年で決めていて、内訳の無い器は見ていなかった。画面の注は「買付の年ごとの内訳が無いときは、全部を残高の時点の年に買ったとみなして、非課税期間の終わりを決めます」と書いている。
2. **旧NISA を課税口座へ移すと、名義人に課税口座が無いときは前提の運用利回りで増える**（R4-002）: 移し先を作るときに元の器を渡していなかった。NISA の枠を超えた分・iDeCo の受け取りを運用に回すときは元の器の資産の配分・利回りにそろえている（0026）。
3. **変額・外貨建の保険（前の入れ方）の積立金が、計算基準年の2年前より前に払った保険料を数えない**（R4-003）: 積立金は払込保険料の支払い（計算基準年の2年前の1月から）だけで伸ばしていた。一時払いが前の契約は0円。同じ部品の払込保険料の累計（`paid`）は前の分も数えていたので、帳票の「払込の累計」と「解約返戻金」が食い違った。
4. **契約者と受取人が違う個人年金を、毎年の年金ごとの贈与にしていた**（R4-004）: 保険料を負担した人と年金の受取人が違うときは、年金の支払が始まる時（給付事由が発生した時）に年金を受け取る権利（定期金に関する権利）の贈与があったとみなされ、その評価額に贈与税がかかる（相続税法6条3項、国税庁 No.1610）。毎年の年金は贈与ではなく雑所得で、相続等（個人からの贈与を含む）で取得した年金は所得税法施行令185条で課税部分だけを総収入金額に入れる。前は毎年 60万円を1件ずつの贈与にし、基礎控除 110万円に収まって贈与税が0円だった。
5. **年金の年数を空にすると、個人年金の必要経費が0になる**（R4-005）: 画面の欄「年金の年数」の説明は「入れなければ保障の終わりまで」なのに、計算は支払総額を出せず必要経費を0にしていた。終身年金も同じ。
6. **必要経費の割合の端数**（R4-006）: 所得税法施行令183条1項4号は、保険料の総額÷支払総額の割合を「小数点以下二位まで算出し、三位以下を切り上げ」とする。前は割合をそのまま使っていた。
7. **引き出せない器が残っていると、預金が負でも「金融資産は○歳まで持ちます」に出ない**（R4-007）: 結論の1文・プランの帯・万一の判定・提案書は「金融資産の合計がマイナスになる年」で決めていた。60歳前の iDeCo のように取り崩せない器が残っていると、預金が負（計算エンジンの資金不足 `cf.balance.shortfall`）でも合計は正で「持つ」になった。同じ年のバランスシートのタブは「金融資産が尽き、資金の不足が○」と書いていて、食い違った。

## 決定

### 1. 旧NISA・ジュニアNISA の内訳が無いときは、残高の時点の年に買った1つの内訳とみなす

- 計算エンジン（`plan.cashflow` の改訂25）は、内訳の無い旧NISA・ジュニアNISA を「時価・取得価額の全部を、残高の時点（`asOf`）の年に買った一般NISA（ジュニアNISA はジュニアNISA）の内訳1つ」とみなす。旧NISA・ジュニアNISA の買付は2023年までなので、2024年以後の時点なら2023年に買ったとみなす（画面の「＋ 買付の年の内訳」が作る初めの行と同じ）。
- つみたてNISA かもしれない器も一般NISA とみなす（決めたこと。内訳の無いときの非課税期間を短い側にした。つみたてNISA の分があるなら内訳を入れる。画面の注のとおり）。

### 2. 課税口座へ移した後も、元の器の資産の配分・利回りで増やす

- 名義人に課税口座が無くて作るときは、移す元の器（旧NISA・ジュニアNISA）の資産の配分・利回りを引き継ぐ。名義人に課税口座があれば、今までどおりその口座に入れ、その口座の利回りで増える。

### 3. 変額・外貨建の積立金に、前の払込保険料も足す

- 積立金（前の入れ方。積立金を前提の利回りで伸ばす形）は、保険年度ごとの払込保険料に、計算基準年の2年前より前の払込（契約の保険料・更新・数表の年額・一時払い。貯蓄型の払込保険料の累計と同じ数え方）も足して伸ばす。
- 同じ所で、払込保険料の累計（解約返戻金・一時所得と雑所得の必要経費の基）を、その時点が計算基準年の2年前より前でも、それまでの前の払込で数える（前は0円。年金の支払が早く始まった契約の必要経費が0になっていた）。

### 4. 年金の税を施行令のとおりにする

対象は、個人年金などの年金（保障の明細の「年金」）、アカウント型の年金、収入保障の月額（`insurance.policy` の改訂6）。

- **受取人が契約者の年金（所得税法施行令183条）**: 必要経費＝年金の額×割合。割合は 保険料の総額÷支払総額 を小数点以下2位まで（3位以下は切り上げ）。必要経費の1円未満は切り捨て（法令に定めが無い。規約 `conv.insurance.annuity`）。
  - 支払総額: 年金の年数があればその回数の額の合計。年数が無ければ保障の終わりまでの回数の額の合計（画面の「入れなければ保障の終わりまで」）。
  - 年数も保障の終わりも無い終身年金は、年額×受取人の支給開始日の満年齢の余命年数（施行令の別表「余命年数表」。性別で引く）を支払総額の見込額にする（施行令183条1項2号イ(2)・82条の3第2項1号ハ）。保証期間つきの終身年金（同ニ）は、保証期間の欄が無いので扱わない。
  - 収入保障の月額は、受取人が何人いても、契約の保険料の総額÷全員の受け取りの合計の割合を使う。
- **受取人が契約者でない年金**（契約者でも、亡くなった人でもない人が受け取る年金。相続税の対象になる収入保障の月額は除く）:
  - 年金の支払が始まる月に、年金を受け取る権利を1回贈与されたとみなす。受け取りの種類 `annuityRight`（約束の版 1.3）・税の区分「贈与税」・額は評価額。お金の動き（キャッシュフロー表の行）は作らない。贈与税は今までの保険の贈与と同じく、受け取る人の贈与税として翌年3月に払う。
  - 評価額（相続税法24条1項1号ハ・3号ハ）＝1年当たりの平均額×予定利率の複利年金現価率。複利年金現価率は（1−1÷（1＋予定利率）の年数乗）÷予定利率を小数点以下3位未満で四捨五入（相続税法施行規則12条の5）。年数は残りの期間（1年未満は切り上げ）、終身年金は上の余命年数。数表にその保険年度の解約返戻金があれば多い方。一時金で受け取る選択の額（同1号ロ）は欄が無いので見ない。
  - 予定利率は契約ごとに違い、欄が無いので、エンジンの目安 `preset.insurance.annuityAssumedRate`（0.25%。事務所の推定の値で置き換えられる）を使う（決めたこと。新しい欄を足すと世帯ファイルの形式の版が上がるため。低めの率は評価額を高めに出す＝贈与税を少なく見せない側）。
  - 毎年の年金は雑所得。総収入金額に入れるのは施行令185条2項の課税部分だけ: 相続税評価割合（評価額÷支払総額）が百分の五十を超えれば「支払総額×課税割合÷（年数×（年数−1）÷2）×経過年数」、百分の五十以下なら「支払総額÷（特定期間年数×年数）×経過年数」（特定期間の後は 特定期間年数分−1円）。年金の回の額が月ごとなら月数÷12を掛ける。課税部分が年金の額以上なら同6号のとおり単位の整数倍に抑える。課税部分の必要経費は上の183条と同じ割合（施行令185条1項8号・11号を同2項が準用）。
  - 受け取りの `cost`（必要経費）に、総収入金額に入れない部分を含めて入れる（雑所得＝年金の額−cost になるように。約束の版 1.3 の説明に書いた）。
  - 課税割合・特定期間年数の割合の表は、相続税評価割合の百分率の1未満を切り上げた整数で引く（表の境目がどれも整数の百分率で「を超え…以下」なので、引く段は割合のままと同じ）。
- 相続税の対象になる収入保障の月額（亡くなった人が契約者）は、今までどおり相続税の区分のまま（下の未確定）。
- 新しい制度データ（`regulation.tax` 2026.20.0。e-Gov法令API の条文で読んだ。原本の写しを非公開のリポジトリにまだ置いていないので確認待ち）: `incomeTax.privateAnnuity.costRatio.rounding`（割合の端数）、`incomeTax.privateAnnuity.lifeExpectancyYears`（余命年数表）、`incomeTax.inheritedAnnuity.taxableShare`（課税割合）、`incomeTax.inheritedAnnuity.specifiedPeriodShare`（特定期間年数の割合）、`inheritanceTax.annuityRight.presentValueFactor.rounding`（複利年金現価率の端数）。値の無い古いデータの組では、割合をそのまま使い、権利の評価の割引をしない（年金の総額）。

### 5. 資産が尽きる年は、使えるお金で払えなくなる年にする

- 「資産が尽きる年」（結論の1文「○歳で資産が尽きます」・資産の推移の「金融資産は○歳まで持ちます」〔尽きる年の前の年〕・プランの帯の「○歳で不足」・万一の判定・プランを比べる表・持ち帰り・グラフの「!」・提案書の「金融資産が不足する年」）は、**計算エンジンの資金不足の行（`cf.balance.shortfall`）がはじめて出る年**にする。金融資産の合計がマイナスの年も尽きたとみる（資金不足の行のある年より遅いことは無いが、念のため両方を見る）。
  - 資金不足の行は、預金と、取り崩しの順序で取り崩せる器で払えなかった額（0026 の6）。引き出せない器（60歳前の iDeCo・企業型DC・引き出せない期間のある器）・取り崩さない器（既定の順序のこどもNISA・ジュニアNISA、雑所得の暗号資産など）は使えるお金に数えない。
  - バランスシートのタブの「資金の不足」と同じ判断になる。0026 の8 の「金融資産は○歳まで持ちます」は、金融資産の合計ではなくこの年で決める（0026 に追記した）。
- バランスシートのタブの文は、資金の不足の年に金融資産が残っていれば「取り崩せるお金が尽き、資金の不足が○（残りの金融資産○は、iDeCo など今は取り崩せないお金です）」にする。金融資産も無ければ今までどおり「金融資産が尽き、資金の不足が○」。

## 理由

- 1・2: 画面の注と、同じ部品の似た場面（NISA の枠を超えた分・iDeCo の受け取りの運用）の決まりにそろえた。
- 3: 同じ部品の貯蓄型の払込保険料の累計と同じ数え方にし、帳票の「払込の累計」と「解約返戻金」を合わせた。
- 4: 制度のとおりにした。予定利率は欄を足さずに目安で済ませ、評価の割引で贈与税が大きく変わらない低めの率にした。贈与の評価額は相続税評価割合を通して毎年の雑所得の課税部分も決めるので、両方を同じ評価額から出す。
- 5: 「持つ」は、その年に払えるかで見るのが利用者の読み方に合う。計算エンジンはすでに資金不足の行を出していて、バランスシートのタブだけがそれを使っていた。判定を1か所（画面の `depletionYear`・提案書の同名の関数）で変え、全部の出口がそろう。

## 影響

- 計算の結果が変わるのは、内訳の無い旧NISA・ジュニアNISA（移す年から後の運用益に税がかかり、売るときに譲渡益の税が出る）、名義人に課税口座の無い旧NISA の移し、前の入れ方の変額・外貨建で計算基準年の2年前より前に払った契約、受取人が契約者でない年金（贈与税が出て、毎年の雑所得は小さくなる）、年金の年数が空の年金・終身年金（必要経費が出る）、個人年金・アカウント型・収入保障の雑所得のある世帯（必要経費の割合の切り上げで、雑所得が年に数百〜数千円少なくなる）、引き出せない器が残る世帯の資産が尽きる年。
- 見本の世帯54件では `insuranceMaturityAnnuity` だけが変わる（個人年金の雑所得が 61,500円→60,000円。2046〜2055年の所得税・住民税・国民健康保険料が少し減り、表の最後の年の金融資産が +3,553円）。ほかの53件は1円も変わらない（資産が尽きる年も変わらない）。
- 部品の約束: `insurance.policy` の受け取り（`receipts`）に種類 `annuityRight` が増えた（約束の版 1.3）。受け取りの種類で分ける部品（相続税の目安・必要保障額）は `death`・`incomeProtection` だけを見るので変わらない。
- 世帯ファイルの形式の版は変えない。

## 未確定

- 相続税の対象になる収入保障の月額（亡くなった人が契約者）の、毎年の雑所得の課税部分（施行令185条2項）と、相続税の目安の評価額（年金受給権の評価。今は受け取る額の合計）。
- 予定利率の欄（契約ごとの予定利率）。保証期間つきの終身年金の保証期間の欄。一時金で受け取る選択の額。
- 終身定期金の評価の余命年数は、相続税法施行令5条の8では完全生命表の平均余命。今は所得税法施行令の余命年数表で代えている（短めに出て評価額が低めになる）。
- 旧相続税法の対象の年金（2011年3月末より前に権利を取得した物。施行令185条1項）は扱わない（同2項の計算をする）。
- つみたてNISA かもしれない内訳の無い旧NISA を一般NISA とみなすこと（決定1）。

## 追記
