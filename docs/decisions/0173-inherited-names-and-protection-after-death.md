# 0173. 亡くなった人の名義の物を相続する人へ移す（家賃・ローン・車・固定資産税・口座・介護費）と、必要保障額の家計急変・共済の死亡一時金・亡くなった人の車・提案書の逆算の方式

- 状態: 採用（一部未確定）（2026-11-08）
- 固定の強さ: 内部（部品の計算の決まり・相続する人の決め方・必要保障額の数え方）。世帯ファイルの形式の版・エンジンの入力は変えない。部品の出力に任意の欄を足した（0006 の4 の MINOR）: `contingency.event` 1.1 → 1.2（`heirs`）、`asset.realEstate` 1.5 → 1.6（`holders`）、`protection.need` 1.1 → 1.2（内訳の `lumpResources.mutualAidLump`）、`expense.car` 1.0 → 1.1（ローンの借りた月 `start`。2026-11-09 の追記）。sdk に足した関数（`inheritanceOf`・`holdersAt`・`splitEqually`・`inheritFlows`・`propertyIncomeOf`）は試験版（0006 の部品の約束と同じ）
- 前提にする記録: 0008（万一の重ね）、0028（住まい以外の不動産）、0039（相続税の目安）、0054（必要保障額の内訳）、0086（雑所得と確定申告不要制度）、0165（亡くなった後のお金の名義）、0168（提案書の万一の章）、0170（必要保障額を死亡の想定の表から組み立てる）

## 背景

- 性質テスト（全モデル世帯で、本人・配偶者の亡くなる時期をずらして計算する）で、亡くなった人の名義の物から出るお金が、亡くなった後も亡くなった人の名のまま続いていた（0165 の未確定）。収益不動産の家賃・経費・売却、住宅ローン・車のローン・そのほかの負債の返済、固定資産税・修繕の積立、車の維持費・買い替え、課税口座の取り崩しと譲渡益の税、介護費の支払い、FP顧問料、年末の残高の行。家賃は亡くなった人の所得として課税され続け、遺族（相続する人）の税・保険料に入らなかった。
- 利用者の判断（2026-11-08）: 配偶者がいれば配偶者、いなければ子（複数なら等分）が全部を相続したとみなし、亡くなった月の翌月から名義を移す。
- 必要保障額（0170 の未確定）について、利用者の判断（2026-11-08）で、次の3つを「入れる・そろえる」に決めた。修学支援の家計急変（生計維持者が亡くなった後にすぐ判定し直す）を入れる。小規模企業共済の死亡一時金を準備できる資金に数える。亡くなった人の車の扱いを万一のタブの場面の表とそろえる。
- 提案書の万一の章の必要保障額は、積み上げの方式だけで計算していた（0168 の未確定）。万一のタブで逆算の方式を選んだプランでも、提案書は積み上げの額を見せていた。

## 決定

### 1. 相続する人と、名義を移す月

- 万一の想定（死亡）で亡くなる構成員の名義の物は、死亡の当時の配偶者が、いなければ子（亡くなる月までに生まれた子。世帯を離れた子も含む）が等分で、全部を相続したとみなす。亡くなった月の翌月から相続する人の物にする。
- 相続する人は `contingency.event`（改訂4・約束の版 1.2）が決め、死亡の event に `heirs` で返す。配偶者も子もいない人（独り身・親だけの世帯）は返さず、名義を変えない（亡くなった人の名のまま。下の未確定）。
- sdk の関数: `inheritanceOf(ctx, member)`（相続する人と移す最初の月）、`holdersAt(ctx, owner, m)`（月 m に持つ人）、`splitEqually(ctx, amount, n)`（等分。円未満は前の人から）、`inheritFlows(ctx, flows)`（名義の人が亡くなった月の翌月から後のお金の動きを相続する人の名にし、人が複数なら額を等分して分ける）、`propertyIncomeOf(property, member, year)`（下の 2）。
- 名義（入力の `owner`・債務者など）と評価額は書き換えない。相続税の目安（0039）は今までどおり入力の名義で数える。

### 2. 部品ごとの当て方

- **収益不動産**（`asset.realEstate` 改訂10・約束の版 1.6）: 家賃・経費・大きな修繕・売却の手取りのお金の動きを相続する人の名にする。不動産所得は、亡くなった年からの年ごとに、持つ人ごとの分（`holders`。亡くなった年は名義の人と相続する人、翌年からは相続する人）に分ける。家賃と経費は月ごとに分け、減価償却費・借入の利息（土地の分を含む）は貸している月数で分け、相続する人の分を人数で等分する。`tax.totalIncomeBase`（改訂2）はその年に持つ人の分で数える（`propertyIncomeOf`。事業的規模の目安の室数も、その年に持つ人に数える）。
- **不動産・その他の資産の売却の所得**（`tax.realEstateSale` 改訂3・`tax.totalIncomeBase`）: 売る月に持つ人（相続する人。等分）の譲渡所得にする。取得費と所有期間は亡くなった人から引き継ぐ（所得税法60条）。`asset.heldSale`（改訂の印は出力の名義のまま）の手取りのお金の動きも相続する人の名。
- **負債**（`debt.schedule`）: 団信で消えない返済（車のローン・奨学金・そのほかの負債、団信の無い住宅ローン、借入の前に亡くなった住宅購入の現金の支払い〔0170〕）を相続する人の名にする。住宅ローン控除は相続する人に付けない（相続で取得した住まいは対象外）。
- **住まい**（`housing.residence`・`housing.valuation`）: 固定資産税・維持費・購入の費用・売却の手取りを相続する人の名にする（住まいの名義は持分の最初の人のまま）。
- **車**（`expense.car`）: 購入・ローン・維持費を相続する人の名にする（「万一のときの扱い」を入れた車は、その割合を当てた後の額）。（扱いを入れていない車は、2026-11-09 の追記で、名義の人が亡くなったら手放す形にした）
- **介護費**（`care.expense`）・**FP顧問料**（`expense.advisoryFee`）: 払う人が亡くなった後は相続する人が払う。
- **金融資産と年末の残高**（`plan.cashflow` 改訂27）: 亡くなった人の器・不動産・車・負債・保険の、亡くなった月の翌月からのお金の動き（取り崩し・譲渡益の税・移し替えなど）と年末の残高の行を、相続する人の名にする（人が複数なら等分）。亡くなった人の NISA（旧NISA・ジュニアNISA を含む）は、亡くなった年の翌年の初めに相続する人の課税口座になる（取得価額はその時の時価。相続の時の時価の近似）。亡くなった年の翌年からは、亡くなった人の NISA の枠の行を出さない。
- 変えない物: 公的年金・給付の、亡くなった月までの分を後の月に払うお金（未支給の年金など。亡くなった人の名のまま）、亡くなった人の死亡の年までの所得の税（準確定申告・翌年の住民税）、児童手当・就学支援金を受け取る親（0165）、受け取る贈与と贈与税（受け取る人の名のまま）。

### 3. 確定申告不要制度の「その他の所得」（`incomeTax.annual` 改訂7。0086 の残り）

- 公的年金等に係る雑所得以外の所得金額に、不動産所得・一時所得（総所得金額に入れた額）・総合課税の譲渡所得（同じ）・分離課税の譲渡所得も足す（所得税法121条3項）。前は家賃のある年金の人も申告しない扱いで、不動産所得の所得税が0円だった（相続で家賃を受け継いだ年金の配偶者で目立った）。

### 4. 修学支援の家計急変（`education.support` 改訂8）

- 生計維持者（親）が万一の想定で亡くなったら、亡くなった月の翌月から、亡くなった人を除き、残った生計維持者の住民税で区分を判定し直す（生計維持者がだれもいなければ第I区分）。給付型奨学金は亡くなった月の翌月の分から、授業料の減免はその月より後に始まる半期から、入学金の減免はその月より後に払う物から。定期の判定で亡くなった人の住民税が残る年度も除く。
- 急変の後の見込みの所得ではなく、残った生計維持者の、判定の年度の住民税で判定する近似。死亡のほかの家計急変（失職・病気など）は扱わない。
- これで、亡くなった後の修学支援が亡くなる年によらなくなり、必要保障額の近似（0170 の2。後の年に最初の年の表を使う）の修学支援のずれが無くなった（下の影響）。

### 5. 必要保障額（`protection.need` 改訂7・約束の版 1.2）

- 小規模企業共済の死亡を事由とする共済金（亡くなる年の前の年末の残高）を準備できる資金（一時の分）に数え、内訳の `lumpResources.mutualAidLump` に出す（任意の欄。無い差し替えの部品の出力も通る）。
- 確定拠出年金の死亡一時金・共済の共済金の「前の年末の残高」は、計算基準年に亡くなる年なら、計算基準月の前の残高（その年の年末−掛金−運用益＋受け取り）にした（前は0円だった。小さな直し）。
- 亡くなった人の車も、場面の表のとおりに数える（前は「万一のときの扱い」を入れていない車を数えなかった）。場面の計算では、車は相続する人が持ち続け、維持費・買い替えが続く。手放す・止めるなら「万一のときの扱い」で入れる。（2026-11-09 の追記で、扱いを入れていない車は手放す形に改めた。数え方〔場面の表のとおり〕は同じ）
- 配偶者がいない（遺族が子）ときは、亡くなる人の器から相続した子の名で入る収入（家賃・売却の代金など）も遺族の収入に数える（子の税は前と同じく数えない近似）。

### 6. 提案書の逆算の方式（`app/src/workspace/report/assemble.ts`・`report/src/build.ts`。0168 の未確定）

- 提案書の必要保障額は、提案のプランの前提（0168 の6）の出し方で計算する。万一のタブでそのプランに逆算の方式を選んでいれば逆算の方式（目標の年齢も同じ）、そうでなければ積み上げの方式。
- 逆算の方式のときは、見出しの下の文を「逆算方式: （遺族）が（年齢）になるまで金融資産が尽きない保険金」にする（年齢が無ければ期間の終わり）。

## 理由

- **配偶者、いなければ子が全部**: 利用者の判断。遺産分割の形は家ごとに違い、計画の表で決めきれない。配偶者がいれば家計はそのまま続くとみなすのが自然で、相続税の目安（0039）の「配偶者がいれば配偶者が多く受け取る」の見方とも合う。
- **お金の動きの名を移す（入力の名義は書き換えない）**: 名義は亡くなる前の計算（税・相続税の目安）にも使う。万一の重ねで入力の名義を書き換えると、亡くなる前の月も相続する人の物になる。部品の出力のお金の動きを、亡くなった月の翌月から相続する人の名にすれば、亡くなる前は変わらず、亡くなった後の税・保険料の部品は名で集めるだけで正しくなる。
- **不動産所得を持つ人ごとに分ける**: 税の部品は年ごとの不動産所得を読む。亡くなった年は名義の人と相続する人の両方に所得があるので、年の額を分けて出す必要がある。家賃と経費は月の額があるので月で分け、減価償却費・利息は月数で分けるのが自然。
- **NISA を課税口座にする**: NISA の口座は相続できない（相続する人の課税口座に時価で移る）。
- **家計急変**: 生計維持者が亡くなったときは、定期の判定を待たずに急変の後の家計で判定し直せる（日本学生支援機構の家計急変の採用）。亡くなった人の所得で判定し続けると、遺族の支援を少なく見積もる。
- **共済・車**: 万一のタブは必要保障額と場面の表を並べるので、数え方をそろえる（0170 の理由と同じ）。
- **提案書の逆算**: 提案書の万一の章はそのプランの前提で計算する約束（0168 の6）。出し方もその前提の一部。

## 代案（採らなかったもの）

- **法定相続分で共有にする**: 配偶者と子で分けると、遺族の家計（配偶者）の外へ家賃などが出ていく形になり、計画の表として分かりにくい。利用者の判断で採らない。
- **名義は変えず、税だけを亡くなった年までにする**: 家賃が遺族の所得に入らず、遺族の税・保険料を少なく見積もる。
- **万一の重ねで入力の名義を書き換える**: 亡くなる前の月も書き換わる（上の理由）。
- **家計急変を急変の後の見込みの所得で判定する**: 見込みの所得の決まりを新しく作る必要がある。残った生計維持者の住民税で近い答えが出る。

## 影響

（PR の説明に見本の世帯ごとの数字）

- 万一の想定（死亡）を入れた世帯で、亡くなった後の家賃・ローン・車・固定資産税・取り崩し・介護費・残高の行の名が相続する人に移る。家賃のある世帯では、相続する人の所得税・住民税・国保（後期）の保険料が増え、亡くなった人の税が無くなる。
- 確定申告不要制度の直しで、家賃などのある年金の人の所得税が増える（万一の想定が無くても）。
- 必要保障額: 修学支援を受けられる子のいる世帯で、亡くなる年が後ろの年の額が減る（家計急変で修学支援が増える）。共済のある世帯で減る。亡くなった人の車のある世帯で増える。
- 提案書: 万一のタブで逆算の方式を選んだプランの必要保障額が、逆算の額になる。
- テスト: `engine/test/inherited-names.test.ts`（全モデル世帯×本人・配偶者×2つの時期で、名義の物から出るお金と残高の行が亡くなった人の名で残らない、家賃の所得と税、子の等分、家計急変、必要保障額の近似・共済・車）、`app/test/report-exits.test.ts`（逆算の方式の提案書）。

## 未確定

- **相続する人を画面で選ぶ**: 万一の前提に「相続する人」の欄（配偶者・子・法定相続分など）を足すかは後で決める（利用者の判断で後回し）。
- 配偶者も子もいない人（独り身・親だけの世帯）の名義の物は、亡くなった人の名のまま（親・兄弟姉妹が相続する形を作っていない）。
- 子が相続した後に世帯を離れても（独立）、名義は子のまま世帯の表に残る。
- 公的年金・給付の未支給の分（亡くなった月までの分を後の月に払う）は亡くなった人の名のまま（遺族の一時所得の扱いをしていない）。
- 亡くなった人が受け取る予定だった贈与（住宅購入の援助など）は、お金の動きは相続する人の名になるが、贈与税は受け取る人（亡くなった人）の計算のまま。
- 暗号資産の譲渡損失の繰越は、相続した後も亡くなった人の分を使う近似（相続する人は引き継げない）。
- 収益不動産の分析の数字（`asset.realEstateAnalysis`）の税の効果は、名義の人で計算したまま（万一の想定の計算で分析を見ることは無い）。
- 家計急変の判定は、残った生計維持者の判定の年度の住民税で行う近似。

## 追記

### 2026-11-09: 亡くなった人の車は、扱いを入れていなければ手放す

- 直す前の動き（2026-11-08 の決定 2 と 5）: 「万一のときの扱い」を入れていない車は、名義の人が亡くなっても相続する人が持ち続け、買い替え・車検・保険・自動車税・維持費と、その後の買い替えの自動車ローンが相続する人の名で最後まで続いた（今の車も、これから買う車も）。
- 利用者の判断（2026-11-09）: 名義の人が万一の想定で亡くなったとき、その人の車で、扱いを入れていない物は手放すとみなす。扱いを入れた車は、その扱いのとおり。
- 決めたこと:
  - **手放すの中身**: 亡くなった月の翌月から「止める」と同じにする（`expense.car` 改訂6）。買い替え（下取りを引いた額）・車検・保険・自動車税・維持費の合計・駐車場代・燃料代・名前つきの行・リースの月額を止め、その後の購入でローンを組まない。亡くなった月までの買い替えはそのまま。
  - **自動車ローンの残り**: 亡くなる前に組んだローンは、相続する人が返し続ける（決定 2 の負債と同じ。自動車ローンには団信が無い。0008 の 2026-10-12 の追記の「止めた後も、組んだローンの返済は続ける」とも同じ）。売った代金で一括で返す形は作らない。
  - **売却の手取り**: 入れない（利用者の判断 2026-11-09 で確かめた）。手放す時期（`until`）と「止める」も売却の代金を入れていない（0101）のにそろえ、遺族の資金を多く見積もらない。手放した車は、亡くなった月より後の年末に評価額を持たない（`asset.car` 改訂4。手放す時期と同じ。亡くなる前の評価額の下げ方は変えない）。
  - **当てる万一**: 名義の人の死亡だけ。ほかの人の死亡、名義の人の障害・就業不能では、今までどおり続く。
  - **扱いを入れた車**: 「続ける」（`mode: "continue"`）は相続する人が持ち続ける（前の既定の動き）。「やめる」「割合を変える」のお金の動きは前のとおり（世帯のだれかの万一の月の翌月から）。
  - **「やめる」の車の評価額**（利用者の判断 2026-11-09）: 手放すときと同じく、万一（`expense.car` と同じ、世帯のだれかの該当する種類の万一）の月より後の年末に評価額を持たない（`asset.car` 改訂4。前は万一の後も買い替えたとして評価額を出していた）。「続ける」「割合を変える」の車の評価額は今までどおり。
  - **必要保障額**（`protection.need` 改訂8）: 数え方は場面の表のとおりのまま。最初の年の表を後の年に使う近似（0170 の2）では、その間に組んだ自動車ローンの返済が抜ける（見本の世帯で1年に最大 約152万円）ので、亡くなった後の買い替えが変わる車（扱いを入れていない亡くなる人の車と、死亡で「止める」「割合を変える」を入れた車）のローンを、亡くなる月までにいくつ組んだかでも表を分ける（その年にもう1回計算する）。`expense.car` の出力のローンに、借りた月 `start` を足した（約束の版 1.1。任意の欄）。
  - **画面**: 車の「万一のときの扱い」（詳細）の選択肢を「既定（名義の人が亡くなったら手放す）／続ける／やめる／割合を変える」にした。既定のときは欄の横に「名義の人が亡くなったら、翌月から買い替え・維持費を止めます」（リースは「リースの月額・維持費」）を出し、説明の「?」に省略のとき・ローン・売却の代金・乗り続けるときの選び方を書いた。ほかの物（周期的な支出・FP顧問料など）の選択肢は前のまま（「続ける（既定）」）。入力項目の名前（`car.onContingency`）とエンジンの入力のスキーマの説明にも省略のときを書き足した。世帯ファイルの形式の版・エンジンの入力の形は変えない。
- 理由: 名義の人が亡くなった後、家族が同じ車を同じ周期で買い替え続けるとみなすより、手放すとみなすほうが多くの家庭に近く、必要保障額を車の分だけ多く見積もらない。乗り続ける家庭は「続ける」を選べば前の形になる。
