# 0240. ボタンを4段 × 大きさ2つにそろえ、選んでいる状態の色を藍にそろえる（押せないときの見た目を共通に・場所ごとの上書きを無くす）

- 状態: 採用（一部未確定）（2026-11-22。同じ日に、未確定のうち お知らせの種類の絞り込みの色と、開いていないときの墨・灰の枠を 0245 で決めた。追記）
- 固定の強さ: 内部（画面の見せ方）。変えるのは CSS とクラス名だけで、画面の言葉・世帯ファイルの形・保存される値・計算は変えない。決まりとして残すのは「ボタンの重みは4段（主・ふつう・控えめ・危ない）」「大きさは2つ（ふつう・小）で、`.small` の有無だけで決める」「場所ごとに余白・文字の大きさ・押せないときの見た目を上書きしない」「選んでいる・押し込んでいる・開いている状態は藍で見せる（墨で塗らない）」の4つ。どのボタンをどちらの大きさにするかは後から変えてよい
- 前提にする記録: 0236（入力画面の部品の見た目。6 の小さなボタンの形、8 の切り替えのボタンの色）、0121（事務所の見た目と暗い画面。基調の色の変数）、0030（持ち帰り用のレポート）

## 背景

- ボタン（`.btn`）の形が、場所ごとの上書きで増えていた。届く画面を見えないブラウザで全部開いて測ると、同じ「枠のあるボタン」が、高さ・余白・文字の大きさ・線の太さの組で **9通り**あった（文字の大きさ「中」。高さ 26.8・29.3・36.8・38.8・40.8〔余白が3通り〕・44.8〔主とふつう〕px）。
  - 余白・文字の大きさの上書きが 17行（結果のタブ・世帯を選ぶ画面・見本の帯・道具の列・提案書の見本の道具・AI の画面・明細・持ち帰り用のレポート）。
  - 小さいボタンに名前が2つあった（`.btn.small` と `.btn.sm`。大きさも違う）。`.btn.small.primary` は、書いた順のせいで主の広い余白のままだった。
  - `.link-btn` は `app.css` の中で2回定義され、後ろの定義が前の定義をほとんど打ち消していた。
  - **押せないボタンの見た目が場所ごと**だった（薄くする指定が 15行に分かれ、指定の無い所では押せるボタンと同じに見えた。要望・不具合を送る画面、書類の確かめ、面談の記録など）。
- 選んでいる・押し込んでいる・開いている状態の色も2通りあった。切り替えのボタン（0236 の 8）は藍の塗りにそろえたが、プランの一覧の印の絞り込み・開いているときの「表示の設定」と FP のメニュー・グラフを小さい画面に出すボタンは墨の塗り、資産と負債の切り替えは薄い藍だった。
- 試しの版で「4段 × 大きさ2つ」「選んでいる状態は藍」の形を画面で確かめ、利用者の判断（2026-11-22）で採用した。試しの版では入力項目のパネルの足元の「キャンセル／保存」も小さくなったが、「保存」はいちばんよく押すボタンなので、**足元の「キャンセル／保存」は今の大きさのまま**にする（利用者の判断）。

## 決定

### 1. 重みは4段

| 段 | クラス | 見た目 | 使う所 |
|---|---|---|---|
| 主 | `.btn.primary` | 藍の塗り・白い文字 | その画面・パネルでいちばん押す1つ（「保存」「次へ」など） |
| ふつう | `.btn`（欄のまわりは `.add-btn`） | 白地に藍の枠・藍の文字。重ねると薄い藍 | 主でないボタン |
| 控えめ | `.link-btn` | 下線のリンク（枠なし） | 文や行の中に置く操作 |
| 危ない | `.btn.danger`・`.link-btn.danger` | 赤い文字（枠があれば赤い枠） | 消す・取り消す・止める・外す |

- 色は変数（`--prop`・`--prop-ink`・`--prop-bg`・`--on-fill`・`--short-ink`）だけで書くので、事務所の基調の色・暗い画面でも同じ決まりになる。
- 色の意味: 藍＝主の操作・選んでいる、緑＝済、黄土＝推定・要確認・注意、赤＝不足・失敗・消す、灰＝参考・まだ。
- 0236 の 6（欄のまわりの小さなボタン）は、この4段と同じ言葉の決まりで、そのまま続ける。`.add-btn`（「＋ 〜」）はふつうの段、「この値にする」（`.fld-fill`）はその小さい物。

### 2. 大きさは2つ（`.small` の有無だけで決める）

| 大きさ | クラス | 余白・文字・線 | 高さ（文字「中」） | 使う所 |
|---|---|---|---|---|
| ふつう | 指定なし | 8px 18px（主は 8px 28px）・1rem・2px | 44.8px | パネルや画面の足元・本文に置く、決める・進めるボタン（足元の「キャンセル／保存」） |
| 小 | `.small` | 4px 10px・0.86rem・1.5px | 32.3px | 帯・道具の列・見出しの行・表や一覧の行・入力のホームの入力項目の中など、ほかの部品と同じ行に並ぶボタン |

- **ふつうは今までの大きさのまま**（足元の「キャンセル／保存」は、幅も高さも 1px も変わらない）。
- **小は、欄のまわりの「＋ 〜」（`.add-btn`）と同じ余白・文字・線**。グラフの切り替え（`.seg-g`）・「表示の設定」とも同じ高さ（32.3px）になる。
- 小さいボタンの名前は `.small` の1つ（`.sm` は使わない）。小の主（`.btn.small.primary`）も小の余白になる。
- **場所ごとに余白・文字の大きさ・線の太さを上書きしない**。別にしているのは、分岐を選ぶ画面の「選ぶための大きなボタン」（中身が名前と説明の2行。`.fork-choices .btn` の余白）だけ。
- 控えめ（`.link-btn`）は枠が無いので大きさは1つ（0.82rem）。まわりの小さな文字に合わせて文字だけ小さくしている所（欄の操作の行など）は今のまま。

場所ごとの上書きがあった所は、次のどちらかに入れた。

| 所 | 前（高さ） | 後 |
|---|---|---|
| 結果のタブの「対策」の見出しの行（変更を取り消す・上書き保存・プランとして保存）と名前を付けて保存する行、説明の帯（戻る・次へ） | 40.8px | 小 |
| 道具の列（事前ヒアリングの「URL生成」、書類の読み取りの「架空の保険証券の見本で試す」など） | 38.8px | 小 |
| 見本の帯・同時に開いているときの帯・保存していない世帯の帯・AI に渡しているときの帯 | 36.8px・40.8px・28.3px | 小 |
| AI との接続の一覧の行（止める・登録する・登録を外す）、提案書の見本の道具（前へ・次へ・拡大・縮小）、明細の取り込み（`.sm` だった物） | 36.8px | 小 |
| 今までの `.btn.small`（入力のホームの「該当なし」「推定で入れる」、書類を見る道具、確かめの表の行など） | 26.8px | 小（32.3px） |
| 世帯を選ぶ画面（使う・使わない・空から作る・区分を保存）、プランの一覧・比較の表の「閉じる」、持ち帰り用のレポートの「1つ前に戻す・最初に戻す」、AI に渡している世帯の「共有を取り消す」 | 40.8px・36.8px | ふつう（44.8px） |

### 3. 押せないときは、どの段・どの画面でも同じ見た目

- 地は薄い灰（`--base-bg`）、枠は灰（`--line`）、文字は灰（`--field`）。主・ふつう・危ないのどれも同じ平らな灰になる。カーソルは「押せない」。
- 透かして薄くする（`opacity`）のはやめる。色みでなく**濃さの差**で分かるようにする: 押せるボタンの文字は地との濃さの比が 8〜10、押せないボタンは 3.3（暗い画面は 4.4）。色の差が分かりにくい人にも、塗り・枠の濃さが消えることで伝わる。
- 欄のまわりの「＋ 〜」（`.add-btn`）も同じ。控えめ（`.link-btn`）は、灰の文字にして下線を外す。
- 決まりは `app.css` の `.btn:disabled` の1行だけに置き、場所ごとの指定（15行）は消す。

### 4. 選んでいる・押し込んでいる・開いている状態は藍

0236 の 8（切り替えのボタン）の続き。残っていた所を同じ藍にそろえる。

| 部品 | 前 | 後 |
|---|---|---|
| お知らせの「未読／すべて」（`.nc-tabs`） | 選んでいる方は藍の塗り。枠は灰・選んでいない方は灰の文字 | 枠も藍・選んでいない方は藍の文字・間に藍の仕切り |
| 資産と負債・収益不動産の「見るもの」（`.bs-vbtn`）、資産と負債の「主な年へ」（`.jb`） | 選んでいる方は薄い藍・藍の枠。選んでいない方は灰の枠・墨の文字 | 選んでいる方は藍の塗り。選んでいない方は藍の枠・藍の文字 |
| 対策の FP顧問料の切り替え（`.tg`）、文字の大きさ（`.fs-opt`） | 選んでいる方は藍の塗り。枠と選んでいない方の文字は墨 | 枠も選んでいない方の文字も藍 |
| プランの一覧の印の絞り込み（`.tag-filter`。1つ選ぶ） | 墨の塗り | 藍の塗り |
| 開いているときの「表示の設定」（`.set-btn`）・FP のメニュー（`.fpm-btn`）・お知らせのベル（未読なし。`.bell-btn.quiet`）、グラフを小さい画面に出しているときのボタン（`.pip-btn`） | 墨（ベルは濃い灰）の塗り | 藍の塗り |
| 「相場が下がった場合を重ねる」（`.stress-btn`）、道具の中の切り替え（提案書の見本・書類を見る道具・持ち帰り用のレポートの年のボタン。`.btn.on`）、資産と負債の「1年ずつ見せる」（押している間） | 薄い藍（「1年ずつ見せる」は変化なし） | 藍の塗り |
| 万一のときの「1年ずつ見せる」（`.ys-btn`） | 色は藍のまま。押せないときは透かして薄く | 押せないときの見た目を 3 にそろえる |

- 決まり: **並んだ中から1つ選ぶ切り替え・押し込むボタン・開くボタンは、選んでいる（押している・開いている）ときに藍の塗りと塗った上の文字の色**。1つ選ぶ切り替えは、選んでいない方も藍の文字・枠も藍。
- いくつも選べる絞り込みの印（見本の棚の特徴）と、一覧の中で選んでいる行・項目（表の行・書類の一覧・明細の段など、面の大きい物）は、今までどおり藍の枠と薄い藍の地（塗ると中の文字が読みにくくなるため）。
- `.btn.on` と `aria-pressed="true"` の `.btn` は、どこでも同じ1つの決まり（場所ごとの4行を消す）。
- 大きさは変えない（お知らせの「未読／すべて」だけ、仕切りの線のぶん幅が 1px 増える）。

## 変えないもの（そろえずに残した所）

- 閉じるだけのボタン（`.x-btn` など）、日付の書き方、お知らせの種類の色と種類の絞り込み（`.nc-cat-pick`。選んでいる方は墨の枠のまま）、世帯の一覧の行の並びは、別の変更で扱う（お知らせの種類の色と絞り込みは 0245 で直した。追記）。
- グラフ・表の「選んでいる年」の印（`--sel`。年の印 `.chip.on`・表の列の線）は墨のまま。藍はプランの線の色なので、線と混ざらないようにするため。
- 事務所の基調の色の見本（`.os-swatch`）で選んでいる色の輪は墨のまま（見本の色と混ざらないように）。
- 開いていないときの「表示の設定」・グラフを小さい画面に出すボタン・FP のメニュー・↶↷ は、墨・灰の枠のまま（選んでいる状態だけを藍にした）。0245 で藍の枠にそろえた（追記）。
- 専用の形を持つボタン（世帯を選ぶボタン、入力のホームの入力項目、単位のボタン、明細の「事業で使った割合」、ひな形の小さな丸いボタンなど）と、お客さまが答えるヒアリングのページ（別の画面）は、この決まりの外。
- 高さが小と同じ「説明モード」「表示の設定」（`.explain-btn`・`.set-btn`）と、少し低い「1年ずつ見せる」（`.ys-btn`）・「相場が下がった場合を重ねる」（`.stress-btn`）は、クラスを `.btn.small` に寄せていない（線の太さ 2px は隣の切り替えのボタンに合わせてある）。

## 確かめたこと

- 変える前と後で、見えないブラウザで同じ手順を流し、押せる物（ボタン・リンク・タブ）の幅・高さ・中の行数・並びの中の行・横のはみ出しを測り、前後の違いを調べた。開いた画面は 266（世帯を選ぶ画面、空の世帯と見本の世帯5つの入力のホーム、全部の入力項目のパネルの標準・詳細、結果・資産と負債・収益不動産・万一のとき・提案書のタブとその中の切り替え、プランの一覧・比較の表、お知らせ、FP のメニューの全部の項目、事務所の既定値、明細、取り崩しの計算）× 見え方5つ（文字 中・大 × 幅 1440px・600px、暗い画面）で、延べ約27万個。持ち帰り用のレポートは幅 1440px・375px で別に測った。
- 大きさが変わったのは、上の 2 の表の所だけ（と、入力のホームの入力項目そのもの。中の「該当なし」が 5.5px 高くなるぶん、行の高さが 5.5px 増える）。足元の「キャンセル／保存」・欄のまわりの「＋ 〜」・控えめのリンク・切り替えのボタンは 0.1px も変わらない。
- ボタンの中の文字の折り返しが増えた所は 0。並びの中で次の行へ落ちた物は 0（見本の帯のボタンと、文字「大」・幅 600px の対策の見出しのボタンは、短くなって前の行に入った）。ページの横のはみ出しは 0。横に動かせる表（収益不動産の売り方の表。幅 600px）は、中のボタンが 11px 広がるぶん、動かせる幅が 11〜13px 増える。
- 届く画面のボタンの形（高さ・余白・文字・線の組）は、9通りから3通り（ふつう・ふつうの主・小）になった。
- 見えないブラウザでは 1.5px の線が 1px に丸まるので、測った小の高さは 31.3px（画面の細かい表示では 32.3px）。
