# 0062. 子ども・教育のカードの中身（推定の進路・段ごとの費用・専門学校の未入力・修学支援の知らせ・奨学金と教育ローン・この子のお金の行）

- 状態: 採用（一部未確定）（2026-10-27）
- 固定の強さ: 内部（画面の作り）。世帯ファイルの形は 0063 で足した2つの欄（学校外の費用の入れ方・行の種類）だけで、ほかは今ある欄（`goals[].education` の `annualOverride`・`entranceOverride`・`boarding`・`scienceAgriculture`・`scholarships`・`loans`・`highSchoolSupport`、お金の行 0044）を画面に出した。欄の並び・簡易と詳細の分け方・文言・ひな形の額は後から変えてよい

## 背景

- 子ども・教育のカードは、進路の型・段ごとの公立と私立・系統・通い方・保育園と、塾・習い事の月謝と子への援助だけだった。学費は統計の平均で計算していたが、画面に額が出ず、年額・入学金・仕送りの上書き、貸与の奨学金・教育ローン（計算エンジンにはある）を入れる所が無かった。
- 専門学校は統計の目安が無いので学費0円で計算し、計算エンジンの知らせ（入力が要る）は画面のどこにも出ていなかった。公立の短大は私立の短大の平均で計算して知らせを出すだけで、これも画面に出ていなかった。国の修学支援は大学だけを計算し、短大・専門学校は扱わないという知らせも同じく画面に出ていなかった。
- 塾・習い事の月謝は、塾・習い事を含む統計の平均の学校外活動費の上に足していた（二重になる。0063）。
- 前提にする記録: 0008（世帯のデータモデル・値の箱）、0010（教育費と学費データ）、0029（保育料と給食費）、0035（世帯ファイルの形）、0041（値の状態の操作・推定で埋める）、0043（入力画面でプランを直す）、0044（お金の行）、0045（14枚のカード）。

## 決定

### 1. 区画（子ごと）

| まとまり | 簡易 | 詳細 |
|---|---|---|
| 進路 | 進路の型、**高校のあとの進路**（大学・短大・専門学校・行かない）、保育園に通う（保育の年齢の子だけ）、読むだけの「独立の時期」 | 児童手当を計算する、高校の就学支援金（対象・対象外。高校の段があるとき）、給食費、この子の教育費を入れない（該当なし）、進路を外す |
| 段ごと | 公立・私立、系統（大学）、通い方（大学・短大・専門学校）。見出しの下に**統計の平均の年額を読むだけ**で出す（「学費 年約99.2万円（統計の平均・今の値段）・入学金 約…・仕送り 月…（推定）」）。専門学校と公立の短大は年額の欄も簡易 | 学費の年額（上書き）・入学金（上書き。空欄は統計の平均を欄の横に）、学校名（同梱まで見せるだけ）、在学年数、浪人の年数、受験・併願の費用、自宅外の仕送り（月額）と初期費用（自宅外のとき。空欄は統計の平均）、理工農系（大学） |
| 学校外の費用 | 入れ方（統計の平均で／行で入れる）と、今の段の統計の平均か行の数の1行（0063） | 行（名前・種類・月額・始まり・終わり）、足すボタン（塾・習い事・その他） |
| 奨学金・教育ローン | — | 貸与の奨学金（月額・受け取る期間・利率・返す年数・返し始め・返す人）、教育ローン（借りる時期・額・金利・返す年数・借りる人） |
| この子の入るお金・出るお金 | 行（0044）。足すボタン: 教育資金の援助を受ける（祖父母など）・留学 | 足すボタン: 給付型の奨学金・学費の助成（額で）・子が払う分（アルバイト・子の貯金から学費に）・その他の教育費（寮費・部活など） |
| 子への援助（結婚・住宅資金。あげる側） | 今の物のまま（`goals[].education.gifts`）。見出しに「相続・贈与のカードにも出ます」 | 出す人・課税の方法・住宅資金の非課税 |

- 学費の統計の平均は、計算エンジンと同じ統計（マスタデータ `master.education.statistics`）を、画面の側の写し（`hearing/src/statistics.generated.ts`。0007）から読み、計算エンジンと同じ値の選び方で出す（`input/educationCost.ts`）。幼稚園〜高校は学習費総額−学校外活動費、大学・短大は授業料＋施設設備費、入学金は統計の入学料。見せる額は計算基準年の額（今の値段）で、学校給食費の負担軽減・教育費の上昇率・修学支援は入れない。
- 「高校のあとの進路」を選び直すと、段を置き換える（同じ物のまま `set`。0043）。通い方・浪人・受験・仕送り・年額と入学金の上書きは同じ意味の欄なので引き継ぎ、系統は大学だけ、在学年数と学校は引き継がない。年額の上書きを引き継いだときは、欄の横で「前の学校の値のままでないか確かめてください」と出す。

### 2. 推定の進路

- **新しく子を足したとき（家族のカード・ヒアリングシートの取り込みで新しく入った子）**: 進路の目標が無ければ、標準の型「大学だけ私立〔文系・自宅〕」（幼稚園〜高校は公立、大学は私立・文系・自宅）を推定（値の状態の行。0041）で入れる。今の学年から始め、これからの段が無い年齢の子には入れない。ヒアリングシートの取り込みで進路が入っていた子はその進路のまま（推定を足さない）。
- **古い世帯（進路の無い子）**: 開いても入れない（0035 の11）。子の区画に「未入力（教育費0円で計算中）」と「推定の進路で埋める（大学だけ私立〔文系・自宅〕）」のボタン（名前は入る型から作る）。確かめの一覧にも出る（0041 の「推定で埋める」と同じ物）。
- 推定で入れた進路は、新しく入れた進路と同じく学校外の費用を「統計の平均で」で始める（0063）。段は要素の ID を持つ（0035 の5）。

### 3. 専門学校と短大

- 専門学校は統計の目安が無いので、年額の欄を**簡易に出し、入れるまで未入力の警告**（「未入力（専門学校の学費の統計の目安はまだありません。年額を入れるまで0円で計算中）」）。確かめの一覧の未入力にも出る。段の見出しにも「⚠ 学費が未入力です（0円で計算中）」。目安は、出典の利用の条件を確かめてから足す（未確定）。
- 公立の短大は、私立の短大の平均で仮に計算していることを段の見出しで知らせ、年額の欄を簡易に出す。
- **国の修学支援（授業料等の減免・給付型奨学金）は大学だけを計算する**。短大・専門学校の段の見出しに「国の修学支援は、短大・専門学校ではまだ計算していません。受ける見込みなら、減免の後の額を年額に入れてください」の1行を出す。計算エンジンの知らせは画面に出ていないので、この1行が FP が気づく唯一の所になる（下の「理由」）。

### 4. 奨学金・教育ローン

- 計算エンジンの `scholarships`・`loans`（前からある）を詳細に出した。足すボタンのひな形の値は推定（目安のボタンの値。根拠の文つき）: 貸与の奨学金は月5万円・大学などの在学中・返す人は子・20年で返す・利率は仮の値、教育ローンは入学の前の1月に本人が200万円・15年で返す・金利は仮の値。利率と金利は公表の条件を原本で確かめる前の仮の値（未確定）。
- 返す年数は年で入れ、月で持つ（`termMonths`）。
- 住まい・ローンのカードの「ほかのローン」に、読むだけの1行「教育ローン n件（子ども・教育）」「子の貸与の奨学金（親が返す）n件」を出す。本人・配偶者が自分の奨学金を返している分は、今までどおり住まい・ローンのほかのローン（種類 奨学金）。

### 5. この子の入るお金・出るお金

- お金の行（0044）のうち、子ども・教育のカードに属する種類（入るお金: 教育資金の援助を受ける・給付型の奨学金・学費の助成・子が払う分、出るお金: 教育費）を、**子ごとの区画**に出す。その子の行かどうかは、入るお金は受け取る人がその子か時期がその子の年齢、出るお金は時期がその子の年齢（`from.memberAge`）で読む。子を決めていない行は、カードの後ろの区画「入るお金（子を決めていない分）」「出るお金（子を決めていない分）」に出す。
- 子の区画から足すと: 入るお金は受け取る人をその子、時期を大学などの在学の期間（無ければ18歳の学年の4月から4年。援助・給付は毎年、子が払う分は毎月）にし、額は未入力の警告（0044 の決まり）。出るお金の留学は1回・20歳（過ぎていれば来年の年齢）・350万円の推定、その他の教育費は毎年・年10万円の推定。表の行は「教育費」。
- 「＋ 項目を追加」の留学で子を選んだときも、同じく種類 教育費・表の行「教育費」の出るお金の行にする（前はライフイベントの種類のまま子の区画に出していた。前に足した行は書き換えず、今までどおり子の区画に出る）。
- 出るお金の種類「教育費」の名前とひな形を「留学・寮費・部活などの教育費」「その他の教育費 年10万円（毎年）」にした（塾・習い事は学校外の費用の行で入れる。0063）。
- 子への援助（結婚・住宅資金。あげる側）は物の形を変えず、このカードで入れる。相続・贈与のカードには読むだけで出る（前から）。

### 6. 古い世帯

- 開いても何も書き換えない。進路の無い子は未入力のまま（2）、学校外の費用の入れ方の無い目標は前の形のまま（0063）、留学の古い行はそのまま。

## 理由

- **新しく足した子だけ推定の進路を入れる**: 開かないと教育費0円で進む（気づかないまま誤る）を新しい世帯で無くす。標準の型は、いちばん大きい大学の費用を少なく見積もらない型。古い世帯は、黙って書き換えない決まり（0035 の11）を守り、ボタンで入れる。
- **専門学校を未入力の警告にする**: 0円のまま黙って進むと、多く見積もる側でも少なく見積もる側でもなく「無い」ことになる。出典の利用の条件が分かる前に目安を置かない。
- **修学支援の知らせを段の1行にする**: 計算エンジンの知らせ（`N_NOT_SUPPORTED`・`N_INPUT_REQUIRED`）は結果のタブにも入力の画面にも出ていない（改定の知らせだけを出している）。知らせの一覧を画面に出すのは結果のタブの回なので、それまでは入力の画面の段の1行で知らせる。短大・専門学校の支援の計算は次の回（未確定）。
- **子ごとの区画にお金の行を出す**: 留学・援助・給付は進路と組で見る。物の形を変えずに、受け取る人と時期から子を読む。

## 代案（採らなかったもの）

- 段ごとの年額を簡易に全部出す: 欄が段の数だけ増える。額は見出しに読むだけで出し、上書きは詳細（専門学校と公立の短大は簡易）。
- 修学支援を計算する・しないの切り替えを出す: 計算エンジンに切り替えが無く、β では入れたのに結果に出ない欄になる（未確定）。
- 子のお金の行を目標の中に持つ: 入るお金・出るお金は世帯のお金の行（0044）にあり、カードを移る操作と同じ形にそろえる。
