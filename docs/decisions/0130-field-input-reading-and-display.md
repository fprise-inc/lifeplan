# 0130. 入力の欄の読み取り（円・万円の末尾の単位・離れたときに決める・生年月に年齢）と、入力例・時点の欄の読み・欄の外の額の書き方

- 状態: 採用（一部未確定）（2026-11-06）
- 固定の強さ: 内部（画面の部品の決まり。世帯ファイルの形式の版・計算・書く値の形は変えない。読み取りの言葉・知らせの文・目安の上限の値・入力例は後から変えてよい。変えたら追記に書く）
- 前提にする記録: 0002（金額は円の整数で持つ）、0038（時点の部品）、0041（値の状態の操作・欄を離れるときに同じ文字なら書かない）、0077（灰色の入力例は欄の幅に収まる物だけ）、0035 の3（仮の印）

## 背景

通しで入力を試した FP の声と、入力項目をまたいだ見直しで、欄の部品に次の問題が見つかった。

1. **円の欄に「15万」と打つと15円になる**（保存しても15円）。万円の欄に「4500円」と打つと4,500万円になる。読み取り（`units.ts` の `parseYen`）が末尾の「万円・万・円」を消すだけで換算していなかった。保険の年金月額・保険料など円の欄で、ざっくり入れる人は気づけない。結果を黙って誤らせる不具合。「1.5億」「1億2000万」は読めなかった。
2. **額の欄・年月の欄は打つたびに世帯に書いていた**（時点の欄だけ欄を離れたときに書く）。打っている途中の空や途中の数（「2036-1」→2036年1月）で値が動き、書いた後の始末（関連する値の調整）が動いて物が消えることがあった（収益不動産の取得の年月を Backspace で消すと取得価額も消える、の元）。
3. 生年月の欄に「38歳」と打てない（年齢しか分からないことが多い）。
4. 灰色の入力例が欄の意味によらず同じ（年月の欄はどれも「例: 2041-06」〔過去の年月の欄にも未来の例〕、年齢の欄はどれも「例: 60歳」〔子や親の年齢の欄にも〕）。空欄の意味は欄に収まるときしか見えない。
5. 働き方の「終わり 60歳」と次の働き方の「始まり 60歳」が違う月を指す（前は60歳になる前の月、後は60歳になる月）のに、欄の下の読みで違いが分からない。
6. 1つのパネルの中で西暦と和暦がまざる（見出し「2036年11月に売る」と、欄の下の「今から10年後・ご本人50歳（令和18年11月）」）。
7. 欄の外（見出しの要約・一覧）の額の書き方が所によって違う（「20.35万円」「7.2933万円」「月50,000円」「月0万円」）。
8. 時点の欄の「誰の年齢で」に、その欄で意味の無い人が並ぶ（ご本人の定年の欄に子）。選ぶ欄に見出しが無く、長い選択肢の並びが読みにくい（保険の種類）。

## 決定

### 1. 円・万円の欄の読み取り（`units.ts` の `readYen`。`parseYen` はその額だけ）

- **末尾の単位を、欄の単位より優先して換算する**: 円の欄の「15万」「15万円」→150,000円、万円の欄の「4500円」「¥4,500」→4,500円（0.45万円）。「1.5億」「1億2000万」「1万5000円」「5千円」も読む（億・万・千・端の数を足す。端の数は、億・万・千の後か「円」付きなら円）。
- 単位を付けずに数字だけで打ったときは、今までどおり欄の単位（万円の欄は万円、円の欄は円）。桁区切り（`1,200`）・全角の数字（`１５万`）・空白は読み飛ばす。
- 計算は10進の文字列の桁移動と整数で行う（浮動小数点で丸めない。0002）。万円で打った1円未満の端数は四捨五入（今までどおり）。
- **読めない打ち方は書かず、理由を欄の下に出す**（打っている間から）: 円で書いた額の1円未満の端数（円の欄の「0.5」、「0.5円」。前は四捨五入して1円にしていた）→「1円未満の端数は入れられません（万円なら「0.5万」のように「万」を付けてください）」、「1億2000」（万が抜けた形。1億2000万円のつもりのことが多い）→「「1億2000万」のように、万まで書いてください」、漢数字→「数字は 0〜9 で」、「月15万」→「月額・年額は欄の横のボタンで切り替えます」、ほか→例つきの「数字で入れてください」。
- **読み替えたら、欄の下に1回知らせる**（次に欄に入るまで）: 欄の単位と違う形で打ったとき「15万円（150,000円）として入れました」「4,500円（0.45万円）として入れました」「1億2,000万円として入れました」。欄の単位のままの形（万円の欄の「15」「15万」、円の欄の「150000」「150,000円」）では出さない。
- **桁が明らかにおかしい額は、書いたうえで1回知らせる**（`amountWarning`）: 万円の欄に数字だけで10億円以上（円で書いてある書類の額を円を付けずに写したとき。「478200」→47億8,200万円）は「円を付けて打ってください」、円の欄に数字だけで1,000円未満（万円のつもりの「15」）は「万円のつもりなら「15万」と」、欄ごとの目安の上限（`FieldDef.typicalMax`）か、それが無ければ月額で1,000万円・年額で1億円を超える額は「桁を確かめてください」。書くのは止めない（本当にその額のこともあるため）。

### 2. 欄は、離れたとき（か Enter）に決める

- 額・整数・率・年月の欄も、時点の欄と同じに、打っている間は下書きだけを持ち、欄を離れたとき（Enter・Tab・ほかを押す）に読んで世帯に書く。打っている途中の空・読めない文字・途中の数では世帯を変えない（書いた後の始末も動かない）。読めない文字の理由は、打っている間から欄の下に出す（今までどおり）。
- 入ったときと同じ文字のまま離れたら書かない（0041 のまま）。読めない文字のまま離れたら前の値のままにし、その旨を出す（今までどおり）。
- 貯蓄・運用の表の数の欄（`SavingsPanel.tsx` の `NumIn`）も同じにした。
- 計算は、欄を離れたときに動く（前は打つたびに動いていた）。

### 3. 生年月の欄に年齢（`FieldDef` の年月の欄の `ageInput`、`when.ts` の `birthFromAge`）

- `ageInput` を付けた年月の欄は、「38歳」「38」「38才」（0〜120歳）を年齢として読み、今の月でその年齢になる生まれ月の幅のまん中（今の月の38年6か月前。例: 2026年11月なら1988年5月）を書く。**仮の印**（`household.assumed`、理由「仮の値（38歳から推定した生年月）」）を付け、欄の下に「38歳（1988年5月生まれとして入れました。月が分かれば直してください）」を1回出す。年月を打ち直せば仮の印は外れる（今までの欄の書き方のまま）。
- 仮の印にしたのは、生年月は推定の箱を持たない値で、空の世帯の生年月の仮の値（「40歳として計算」）と同じ置き場所にそろえるため（0035 の3）。どの欄に付けるか（家族の生年月）は、その入力項目の見直しで当てはめる。

### 4. 入力例と空欄の意味（`FieldDef.example`・`blankMeans`）

- 欄の定義に、灰色の入力例 `example` と空欄の意味 `blankMeans` を持てるようにした（`plain`・`yenBox`・`timepointField` からも渡せる）。欄の中は「空欄＝○○」を先に、収まらなければ入力例（0077 の幅の決まりのまま）。収まらない「空欄＝○○」は、欄が空のとき欄の下に「空欄なら: ○○」の1行で出す（`placeholder.ts` の `blankLineFor`）。
- 例を持たない年月の欄の共通の例は「例: 2020-04」（過去の年月。年月だけの欄は残高の時点・契約年月など過去の事実が多い）。生年月の欄（`ageInput`）は「例: 1988-05」。年月を打てないときの理由の例も「2020-04」「令和2年4月」に（生年月の欄は「年齢しか分からなければ「38歳」」を添える）。
- 時点の欄の年齢の入れ方の例は、欄の物差しの人で変える（`ageExample`）: 子は「例: 22歳」、親・祖父母は「例: 85歳」、ほかの大人は「例: 65歳」（前はどれも「例: 60歳」）。欄の `example` があればそちらを使う。

### 5. 時点の欄の読み: 西暦を主に、期間の端の「まで」「から」

- 欄の外の年月は「2036年11月・令和18年」（西暦の年月を主に、和暦の年を添える。`units.ts` の `ymWithEra`）。欄の中は今までどおり「2036-11」。時点の欄の読みは「今から10年後・ご本人50歳（2036年11月・令和18年）」、出来事からは「入居から10年後（2038年4月・令和20年。入居は2028年4月）」、年月だけの欄の横の読みは「今から10年後（2036年11月・令和18年）」（今月より前は「2020年4月・令和2年」）。0038 の 2026-10-28 の追記（読みは和暦だけ）を改めた。
- **期間の端の欄は、読みの後ろに「まで」「から」を付ける**（`WhenSpec.edge`、`when.ts` の `edgeOf`）: 終わりの欄は「ご本人が60歳になる前の月（2046年5月・令和28年）まで」、始まりの欄は「ご本人が60歳になる月（2046年6月・令和28年）から」。年月で入れても、その欄で「○歳」と言える月なら同じ言い方を添える。明示が無いときは欄の決まりから: 始まりのある終わりの欄（`startPath`）と「○歳になる前の月まで」の欄（`ageMeans: "before"`）は「まで」、受け取り開始のような「翌月から」の欄（`ageMeans: "after"`）は「から」、ほかは付けない。期間は始まりの月も終わりの月も含む（0003）ので、終わりの欄の「まで」はその月を含む。働き方の期間の「始まり」に `edge: "from"` を付けた。

### 6. 時点の欄で選べる人を絞る（`WhenSpec.who`）

- `who: "fixed"` はその欄の人だけ（「誰の年齢で」の選択を出さない。定年・働く最後など）、関数はその人を候補に出すか（例: 18歳以上だけ）。今入っている時点の人と欄の人は、絞っても残す（前の値を読めるように）。どの欄に付けるかは、それぞれの入力項目の見直しで当てはめる。

### 7. 欄の外の額と率の書き方（`units.ts` の `amountText`・`rateText`）

- 額: 1万円以上は万円で小数1桁まで（「8.3万円」「1,234万円」。千円の位で四捨五入）、1万円未満は円（「4,500円」）、「月5万円」「年120万円」（「月」「年」を前）、マイナスは「▲」（結果の画面と同じ）。率: 百分率で小数2桁まで（「1.25%」）。欄の中は入れた値のまま（`formatYen`）。見出しの要約・一覧への当てはめは、それぞれの入力項目の見直しで行う。

### 8. 選ぶ欄の見出し（`Option.group`）

- 選択肢に見出し `group` を持てるようにし、同じ見出しが続く選択肢を1つの optgroup にまとめて描く（`FieldViews.tsx` の `optionNodes`）。見出しの無い選択肢は見出しの外。保険の種類への当てはめは保険の入力項目の見直しで行う。

## 理由

- 末尾の単位を優先するのは、打った人が単位を書いたならその意味がいちばん確か（欄の単位の切り替えボタンを見落としても誤らない）だから。「1億2000」を読まないのは、1億2,000円と1億2,000万円のどちらにも読めて、取り違えると桁が4つ違うため。円の欄の「0.5」を1円にしないのも同じ（打った人は5,000円のつもりのことが多い）。
- 離れたときに決めるのは、打っている途中の形（空・途中の年月・途中の額）で書いた後の始末が動いて物が消える誤りを、欄ごとに防ぐのではなく部品で一度に防ぐため。時点の欄はもとからこの形で、そろえると欄ごとの違いも無くなる。
- 和暦を年だけ添えるのは、書類（定期便・証券・登記）は和暦の年で書かれていることが多い一方、見出し・結果の画面・提案書は西暦なので、同じパネルの中で同じ年月を同じ形で読めるようにするため。

## 代案（採らなかったもの）

- **円の欄だけ単位を読む**: 万円の欄の「4500円」の誤りが残るので採らなかった。
- **打つたびに書き、途中の空だけ書かない**: 途中の年月（「2036-1」→1月）・途中の額で後の始末が動くのは残るので採らなかった。
- **桁がおかしい額は書かない**: 本当にその額のこともある（資産の多い世帯・役員の報酬）ので、書いたうえで知らせる形にした。
