# 0031. 黒字のうち貯まる割合（ゆとりの支出）と生活防衛資金・運用しない分

- 状態: 採用（一部未確定）（2026-10-21）
- 固定の強さ: β公開から変えない（骨格）。前提の欄（`assumptions.surplusSaving`（`ratio`・`cap`・`changes[]`）・`assumptions.emergencyReserve`（`months`・`amount`・`countInLasting`））・器の欄（`accounts[].uninvested`）・行ID（`cf.expense.living.surplus`・`cf.balance.account.reserve`・`cf.balance.financial.reserveTarget`・`cf.balance.financial.usable`）・計算式ID（`plan.cashflow.surplus`・`plan.cashflow.reserveTarget`・`plan.cashflow.usable`）・丸めの規則ID（`conv.surplus.saving`・`conv.reserve.target`）と、下の決まり（黒字の決め方・生活防衛資金の分け方と取り崩しの順・「○歳まで持つ」と資金の不足の関係）は骨格。控えから見た実際の割合の出し方（期間・運用益の扱い・刻み）、画面・帳票の見せ方・言葉は後から変えてよい（変えたら追記に書く）

## 背景

- 現場の FP の声（1）: 年間収支が500万円の黒字だと、ソフトは毎年500万円ずつ金融資産に積み上げるが、実際はその一部を使ってしまい、本当に貯まるのは200万円くらい。翌年の支出として毎回入れるのは面倒なので、「使ってしまう分は無いものとして」扱う決まりが欲しい。
- 現場の FP の声（2）: 運用を入れると、金融資産の全部（例 2,000万円）に 4% がかかってどんどん増える。実際は生活防衛資金など運用しないお金があるはず。生活防衛資金を「絶対に使わないお金」として外しておくのもよい。
- 今までは、入れ方が「口座」「資産配分」なら預金は預金の利回りで分けて計算できたが、「合計」（0026 の1。まとめた金融資産の器 `pooled`）だと全部に同じ利回りがかかっていた。取り崩しの順序（0026 の5・plan.cashflow）は、決済口座 → まとめた金融資産 → 前提の順序で、取り崩さないお金の決まりは無かった。
- 0002（丸め）、0003 の3（運用益）、0004（科目の木の中分類は固定）、0008（世帯のデータ）、0009（控え）、0011（形式の版）、0026（資産運用・取り崩し）、0027（資産と負債のタブ）が前提。

## 決定

### 1. 黒字のうち貯まる割合（`assumptions.surplusSaving`）

- 前提に「黒字のうち貯まる割合」`ratio`（0〜1。省略は1＝今まで通り）と、代わりの決め方として「黒字のうち貯まる額の上限」`cap`（年額。省略は上限なし）を置く。両方なら、割合で出した額と上限の少ないほう。どちらも任意で、前提が無ければ計算は今までと同じ。
- **黒字**: その年の年間収支（取り崩しの計画の前・現状の検算の使途不明金を引いた後）から、一時金の収入（`cf.income.lumpSum` の下。退職金・満期金・相続・不動産の売却など）を除いた額。黒字の年だけ、貯まる額＝黒字×割合（円未満切り捨て。`conv.surplus.saving`。上限があれば上限まで）とし、残り（黒字−貯まる額）を「ゆとりの支出」（`cf.expense.living.surplus`）として、その年の月に等しく分けて支出に足し、年間収支から引く。赤字の年は何もしない。一時金の収入は全部が貯まる（割合を当てると、退職金の何割かを使ってしまう不自然な結果になるため）。
- iDeCo・企業型DC の本人の掛金・NISA などの積立は器の間の移動なので、黒字から引かない（年間収支のまま）。貯まる額は、金融資産の増え方（積立の分も含む）の目安になる。
- **期間で変える**（`changes[]`）: `from`（時点）の年から、書いた組（`ratio`・`cap`。書いていない `ratio` は1、`cap` は上限なし）に置き換える。始まりの組の後に、`from` の年の順に重ね、その年に当てはまる最後の組を使う（計算基準年より前の `from` は始まりの組の代わり）。画面は「本人の○歳から」で入れ、足すときの既定は基本生活費の「子の独立」の時点（無ければ今の年齢＋10歳）で 80%。
- 取り崩しの計画（0026 の6）より先に引く。ゆとりの支出があるのは黒字の年だけなので、取り崩しの計画の「収支の不足」とは重ならない。黒字の年に取り崩しの計画も始まっているときは、両方を支出に足す（年金などで黒字の年に、計画の額も使う前提。下の未確定）。
- 対策のつまみ（動かす項目）に「黒字のうち貯まる割合」（5% の刻み）を足し、プランごとに変えられるようにした。前提の欄と同じものは重ねて出さない。

### 2. 控えから実際の貯まり方を出す（画面だけ。計算エンジンは変えない）

- 世帯に控え（0009 の2）があるとき、前提条件の「黒字のうち貯まる割合」の欄の横に「控えから見た実際の割合: ○%（入れる）」を出す。押すと値が入る。自動では変えない。根拠（期間・金融資産・見込みの黒字・除いた運用益）を開いて見られる。
- 使う控え: 新しい順に見て、今の計算の基準の月から6か月以上前に作った最初の控え（期間の数え方は資産と負債のタブの「前回と比べる」と同じ。控えを作った月 〜 今の計算の基準の月）。
- 割合＝（今の実際の金融資産 − 控えの時点の金融資産 − 見込みの運用益）÷ 見込みの黒字。金融資産は入力の器の時価（不動産・その他の資産・保険を除く）。見込みの黒字と運用益は、控えの入力で計算した年ごとの値（黒字は 1 の決め方。ゆとりの支出を引く前）を月の数で按分する（控えの計算の最初の年より前の月は最初の年の値）。
- **控えめに**: 相場で増えた分を「貯まった」と数えないよう、見込みの運用益を差し引く。割合は 0〜100% に収め、5% の刻みに切り下げる。見込みの黒字が無い期間・6か月未満の控えからは出さない（理由を出す）。大きな出入り（一時金・住宅の購入など）があった期間はずれが大きいことを根拠に書く。

### 3. 合計の入れ方の「運用しない分」（`accounts[].uninvested`）

- まとめた金融資産の器（`pooled`）に「運用しない分（金額）」を置ける。年の初めの残高のうちこの額まで（残高が少なければ残高まで）は預金の利回り（`accountReturnRate` の預金。前提の `cash.deposit`）、残り（と、その年の出入り）に器の利回りをかける。相場の下落（0026 の7）も運用する分だけに当てる。
- 口座・資産配分の入れ方では使わない（「まだ口座に分けていない分」を作るときに外す。預金は預金の口座に入れる）。合計 2,000万円（うち運用しない分 500万円）と、預金 500万円＋課税口座 1,500万円は、最初の年の金融資産が同じになる（テストで確かめる）。
- 運用しない分は決まった額として持つ（取り崩しで先に減らす扱いはしない。残高が運用しない分より少なくなれば、全部が運用しない分）。

### 4. 生活防衛資金（`assumptions.emergencyReserve`）

- 前提に「生活防衛資金（取り崩さないお金）」: 金額（`amount`）か、基本生活費の○か月分（`months`。金額が無いとき）。既定はなし。○か月分の額は、その年の基本生活費（`cf.expense.living` の下。取り崩して使うお金・ゆとりの支出を除く）÷ その年の月数 × 月数（円未満切り捨て。`conv.reserve.target`）で、生活費が変われば目安も動く。
- **分け方**: 計算の始めに、目安の額を決済口座 → ほかの預金 → まとめた金融資産の順に分け、入力の無い器「生活防衛資金」（行 `cf.balance.account.reserve`。金融資産に入る）に置く（引き出せない期間の器からは分けない）。まとめた金融資産から分けた分は、運用しない分の内に数える（運用しない分から引く）。足りなければ置けるだけ置き、後の年に足す。
- **運用しない**: 預金の利回りで増やす。毎年、取り崩しの前に目安より多い分を決済口座へ戻し、取り崩しの後に、決済口座の余り（残す額 `minimumDeposit` より多い分）から目安に足りない分を足す（運用する器を売って足すことはしない）。相場の下落の対象にしない。
- **取り崩しは最後**: 取り崩しの順序の最後（ほかの器をすべて取り崩した後）に置く。定率の取り崩しの計画（0026 の6）の基は、年の初めの金融資産から生活防衛資金の目安を除いた額。
- 金融資産の残高（`cf.balance.financial`）には含める。

### 5. 「金融資産は○歳まで持つ」と資金の不足の関係

- 生活防衛資金を入れたとき、エンジンは年ごとに目安（`cf.balance.financial.reserveTarget`）と、判定の基「使えるお金」＝金融資産−目安（`cf.balance.financial.usable`）を出す。
- 「金融資産は○歳まで持つ」（0026 の8）・資産が尽きる年・結果の結論の文・提案書の「金融資産が不足する年」・持ち帰り用のレポートは、使えるお金がはじめてマイナスになる年で判定する（＝生活防衛資金に手をつけ始める年）。尽きる年の文には「（生活防衛資金を除く）」と添える。
- 判定に含める前提（`countInLasting: true`。前提条件の詳細の欄）なら、使えるお金の行を出さず、今まで通り金融資産で判定する。判定の決まりを1か所（エンジンの行）にしたので、画面・帳票・持ち帰り用のレポート・万一のときの計算で同じ年になる。
- **資金の不足**（`cf.balance.shortfall`・資産と負債のタブの「資金の不足」）は今まで通り決済口座のマイナス＝生活防衛資金も使い切った後の不足。したがって、除いて判定したときの「尽きる年」≦ 資金の不足が出る年。

### 6. 行と表示

- キャッシュフロー表（画面・提案書）: 「基本生活費」の行からゆとりの支出を外し、その次に「ゆとりの支出」の行（値のある年があるときだけ）。「金融資産残高」の下に「うち生活防衛資金」（入れたときだけ）。根拠の表示に、その年の黒字・割合・貯まる額・ゆとりの支出（何を差し引いたか）、生活防衛資金の決め方の一言を出す。説明モードの「支出」の段に、ゆとりの支出の一文を足す。
- 資産と負債のタブ・提案書のバランスシート: 「すぐ使えるお金」の中に「生活防衛資金」の項目を分けて見せる（凡例・図の下の一覧・すぐ使えるお金の説明）。図の箱は分け方（4つ）のまま細かく分けない。
- 結果のグラフ（資産の推移）: 生活防衛資金の目安の線（点線。「生活防衛資金（目安）」）を出す。口座の内訳の面にも「生活防衛資金」を一番下に積む。「金融資産は○歳まで持ちます」の下の条件の文に「生活防衛資金（…）を除いて判定」を添える。
- 提案書の前提の一覧に「黒字のうち貯まる割合」「生活防衛資金」を足す。
- AI に渡す縮約版の許可リストに `assumptions.surplusSaving`・`assumptions.emergencyReserve`・`account.uninvested` を入れ、版を `reduced@5` にした（計算に要る数の項目。0015 の6）。
- 科目の木の中分類（0004）は変えない。新しい行はどれも既にある中分類の下（`cf.expense.living`・`cf.balance.account`・`cf.balance.financial`）に置いた。

### 7. 形式の版

- 世帯ファイルの形式の版を `0.11` に上げた（足すだけの MINOR。0011 の追記）。読み方は変えない（無ければ今まで通り）。

## 理由

- **一時金を黒字から除く**: 割合は「毎年の暮らしの中で使ってしまう分」の目安で、退職金や相続の何割かを使う前提にすると、FP の意図と違う大きな支出になる。上限（年○万円まで）でも、一時金の年に貯まる額が上限で止まってしまう。
- **年間収支から引く（翌年の支出にしない）**: 現場の声どおり、使ってしまう分は「無いもの」として扱うのが分かりやすい。行を分けて見せるので、表の支出の合計と年間収支の関係は崩れない。
- **生活防衛資金を器にする**: 残高の中で分けて見せられ（キャッシュフロー表・資産と負債のタブ・グラフ）、利回りと取り崩しの順序を器の決まりのまま扱える。目安だけを持って判定する案より、どこにあるお金かが説明しやすい。
- **判定の基をエンジンの行にする**: 「○歳まで持つ」を出す所が画面・帳票・持ち帰り用のレポート・万一の計算に散っている。前提で選ぶ「含めるか」をエンジンが行に反映すれば、どこでも同じ年になる。
- **控えからの割合は提案だけにする**: 相場・一時金・入力の直しの影響を切り分けられないので、FP が根拠を見て決める。

## 影響

- 後から変えると: 既存の世帯ファイルの結果（割合・生活防衛資金を入れた世帯）が変わる。行ID・前提の欄の意味を変えると、帳票・持ち帰り用のレポート・AI の縮約版が壊れる。
- 守るべき決まり: 前提が無い世帯の結果を変えない（テストで既存の結果と同じことを確かめる）。「○歳まで持つ」を新しく出す所は `cf.balance.financial.usable` があればそれで判定する。
- 見本: モデル世帯 `surplusReserve`（合計の入れ方・運用しない分・割合 60%→80%・生活防衛資金6か月分。3つの実行環境の一致の検査の入力）と、アプリの見本の世帯「共働きの夫婦と子2人（資産が多め）」のプランE（黒字の6割・生活防衛資金6か月分）。同じ見本の1年前の控えの残高を、控えから見た実際の割合が出る値に直した（架空の値）。
- テストで確かめること（エンジン `engine/test/surplus.test.ts`、画面 `app/test/surplus.test.ts`、帳票 `report/test/build.test.ts`）: 黒字の年だけ効く・割合と上限・赤字の年は変わらない・期間で変える・一時金を除く・ゆとりの支出の行、生活防衛資金の分け方・預金の利回り・取り崩しは最後・判定の年と資金の不足の年の順・含める前提・定率の取り崩しの基、合計の入れ方の運用しない分と口座の入れ方との整合、控えからの割合の計算。

## 未確定

- 生活防衛資金の目安の既定（6か月分を勧めるか）と、退職の後に目安を下げるか（今は基本生活費に比例するので、退職の後の生活費の段で自然に下がる）。
- 黒字の決め方に、一時金の支出（車の購入など）の年をどう扱うか（今は黒字が減り、ゆとりの支出も減る）。期間で変える組を「できごと」（子の独立・退職）の時点で持たせる画面。
- 控えから見た割合で、相場の実際の動き（実際の運用益）を FP が入れて差し引く形を作るか。控えが2つ以上あるときに平均するか。
- 万一のときの想定で、ゆとりの支出・生活防衛資金をどう扱うか（今は前提のまま重ねる）。
- 黒字の年に取り崩しの計画が重なるとき、ゆとりの支出を取り崩しの計画の額に含めるか（今は両方を足す）。
