# 0073. 事務所の既定値（カードの並びと最初の5枚・本人と配偶者の介護・受け取る予定の見込み・前提条件の標準値・不動産の評価の割合）

- 状態: 採用（一部未確定）（2026-10-27）
- 固定の強さ: 内部（事務所データの任意の欄と画面の作り）。事務所データに足した欄 `defaults`（JSON のオブジェクト）は足すだけの形で、中身の形（`version: 1` の画面の側の形）は画面が読むときに確かめる。「新しい世帯を作るときに写し、作った世帯は黙って変えない」決まりは結果の数に効くので、変えるときは追記に書く。並べる項目・文言・入力の範囲は後から変えてよい

## 背景

- 事務所データには、前提条件の標準値・事務所のひな形などを置く区分がある（0011 の6）が、画面から決める所が無かった。
- 各カードの回で「事務所の設定として持てる形」だけを作り、保存の場所を残していた: カードの並びと最初の5枚（0045 の `CardLayout`）、本人・配偶者の介護を最初から入れるか（0059 の `CareDefaults`）、前提条件の標準値（0070。今は提供元の標準の仮の値）、相続税の目安の不動産の評価の割合（0061）。受け取る予定の相続・贈与の見込みの既定（「不確か」を既定にすると、受け取る予定を基本の計算に入れないのが事務所の決まりになる）も、置き場所が無かった。
- 世帯ファイルは事務所データを参照だけで頼らない（必要なものは写す。0011 の6）。

## 決定

### 1. 置き場所

- 事務所データ（暗号化。0011 の6）に任意の欄 `defaults` を足す。中身は画面の側の形の JSON のオブジェクト（上限 32KB。オブジェクトでない・大きすぎる値は本体が受けない `E_STORE_OFFICE_DEFAULTS`）。空のオブジェクトを書くと欄を外す。欄の無い古い事務所データは「決めていない」と読む。事務所データの形式の版（`0.1`）は上げない（明細の辞書の欄と同じ、足すだけの任意の欄。0034 の追記）。
- 本体の命令 `office_defaults_get`・`office_defaults_put`。形を確かめて読むのは画面（`office/settings.ts` の `readOfficeSettings`。読めない所は標準）。
- 事務所で共有しているときも、今はこの PC の設定（共有フォルダには置かない）。画面にもそう書く。

### 2. 中身（`version: 1`）

| 設定 | 既定 | 効く所 |
|---|---|---|
| カードの並びと最初の5枚（`layout`） | 標準の並び（null） | 入力のホーム（0045 の `CardLayout`。設定に無いカードは標準の順で後ろに足す） |
| 本人・配偶者の介護（`care.selfAndSpouse`） | `warn`（自動で入れない） | 新しい世帯を作るとき。`fill` なら目安で入れる（0059） |
| 受け取る予定の見込みの既定（`inheritLikelihood`） | `likely`（たぶん） | 相続・贈与のカードで受け取る予定の行・相続で受け継ぐ借金を足すとき。`uncertain` なら足した行が「不確か」（基本の計算に入れない。行ごとに直せる） |
| 前提条件の標準値（`assumptions`: 物価・賃金・運用利回り・年金の調整率） | 無し（提供元の標準） | 新しい世帯を作るとき |
| 不動産の評価の割合（`realEstateRatio`） | 無し（時価の80%） | 新しい世帯を作るとき（相続税の目安の設定） |
| 最後に変えた日（`changedOn`） | — | 推定の根拠の文の年月 |

### 3. 写し方と知らせ

- 空の世帯を作るときだけ写す（見本・古い世帯・見本から写した世帯には当てない）。前提条件と評価の割合は**推定の印**で入れ、根拠は「事務所の標準（2026-10）」（年月は最後に変えた日）。
- 後で事務所の値を変えても、作った世帯は黙って変わらない。世帯の前提条件の値が推定のまま（FP が確定していない）で事務所の今の値と違えば、確かめの一覧の「確かめの注意」に「事務所の新しい値があります（○%）」と出し、「事務所の値にする」（推定の印のまま事務所の今の値と根拠にする）を置く。確定にした値には出さない。
- 画面の側の操作が読む今の値（受け取る予定の見込み・前提の標準値と根拠の文）は、読み込んだとき・保存したときに `office/current.ts` に入れる（ほかの所に頼らない小さな置き場）。

### 4. 画面

- 世帯の一覧の下の「事務所の既定値」から開く中央のパネル（`office/OfficeSettingsPanel.tsx`）: カードの並び（↑↓）と最初の5枚の印・標準の並びに戻す、介護・見込みの選択、前提と評価の割合の％の欄（空欄は標準。読めない・範囲の外は保存しない）、全部を標準に戻す、保存。

## 理由

- 写す（参照しない）: 世帯ファイルは事務所データに頼らない決まり（0011 の6）。後で事務所の値を変えたときに、作った世帯の数字が黙って変わると、お客さまに見せた結果と食い違う。
- 推定の印で入れる: 事務所の標準もお客さまの事実ではない。確かめの一覧に残り、FP が確定するまで「推定」と分かる。
- 中身を画面の形の JSON にした: 並べる項目はこれから増える（推定の目安の上書き・よく使う進路など）。本体は暗号化と大きさの確かめだけを受け持ち、形の確かめは画面の1か所（読むときに標準へ落とす）にした方が、項目を足すたびに本体を変えずに済む。

## 代案（採らなかったもの）

- 世帯ファイルに事務所の既定値を参照で持つ: 上の理由。
- 事務所で共有しているときに共有フォルダの名簿へ置く: 名簿の形（0023 の骨格）を変えることになり、誰がいつ変えたかの扱いも要る。共有は後の回に。

## 未確定

- 推定の目安の上書き（学費・家賃・退職金の率・介護の月額と期間・親の生活費）、よく使う進路パターン・働き方のつながり・よく使う一時的支出、カードごとの既定の段、事務所の注意の線、ヒアリングシートの事務所の版。各推定の元・注意の線の部品が事務所の値を受ける形にしてから足す。
