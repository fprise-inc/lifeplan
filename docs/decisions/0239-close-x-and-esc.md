# 0239. 重ねて出す画面の閉じ方をそろえる（どの画面も右上の同じ丸い × と Esc。Esc は上の1つだけ・書きかけの欄では閉じない）

- 状態: 採用（一部未確定）（2026-11-22）
- 固定の強さ: 内部（画面の見せ方と操作）。世帯ファイルの形・保存される値・計算は変えない。決まりとして残すのは「重ねて出す画面は、右上の同じ丸い ×（`.x-btn`）と Esc で閉じる」「× を描くのは `CloseX`、Esc を受けるのは `useEscClose` だけ（部品ごとに Esc を document で受けない）」「重ねて出しているときの Esc は上の1つだけ」「文字を打つ欄・変換中・開いているプルダウンの Esc では閉じない」。× の大きさ・置き場所の余白、足元の「閉じる」を残す画面は後から変えてよい（変えたら追記に書く）
- 前提にする記録: 0016（提示層は作業の層を読み込まない）、0041（値の状態）、0077（説明は「?」の中・FP のメニューから開く物は入力のホームの上部）、0087（お知らせの一覧）、0131（打ちかけの値を、画面を変える操作の前に決める）、0191（届いた書類を横に出す枠）、0236（入力画面の部品の見た目をそろえる）

## 背景

- 上に重ねて出す画面は7種類あり、閉じ方がばらばらだった。

  | 種類 | 今まで |
  |---|---|
  | 帯の下の一覧（FP のメニュー・お知らせ） | × なし（Esc・外を押す） |
  | 世帯の選択 | 四角い小さな ×（32px） |
  | 中央のパネル（事務所の既定値・保存先・事務所の共有・復元キー・要望を送る・書類の読み取り・AI と接続する画面） | 足元の「閉じる」だけ |
  | 入力項目のパネル・明細のパネル | 右上の丸い ×（40px） |
  | 右の引き出し・届いた書類の枠（メモ・根拠・書類） | 丸い ×／「閉じる ×」の四角いボタン／枠のない × |
  | 入力のホーム・結果のタブの中で開く物（控え・面談の履歴・世帯の中身の一覧・次の1年・前回から変わったこと・取り込む・プランの一覧・比較の表 など） | 「閉じる」のボタンが右上か下。Esc が効かない |
  | 確かめの問い（保存していない変更があるとき） | × なし（Esc は「やめる」） |

- Esc は部品ごとに document で受けていたので、重ねて2つ出ているときに1回の Esc で両方が閉じた（保存先の上の復元キー、世帯の一覧の上の保存先・確かめの問い、入力項目のパネルの上の根拠）。
- 中央のパネルは、文字を打つ欄にいるとき・日本語の変換中の Esc でもパネルごと閉じた（打ちかけが消える）。
- 形を先に画面で比較し、利用者の判断で「どの画面も右上の同じ丸い × と Esc」にそろえることにした。AI と接続する画面にも同じ × を付ける（利用者の判断）。

## 決定

### 1. × は1つの部品（`app/src/presentation/CloseX.tsx` の `CloseX`）

- 形は入力項目のパネルの丸い ×（`.x-btn`。40px の丸・墨の枠 2px）。形を決めるのは `app/src/styles/app.css` の1か所だけ。置き場所は、それぞれの見出しの行の決まり（`app.css`・`header.css`・`store.css`）に書く。
- 置き場所は、どの画面も右上。中を縦に送っても × は右上に残す（中央のパネル・世帯の選択・引き出しの頭）。見出しと説明は × の左で折り返す。文字の大きさ（中・大）・暗い画面でも同じ場所・同じ大きさ。
- 読み上げは「○○を閉じる（Esc）」（入力項目のパネルと確かめの問いは「閉じる（Esc）」）。乗せたときの説明は「閉じる（Esc）」。
- 前の形（`.hh-x`・`.ev-close`・`.dv-close`）と、その CSS は消した。
- 提示層の引き出し（根拠）も使うので、部品は提示層に置く（作業の層・エンジンは読み込まない。0016）。

### 2. Esc は1か所で受け、重ねた順の上の1つだけを閉じる（`useEscClose`）

- 部品は、出している間 `useEscClose(閉じる処理, 出しているか, 受け方)` で、Esc の受け手として重ねる。Esc を受けるのは `CloseX.tsx` が document に付けた1つの受け手だけで、**後から出した物（いちばん上）の1つだけ**を閉じる。もう一度の Esc で、その下の1つを閉じる。
- 受けたら `preventDefault` して、後ろの画面の Esc（グラフの年の固定を外すなど）には渡さない。受け手は読み込んだときに付ける（後ろの画面が後から付ける受け手より先に受けるため）。
- 中の部品（説明の「?」・選択肢の一覧・探す欄・学校の候補・名前の打ち直し）が先に受けた Esc（伝えるのを止めた・`preventDefault` した）は受けない。
- 引き出し（メモ・根拠）と届いた書類の枠は、ほかの物の横に並ぶ物（受け方の `side`）。**後から出しても、重ねた順のいちばん下に置く**（書類を横に出したまま入力項目のパネルで Esc を押したら、パネルの側が受ける）。**その中にいるときの Esc は、その枠が自分で受けて閉じる**（枠の `onKeyDown`。今までどおり。メモは書いた物を入れてから閉じる）。枠の外にいるときは、ほかに出ている物が無ければ閉じる（今までは、枠の外にいると Esc が効かなかった）。

### 3. Esc で閉じないとき

| とき | 動き |
|---|---|
| 日本語の変換中（`isComposing`・キーコード 229） | 何もしない |
| 開いているプルダウン（`select:open`） | 何もしない（開いているかを聞けない画面では見ない。その画面は、開いている間の Esc をページに渡さない） |
| 文字を打つ欄・選ぶ欄にいる（`input` の文字の種類・`textarea`・`select`・書ける所） | 閉じない（Esc も止めない）。欄から出て Esc か、× で閉じる |
| 選ばせる問い（閉じる処理が `null`） | 閉じない。下の物にも後ろの画面にも Esc を渡さない |

- **入力項目のパネルは、欄にいても Esc を受ける**（今までどおり。0131）: 閉じる前に打ちかけの値を決め、変わっていれば「保存していない変更があります」で止まる（もう一度の Esc か「変更を捨てて閉じる」で閉じる）。何も変えていなければ、そのまま閉じる。× と外側を押したときも同じ流れ。
- 閉じる処理が `null` になるのは: 世帯の分岐（どちらを残すかを選ぶまで）、鍵を戻す画面、確かめの問い・直前の保存で開き直す画面・控えを残す・ヒアリングシートの書き出し・URL の発行の処理中、面談の記録を足す・直す途中、事前ヒアリングの取り込みを確かめている途中（書いた物・選んだ物を消さない。やめるときは「キャンセル」）。

### 4. 画面ごとの形

| 種類 | × | Esc | 足元の「閉じる」 |
|---|---|---|---|

| お知らせ | 頭の行の右上（一覧・詳しい中身のどちらも） | 一覧は閉じる。詳しい中身は一覧に戻る（開いていた行に選択を戻す。2026-11-23 の追記・0245） | — |
| 世帯の選択 | 頭の行の右上（四角い × を置き換え） | 閉じる | — |
| 中央のパネル | 右上（足した） | 閉じる（欄にいるときは閉じない） | 残す |
| AI と接続する画面（事務所全体の設定・共有・発行した URL・新しい世帯の候補） | 右上（足した） | 同上 | 残す |

- お知らせに、開いた状態で描く指定（`initialOpen`。画面の確かめ用）を足した。比較の表の枠は部品（`presentation/Compare.tsx` の `CompareCard`）にした。

### 5. 形を合わせずに残した物

- **グラフを浮かせた小窓の帯の ×**（`.pip-x`）: 帯は高さ 1.75rem の細い帯で、同じ大きさの四角いボタンが並ぶ場所。40px の丸い × は帯に入らない（帯を太くすると、グラフが狭くなる）。Esc でも閉じない（浮かせたまま、ほかの操作をする物）。
- **その場に開く小さな物**（表示の設定・「＋ 動かす項目を追加」の一覧・取り崩しの計算・プランの違いの一覧・入力項目を選ぶ・内訳の小窓・時点の年を選ぶ小窓）: 押したボタンのすぐ下に開く小さな枠で、文字のリンクの「閉じる」か小さな × のまま。入力項目を選ぶの Esc だけ、重ねた順に入れた（入力のホームの中で開いた物と一緒に閉じないように）。
- **取り消しのボタンの言葉**（「キャンセル」「やめる」）は変えない（別に決める）。

## 理由

- 閉じる所が画面ごとに違うと、毎回探すことになる。右上の同じ形にそろえると、覚えるのは1つで済む。
- Esc を部品ごとに受けると、重なったときに両方閉じる・片方だけ効かない、が部品の組み合わせの数だけ起きる。1か所で重ねた順に受ければ、組み合わせを考えなくてよい。
- 文字を打つ欄の Esc で閉じないのは、変換の取り消しや打ち直しのつもりの Esc で、打った物ごと画面が消えるのを防ぐため。入力項目のパネルだけ別にしたのは、閉じる前に値を決めて知らせで止める流れ（0131）がすでにあり、開いてすぐの Esc で閉じられる今の動きを変えないため。

## 代案（採らなかったもの）

- **FP のメニューにも × を置く**: 項目を選ぶ一覧で、項目か外を押せば閉じる。× の行を足すと、一覧が1行ぶん長くなる。
- **足元の「閉じる」を中央のパネルからも消す**: 縦に長いパネル（事務所の既定値）では、読み終えた下で閉じられるほうが楽。
- **文字を打つ欄にいるときの最初の Esc で欄から出て、次の Esc で閉じる**: 欄から出ると値が決まる欄があり（離れたときに決める。0131）、取り消しのつもりの Esc で値が入ってしまう。
- **入力項目のパネルも、欄にいるときは閉じない**: 開いた直後は最初の欄にいるので、開いてすぐの Esc で閉じられなくなる。
- **重なっているかを画面の要素（`.scrim`・`role="dialog"`）で見る**: 部品を足すたびに見る物の一覧を直す必要がある。重ねた順は、出したときに自分で言うほうが漏れない。

## 未確定

- 開いているプルダウンの Esc: 画面がプルダウンの開け閉めを答えられる（`select:open`）ときだけ見分ける。答えられない画面で、開いている間の Esc がページに届くかは、アプリ本体（Mac・Windows）で確かめる。届くなら、入力項目のパネルで選ぶ欄にいるときの Esc を閉じない側に倒す。
- その場に開く小さな物（表示の設定・動かす項目の一覧・取り崩しの計算・違いの一覧・入力項目を選ぶ・内訳の小窓）の閉じ方も、同じ決まり（小さい丸い × か、文字のリンクの「閉じる」のどちらか1つ）にそろえるか。小窓の Esc も重ねた順に入れるか。

- 中央のパネルの足元の「閉じる」を、短いパネル（保存先・要望を送る など）では消すか。
- 明細のパネルの足元の「閉じる」を消すか（入力項目のパネルと同じ形の物。今は残した）。
