# 0074. 面談の準備（世帯の中身の一覧・次の1年に起きること・前回から変わったこと・結果のタブの気づき）

- 状態: 採用（一部未確定）（2026-10-27）
- 名前: 2026-10-28 に「FPの道具」から「面談の準備」に改めた（0077 の追記）。2026-11-05 に中身の「見直し」を「前回から変わったこと」に改めた（下の追記）
- 固定の強さ: 内部（画面の作り。世帯ファイル・計算エンジンは変えない。読むだけ）。気づきの決まり（何を「少ない」「続く」と言うか）は FP に出す文の意味に効くので、変えるときは追記に書く。並び・文言・出す件数は後から変えてよい

## 背景

- 世帯の物は14枚のカードに分かれ、生活全体を1画面で見て漏れに気づく所が無かった。次の見直しまでに何が起きるか（年齢の節目・保険の払込の終わり・金利が変わる時期・進学・年金の始まり）を拾う道具も無かった。
- 見直しの面談の準備（控えを取る・過ぎた予定の確かめ・事前の票・前回との違い）は、FP が手で順番を覚えていた。前回との違いは資産と負債のタブの「前回と比べる」（純資産の見込みと実際）だけで、入力のどこが変わったかは見られなかった。
- 結果のタブは数字とグラフを出すが、「預金が少なくなる年」「赤字が続く」のような気づきは FP が読み取っていた。

## 決定

### 1. 入力のホームの「面談の準備」

控えの道具の下に並べる（どれも読むだけで、押すとそのカードを開く）。

- **世帯の中身の一覧**: 世帯の物の全部（人〔年齢・世帯の外〕・働き方・退職給付・年金の記録・口座〔時価〕・住まい・ローン〔残高か借入額〕・保険〔保険料〕・生活費・出るお金と入るお金の行・介護・贈与）を、物を出すカードごとに1画面に。物とカードの対応は欄の当て先から引く（`planEdit.ts` の `objectCards`。違いの一覧と同じ対応）。
- **次の1年に起きること**（計算の基準の月から12か月）: 年月が決まる物は年月で、計算の結果から読む物は年で出す。
  - 入れた物から: 本人・配偶者の60・65・70・75歳、保険の払込の終わり・更新・解約、ローンの金利が変わる時期（金利の段の2つ目から）、介護の始まり、受け取る予定の相続・贈与、1回きりの入るお金・出るお金。
  - 計算の結果から: 子の入学（入学金の年）、年金の受け取りの始まり、ローンの完済。
- **見直し**（流れ）: ① 控えを取る（「見直しの前」のメモつき）② 過ぎた予定の確かめ（計算の基準の月より前に終わった1回きりの入るお金・出るお金。済んだら外し、受け取ったお金は口座の残高に入れる）③ ヒアリングシートの見直し（「取り込む」で前回の値つきの版を書き出す。次回確かめるの印の行を写す。0072）④ 前回との違い（控えを選ぶ）。
  - 前回との違い: **入力の違い**（控えの現状の入力と今の入力を、欄の当て先で比べる。足した物・外した物は物ごとに1行で、その物の欄は出さない）と**結果の違い**（資産が尽きる年・「○歳時点」の年齢の金融資産。控えの入力は今の計算エンジンで計算し直す。計算できなければそう出す）。見込んでいた今の純資産と実際は、資産と負債のタブの「前回と比べる」へ。
  - 見出しの横に「最後の控え（年月）・次の見直しの目安（1年後）」。

### 2. 結果のタブの気づき

選んでいるプランの結果から、決まりで出す（入力は増えない）。年のある気づきは「その年を見る」、どれも「対策を考える」（対策へ）。

| 気づき | 決まり |
|---|---|
| 預金が少なくなる年 | 預金の残高（`cf.balance.account.deposit`）が、その年の生活費（`cf.expense.living` の行。黒字の貯まり・取り崩しの行を除く）の何か月分（お金の3つの分け方の「何か月分」。既定は6か月）を下回る最初の年 |
| 赤字が続く | 年間収支（`cf.net`）の赤字が3年以上続く最初の所 |
| 教育と介護が重なる | 教育費と介護の費用が同じ年にある |
| NISA の枠を使い切る年 | 人ごとの生涯の投資枠の残り（`cf.balance.nisaFrame`）が0になる年 |
| 相続税がかかる見込み | いま亡くなったときの相続税の目安が0円でない（相続・贈与のカードと同じ写しの要求。結果のタブを見ている間だけ計算する） |

## 理由

- 読むだけにした: 一覧・次の1年・気づきは入力を増やさずに漏れと打ち手に気づくための道具で、値はカードで直す（1つの物は1つのカード）。
- 入力の違いを当て先で比べる: 欄の見せ方・並びが版で変わっても、同じ値を同じと読める（違いの一覧と同じ考え方）。
- 気づきを決まりにした: FP に毎回同じ物差しで出し、どの数字から言っているかを文に書ける。

## 代案（採らなかったもの）

- 気づきを計算エンジンの知らせにする: 表の行から読めるので、エンジンを変えずに画面で足りる。
- 前回との違いを差分（プラン）の形で作る: 控えは作った後に変えない写しで、差分に当てる向き先が今の世帯に無いこともある。欄の当て先での比べで足りる。
