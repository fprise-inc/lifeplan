# 0144. 住まい・ローン・保険の見せ方（未入力の警告の欄を入るまで標準に出す共通の決まり・今の残高から入れる住宅ローンの借りた年月と円の返済額・固定資産税の推定の段の表・保険の欄の出し方と並び）

- 状態: 採用（一部未確定）（2026-11-07）
- 固定の強さ: 内部（画面の欄の出し方・並び・言葉・入力の単位。世帯ファイルの形式の版・計算エンジン・書く値の形は変えない。欄の部品の任意の印 `missingShownBy` と `raiseFields` の決まりは、ほかの入力項目も同じ形で使う）
- 前提にする記録: 0025（持ち家の評価）、0040（段階と例外の年）、0041（推定と未入力の数え方）、0052（住まい・ローンの入力項目）、0055（保険）、0078（標準と詳細の分け方）、0112（固定資産税の推定）、0129・0132（見張り・通しの入力のテスト）、0130・0131（言葉と欄の部品）、0135（親を援助の贈与する人に）、0136（住まい・ローンの時期の連動・売却・借り換え）

## 背景

入力項目を通しで入れて見直したとき、住まい・ローン・保険に、次の迷いと誤りの元が見つかった。

1. 持ち家を標準の欄だけで入れると、評価額が「▸」の中にあって入らず、今の家が資産に入らない（純資産が大きくマイナス）。入力項目の札は「未入力（0円の所あり）」なのに、その欄は標準に無い。ヒアリングシートから取り込んだ持ち家・相続する家も同じ。
2. 今の残高から入れる住宅ローンは、借りた年月が今月の推定のままで、入居の年月を詳細で入れるまで住宅ローン控除を計算しない（控除が黙って0円）。毎月の返済額は万円の欄で、返済予定表の 72,933円 を 7.2933 と打ち直す。
3. 住宅の購入の詳細で、固定資産税の推定の段が20まとまり（各4欄）並び、住まい・ローンが約80欄の長い壁になる。
4. 全期間固定にしても後の変動金利の段が残る、控除の期間が終わったローンでも「受ける」と標準に出る、「＋ 金利の段階」の既定がこれから借りるローンでも今から5年後、カードローンの残高の「?」が年末残高証明書を指す、過去の年月の欄の入力例が未来の年。
5. 住まい: 購入の1件の修繕の「?」が無い欄（建て方）を指す、「住み終わりの後」が持ち家の評価の後ろに離れる、相続する家の見出しが「持ち家」、住まずに持つ実家の入れ場所が分からない、援助する人をその場で足せない、戸建ての大きな修繕の「＋」が標準に無い、賃貸の世帯にも売電・修繕・リフォームローンが出る、率の欄が「変動率」、家賃の目安の長い文が欄の下。
6. 働き方の入るお金の「＋ 売却代金」が標準に出る（めったに使わない）。
7. 保険: 医療保険にも死亡保険金の受取人・税が出る、受取人の候補に被保険者、種類の選択肢が足す一覧と分け方が違う（標準でも損害保険、子のいない世帯にも学資保険）、説明の「5つで計算します」と欄の数が合わない、詳細で主な保障の額・終わりが2か所に出る、終わりの2つが離れる、終身払いの空欄の意味、外貨建て・変額の円への直し方、必要保障額をどこで見るか、選び直しの取りやめが「やめる」。

## 決定

### 1. 未入力の警告の欄は、入るまで標準に出す（共通の決まり。`form.ts` の `raiseFields`・`InputPanel.tsx`）

- 入力のパネルを開いたとき、詳細の欄のうち状態が未入力（0円で計算している。`fieldStatus` の `missing`）の欄を標準にする。詳細のまとまり・区画の中にあれば、そのまとまり・区画も標準にし、まとまりは物の中の中枠（`band`）にする（ほかの詳細の欄は今のまま、物の頭の「▸」で開く。「▸」を2つ並べない）。名義と持分が「持分の無い人がいる」ときだけ標準に上がるのと同じ形を、どの入力項目にも当てる（利用者の判断 2026-11-06）。
- 開いている間は、入れた後も標準に残す（入れた途端に欄が消えると、打った所を見失うため）。開き直すと元の標準・詳細に戻る。
- 同じ値を標準の別の欄で入れる欄は上げない（欄の任意の印 `missingShownBy` に、代わりの欄のキー）。今の残高から入れた住まいの住宅ローンの「入居の年月（控除）」は、標準の「借りた年月（入居の年月）」で入れる。
- 今の見本の棚・モデル世帯・入力の操作の世帯で上がるのは、持ち家の評価額（時価の元が無い家）と、ヒアリングシートから取り込んだ住宅ローンの控除の入居だけ（後者は 3 の印で上げない）。

### 2. 見張り（0129）と通しの入力のテスト（0132）

- 「今住んでいる持ち家が資産に入っていない」は、その家の評価額が未入力の警告（＝標準に出ている）なら、おかしい所としない（黙っていない）。純資産が大きくマイナスかは、その家の住宅ローンの残高を足し戻して見る（家の値が0円のぶんだけのマイナスは知らせのとおり。ほかの誤りで大きくマイナスなら引っかかる）。評価額を0円の確定にした家は今までどおり引っかかる。
- 直す待ちの一覧から、取り込んだ持ち家の時価の元・モデル世帯の持ち家の時価の元の2行を外した（どちらも評価額が未入力の警告で標準に出る）。
- 通しの入力の世帯①（標準の欄だけ）は、標準に出た評価額を入れる。持ち家の価値が資産に入り純資産がマイナスにならないことを、直す待ちから確かめに移した。

### 3. 今の残高から入れる住宅ローン（利用者の判断 2026-11-06）

- 借りた年月を標準に1欄（名前は「借りた年月（入居の年月）」。住まいの住宅ローンで「今の残高から」のときだけ）。入れると持ち家の住み始めと控除の入居も同じ年月にする（0136 の 10 のまま）。控除の要約は「借りた年月（入居の年月）を入れるまで控除を計算しません」。
- 毎月の返済額は円で入れる欄（住宅ローン・ほかのローン・今返している自動車ローン。返済予定表・通帳の数字をそのまま打つ。保険料と同じ。「9万」と打てば9万円。0131）。世帯ファイルの値はもとから円なので形は変わらない。

### 4. 住宅ローンのほかの欄

- 最初の段が全期間固定なのに、後に変動金利・固定期間選択型の段が残るときは、金利の種類の欄に知らせ「全期間固定なのに、後の金利の段階（2031年 1%〔変動金利〕…）が残っています」と「後の金利の段階を外す」（押したときだけ外す。全期間固定の段〔当初の引き下げの後の段〕は残す）。「金利の段階で入れている」の文は、標準では「（「詳細」で直す）」、詳細では「（下の金利の段階で直す）」（標準だけの欄と詳細の欄の2つ）。
- 控除の期間が終わったローン（住宅の種類の欄と同じ決まり: 入居から13年を過ぎた）は、要約を「控除の期間は終わっています（2012年4月入居・2021年まで）」にして詳細へ。文の「○年まで」は、2019年9月までの入居は10年、それより後は13年で数える（10年の世帯は、終わってから3年は今までどおりの要約。計算エンジンは制度データの期間で控除するので、見せ方だけ）。住宅の種類の「?」の2027・2028年の話は、入居が2024年からのローンだけ。
- 「＋ 金利の段階」の既定の時点は、これから借りるローンは借入の月から、今返しているローンは今月から5年後（後ろの段があれば、その段の5年後）。
- ほかのローンの今の残高の「?」は種類で写す書類を変える（カードローン・リボは利用明細・カード会社のサイト、奨学金は返還のお知らせ、契約者貸付は契約内容のお知らせ、親・知人・会社からの借入は借用書・返済の記録）。
- 過去の年月を入れる欄（今の借入の年月・残高の時点）の入力例を過去の年月に（「例: 2018-04」「例: 2025-12」）。
- 配偶者のいる世帯の住宅ローンは、ローンの名義を標準に出す（「＋ ペアローン」の入口と並べる。誰が借りたか・連帯債務かで控除と団信が変わる）。単身の世帯・ほかのローンは詳細のまま。「本人の」は「ご本人の」（0130）。

### 5. 住まい

- 固定資産税の推定の段（今の額に対する割合が推定のままの段）が3つを超えたら、1つのまとまり「固定資産税の推定の変化（新築の軽減の終わり・3年ごとの評価替え・2030〜2060年・12件）」に畳む。1段1行の「2033年から」の割合の欄と、横にその年の額の目安（「年約18.7万円（今の額から）」）。割合を直した段は推定でなくなり、ふつうの段（いつから・入れ方・割合・移す年数・この変化を外す）として並ぶ（直したい行だけ欄が開く）。畳んだ表の「推定の変化を外す」は、推定の段を全部外して覚える（入れ直しで足し直さない。0112）。FP が足した段は今のまま1つずつ。管理費・修繕積立金・家賃の段も、推定の段が3つを超えたら同じ畳み方（`staged.ts` の共通の作り）。
- 率の欄の名前を「伸び率（年）」に（「家賃の伸び率（年）」「固定資産税の伸び率（年）」「修繕・管理の費用の伸び率（年）」など。既定の値は変えない。0130）。家賃の統計の目安の長い文は欄の下から「?」へ。
- 購入の1件の修繕・管理の費用の「?」は「購入の種類を選ぶと、呼び方と目安が変わります」。購入の予定の評価の基にする額は「買った直後の評価額」（空欄＝物件の価格）。
- 「住み終わりの後」（と売却価格・売ったときの税）を、住まいの1件の「住み終わり」のすぐ下に並べる（`placeIn`）。
- 相続する家の見出しは「住まい 2（相続する家・2036年11月から）」。家賃なしの注記に「住まずに持つ実家（空き家）・土地は、貯蓄・運用の『貸していない不動産』で入れます」。
- 住宅資金の援助の援助する人の候補がいないときは「＋ 親を足す」「＋ 祖父母を足す」（その場で世帯の外の家族として足し、この援助の援助する人にする。介護・親の項目の足し方 `addOutside` と同じ。0135）。「?」は介護・親の項目で足した親・祖父母から選ぶと書く。
- 住まいのお金の行のボタン（`moneyRows.ts` の `kindLevel`・`stages/index.ts` の `housingMoneyLevel`）: 売電・修繕・リフォームは持ち家（購入の予定を含む）があるときだけ。戸建て（か建て方を選んでいない持ち家）の「＋ 修繕・リフォーム」は標準でも出す（外壁・屋根などの大きな修繕を毎回聞くため。マンションは管理費・修繕積立金に含むので詳細のまま）。標準のボタンがあれば区画も標準に出す（行の中の欄は今の標準・詳細のまま）。リフォームローンの「＋」も持ち家の世帯だけ。

### 6. 働き方の入るお金

働き方と収入の「入るお金」の区画の「＋ 売却代金（事業・出資持分）」は詳細だけに出す（会社員・自営業の入力でめったに使わない。ほかの「＋」と区画は標準のまま。お金の行の種類ごとのボタンの出し方 `kindLevel` を使う）。

### 7. 保険

- 受取人（死亡保険金）と死亡保険金にかかる税は、死亡の保障（死亡保険金・収入保障。主契約か特約、アカウント型）のある契約だけ（入っている受取人は残して出す）。受取人の候補から被保険者を外す（入っている値なら出す）。
- 種類の選択肢は「＋ 保険契約を足す」の一覧と同じ見出し（死亡の保障・病気・けが・貯める・受け取る・そのほか）で分ける。学資保険は子のいる世帯だけ。標準では損害保険を出さない（標準だけの欄と、損害保険も出す詳細の欄の2つ。今の契約の種類はいつも出す）。
- 説明の文は「種類・被保険者・保険料と払い方・主な保障の額・終わりで計算します（満期金・年金のある保険は、受け取りと払込の終わりの両方）」（欄の数を書かない）。
- 詳細の並びを「保障の終わり（受け取りの始まり）→ 払込の終わり → 払込免除 → 契約の表示名・契約者・契約年月・受取人・控除 → 解約」に。一時払いには払込の終わりの欄を出さない。払込の終わりの空欄の意味は「終身払い」（損害保険の保険期間の終わりは「終わりなし」）。
- 保障の明細の主契約の行（契約の上の欄で額と終わりを入れる保障）は、額と終わり（年金は受け取りの始まり）を読むだけ「（上の『死亡保険金』と同じ）」にする（同じ値を2か所で直せると迷う。印も上の欄だけ）。契約の上の欄と明細の行は同じ値を指していて、上の欄で直すと明細の行にも出ることをテストで確かめた。給付の種類・被保険者・始まり・推移の形・限度日数は今のまま欄。
- 外貨建て保険の保険料・死亡保険金（円の目安）・解約返戻金の「?」に、今の為替で円に直した額（設計書の円換算の額）を入れると書く。変額保険の死亡保険金は設計書の基本保険金額。
- 保険料の行の下に1行「必要保障額との過不足は、結果の『万一のとき』のタブで見ます」（数字は出さない。同じ計算を2か所に出さない 0055 の 2026-10-29 の追記のまま）。
- 選択肢をまとめた「＋」のボタン（保険の種類を選ぶ一覧・額の変化など）の取りやめは「キャンセル」（0130）。

## 理由

- 未入力の警告の欄が「▸」の中にあると、標準だけで入れる FP は赤い印の欄を見つけられず、結果を大きく誤らせたままになる。上げるのは0円で計算している欄だけなので、入れた世帯の標準の欄は増えない（見本の棚でも上がるのは持ち家の評価額だけ）。
- 今の残高から入れるローンの借りた年月は、控除・持ち家の住み始めの元になる要の欄で、1欄で3つ（借入・入居・住み始め）がそろう。返済額は書類の円の数字を写す欄で、万円に直す手間と、単位を付けずに打つ誤り（万円の欄に 72933 で7億円）を防ぐ。
- 固定資産税の推定の段は、FP が1段ずつ直すことは少なく、表で見えれば足りる。直したい段だけ欄にすれば、詳細の長さが半分以下になる。
- 保険の受取人・種類・並びは、契約に関係の無い欄と同じ値の欄を減らし、証券の順に近づける。

## 影響

- 計算の結果は変わらない（欄の出し方・単位・言葉だけ。世帯ファイルの形も同じ）。
- 標準の欄の数: 配偶者のいる世帯の住宅ローンに1欄（ローンの名義）、今の残高から入れる住宅ローンに1欄（借りた年月）増える（代表の世帯の最初の5項目で 39 → 41）。評価額などの未入力の警告の欄は、入るまで標準に出る。
- 今の残高から入れるローンの毎月の返済額を、前の版の万円のつもりで「9」と打つと9円になる（欄の単位の札は「円」）。通しの入力のテストは「9万」に直した。
- 固定資産税の推定の段は、1段ずつの「この変化を外す」でなく、畳んだ表の「推定の変化を外す」でまとめて外す（1段だけ外したいときは、割合を直してふつうの段にしてから外す。そのときは入れ直しで同じ年の推定の段が戻ることがある）。

## 未確定

- 入力項目をまたぐ移動の口が無いので、家賃なしの注記の「貸していない不動産を開く」と、保険の「万一のとき」のタブを開くボタンは作らず、1行の案内だけにした（入力のホーム・アプリの画面の側に、パネルから別の入力項目・タブを開く口ができたら足す）。
- 保険の入力項目の見出しの、書類の読み取り（保険証券など）への1行は、読み取りをどこまで作るかの利用者の判断を待って入れる。
- 1段だけ外した推定の段を覚えるのは、推定のままの段だけ（割合を直した段は FP の段として扱う。0112 のまま）。
- 未入力の警告の欄を上げる決まりの当てはめで、上げた欄がほかの欄と意味の重なる所が見つかったら、その欄に `missingShownBy` を付ける。
