# 0047. 働き方と収入のカードの中身（辞め方と雇用保険の給付・定年後の再雇用の推定・勤め先の社会保険・休業の終わり）

- 状態: 採用（一部未確定）（2026-10-26）
- 固定の強さ: 内部（画面の作り）。世帯ファイルの形は変えない（辞め方・失業の給付・高年齢雇用継続給付の欄は 0037、被用者保険の上書き・通勤手当・学生・企業年金の欄は 0008 のエンジンの入力にある）。推定の決まり（定年60歳・65歳まで再雇用・年収の割合の作り方・公務員の定年の段階の近似）、推定の根拠の文、欄の名前・並びは後から変えてよい

## 背景

- 0037 で雇用保険の失業の給付（基本手当・高年齢求職者給付金）と高年齢雇用継続給付を計算に入れた。入力は働き方の期間の「辞め方」（`employment.endsWith`）・「失業給付を受け取る」（`employment.unemploymentClaim`）・「高年齢雇用継続給付を受け取る」（`employment.elderlyContinuationClaim`）で、欄が無ければ受け取らない。画面の欄はまだ無く、推定（SDK の `estimateUnemploymentClaim`）を新しい世帯に入れる所も無かった。
- 新しい世帯で「会社員として入れる」と、60歳の定年で働く最後になり、60〜65歳の収入が0円のまま出た（65歳までの雇用確保で多くの人に当たる再雇用が入らない）。公務員の定年も60歳のままだった。
- パートの社会保険は、週の時間と勤め先の規模の推定からエンジンが判定するだけで、「入っている」と分かっている人も入れる欄が無かった。休業中の人は、休業の終わり（戻る時期）を詳細の期間の表でしか入れられなかった。
- 働き方のお金の行（副業・その他の働く収入・売却代金・失業給付などの額）は区画が詳細にだけあり、失業給付の行は計算が入った後も「失業給付などの額」のままだった（二重に入れやすい）。

## 決定

### 1. 辞め方と雇用保険の給付の欄（詳細の働き方の期間）

- **辞め方**（終わりのある正社員・契約・パートと休業の期間）: 自動（エンジンの決まり: 終わりの月に60歳に達しているか定年の出来事なら定年、ほかは自己都合）／定年／自己都合／会社都合／契約満了／休業のまま辞める。自動は欄を省く。
- **辞めた後に失業給付を受け取る**（同じ期間）・**60〜64歳で高年齢雇用継続給付を受け取る**（60〜64歳の月を含む正社員・契約・パートの期間）: おまかせ（推定）／受け取る／受け取らない。
  - おまかせは、値と、期間の値の状態の行（`valueStates` の `employment.unemploymentClaim` などに推定・出どころ auto・出し方 standard）の組で持つ。期間の終わり・次の期間・年齢・辞め方が変わると、推定のままの値だけ入れ直す（推定の入れ直しの関数 `refreshEstimates` から）。
  - 失業給付の推定はエンジンの SDK と同じ決まり（65歳未満で辞め、次に働くまで3か月以上あり、休業のまま辞めるのでなければ受け取る）。高年齢雇用継続給付の推定は「受け取る」（要件と額はエンジンが判定する）。
  - 受け取る・受け取らないを選ぶと行を外し、値をそのまま書く（入れ直さない）。欄が無い期間は「受け取らない」と見せ、「入れていません」と添える。
- 欄の当て先は期間（`{object: 期間の ID}`）の入力項目ID。プランで「受け取らない案」を作れる（年金のほうが多い人の比べ）。

### 2. 推定（おまかせ）を入れる期間

- **画面が新しく作った期間だけ**に入れる: 働き方と収入のカードの欄・ボタンの後に、前の世帯に無い ID の期間（会社員として入れる・期間を足す・働く最後の年齢で定年後の期間を足す）と、推定を持っていた期間が作り直されて欄も行も無くなった期間（働く最後の年齢を変えて定年後の期間を作り直したとき）。打ち手が定年後の期間を作るときは、今の勤め先の期間の辞め方・給付の欄と値の状態の行を写さない。
- **古い世帯の期間には入れない**（開いた世帯の結果を黙って変えない）。代わりに、推定なら受け取る期間（本人・配偶者）を確かめの一覧の「入っていない物」に「〇〇の失業給付（〇年〇月に辞めた後）: 失業給付を入れていないので、受け取らないで計算しています」として出す。「推定で埋める」はおまかせ、「該当なし（受け取らない）」は受け取らないを書く。カードの状態は未入力（0円の所あり）になる。

### 3. 新しい世帯の定年と定年後の再雇用の推定

- 「会社員として入れる」と、定年60歳（推定）、定年後は65歳まで再雇用（契約・嘱託）、働く最後65歳を入れる。どれも仮の印（推定）で、FP が直すと外れる。
- 再雇用の年収は、**定年前の年収 ×（同じ働き方・性別の60〜64歳の平均÷55〜59歳の平均）**（賃金の統計の年齢階級の表。`hearing/src/estimates.ts` の年齢を使う年収の推定と同じ表）。定年後の期間の年収の値の箱に推定（出し方 derived）で入れる。定年前の年収を直すと、推定のままの再雇用の年収も入れ直す。働く最後の年齢を変えて定年後の期間を作り直しても推定の箱のまま。定年後の年収の欄の値の状態は、この箱で読む（「✓ この値で確定」も箱に書く）。
- 定年の期間の辞め方は「定年」（推定の行つき）。「60歳になる前の月まで」の期間は、エンジンの自動の決まりでは自己都合になるため。
- **公務員**の定年は生まれた年度で決める（定年は2023年度から2年ごとに1歳ずつ上がり2031年度に65歳: 1962年度以前の生まれ60歳、1963年度61歳、1964年度62歳、1965年度63歳、1966年度64歳、1967年度以後65歳）。年度末の退職を「その年齢になる前の月まで」の決まりにそろえる近似。定年が65歳なら定年後の予定は入れない。推定のままの世帯で働き方を正社員⇄公務員に変えると、定年と定年後の予定を入れ直す。
- 古い世帯には入れない（定年後の予定が無い人は今のまま）。

### 4. 勤め先の社会保険・休業の終わり・健康保険の種類

- **勤め先の社会保険（健康保険・厚生年金）**（パート・契約。簡易）: わからない（週の時間と勤め先の規模から判定。上書きを省く）／入っている／入っていない。エンジンの上書き `employment.employeeInsurance`（確定の箱）。入っているにしたら、健康保険と厚生年金が勤め先の種類でなければ協会けんぽ・厚生年金にする（エンジンは勤め先の種類のときだけ入ると読むため）。
- **休業の終わり（最後の月）**（今の働き方が休業中のとき。簡易）: 入れると、翌月から休業の前と同じ働き方の期間を作る（もう後の期間があれば作らない）。
- **健康保険の種類**（と協会けんぽの支部・料率）は詳細だけにした（働き方から推定。差は小さい）。
- 詳細の期間に、通勤手当（非課税・月額）・学生・勤め先の確定給付企業年金など（iDeCo の上限）と他制度掛金相当額を足した。

### 5. 働き方のお金の行

- 区画を簡易に出す。失業給付の額の行は「教育訓練給付などの額（失業給付は働き方の期間で計算します）」に名前を変えた（種類 `unemployment`・表の行は同じ）。

### 6. 出さない欄（計算がまだ無い）

計算に入らない欄は出さない。次は計算を足す回に欄を出す: 事業所得の赤字の年、3歳未満の子の養育特例、住民税の残りを最後の給与で一括で引いてもらう申し出、辞めた後の健康保険で世帯の外の家族の扶養に入る、休業のまま辞めた後の傷病手当金の継続、健保組合・共済の任意継続の保険料の月額、子ども・子育て支援金分の目安、制度の境目までの額。

## 理由

- **推定を値と行の組で持つ**: エンジンは欄が無ければ受け取らないので、推定もエンジンに渡す値として書く必要がある。行で「推定のまま」を持てば、期間が変わったときに入れ直す値と、FP が決めた値を分けられる。行は期間に付くので、画面の側の印（欄のキー）を持たずに済み、世帯ファイルにもそのまま入る。
- **新しく作った期間だけ**: 古い世帯を開いたときに推定を入れると、受給と年金の停止で結果が黙って変わる（0037 の決まり）。確かめの一覧に出せば、気づかないまま0円のことは無くなる。
- **再雇用の年収を年齢階級の比で**: 60〜64歳の平均は再雇用で下がった賃金を含むので、定年前の年収にその比を掛ければ、勤め先の水準を保ったまま下がり方だけを当てられる。働き方の統計の値（契約社員の平均）にすると、定年前の年収と関係の無い額になる。
- **公務員の定年の近似**: 年度末の退職を表すと、定年の欄（「〇歳になる前の月まで」）の形を変えることになる。今の働く世代（1967年度以後の生まれ）はどれも65歳で、近似が効くのは60〜63歳の人だけ。

## 影響

- 世帯ファイルの形・見本の世帯の結果は変わらない（古い世帯には入れない）。見本の世帯のうち、定年で辞めて働かない期間のある世帯は、働き方と収入のカードが未入力（0円の所あり）になり、確かめの一覧に失業給付の行が出る。
- 新しい世帯で会社員として入れると、60〜65歳の再雇用の給与・厚生年金と、65歳前に辞めた後の基本手当、60〜64歳の高年齢雇用継続給付（給与が下がるとき）が結果に入る（今より良く出る方向）。
