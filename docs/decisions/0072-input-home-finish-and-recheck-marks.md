# 0072. 入力のホームの仕上げ（進み具合で絞る・小さな結果・全部のカードの入れ方・取り込むの入口・確かめの一覧の1行と絞り込み・次回確かめるの印・形式 0.29）

- 状態: 採用（一部未確定）（2026-10-27）
- 固定の強さ: 内部（画面の作り）。世帯ファイルに足した画面の側の値 `household.recheck`（次回確かめるの印）は形式 0.29 の足すだけの形。値の確かさを出どころから決める決まり（取り込み → 書類で確認、ヒアリング → 本人の申告）は、確かめの一覧と後の書き出しの数に効くので、変えるときは追記に書く。文言・並び・色・小さな結果の大きさは後から変えてよい

## 背景

- 入力のホームの14枚のカード・状態4つ・進み具合・ピン（0045）、確かめの一覧（0041）、入力画面でプランを直す仕組み（0043）、計算の知らせ（0064）は入っていた。
- 残っていたこと: 進み具合を押してそのカードだけに絞る（0045 の未確定）。確かめの一覧の1行に今の値・出どころ・確かさが無く、絞り込みはカードだけ。「このカードの推定をまとめて確定」が無い。次回の面談で確かめる所に印を付けて書き出す道（0041 の未確定）。プランの編集中に、そのプランで足した物の推定が一覧に出ない。
- 入力のホームから結果が見えず、結果のタブと行き来しないと「直したら足りるようになったか」が分からない。
- 取り込み（ヒアリングシート）は控えと同じ並びに置かれ、プランの編集中も押せた（現状に入る、の注意だけ）。カードをまたぐ資料の入口が1か所にまとまっていない。
- 入れ方（簡易／詳細）はパネルの中でしか切り替えられなかった（全部のカードに効く値なのに、ホームに出ていない）。

## 決定

### 1. 進み具合で絞る

- 進み具合の「未入力（0円の所あり）」「入力済み」「推定で計算中」「当てはまらない」はボタンにし、押すとその状態のカードだけを格子に出す（もう一度押すか「全部のカードを出す」で戻す）。絞っている間は「＋ 項目を追加」を出さない。数と並びは変えない。

### 2. ホームの帯（全部のカードの入れ方・小さな結果）

- 進み具合の下に「入れ方（全部のカード）: 簡易／詳細」。パネルの中の切り替えと同じ値（画面の側の値。世帯ファイルには書かない）。
- 小さな結果（`input/MiniResult.tsx`）: 現状の計算結果の金融資産の残高（`cf.balance.financial`）の線と、足りなくなる年（金融資産がはじめてマイナスになる年。本人の年齢つき）か「○年まで足ります」。結果のタブの計算と同じ結果を読むだけ。プランの編集中は、そのプランの結果があるとき（帯に並べたプラン）に線を重ね、現状の線は点線にする。「結果を見る」で結果のタブへ。

### 3. 編集の対象の帯

- プランの編集中は、帯の中に「違いの一覧（○件）」の入口と「結果を見る」を置く（前は帯の下に入口だけ）。新しいプランの3つ（現状から・複製・土台に）は今のまま。

### 4. 取り込むの入口（カードをまたぐ資料だけ）

- ホームの「取り込む ▾」に、ヒアリングシート（書き出す・取り込む）と「AI に資料を渡す」（保存した世帯だけ。AI接続口の同意と共有を開く。AI が読んだ値は候補として届き、承認したものだけが現状に入る）を並べる。明細（口座・カード）は基本生活費のカードの見出しの「明細から出す」のまま（ホームに置かない）。保険の書類などカードの中の資料の取り込みは、そのカードの見出しに置く（各カードの回）。
- 取り込みは現状にだけ入るので、**プランの編集中は「取り込む」を押せない**。代わりに「取り込みは現状に入ります。○○の編集中は使えません」と「現状に切り替える」を出す（前は押せて、現状に入る注意だけだった）。控え（この時点を残す）は、プランの編集中も今までどおり使える。

### 5. 確かめの一覧の1行と絞り込み

- 1行: カード・まとまりと欄の名前・**今の値**（言葉で。未入力・該当なしは出さない）・**出どころ**（ヒアリング・取り込み・AI・上書き。手で入れた値と自動の推定は札を出さない）・**確かさ**・根拠・操作・開く・**次回確かめる**。
- 値の確かさ（値の箱・値の状態の行の `certainty`。計算には使わない）は、印があれば印、無ければ出どころから決める: 取り込み → 書類で確認、ヒアリング → 本人の申告。手で入れた値は決めない（`checkRows.ts` の `valueMeta`）。
- 種類に「確かさが申告・概算の値」（確定の値で、確かさが本人の申告か概算）を足し、いちばん下に並べる。**この種類は、確かさか種類で絞り込んだときだけ出す**（ふだんの一覧と入口の数には入れない。書類で確かめるときの候補）。
- 絞り込み: カード・状態（種類と「次回確かめる（印の行）」）・出どころ・確かさ。
- まとめての確定: カードで絞り込んでいるときは「このカードの推定をまとめて確定」（そのカードの推定だけ）。絞り込まないときは今までどおり全部。

### 6. 次回確かめるの印（形式 0.29）

- 行ごとに「次回確かめる」の印を付け外しできる（`input/recheck.ts`）。印は世帯ファイルの `household.recheck` に、行の ID（欄のキーか入っていない物の ID）・付けたときのカードと見出し・付けた日で残す。**値は写さない**。計算の要求には入れない。印が無くなったら欄ごと外す。
- 「次回確かめることを写す（○件）」: 印の行を、面談で確かめることの文（カード › 見出し、今の値と根拠）にしてクリップボードへ写す。氏名・顧客番号は入れない。写せないときは文を選べる形で見せる。
- 印を付けた行が確定などで一覧から消えても印は残し、状態を「次回確かめる」で絞ったときに「今は一覧に無いもの」として見せる（書き出しにも残る）。
- 読むときは形を確かめ、形の合わない行（ID が空・日付の形が違う・重なり）は捨てる。

### 7. プランの編集中の確かめの一覧

- 今までどおり現状の一覧を出し（見出しは「現状の確かめの一覧」）、加えて**そのプランで足した物**（現状に無い物・構成員の欄）の行を「○○で足した物」の区画に、札「○○で足した」つきで出す。行の操作はそのプランを当てた世帯に当て、そのプランの差分にする（`recordPlanEdit`）。次回確かめるの印は現状の行だけに付ける。

### 8. 形式 0.29

- 世帯ファイルの形式の版を `0.29` に上げた（`household.recheck` を足すだけの MINOR。任意）。前の版のアプリは知らない欄を読み落として書き戻すので、版を上げて閲覧だけにする。`0.28` → `0.29` の変換の段は形式の版だけを書き換える。見本 `crates/household-store/tests/fixtures/household-format/0.29/`。封筒の見出しは変えていない。AI に渡す縮約版は変えていない（入力項目を足していない。`reduced@19` のまま）。

## 理由

- 進み具合で絞る: 「未入力が5つ」と分かっても、14枚から探すのが手間だった。数の横で絞れば、ざっくり派の「未入力を消す」順がホームで終わる。
- 小さな結果をホームに: 入力を直すたびに結果のタブへ行かなくても、足りなくなる年が動くのが見える。読むだけで、計算も表示の設定も増やさない。
- 取り込みをプランの編集中に止めた: 取り込んだ値は顧客の事実で現状に入る決まり（0043）。押せて現状に入ると、プランを直しているつもりの FP が、プランの差分になったと誤る。止めて切り替えの1押しを出す方が誤らない。
- 確かさを出どころから決める: 取り込み・ヒアリングの値に印を付ける画面がまだ無くても、「書類で確かめる候補」を一覧で絞れる。印を付けた値（ヒアリングシートの範囲の答えの概算など）は印が勝つ。
- 確かさの行をふだん出さない: 確定の値まで並べると一覧が長くなり、未入力・推定が埋もれる。書類を集める前の確かめで絞るときだけ要る。
- 印を世帯ファイルに: 次の面談（数か月後・別の PC・別の FP）まで残らないと意味が無い。値を写さないのは、写すと古い値が残り、今の値と食い違うため。

## 代案（採らなかったもの）

- 次回確かめるの印を値の箱・値の状態の行に持つ: 入っていない物（物の行）や計算の知らせには箱が無い。行の ID で1か所に持つ方が、どの種類の行にも付けられる。
- 取り込みをプランの編集中も押せるまま（注意だけ）: 上の理由。
- 小さな結果を結果のタブのグラフの部品で描く: 大きく、帯や表示の設定まで連れてくる。ホームには線と1行で足りる。
