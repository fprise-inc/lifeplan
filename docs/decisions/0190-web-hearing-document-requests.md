# 0190. Web のヒアリングの書類の頼み方: 頼んだ書類で分かる問いは出さない・「手元にない」ならその場で聞く・書類の持ち主・書類の一覧・1通1画面

- 状態: 採用（一部未確定）（2026-11-08）
- 固定の強さ: 内部（書類の一覧と説明・書類と問いの対応の表・お客さまの画面と FP の画面の作りと言葉。0125 の4・5 の「内部」の範囲）。依頼の記録の選び方の書類に足した持ち主の欄 `owner`（`self`・`spouse`）と、問いの中の書類に足した `covers` の形は 0125 の追記として記録する。届いた答えの中身の形（`fprise-lifeplan-hearing-web-answers` 0.2）・書類の送り状の形・暗号の形・受け付けの API は変えない。世帯ファイルの形式は 0.71（`hearing.web` の1件の選び方の書類に任意の欄を足すだけの MINOR。変換の段は版だけを書き換える。6）
- 前提にする記録: 0018（ヒアリングシートの形式）、0102（書類のお願い）、0125（Web のヒアリング）、0138（お客さまの画面）、0158（書類は答えと別に何回でも送れる）、0159（書類の読み取りは保険証券などに絞る）

## 背景

- Web のヒアリングを発行から取り込みまで通して確かめたところ、聞くことと頼む書類がつながっていなかった。
  - 源泉徴収票を頼んでも年収を聞き、ねんきん定期便を頼んでも年金の加入期間と額（詳細の票の6問）を聞き、保険証券を頼んでも保険の9問を件数の分だけ聞いていた。
  - 一覧から足した書類の持ち主を選べず、「源泉徴収票」を2回足すと同じ見出しが2つ並んだ（お客さまの画面でもどちらがどちらか分からない）。
  - 事前に頼むことの多い書類（預貯金の残高・証券口座・企業型DC・年金額改定通知書・会社の決算書・ほかのローン・賞与の明細など）が一覧に無かった。
  - お客さまの画面では、頼んだ書類が全部1画面に縦に並び、撮る前の注意が上を占めた。番号を隠してもらう注意の言い方が、最初の画面・書類の画面・案内文で違った。
- 利用者の判断（2026-11-06〜11-08）:
  - **頼んだ書類で分かる問いは、お客さまの画面に出さない**（「答えなくて大丈夫」と出すのではなく、そもそも出さない）。言い方は「聞きません」ではなく「書類の数字を使います」のように、お客さまが見て納得できる言葉にする。
  - **お客さまが「手元にない」を選んだら、その書類の分の問いをその場で出す**。
  - 書類の一覧を足す（預貯金の残高の分かるもの・証券口座の残高・企業型DC のお知らせ・年金額改定通知書・確定申告書と決算書・ほかのローンの返済予定表・生命保険料控除証明書・賞与の明細・家計簿／カードの明細・賃貸の契約書・その他の書類）。今ある書類の名前の言い方もそろえる。
  - 書類の持ち主（ご本人・配偶者の方）を FP が依頼のときに選び、お客さまの画面にも「ご本人さまの源泉徴収票」のように出す。
  - お客さまの画面は書類を1通1画面にし、「どこが写っていればよいか」と撮る前の注意を添える。見本の絵は β の後。
  - 主軸は「聞くことは少なく、まずお客さまに行動してもらう」。画面の数・問いの数が増えないようにする。
- 書類の取り込み（読み取り）は保険証券などに絞った（0159）。ほかの書類は FP が見て打つ。書類で分かる問いを出さない形は、FP が見て打つ形のままで成り立つ。

### 2. 書類と問いの対応（`documentCovers`）

- 書類のひな形が「この書類で分かる問い」（項目キー）を持つ。選んだ項目のうち、そこに載るものだけが対象。範囲の項目は、元の金額の項目に付いてくる。
- 書類から FP が見て打てる数字だけを載せる（書類に載っていない数字・計算しないと出ない数字は載せない）。
- 持ち主との関係:
  - 大人の繰り返しの項目（ご本人・配偶者の方ごと）: 持ち主を選んだ書類はその人の分だけ（`キー#番号`）。持ち主を選ばない「人の書類」は載せない（誰の物か分からない）。持ち主を選べる書類（預貯金など）で選ばなければ、全員の分。
  - 繰り返さない項目（ご家族の合計など）: 持ち主を選んだ書類では載せない（1人の書類ではご家族の合計は分からない）。
  - ほかの繰り返し（住宅ローン・保険）: 全部の分。
- 問いを作るとき（`buildPacket`）に、問いの中の書類1通に `covers`（`キー` か `キー#番号`）を入れる。お客さまの画面はこの一覧で決める（ページとアプリの版が違っても、FP のアプリが決めたとおりに動く）。

### 3. お客さまの画面（`hearing/src/web/flow.ts`・`app/src/hearingForm/Form.tsx`）

- **書類で分かる問いは、問いの画面に出さない**（その書類の状態によらない）。まとまりの問いが全員の分とも書類で分かるなら、そのための分岐の問いも出さない（例: 保険証券を頼むと保険の件数も聞かない）。
- **書類は1通1画面**（画面の名前 `doc:<書類の ID>`）。画面の上に「送っていただきたい書類（1/2）」、見出しは「ご本人さまの源泉徴収票」（持ち主があれば。FP の見出しの「（ご本人）」は外す）。何のため・「お給料の額は、この書類の数字を使います。」（書類で分かる問いがあるときだけ）・「どこが写っていればよいか」・撮る前の注意（開いて出す）・撮る・ファイルを選ぶ・手元にない・あとで送る。
- **「手元にない」を選ぶと、その画面で聞く**:「大丈夫です。かわりに、お給料のだいたいの額をうかがいます（1問）。」と、その書類で分かるはずだった問い（範囲があれば範囲が先）。要る分岐の問い（保険の件数など）がまだなら、先に同じ画面で聞く。ほかの書類（「手元にない」でないもの）で分かる問いは聞かない。同じ問いを2通の書類で分かるとき（源泉徴収票と確定申告書など）は、両方が「手元にない」のとき前の書類の画面で1回聞く。答えは今までどおりの答えの一覧に入る（確かめの画面では「書類のかわりにうかがったこと」）。「手元にない」をやめれば、その答えは送らない（下書きには残る）。
- **「あとで送る」「まだ」のときは聞かない**。FP には書類の状態（あとで送る・まだ）が届く。「あとで送る」の書類には「用意できたら、お答えを送った後でも、期限までにこのページから送れます」（0158 のとおり答えの後も送れる）。
- 配偶者の方の書類は、配偶者の方が「いらっしゃらない」と答えたら出さない（まだの書類にも数えない）。
- **最初の画面**に「お給料と年金の額は、お送りいただく源泉徴収票・ねんきん定期便の数字を使います。そのぶん、お答えいただく問いが少なくなっています。」（書類で分かる問いがあるときだけ。何の・何を〔額・内容〕は書類のひな形の `topic`）。
- **撮る前の注意**（H-406）: 書類ごとに隠してよい番号（「マイナンバー（個人番号）は、写さないか隠してかまいません。」）と、「明るい所で、書類の全体が入るように、まっすぐ上から」「何枚かに分けてかまいません」「ほかのものが写らないように」。番号の決まった書類が無いときと、最初の画面の注意・FP の案内文は「マイナンバー・基礎年金番号・証券番号・口座番号は、写さないか隠してください。」（`HIDE_NUMBERS`）にそろえた。
- 答えを送った後の「書類を送る」の画面（0158）は、今までどおり頼んだ書類の一覧（1画面）で、撮る前の注意は上に1回。
- FP のアプリの見本の「見る」で、書類で分かる問いはその書類の画面を開く。

### 4. FP の画面（`app/src/workspace/hearing/WebBuilder.tsx`・`web.ts`）

- 書類の一覧を「収入・年金・貯蓄・投資・保険・住まい・ローン・家計・その他」に分けて出す。
- **誰の書類**: 人の書類は「ご本人」「配偶者の方」を選ぶ（一覧から足すとご本人。同じ書類をもうご本人の分で頼んでいれば配偶者の方）。預貯金などは「ご家族（まとめて）」も選べる。持ち主を変えると見出しの括弧も変わる（「源泉徴収票（ご本人）」）。見出しに括弧を残すのは、依頼の一覧・受け取った書類・保存するファイルの名前で、どなたの書類か分かるようにするため。書類待ちの1通（0102）から頼むときは、人の書類なら書類待ちの持ち主（ご本人・配偶者）を入れる。
- **その他の書類**: 名前・何のため・どこが写っていればよいかを FP が書く（名前が空なら発行できない）。
- **項目の行**: 頼んだ書類で分かる問いの行に「源泉徴収票（ご本人）の数字を使います」と「？」。「？」の説明は「源泉徴収票（ご本人）を頼んでいるので、お客さまの画面にはこの問い（ご本人の分）を出しません。お客さまが「手元にない」を選んだときだけ、この問いを出します。」。書類の欄にも「この書類の数字を使う問い（お客さまの画面に出しません）: 年収」。
- 発行のボタンの「問い N」は、書類で分かる問いを除いた問いの画面の数になる。
- 案内文の番号の注意を `HIDE_NUMBERS` にそろえた。

### 5. 依頼の形（0125 の追記）

- 選び方の書類（`RequestedDocument`）に、任意の欄 `owner`（`self`・`spouse`）を足した。問いの中の書類（`PacketDocument`）に、任意の欄 `covers`（2）を足した（問いの形の版の文字は 0.2 のまま。問いの形は内部で、ページは知らない欄を読まない）。
- 選び方の指紋に、持ち主を選んだ書類だけ持ち主を入れた（`[ID, 種類, 持ち主]`。持ち主の無い書類は前と同じ `[ID, 種類]` なので、前に発行した依頼の指紋の作り方は変わらない）。書類で分かる問いは、種類・持ち主・選んだ項目から決まるので指紋に入れない。
- 届いた答えの中身は変えない（書類で分かる問いは答えに入らない＝空欄。取り込みでは「お答えなし」で今の値を残す〔0139〕）。

### 6. 世帯ファイルの形式 0.71

- 依頼の記録（`hearing.web` の1件）の `record.selection.documents[]` に `owner` を足した（足すだけの MINOR）。書類の種類 `kind` に値が増えた（形は同じ文字）。前の版のアプリは持ち主を知らないので、版を上げて閲覧だけにする。変換の段は形式の版だけを書き換える（0.70 の段の後に積む。前の版の記録は欄が無い＝持ち主を選んでいない書類）。
- 見本 `crates/household-store/tests/fixtures/household-format/0.71/`（0.70 の見本の Web の依頼の記録の書類に持ち主〔ご本人〕と、持ち主を選んだ預貯金の書類〔配偶者の方〕を足したもの）。
- 事務所のひな形（0073 の `hearingTemplates`）も同じ選び方を持つが、読むときに形を広く受ける（`readHearingTemplates`）ので、事務所データの形式は変えない。

### 決めたこと（迷った所）

- **「あとで送る」は問いを出さない。FP には「あとで送る」と届く**。理由: 書類は期限まで何回でも送れる（0158）。問いを出すと、書類も届いて二度手間になり、「聞くことは少なく」に反する。届かなければ FP が面談で聞くか、状態を見て催促できる。「まだ」（何も選ばない）も同じ。
- **書類で分かる問いは、書類の状態によらず問いの画面に出さず、「手元にない」なら書類の画面で聞く**。理由: 書類の画面は問いの後にあるので、問いの画面に戻して出すと、お客さまが戻らないと答えられない。書類の画面で聞けば「その場で」答えられ、画面の数も増えない。
- **持ち主を選ばない人の書類は、問いを書類で分かるものにしない**（前に保存した事務所のひな形など）。理由: 誰の物か分からないまま両方の年収を出さないと、配偶者の方の年収が誰からも届かない。FP の画面に「誰の書類かを選ぶと、その方の問いをお客さまの画面に出さずに済みます」と出す。
- **1人の書類では、ご家族の合計の問いを書類で分かるものにしない**（簡易の票の預貯金の合計など）。理由: 1人分の残高ではご家族の合計にならない。預貯金を「ご家族（まとめて）」で頼めば合計も書類で分かる。
- **「お二人とも」の持ち主は作らない**。同じ書類を2回足すと、2通目は配偶者の方になる。理由: 1通に2人分のファイルが混ざると、どの写真が誰のものか FP が見分けにくい。
- **確定申告書と決算書は自営業の方の物（`taxReturn`）と、会社の決算書（`companyAccounts`）に分けた**。理由: 自営業の青色申告決算書・収支内訳書と、会社役員の会社の決算書では、見る所も分かる問いも違う。
- **年金額改定通知書は加入期間を書類で分かるものにしない**。理由: 通知書に加入月数は載っていない（FP が打てない）。
- **給与明細・生命保険料控除証明書・ほかのローン・家計簿・その他の書類は、書類で分かる問いを持たない**（頼んでも問いは減らない）。理由は1の表のとおり。
- **配偶者の方の書類は、配偶者の方がいらっしゃらないと答えたら出さない**。理由: 当てはまらない書類を「まだ」として残すと、確かめの画面で「まだの書類」に数えられる。

## 理由

- **対応の表を書類のひな形に持つ**: 書類と問いの結びつきを1か所で持てば、FP の画面（項目の行の言い方）とお客さまの画面（出さない・その場で聞く）が同じ表で動き、テストで確かめられる。
- **問いの中に `covers` を入れる**: お客さまのページとアプリは別に配る。ページが表を持つと、アプリとページの版が違うときに、FP の画面の言い方とお客さまの画面の出し方が食い違う。FP のアプリが決めた一覧を問いに入れれば、ページは一覧のとおりに動く。
- **持ち主を別の欄にし、見出しの括弧も残す**: 欄があれば書類で分かる問いを人ごとに決められる。見出しの括弧は、持ち主の欄を知らない画面（依頼の一覧・保存するファイルの名前）でも、どなたの書類か分かるようにするため。

## 代案（採らなかったもの）

- **書類で分かる問いを出し、「書類を送る方は答えなくて大丈夫です」と添える**（前のおすすめ）: 利用者の判断で、そもそも出さない。
- **「手元にない」のとき、問いの画面に問いを戻す**: 書類の画面は問いの後にあるので、お客さまが戻らないと答えられない。
- **「あとで送る」でも問いを出す**: 書類が後で届くと二度手間。
