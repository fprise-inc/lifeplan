# 0115. 注文住宅（土地を買って建てる）: 土地と建物の代金・支払いの時期・つなぎ融資と土地先行融資・住宅ローン控除・固定資産税・評価と世帯ファイルの形式 0.54

- 状態: 採用（一部未確定）（2026-11-03）
- 固定の強さ: β公開から変えない（骨格）。世帯ファイルの欄 `residences[].purchase.land`（`at`・`price`・`downPayment`・`costs`）と `residences[].purchase.payments[]`（`id`・`at`・`amount`・`kind`）の名前と意味（購入の `price`・`downPayment`・`costs` は土地と建物の合計のままで、土地と支払いはその内数。土地があれば注文住宅）、計算エンジンの読み方（内数をそれぞれの月に払い残りを引き渡しの月に払う・合計を超える分は止めて知らせる・土地を決済の月から土地の代金で評価し建物は引き渡しの年から）は骨格。推定の目安の値・根拠の文・欄の並びと標準と詳細の分け方・つなぎ融資の費用の式は後から変えてよい（変えたら追記に書く）
- 前提にする記録: 0008（値の箱と推定）、0011（形式の版と変換の段）、0025（持ち家の評価と売却）、0028（土地と建物の行）、0035（足すだけの形・並びの要素の ID）、0041（値の状態の操作）、0052（住まい・ローン。2026-11-03 の追記の購入の種類）、0053（譲渡所得の税の額の口）、0111（事務所の推定の値）、0112（固定資産税の推定）

## 背景

- 住宅の購入の種類（新築・中古×マンション・戸建て。0052 の追記 2026-11-03）を入れたとき、注文住宅（土地を買って建てる）は後回しにした。注文住宅は、土地の代金と建物の代金が分かれ、支払いが土地の決済・建物の契約金・着工金・中間金・引き渡しに分かれ、資金はつなぎ融資か、土地と建物で分けて借りる住宅ローン（土地先行融資・分割の融資）で用意するのがふつうで、購入の月に全部を払う今の形（頭金と諸費用を購入の月に払い、評価は購入の月から）では、引き渡しまでの手元のお金の動き・土地の分のローン・土地の評価が表せなかった。
- 全国の土地付注文住宅の平均は、建設費 3,737.6万円・土地取得費 1,575.3万円・手持金 481.1万円（住宅金融支援機構「フラット35利用者調査」2025年度 集計表 p.20〔取得 2026-11-03、集計表 PDF の sha256 `8c3a0ddcd3f68994ecd733bfa6154891acecdcdd52465ce020e7c1fa1c404a8f`〕）。土地の分は合計の約3割（首都圏は約4割）で、建物と土地で金額が大きく、時期もずれる。

## 決定

### 1. 世帯ファイルの形（形式 0.54）

- 住宅の購入 `residences[].purchase` に、注文住宅の土地 `land` を足す: `at`（土地の決済の月）・`price`（土地の代金）・`downPayment`（土地の決済で払う頭金。省略は0）・`costs`（土地の諸費用。省略は0）。**`land` があれば注文住宅**（建て方は戸建て・新築か中古かは新築を入れる。種類の印は別に持たない）。
- 引き渡しの前に頭金から払う建物の代金 `payments[]` を足す: `id`（並びの要素の ID。0035 の5）・`at`・`amount`・`kind`（契約金・着工金・中間金・その他。表示だけ）。
- **購入の `price`・`downPayment`・`costs` は土地と建物の合計のまま**で、土地と支払いはその内数。前の版の読み手（購入の予定とつながるローンの借入額の推定・住宅資金の援助・持ち家の評価の基にする額）は合計をそのまま読める。建物の代金は合計−土地の代金（世帯ファイルに持たない）。
- 足すだけの MINOR（0035 の1）。前の版のアプリは土地を読めない（土地の決済の支払いと土地の評価が落ちる）ので、版を上げて閲覧だけにする。`0.53` → `0.54` の変換の段は版だけを書き換える。見本 `crates/household-store/tests/fixtures/household-format/0.54/`（前の版の見本の本文に、注文住宅の購入〔土地の決済・着工金〕と土地の分のローンを足したもの）。

### 2. 計算エンジン

- `housing.residence` 改訂5: 土地の決済の月に土地の頭金と土地の諸費用、`payments` の月にその額（頭金から）、残りの頭金と諸費用を購入の月（引き渡し）に払う。表の行は前と同じ（`cf.expense.housing.purchase.downPayment`・`.costs`）、計算式ID は `housing.residence.landDownPayment`・`landCosts`・`buildingPayment`。内数の合計が頭金・諸費用を超える分は、早い支払いから順に合計で止め、知らせ `N_LIMIT_APPLIED`（`residence.purchase.split`）を出す（払うお金の合計は頭金・諸費用のまま）。
- `housing.valuation` 改訂3: 土地があれば、持つ期間を土地の決済の月からにし、引き渡しの年より前の年末は土地だけを出す（建物は0）。評価の基にする額が購入の価格（`valuation.value` が無い）なら、土地は土地の代金のまま（割合で分けない。土地の割合の知らせ `N_DEFAULT_USED` も出さない）、建物は残り。土地は今までどおり基にする年（引き渡しの年）の翌年から上昇率で動かす（土地の決済から引き渡しまでの1年ほどの値動きは見ない）。`valuation.value` を入れた持ち家は今までどおり割合で分ける。分ける計算は SDK の `landBuildingValuer` に土地の額 `landAmount` を渡せるようにした（住まい以外の不動産は変わらない）。
- 住宅ローンの返済・住宅ローン控除の計算は変えない（土地の分のローンは借入の月から返し、控除は入居の年から、同じ人のローンを合わせて借入限度額で止める今の計算で扱える）。固定資産税は今までどおり住み始めの年から入れた額を払う（0112 の通り計算エンジンは固定資産税を計算しない）。

### 3. 画面の入れ方（簡単な形を既定に）

- 「住宅の購入」の購入の種類に「注文住宅（土地を買って建てる）」を足した。選ぶと土地を推定で足し、ほかの種類にすると土地と `payments` とその値の状態の行を外す（土地があると計算が変わるので、種類を変えたら残さない。0052 の1 の「種類を変えても値を消さない」の例外）。
- **標準の欄**: 購入の種類・建物の引き渡しの時期（前の「購入の時期」の欄）・土地と建物の合計（前の「物件の価格」）・土地の決済の時期・土地の代金・頭金（合計）・諸費用（合計）。合計の額と引き渡しの時期だけでも、ほかは推定で動く。
- **詳細の欄**: 建物の代金（合計−土地の代金を見せ、直すと合計を土地の代金＋建物の代金にし、土地の代金の推定の印を外す）・頭金のうち土地の決済で払う額・諸費用のうち土地の決済で払う額・「＋ 建物の代金の支払い（契約金・着工金・中間金）」（種類・時期・頭金から払う額。足した直後は土地の決済の3か月後・0円）・「＋ 土地の分のローン（土地先行融資）」。持ち家の評価の「土地の割合」の欄は出さない（土地の代金で分ける。評価額を入れたときは出す）。
- **推定**（推定のままの値だけ入れ直す。FP が入れた値は変えない。根拠の文に値を入れる。0041）:

| 値 | 推定 | 目安（事務所の推定の値 `hearing/src/presets.ts`） |
|---|---|---|
| 土地の代金 | 合計×土地の割合（持ち家の評価の欄 → 前提条件 → 目安） | `preset.realEstate.landShare` 30%（上のフラット35利用者調査の全国の29.7%。出典を書き直した） |
| 土地の決済の時期 | 引き渡しの9か月前 | `preset.housing.purchase.custom.landLeadMonths`（出典なし。設計・建築確認の2〜4か月と工事の4〜6か月） |
| 土地の決済で払う頭金 | 頭金のうち土地の代金まで（自己資金は先に来る支払いに充てる） | — |
| 土地の諸費用 | 土地の代金×6% | `preset.housing.purchase.costsRate.land`（出典なし。仲介手数料〔上限は3%＋6万円と消費税〕・登記・印紙・固定資産税の精算。5〜8%） |
| 諸費用（合計） | 土地の諸費用＋建物の代金×5%（新築の諸費用の割合 `preset.housing.purchase.costsRate`）＋つなぎ融資の利息と手数料 | 下の4 |

### 4. つなぎ融資と土地先行融資

- **既定はつなぎ融資**: 土地の分のローンが無ければ、引き渡しまでの支払い（土地の代金・着工金・中間金）はつなぎ融資で払い、引き渡しの月に住宅ローン（本融資）を1本借りるとみなす。借入額の推定は今までどおり合計−頭金（0052 の4）。
- **つなぎ融資の費用**は諸費用の推定に入れる（住宅ローンを組むときだけ。組まなければ0）: 土地の代金のうち土地の決済の頭金を除いた額を土地の決済から引き渡しまでの月数、建物の代金×着工金・中間金の割合（60%。`payments` で頭金から払う分は除く）を平均の月数（3か月。引き渡しまでの月数を超えない）だけ、年3%で借りるとみなした利息に、事務手数料・印紙代（10万円）を足し、万円に丸める。根拠の文に内訳を書く。目安は `preset.housing.purchase.custom.bridgeRate`・`bridgeFee`・`interimShare`・`interimMonths`（どれも出典なし。金融機関が公表するつなぎ融資の金利は年2〜4%程度、手数料は0〜10万円程度。支払いの割合は契約金1割・着工金3割・中間金3割・残金3割の目安）。つなぎ融資は借入（負債）として持たない（短い借入で、引き渡しの本融資で返すため。利息と手数料だけをお金の動きに入れる）。
- **土地の分のローン（土地先行融資）**: 「＋ 土地の分のローン」で住宅ローンを1本足し、借入の年月を土地の決済の月、借入額を土地の代金−土地の決済の頭金の推定にする。引き渡しのローンの推定の借入額は、合計−頭金からこのローンの分を引いた額に入れ直る（借入額の合計は合計−頭金と合う。合わなければ今の知らせ）。土地の分は土地の決済の月から返済が始まり、バランスシートでは土地の年末から土地と借入が載る。つなぎ融資の費用は着工金・中間金の分だけになる。
- 購入の予定とつながるローン（借入額の推定・控除の仮の条件・固定資産税の長期優良住宅の読み・控除の新築か中古か）は、借入の年月が引き渡しの月か土地の決済の月のローンにした（`housingCredit.ts` の `purchaseLink`、`propertyTax.ts` の `purchaseLoans`）。

### 5. 住宅ローン控除

- 土地の分のローンの控除の仮の条件: 住まいはその注文住宅、**入居は注文住宅の住み始め**（借入の月ではない）、新築。取得対価は、土地と建物で分けて借りるときは**ローンごとに土地の代金・建物の代金**（計算エンジンは取得対価をローンごとに止めるため。合計で止める形と同じになる）、分けないときは合計。
- 家屋の新築の日前2年以内に取得した敷地の借入金が対象（金融機関からの借入は、家屋に抵当権を付けることも要件。国税庁 タックスアンサー No.1211-1、措置法施行令 第26条）なので、土地の決済から引き渡しまで24か月を超えると、仮の条件に「控除の対象にしない」（`creditDisabled`）を入れ、欄の下で知らせる。抵当権などのほかの要件は見ない（満たすとみなす）。
- つなぎ融資は控除の対象にしない（借入として持たないので計算にも入らない）。引き渡しの本融資は今までどおり（つなぎ融資を返した後の住宅ローンとして、土地と建物の合計の取得対価で控除を計算する）。

### 6. 固定資産税の推定（0112）と知らせ

- 注文住宅の推定は、土地の割合を土地の代金÷合計にし（評価額の目安を土地と建物それぞれの代金から作る）、新築の戸建て（軽減3年、長期優良住宅は5年）として計算する。根拠の文は「土地の代金・建物の代金・注文住宅（新築の戸建て）」。最初の年・引き渡しの年の扱いは 0112 のまま（引き渡しの年もこの額を払う）。
- 計算に入れていないことと、合わない入力は、諸費用の欄の下に知らせる: 土地の決済が引き渡しより後、2年を超える土地の分のローン（控除の対象にしない）、引き渡しの2年以上前に土地を買ったときの引き渡しの前の年の土地だけの固定資産税（計算に入れていない。「出るお金」の行で入れる）、内数が合計を超える。

## 理由

- **合計を持ち、土地と支払いを内数にする**: 合計を読む今の部品・推定・見本の世帯がそのまま動き、土地と支払いを入れていない世帯の計算は変わらない。合計の額と時期だけでも、内数を推定で入れれば注文住宅として動く（「簡単な形を既定に」）。
- **土地を `land` の有無で注文住宅と見分ける**: 種類の印を別に持つと、印と土地の有無が食い違う形ができる。
- **つなぎ融資を負債にしない**: つなぎ融資は数か月〜1年の借入で、本融資の実行で返すので、資産と負債の推移に載せても見る人の判断に効かない。手元のお金に効くのは利息と手数料で、FP の実務でも諸費用の一つとして見積もる。
- **土地の分のローンは住宅ローンの1本として足す**: 返済・金利・団信・控除の欄と計算が今の住宅ローンのまま使える（ペアローンと同じ考え方）。
- **ローンごとの取得対価**: 計算エンジンは取得対価をローンごとに当てるので、2本とも合計を入れると合計の2倍まで控除の対象になる。

## 代案（採らなかったもの）

- **土地の購入と建物の購入を2つの購入（住まいの2件）にする**: 住まいの期間・固定資産税・評価が2件に分かれ、住み始めの前の土地を住まいとして持つ形が無い。
- **建物の代金を世帯ファイルに持つ**: 合計−土地の代金で決まり、値が2か所になる。
- **つなぎ融資を借入の種類として計算エンジンに足す（利息だけ払い、引き渡しで一括で返す）**: 利息だけ・一括返済の返し方が今の返済の部品に無く（0052 の未確定）、効くのは利息と手数料だけ。
- **建物の分割の融資（着工金・中間金を本融資の分割で借りる）を返済の部品で表す**: 返し方の部品が要る。今は着工金・中間金の利息をつなぎ融資の費用と同じ式で見積もる。
