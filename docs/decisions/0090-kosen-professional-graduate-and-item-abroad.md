# 0090. 高専の段、専門職大学院（法科大学院）の段と学費の統計、「＋ 項目を追加」の留学と、世帯ファイルの形式 0.42

- 状態: 採用（一部未確定）（2026-10-31）
- 固定の強さ: β公開から変えない（骨格）。教育の段の種類 `kosen`・`graduateProfessional`、系統の値 `law`、マスタデータの値ID `education.statistics.kosen.*`・`education.statistics.graduate.national.law.*`・`education.statistics.graduate.private.{law,professional}.*`、制度データの値ID `educationSupport.highSchool.kosenPublicAnnual` は骨格。画面の見せ方は後から変えてよい

## 背景

- 0089 の未確定に、高専の段、法科大学院・専門職大学院の学費、0088 の未確定に「＋ 項目を追加」の留学を残していた。
- 高専（高等専門学校）は15歳の学年から5年（本科）。国立の高専の入学料・授業料は国立高等専門学校機構が決めていて、額を定めた規則の条文は見つけられなかった。
- 前提にする記録: 0010、0062、0088、0089。

## 決定

### 1. 高専の段（`stage: kosen`）

- 15歳の学年の4月から5年。高校の段の詳細の「高校・高専」で、高校（3年）と高専（5年）を入れ替える（段の ID は今のまま。入れた年額・入学金・部活動などの費用・学校外の費用・給食費は外す）。高校と高専は、どちらか1つ（足すボタンも片方だけ）。
- 学費: 国立は国立高等専門学校機構の入学料 84,600円・授業料 年234,600円（統計の推定。授業料は4月と10月に半分ずつ、入学料は入学の前の3月）。公立・私立は統計の目安が無いので、年額を入れるまで未入力の警告（0円で計算中。計算エンジンの知らせ `N_INPUT_REQUIRED`）。学校外の費用・部活動・給食費の欄は出さない（子供の学習費調査に高専の区分が無い）。
- 高専の後の大学・短大・専門学校（編入）は、高専を出た翌月の4月から（`education.cost` の改訂8）。3年次に編入するときは大学の段の在学年数を2年にする（「?」に書いた）。子の独立も、その学校を出た後。
- 高等学校等就学支援金: 高専の1〜3年に、国公立は月19,550円（年234,600円。授業料の全額に当たる）、私立は私立の高等学校等の額（`education.support` の改訂6）。4・5年は高等教育の修学支援の対象だが、まだ計算しない（知らせ `N_NOT_SUPPORTED`・`educationSupport.higher.kosenUpper`）。専攻科（2年）は段に持たない（大学などの段で近づける）。

### 2. 専門職大学院の段（`stage: graduateProfessional`。系統 `field: law` は法科大学院）

- 前の段（大学など・修士）を出た翌月の4月から（大学院の段と同じ。0089）。在学年数の既定は2年、法科大学院は3年（法学既修者の2年は在学年数で直す）。
- 学費: 国立の法科大学院は省令の別表の「法科大学院」（授業料 804,000円・入学料 282,000円）、国立のほかの専門職大学院は大学院の研究科の標準額（535,800円・282,000円）。公立は公立大学の大学院の平均（0089。課程で分かれていない）。私立は「私立大学大学院入学者に係る初年度学生納付金等平均額」の専門職学位課程の「法科大学院」（授業料 1,194,241円・入学料 203,311円・施設設備費 134,172円）と「その他」（1,035,086円・209,723円・31,500円）。
- 画面: 大学などがある進路に「＋ 専門職大学院」（詳細）。種類（専門職大学院〔教職・経営など〕／法科大学院）は標準。

### 3. 「＋ 項目を追加」の留学

- 子を選んだ留学は、その子の進路に高校・大学・短大・専門学校があれば、子ども・教育のカードの留学（教育の目標の `abroad`。0088）を1回足して、子ども・教育のカードを開く（入力のホームのピンにはしない。留学は進路の中の物なので、子のカードにまとめる）。
- 進路に高校・大学などが無い子・子を選ばない留学は、今までどおり出るお金の行（子を選ばなければライフイベント）。前に足した留学の行は書き換えない。

### 5. 世帯ファイルの形式 0.42

- 選べる値を足すだけの MINOR（段の種類 `kosen`・`graduateProfessional`、系統 `law`）。0.41 のエンジンはこの値を知らずに計算できないので、版を上げて閲覧だけにする。0.41 → 0.42 の変換の段は形式の版だけを書き換える。
- 見本 `crates/household-store/tests/fixtures/household-format/0.42/`（0.41 の見本の大学院の段のある子に私立の法科大学院、インターナショナルスクールの高校の子の高校を国立の高専にした物）。

## 理由

- **高専を高校と入れ替える段にする**: 高専は高校の年齢から始まり、高校と同時には通わない。高校の段と別の段にすると、両方が入って二重になる。
- **国立の高専の額を機構の資料で**: 規則の条文が見つからなくても、機構の公表した額は全国の国立高専で同じで、就学支援金の国立の高専の額（授業料の全額）と一致する。
- **留学を子のカードに入れる**: 「＋ 項目を追加」と子の区画の「＋ 留学」で、同じ留学が別の形にならないようにする。
