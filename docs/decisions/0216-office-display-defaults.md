# 0216. 結果のタブ・資産と負債のタブの表示の設定に事務所の既定値を足し、世帯では「事務所の既定値に従う」を印で持つ（0213 の段C）

- 状態: 採用（一部未確定）（2026-11-15）
- 固定の強さ: 世帯ファイルの欄 `display.followOffice`（形式の版 0.80）と事務所データの欄 `display`（`defaults.version: 4`）は、AI接続口の道具からも読む名前なので、足すことはあっても別の意味に使い回さない。次は固定: 前からある世帯は今の値のまま（事務所の既定値を変えても変わらない）、事務所の既定値を変えても作った世帯にそろえる操作は出さない、事務所の既定値はカスタム層に置かない（0016 の 2026-11-02 の追記の3）、AI は設定を直接変えない（変わるのは FP が「反映する」を押したときだけ）、どの設定でも隠せない知らせ（0213 の1）は今のまま。画面の言葉・区画の並び・印の見た目は後から変えてよい
- 前提にする記録: 0213（表示の設定の全体の形・段A）、0215（段B の前半。案を出す道具・承認の画面・前の値）、0214（前提条件の事務所の既定値と「事務所の既定値」「この世帯だけ」の見せ方）、0073（事務所の既定値）、0027（資産と負債のタブ）、0032（お金の3つの分け方）、0011 の5（世帯ファイルの形式の版）

## 背景

- 結果のタブ・資産と負債のタブの表示の設定（出す数字・「○歳時点」の年齢・比較の仕方・家計の体力の目安・「時点を並べる」の既定・お金の3つの分け方など）は、世帯ごとに世帯ファイルの本文の `display` に持っていた。事務所で「いつも85歳時点で話す」「いつも左右に並べて見せる」と決めていても、FP は世帯ごとに同じ設定をし直していた。
- 0213 の段C は、この設定に事務所の既定値を足し、値を変えていない世帯は事務所の既定値に従う形にすると決め、世帯ファイルの形（「値を変えていない」を欄が無いことで持つか、印で持つか）を未確定にしていた。

## 決定（利用者の決定 2026-11-15）

### 1. 対象の11件

- `result.metrics`（出す数字）・`result.atAge`（「○歳時点の金融資産」の年齢）・`result.layout`（比較の仕方）・`result.invBreakdown`（口座の内訳を表示）・`result.invPeriods`（運用の期間を表示）・`balance.health`（家計の体力の目安を表示する）・`balance.guide`（家計の体力の目安の幅）・`balance.points`（「時点を並べる」の既定）・`balance.moneyThree.wording`・`balance.moneyThree.months`・`balance.moneyThree.years`（お金の3つの分け方）。並びは `app/src/workspace/settings.ts` の `OFFICE_DISPLAY_IDS` の1か所。
- この世帯で並べる時点（`balance.columns`）と対策に足した項目（`result.addedItems`。物の ID を含む）は世帯だけのまま（事務所の既定にしない）。事務所データに書いても読まない。

### 2. 事務所データの形（`defaults.version: 4`）

- 足すだけの欄 `display`: 世帯ファイルの本文の `display` と同じ形（`{ result: {…}, balance: { health, guide, points, moneyThree: {…} } }`）で、提供元の既定と違う欄だけを持つ（全部が既定なら欄を持たない）。読むときは欄ごとに世帯と同じ関数（`readDisplayPair`）で読み、読めない値は提供元の既定にする。「○歳時点」の年齢は選択肢の年齢（60〜100歳の5歳ごと）だけを読む。`columns` は読まない。
- 版 1〜3 の事務所データはそのまま読める（欄が無い＝提供元の既定）。前の版のアプリは知らない欄を読まずに通すので、版 4 の事務所データも読める（前の版のアプリで保存し直すと `display` は消える。0215 の `displayHistory` と同じ）。
- 事務所の既定値の画面に区画「結果のタブ・資産と負債のタブの表示の設定」を足した（対策に最初から出す項目の次。`office/DisplayDefaultsSection.tsx`）。欄の部品は世帯の表示の設定と同じ物（時点を並べるの既定・家計の体力の目安の幅）を使い、家計の体力の目安の分母には「世帯から決める（既定）」も選べる。パネルの「保存」で書く（手で変えた値は前の値に残さない。0215 の5 のまま）。「既定に戻す」で提供元の既定にする。
- AI接続口に渡す見せ方の欄（`ai_share::display::office_display_of`）に `display` を足した（前の値 `displayHistory` は今までどおり渡さない）。

### 3. 世帯ファイルの形（形式の版 0.80）と、前からある世帯の読み方

- 「事務所の既定値に従う」は、欄が無いことでなく**印**で持つ: `display.followOffice`（11件の id の並び。知らない id・世帯だけの設定・重なりは読むときに捨てる）。印のある設定は事務所の既定値を読み（`resolveDisplay`）、その世帯で値を変えたら印を外してその世帯の値を持つ（`withOwnChange`。変えた設定だけ。事務所の既定値と同じ値に変えても印は付けない）。「事務所の既定値に戻す」で印を付け直す（`withFollowOffice`）。
- 印のある設定の `display.result`・`display.balance` の値は、印を付けたとき（新しい世帯を作ったとき・「事務所の既定値に戻す」を押したとき）の事務所の既定値の写しで、事務所の既定値を変えても書き換えない（事務所の既定値を変えただけでは、作った世帯の世帯ファイルを書かない）。画面・提案書・持ち帰り用のレポート・AI接続口は、印を見て事務所の今の値を読む。
- 新しく作る世帯（空の世帯・見本の世帯から作る世帯・AI の候補から作る世帯）は、11件とも印を付け、世帯の値にも作ったときの事務所の既定値を書く。見本・空の世帯を開いたときも、前に開いていた世帯の表示の設定を持ち越さず、事務所の既定値に従う形で開く。
- **前からある世帯（印の無い世帯ファイル）は、どの設定も「この世帯だけ」として今の値のまま読む**（今の値が提供元の既定と同じでも、従う印を付けて読まない）。理由:
  - 2つの読み方のどちらでも、読んだその時の見た目は変わらない（事務所の既定値はまだ何も決めていない＝提供元の既定なので、既定と同じ値に印を付けても見た目は同じ）。違いが出るのは、その後に事務所の既定値を変えたとき。
  - 「今の値が既定と同じなら従う印を付けて読む」形にすると、事務所の既定値を変えたときに、FP が一度も触っていない前からある世帯の結果のタブ・提案書の「○歳時点」・バランスシートの図の時点・お金の3つの分け方が黙って変わる。お客さまに見せた提案書と、開き直した画面・作り直した提案書がずれる（0073 の「作った世帯は黙って変えない」と同じ理由）。読むたびに事務所の今の既定値と比較する形なので、事務所の既定値を変えた前と後で、同じ世帯ファイルの読み方が変わってしまう。
  - 「この世帯だけ」と読む形なら、前からある世帯は事務所の既定値を変えても変わらない（利用者の決定の「印の無い世帯は変わらない」と同じ）。従わせたい世帯は、表示の設定の「事務所の既定値に戻す」で設定ごとに従わせられる。
- 形式の版を 0.80 に上げた（足すだけの MINOR。本体の変換の段 0.79 → 0.80 は版だけを書き換える。前の版の世帯は欄が無い＝印なし）。0.79 は同じ時期に別の変更（個人事業税の業種の区分）が使う版で、その段が入るまでは 0.78 から直接 0.80 にする（変換の中身は同じ。その段が入ったら 0.79 → 0.80 の段にする）。見本 `0.80/` は 0.79 の見本（0.78 の見本に個人事業税の業種の区分を足した形）に印3件（比較の仕方・家計の体力の目安を表示するか・何年先まで）を足した形。
- **前の版のアプリが世帯ファイルを書き戻したとき**: 前の版のアプリは表示の設定の区画の知らない欄を読み落とすので、書き戻すと印が消え、印のあった設定は写しの値（印を付けたときの事務所の既定値）の「この世帯だけ」になる（事務所の既定値に従わなくなる）。これを避けるため形式の版を上げ、前の版のアプリは 0.80 の世帯ファイルを閲覧だけで開く（0.77 の `health`・0.78 の `endYearChoice` と同じ考え方。書き戻さない）。閲覧で見えるのは写しの値なので、印を付けた後に事務所の既定値を変えていれば、前の版のアプリの見た目は新しい版と違うことがある。

### 4. 世帯の表示の設定の見せ方（0214 にそろえる）

- 結果のタブの「表示の設定」と資産と負債のタブの「表示の設定」に、設定ごとに小さく「事務所の既定値」か「この世帯だけ」を出し、「この世帯だけ」には「事務所の既定値に戻す」を置く（見た目は前提条件の欄の印と同じ。`presentation/OfficeMark.tsx`）。印の説明（カーソルを合わせると出る文）に事務所の今の既定値を添える。
- 表示の設定の外で変える設定も同じ画面に印を並べる: 結果のタブの「口座の内訳を表示」「運用の期間を表示」（資産の推移のグラフの上のチェック）と、資産と負債のタブのお金の3つの分け方の「何か月分」「何年先まで」（区画の欄）。
- 「事務所の既定値に戻す」・その世帯で変えたこと・印は、元に戻すの履歴に入る（履歴の状態に印を足した）。

### 5. 事務所の既定値を変えたとき

- 印のある世帯は、開いている世帯も含めてすぐ従う（「FP顧問料の一文」を出すかが変わったら、顧問料の枠も足す・外す）。印の無い設定・前からある世帯は変わらない。作った世帯にそろえる操作は出さない。

### 6. 提案書・持ち帰り用のレポート

- 提案書の目標の年齢・バランスシートの図の時点、持ち帰り用のレポートの目標の年齢・お金の3つの分け方は、画面と同じく印を見て読んだ値（事務所の既定値に従う設定は事務所の今の値）で出す。控えに残すのは今までどおり出したときの値。

### 7. AI の案（`propose_display_settings`）と `get_display_settings`

- 案を出せる設定（一覧の `proposable`）を18件にした（0215 の7つ＋11件）。11件の案はどれも事務所の既定値の案で、承認の画面・「反映する」（すぐ保存）・前の値（設定ごとに直近3件。`defaults.displayHistory`）・前の値に戻すは 0215 と同じ作りで効く。承認の画面の効き方は「事務所の既定値に従う世帯にすぐ効きます（世帯で変えた設定と、前からある世帯は変わりません）」。
- 一覧の11件は `scope: both`・`officeEffect: followers`（新しい値）・`change.office` に事務所の既定値の画面の区画の名前・`stored.office` に `defaults.display.…`。
- 値の確かめに3つの形を足した（`app/src/connector/displayProposal.ts`。接続口とアプリの承認の画面が同じ関数を使う）: 真偽（`true`・`false` だけ。文字は受けない）・整数（選べる値があればその中から＝「○歳時点」の年齢。無ければ範囲の中＝何か月分 1〜24・何年先まで 1〜30）・家計の体力の目安の幅（`months`・`risk` は下限より大きい上限で範囲の中、`debt` は 1〜100、`basis` は2つの分母か書かない）。並び（出す数字・時点を並べるの既定）は選べる値の中から重ならずに（時点は2〜4つ）。知らない名前・近い値は「〜のことですか」を添えて断る。アプリ本体の受け口の並び（`ai_share::display_proposals::PROPOSABLE_IDS`）も18件にした。
- `get_display_settings` の `current.office` に11件の事務所の既定値を入れた。渡された世帯の `current.household` の11件には `followsOffice`（`true` は事務所の既定値に従っていて値は事務所の今の値、`false` はこの世帯だけの値）を添えた（世帯の見せ方の区画は、印も含めて今までどおり数・真偽・短い英数字だけを渡す）。
- 渡された世帯ごとの案は、この記録に入れない（段B の後半。次）。

## 理由

- 印で持つ: 欄が無いことで持つと、前の版のアプリや読み書きの途中で欄が欠けた世帯が、FP の意図と関係なく事務所の既定値に従い始める。印なら「従う」は FP か新しい世帯の作成が付けたときだけになる（利用者の決定）。
- 前からある世帯は今の値のまま: 3 のとおり。提案書に出る設定（「○歳時点」の年齢・時点・お金の3つの分け方）が、事務所の既定値を変えただけで前からある世帯で変わらないようにした。
- 印のある設定にも値の写しを書く: 前の版のアプリで閲覧したときにも、作ったときと同じ見た目になる。事務所の既定値を変えたときに写しを書き換えないのは、事務所の既定値を変えただけで作った世帯の世帯ファイル（保存した日時・直した人）を書かないため。
- 事務所の既定値と同じ値に変えても印を付けない: 利用者の決定（その世帯で値を変えたら印を外す）のとおり。FP が「この世帯はこの値」と決めた設定を、事務所の既定値がたまたま同じだからといって従わせない。従わせるのは「事務所の既定値に戻す」。

## 代案（採らなかったもの）

- **前からある世帯で、今の値が既定と同じ設定には従う印を付けて読む**: 3 の理由。読んだ時の見た目は変わらないが、その後に事務所の既定値を変えると、FP が触っていない前からある世帯と提案書の見た目が黙って変わる。
- **「事務所の既定値に従う」を欄が無いことで持つ**: 前の版のアプリが書き戻すと、FP が決めた世帯の値まで事務所の既定値に従うようになることがある（0213 の未確定の注記）。利用者の判断で印にした。
- **事務所の既定値を変えたら、作った世帯にそろえる操作を出す**: 利用者の判断で出さない（従う印のある世帯は自然に従う）。
- **事務所の既定値をカスタム層に置く**: 0016 の 2026-11-02 の追記の3 のまま置かない。
