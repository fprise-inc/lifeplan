# 0085. 雑所得（公的年金等以外）を1つの所得の区分にする・所得の区分と表の行を分けて持つ・副業の所得の区分・表の行「雑所得」と、世帯ファイルの形式 0.36

- 状態: 採用（一部未確定）（2026-10-29）
- 固定の強さ: 所得の区分の表（`INCOME_CATEGORY_OF`。課税の扱い → 所得の区分）と、雑所得の赤字の差し引き方（雑所得の中だけ・公的年金等の雑所得から引く・ほかの所得と通算しない）、事業所得の赤字の通算、表の行 `cf.income.other.miscellaneous`、`income.flows` の約束の版 1.1 の任意の欄（`miscellaneousNet`・`businessNet`）、`insurance.income` の約束の版 1.2 の任意の欄（`miscellaneousNet`）、`tax.totalIncome` の約束の版 1.7 の任意の欄（`miscellaneousLoss`）は骨格。副業の所得の区分の欄の出し方・知らせの文・種類ごとの表の行の選択肢は後から変えてよい（変えたら追記に書く）
- 前提にする記録: 0006（約束の版と改訂）、0011（世帯ファイルの形式と一方向の移行）、0035（足すだけの形の版上げ）、0044（お金の行・課税の扱い）、0064（計算の知らせ）、0081（民泊・宿の所得の区分・青色申告・純損失の繰り越し）

## 背景

- 入るお金の行の「副業・雑所得」の表の行は、エンジンの表の行の一覧に「雑所得」が無いため「副業」「その他の収入」の2つにしていた（0044 の追記 2026-10-29）。FP から「雑所得は計算できる方がよい。ほかの項目でも使う可能性があるので仕組みを見直して」と求められた。
- 調べた今の作り（直す前）:
  - **所得の区分と税・社会保険料**: 合計所得金額の部品（`tax.totalIncome`）が、給与所得（`tax.employmentIncome`。所得金額調整控除の後）・公的年金等に係る雑所得（`tax.publicPensionIncome`。公的年金・iDeCo と企業型DC の年金・確定給付企業年金など・小規模企業共済の分割）・事業所得（自営の働き方の期間 `income.business`・入るお金の行・事業所得の民泊・宿）・不動産所得（`asset.realEstate`）・公的年金等以外の雑所得（保険 `insurance.income`・入るお金の行・雑所得の民泊・宿）・一時所得（保険・入るお金の行。特別控除の後の2分の1）を足して total（総所得金額等）にする。退職所得（`tax.retirementIncome`）と分離課税の譲渡所得（入るお金の行・土地建物等）は total の外に添えて、合計所得金額の判定にだけ足す。所得税・住民税・国民健康保険料・後期高齢者医療の保険料は、どれもこの部品の total（と separate）を読む。
  - **入るお金の行**: 行は課税の扱い（`taxTreatment`。省略は種類の既定）と表の行（`row`。省略は種類の既定）を別々に持ち、税の計算は課税の扱いだけで決まっていた（表の行は見せ方だけ）。副業は雑所得（業務）が既定。部品 `income.flows` は課税の扱いごとに人×年で足し、**区分ごとに0円で止めて**いた（0044 の2: 損失はその区分の中で0円）。そのため、雑所得（業務）の赤字は雑所得（その他）の黒字から引かれず、**事業所得を選んだ行の赤字もほかの所得と通算されていなかった**。
  - **公的年金等の雑所得**: 公的年金等控除で別に計算し、公的年金等以外の雑所得とは別の欄（`publicPension`）。雑所得の民泊・宿の赤字だけが、公的年金等の雑所得から引かれていた（0081 の6）。
  - **個人年金保険の年金**: 受取人＝契約者なら公的年金等以外の雑所得（必要経費＝払込保険料の総額×その年の年金額÷年金の総額。終身は年金の総額が分からないので必要経費0円）。保険の部品が0円で止めるので、元本割れの赤字はほかの雑所得から引かれていなかった。収入保障保険の月額（契約者が受け取る）も雑所得。
  - **確定申告不要制度**: 「公的年金等に係る雑所得以外の所得金額」を給与所得＋事業所得だけで見ていたので、副業・売電・個人年金の雑所得がある年金の人も、申告せず追加の所得税を払わない扱いになっていた。

## 決定

### 1. 所得の区分（税の計算）と表の行（見せ方）を分けて持つ

- エンジンの SDK に **所得の区分** の表 `INCOME_CATEGORY_OF`（`engine/src/sdk/incomeKinds.ts`）を置く。課税の扱い → 所得の区分（`salary` 給与所得・`business` 事業所得・`miscellaneous` 公的年金等以外の雑所得・`temporary` 一時所得・`capitalGains` 分離課税の譲渡所得・`null` 所得に入れない〔非課税・相続税で見る・贈与税で見る〕）。
- 入るお金の行の所得は、この区分で集める（`income.flows`）。表の行は見せ方だけで、表の行を何にしても税・社会保険料は変わらない（今までどおり。テストで確かめる）。新しい種類を足すときは、課税の扱いの既定を決めれば、どの所得に入るかが決まる。
- 雑所得（業務）と雑所得（その他）は、課税の扱いとしては2つのまま残す（申告書の欄が別で、業務に係る雑所得は前々年の収入が300万円を超えると書類の決まりがある。計算には関係しないので計算では1つの区分）。

### 2. 雑所得（公的年金等以外）の計算

- **収入−必要経費**（所得税法35条2項2号）。入るお金の行の雑所得（業務・その他）・保険の雑所得（個人年金・収入保障の月額）・雑所得の民泊・宿を、**1つの区分として赤字も含めて差し引く**。
- 合わせて赤字なら、**公的年金等の雑所得から引く**（雑所得の金額は公的年金等の雑所得〔35条2項1号〕と2号の合計）。公的年金等の雑所得は公的年金等控除で別に計算したままで、所得金額調整控除は引く前の公的年金等の雑所得で計算する。
- 引ききれない赤字は、**ほかの所得（給与所得・事業所得・不動産所得など）と通算しない**（所得税法69条1項の損益通算は不動産・事業・山林・譲渡の損失だけ。国税庁 No.1500・No.2250）。0円として捨てた額を `tax.totalIncome` の `miscellaneousLoss` で添え、知らせ `N_LIMIT_APPLIED`（`income.miscellaneousLoss`。構成員）を出す。
- 雑所得は総合課税で、所得税・住民税・国民健康保険料・後期高齢者医療の保険料の所得に入る（今までどおり、どれも合計所得金額の部品の total を読む）。住民税も同じ年分の所得で計算する。
- 部品の出力: `income.flows`（約束の版 1.1・改訂3）は人×年に、公的年金等以外の雑所得の収入−必要経費 `miscellaneousNet` と事業所得の収入−必要経費 `businessNet` を、赤字はマイナスのまま添える（その区分の行がある年だけ）。前の欄（区分ごとに0円で止めた `miscBusiness`・`miscOther`・`business`）はそのまま出す。`insurance.income`（約束の版 1.2・改訂3）は雑所得が赤字の年にその赤字を `miscellaneousNet` で添える（`miscellaneous` は0円より下げない）。`tax.totalIncome`（約束の版 1.7・改訂8）がこれらを差し引く。
- 業務に係る雑所得の前々年の収入が300万円を超えるときの書類の決まり・現金主義の特例は、計算に関係しないので扱わない。

### 3. 事業所得の赤字は通算する

- 入るお金の行で事業所得を選んだ行は、赤字のまま事業所得に足す（`businessNet`）。自営の事業所得・事業所得の民泊・宿と合わせ、赤字はほかの所得と通算する（損益通算）。青色申告なら特別控除（黒字から）と純損失の繰り越し（0081）も当たる。55万円・65万円の控除を使える「事業所得がある」には、入るお金の行の事業所得の行がある年（黒字・赤字によらない）も数える。

### 4. 副業の所得の区分（行ごとに選ぶ）

- 副業の行は、簡易の欄「所得の区分」で **雑所得（業務）** か **事業所得** かを選ぶ（`incomeFlow.taxTreatment`。ほかの種類は今までどおり詳細の「課税の扱い」で9通り）。前にほかの扱いを入れた行は、その扱いも選択肢に残す（世帯の値は書き換えない）。
- **既定は雑所得（業務）のまま**: 副業（会社員などの本業の外の収入。原稿料・講演料・ネットでの販売・シェアリングエコノミーなど）の多くは雑所得として申告される。事業所得になるのは、社会通念で事業と言える規模で営み、帳簿を付けて書類を保存しているとき（所得税基本通達35-2。帳簿書類の保存が無い場合は業務に係る雑所得に当たるとする令和4年の改正。原本での確認待ち）。事業所得には青色申告特別控除と損益通算があり、選ぶと赤字の扱いと税が変わる。既存の世帯の行は課税の扱いを書き換えない（既定が同じなので、今までと同じ扱いのまま）。
- 画面の「?」に、選び方（帳簿を付けて事業として続けているなら事業所得）と、事業所得は赤字を給与などから引けて青色申告の特別控除も受けられることを書く。

### 5. 表の行「雑所得」

- 科目の木に `cf.income.other.miscellaneous`（雑所得。親は「その他の収入」）を足した（足すだけ。0004 の3）。入るお金の行の表の行（`incomeFlow.row`）の選択肢に入れ、副業（「その他の収入」「副業」「雑所得」「事業」）・売電・外国の年金で選べる（その他の入金は全部）。種類の既定の表の行は変えない（副業は「副業」のまま）。
- ほかの種類で雑所得の区分を使うもの・使うべきものの洗い出し（どれも課税の扱いの既定は変えていない）:

| 種類 | 今の課税の扱い | 所得の区分 | 見立て |
|---|---|---|---|
| 副業・雑所得 | 雑所得（業務） | 雑所得 | 既定のまま。事業所得を簡易で選べる（4） |
| 売電の収入 | 雑所得（その他） | 雑所得 | 給与所得者の余剰電力の売電は雑所得。事業として営むなら事業所得（課税の扱いで選べる） |
| 外国の年金 | 雑所得（その他） | 雑所得 | 外国の公的年金は公的年金等（公的年金等控除の対象）に当たりうる。公的年金等の雑所得として計算するかは 0044 の未確定のまま（残り） |
| その他の働く収入 | 給与 | 給与所得 | アルバイト・パートの給与。原稿料・謝礼などの報酬は副業（雑所得）で入れる |
| 個人年金保険の年金（保険の入力項目） | 雑所得（受取人＝契約者） | 雑所得 | 1つの区分に入れた（赤字もほかの雑所得と差し引く）。表の行は「個人年金」のまま |
| 収入保障保険の月額（契約者が受け取る） | 雑所得 | 雑所得 | 同上 |
| 民泊・宿（住宅宿泊事業・特区民泊） | 雑所得（0081） | 雑所得 | 同上 |
| 一時所得・住まいの補助金 | 一時所得 | 一時所得 | 雑所得ではない（変えない） |

### 6. 確定申告不要制度の「その他の所得」に雑所得を入れる

- 公的年金等の収入が400万円以下で、**公的年金等に係る雑所得以外の所得金額**が20万円以下なら、追加の納付は申告しない（国税庁 No.1600）。この「以外の所得金額」に、給与所得・事業所得のほか公的年金等以外の雑所得を足した（`incomeTax.annual` 改訂6）。一時所得・不動産所得はまだ足していない（残り）。
- 申告不要でも住民税の申告は要る（住民税は今までどおり所得に入れて計算する）。

### 7. 世帯ファイルの形式 0.36

- 表の行の選べる値に `cf.income.other.miscellaneous` を足したので、形式の版を `0.36` に上げた（選べる値を足すだけの MINOR。0011 の5・0035 の1）。`0.35` のアプリのエンジンはこの値を知らずに計算できないので、版を上げて閲覧だけにする。`0.35` → `0.36` の変換の段は形式の版だけを書き換える（既存の行の課税の扱い・表の行は書き換えない。既定が同じなので結果が黙って変わらない）。見本 `crates/household-store/tests/fixtures/household-format/0.36/` は、`0.35` の見本の副業の行を表の行「雑所得」に載せ、事業所得として扱う副業の行（表の行は事業）を1つ足した物。

## 理由

- **区分の表を1か所に置く**: 課税の扱いと表の行はもとから別の欄だったが、どの所得に入るかが部品の中の if の並びにあり、ほかの入れ物（保険・民泊・宿）と同じ区分として扱う決まりが無かった。表にすれば、新しい種類や入れ物が同じ区分を使える。
- **雑所得を1つの区分として差し引く**: 法令で雑所得の金額は公的年金等の分とそれ以外の分の合計で、それ以外の分の中（業務・その他）は区別なく差し引く。区分ごとに0円で止めると、元本割れの個人年金と副業の黒字のように、同じ人の雑所得の中の赤字が消えてしまう。
- **前の欄を残す**: `income.flows` の欄の意味を変えると約束の版の MAJOR が上がり、読む部品をすべて直すことになる。足すだけにして、合計所得金額の部品だけが新しい欄を読む。
- **既定を雑所得のままにする**: 副業の多くは雑所得で、帳簿を付けていない副業を事業所得にすると赤字の通算で税を小さく見せてしまう。既存の世帯の結果も変わらない。

## 代案（採らなかったもの）

- 雑所得（業務）と雑所得（その他）を1つの課税の扱いにまとめる: 世帯ファイルの値を書き換える移行が要り、申告書の欄の区別も失う。計算で1つの区分にすれば足りる。
- 所得の区分を行の新しい欄にする: 課税の扱いが既に区分を決めているので、同じことを2つの欄に持つことになる。
- 副業の既定の表の行を「雑所得」にする: 既存の世帯の表の見え方が黙って変わる。表の行は選べるようにするだけにした。
- 雑所得の赤字を公的年金等の雑所得からも引かない: 法令では雑所得の中の合計なので引く（0081 の民泊・宿の決まりとも同じ）。

## 影響

- **エンジン**: `engine/src/sdk/incomeKinds.ts`（所得の区分の表）・`moneyRows.ts`・`index.ts`、部品 `income.flows`（1.1・改訂3）・`insurance.income`（1.2・改訂3）・`tax.totalIncome`（1.7・改訂8）・`incomeTax.annual`（改訂6）、約束 `engine/src/sdk/contracts.ts`、出力のスキーマ（`income.flows.output`・`insurance.income.output`・`tax.totalIncome.output`）、入力のスキーマ（`incomeFlow.row` の値）、登録簿 `registry/rows.yaml`。制度の値は足していない（税率・控除額は今の値を使う）。
- **画面**: `app/src/workspace/input/moneyRows.ts`（表の行「雑所得」と種類ごとの選択肢、副業の所得の区分の欄、課税の扱いの効き方の文）、`engineNotices.ts`（知らせ1つ）、`store/body.ts`（形式 0.36）。
- **世帯ファイル**: 形式 0.36（`crates/household-store/src/migrate.rs`・見本・`tests/format_fixtures.rs`）。
- **テスト**: `engine/test/miscIncome.test.ts`（雑所得の赤字が給与所得と通算されない・事業所得を選ぶと通算される・雑所得の中の差し引き・公的年金等の雑所得から引く・個人年金の元本割れの赤字・住民税と国民健康保険料に入る・表の行を変えても税が同じ・確定申告不要制度）、`app/test/misc-income.test.ts`（表の行・副業の所得の区分の欄）、`app/test/money-row-choices.test.ts`、`app/test/store.test.ts`（0.36 の形）。
- **結果の変わり方**: 赤字の雑所得・事業所得の行（必要経費が収入より多い年）・元本割れの個人年金・雑所得のある年金の人の無い世帯の結果は変わらない（エンジンの結果を前の版と比べる道具で、モデル世帯すべてと一致の見本の数字が同じことを確かめた）。変わるのは、(1) 雑所得の中で赤字と黒字がある年（雑所得が小さくなる）、(2) 雑所得の赤字があって公的年金等の雑所得がある年（年金の雑所得から引く）、(3) 入るお金の行の事業所得の赤字の年（ほかの所得と通算して税・保険料が下がる）、(4) 年金の収入が400万円以下で雑所得が20万円を超える年（翌年3月に追加の所得税を払う）。

## 未確定・後の段階に回したこと

- 外国の年金を公的年金等の雑所得（公的年金等控除）として計算するか（0044 の未確定のまま）。
- 公的年金等控除の段（公的年金等に係る雑所得以外の合計所得金額が1,000万円・2,000万円を超えるか）に、公的年金等以外の雑所得・不動産所得・一時所得を足すこと（今は給与所得と自営の事業所得だけ）。
- 確定申告不要制度の「その他の所得」に一時所得・不動産所得を足すこと。給与所得者の給与以外の所得が20万円以下のときの申告不要（所得税だけ。住民税は要る）と、副業の雑所得の所得税を翌年3月の確定申告で払う時期（今は年末調整を受ける年は給与の月に分けて載せる）。
- 個人年金の源泉徴収（年金額−必要経費が25万円以上のとき）の時期と、終身年金の必要経費（余命年数で年金の総額を見込む）。
- 所得税基本通達35-2 の令和4年の改正（帳簿書類の保存と業務に係る雑所得）の原本での確認。
