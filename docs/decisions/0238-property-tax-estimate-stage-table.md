# 0238. 固定資産税の推定の変化を、確かめた後・直した後も1つの表のまま見せる（閉じた形から始める・1年1行・推定のままの年は「いつから」「何年かけて移すか」を出さない）

- 状態: 採用（一部未確定）（2026-11-21）
- 固定の強さ: 内部（画面の見せ方だけ。世帯ファイルの形式の版・計算エンジン・書く値の形・文言の一覧は変えない。まとまりのキー `<物>/propertyTax/autoStages` と、表の目印 `data-stage-table`・`data-stage-row`・`data-stage-row-state` は、テストと写真の道具が使う）
- 前提にする記録: 0040（段階と例外の年）、0041（値の状態の操作と確かめの一覧）、0052（住まい・ローンの入力項目）、0112（固定資産税の推定）、0144（住まい・ローン・保険の見せ方。5 の「固定資産税の推定の変化を畳む」をこの記録で置き換える）

## 背景

- 固定資産税・都市計画税の額が推定のとき、新築の軽減の終わりと3年ごとの評価替えを「今の額に対する割合」の段階として年ごとに入れる（0112）。0144 は、この推定の段階が3つを超えたら1つの短い表に畳み、割合を直した年は「ふつうの段階」として1件ずつの枠（いつから・入れ方・割合・移す年数・外す）に開く形にした。
- この形だと、**推定のままの年だけが表に残る**。確かめの一覧のまとめて「この値にする」を押す・割合を手で直すと、その年は表から外れて1件ずつの枠（1件で約215〜240px）になる。測ると、住まいの入力項目の固定資産税まわりの縦の長さは次のとおり伸びる（幅1440・文字「中」）。

  | 場面 | 推定のまま | まとめて「この値にする」の後 |
  |---|---|---|
  | 今住んでいる持ち家・5件 | 373px | 1,198px |
  | 今住んでいる持ち家・18件 | 836px | 3,992px |
  | 購入の予定・10件 | 741px | 2,898px |

- 推定を確かめるのは「この値でよい」と決めるだけの操作で、見たい物（年ごとの割合と額の目安）は確かめる前と同じ。確かめた途端に画面が3〜5倍に伸びるのは、操作の重さに合わない。3件以下のときは、推定のままでも最初から1件ずつの枠だった。

## 決定

### 1. 推定から入った年は、何件でも・どの状態でも1つの表に置く

- 推定から入った年（推定のままの段階と、推定が入れる年の ID を持つ段階）は、**推定のまま・確かめた後（「この値にする」）・手で直した後のどれでも、同じ1つの表**「固定資産税の推定の変化」の行にする。件数で分けない（1件でも表。0144 の「3つを超えたら」をやめる）。
- 推定から入ったかどうかは、段階の ID で見分ける（固定資産税の推定は、年ごとに決まった ID で段階を入れる。`propertyTax.ts` の `isTaxEstimateStageId`）。値の状態（推定かどうか）では見分けない（確かめた後も表に残すため）。
- 表の並びは年の順。まとまりのキーは今までと同じ `<物>/propertyTax/autoStages`。

### 2. 表は閉じた形から始める

- 最初は**要約の1行**（表の名前・理由と期間と件数〔「新築の軽減の終わり・3年ごとの評価替え・2027〜2039年・5件」〕・推定のままの印〔一部だけ推定のままなら「推定 のまま 2件」〕・最初と最後の額の目安〔「2027年から 年約16.6万円 → 2039年から 年約11万円」〕）と、「▸ 年ごとの割合を見る・直す」のボタンだけ。推定のままの画面も、確かめた後の画面も同じ。
- 開くと、説明の文と、1年1行（年・割合の欄・その年からの額の目安・「詳しく」）。
- 閉じている間も、行と行の中身は描いておく（隠すだけ）。確かめの一覧などから表の中の欄へ移ってきたときは、表とその行を開いてその欄へ移る。
- 開け閉めは画面だけの状態（世帯ファイルに書かない。同じ世帯を開いている間だけ覚え、保存しない。ほかのまとまりの「▸ 詳しく」と同じ入れ物）。

### 3. 細かい欄は、行の「詳しく」から

- 行の「詳しく」を開くと、その年だけの細かい欄と「外す」が出る。
  - **確かめた年・直した年**: 「いつから」「入れ方（今の額に対する割合・額で）」「ここから次の段階まで何年かけて移すか」（最後の年には出さない。今までと同じ）と「外す」。
  - **推定のままの年**: 「入れ方」と「外す」だけ（下の 4）。
- 表の下に「推定のままのN件を外す」（推定のままの年が1件でもあれば出す。0144 では畳んだ表にだけあった）。
- 1件ずつ外せるようになる（0144 の「1件だけ外したいときは、割合を直してふつうの段階にしてから外す」をやめる）。外した後の覚え方は 0112 のまま（推定のままの年を外したときだけ覚えて、入れ直しで足し直さない）。

### 4. 推定のままの年には「いつから」「何年かけて移すか」を出さない（利用者の判断。2026-11-21）

- 推定のままの年は、入力を直すたびに推定し直す（外して作り直す。0112）。「いつから」と「何年かけて移すか」は、直しても推定し直すと元に戻る。直せるように見えて直らない欄は出さない。
- 対象は、**推定から入って、まだ推定のままの年だけ**。確かめた年・手で直した年、自分で足した変化・例外の年は、今までどおり2つの欄を出す。
- 見せないだけで、値はそのまま持つ（書く値の形・計算は変えない）。
- 直したい人の道筋は画面に書く: 表の名前の横の「?」の説明に「確かめた年・直した年は『いつから』『何年かけて移すか』も直せます（推定のままの年は、推定し直すと元に戻るので出しません）」、推定のままの年の「詳しく」の中に「推定のままの年は、『いつから』と『何年かけて移すか』を出しません（推定し直すと元に戻るため）。直すときは、先にこの年の割合を直すか『この値にする』で確かめます」。

### 5. 変えない物

- 自分で足した変化（「＋ 固定資産税の変化」）と例外の年は、今までどおり1件ずつの枠。
- 家賃・修繕・管理の費用・不動産の家賃と経費の変化は変えない（推定が年ごとの段階を入れるのは固定資産税だけなので、表になるのは固定資産税だけ）。
- 標準の表示（固定資産税の1行）、確かめの一覧、まとめて「この値にする」、推定の数え方は変えない。

### 6. 表の欄・ボタンは、まとまりの欄・ボタンと同じ物を使う

- 入力項目を組み立てるときの、書いた後の片付け（ほかの欄をついてこさせる・外した物を指す欄を片付ける。`stages/index.ts`）は、まとまりの欄・ボタン（`fields`・`actions`）に付く。表の行の欄・ボタンをそのまま使うと、この片付けを通らない。
- 表の行の欄・ボタンは、**同じキーでまとまりの `fields`・`actions` にも入れ**、描くときは `fields`・`actions` の物を引いて使う（行の物からは名前だけ。`StageTable.tsx` の `tableField`・`tableAction`）。確かめの一覧・検索・欄の数え方も、今までと同じ `fields` を見る。

## 理由

- 確かめる前と後で見たい物は同じなので、同じ場所・同じ形に置く。伸びるのは、開いた行の「詳しく」の分だけになる。
- 閉じた形から始めるのは、固定資産税の年ごとの割合を1年ずつ直す場面が少ないため（0144 の理由と同じ）。要約の1行に期間・件数・最初と最後の額があれば、開かなくても推定の中身が分かる。
- 推定のままの年の「いつから」「何年かけて移すか」は、直しても黙って戻る。出さないほうが、直したのに戻ったという誤りが起きない。
- 状態でなく ID で見分けると、確かめた年を表に残せる。世帯ファイルに新しい印を足さずに済む。

## 代案（採らなかったもの）

- **確かめた年・直した年だけを別の短い表にする**: 表が2つに分かれ、年の順に読めない。
- **開いた形から始める**: 18件で約680pxあり、住まいの入力項目のほかの欄が遠くなる。
- **推定のままの年の2つの欄を、直せない見た目（灰色）で出す**: 行の「詳しく」が長くなり、なぜ直せないかの説明がどのみち要る。
- **推定のままの年で2つの欄を直したら、その年を確かめた扱いにする**: 値の状態は明示の操作だけで変える（0041）。欄を直しただけで推定でなくなると、推定の数が黙って減る。
- **開け閉めを世帯ファイルに書く**: 見せ方だけの状態で、世帯の中身ではない。

## 追記

### 2026-11-21: 欄の名前と説明の「段」を「段階」に（利用者の判断）

画面の言葉は「段階」にそろえている（0130・0237）が、額の変化の欄の名前と説明に「段」が残っていた。この表から開く欄にも出るので、合わせて直す。見せ方（言葉）だけで、世帯ファイルの形・計算は変えない。

| 所 | 前 | 後 |
|---|---|---|
| 額の変化の欄の名前 | ここから次の段まで何年かけて移すか | ここから次の段階まで何年かけて移すか |
| 額の変化の欄の名前 | ○○（この段から）・利回り（年・この段から） | ○○（この段階から）・利回り（年・この段階から） |
| 上の欄の「?」 | 段の時点から1年ごとに、次の段の額へ… | 段階の時点から1年ごとに、次の段階の額へ… |
| 足したときの根拠の文 | 元の額と同じ（この段の額を入れてください） | 元の額と同じ（この段階の額を入れてください） |
| 資産配分の段階 | この段を外す・資産の配分の段では…・「資産配分の段階 2段」 | この段階を外す・資産の配分の段階では…・「資産配分 2段階」 |
| プランの金利の見込み・上乗せ | 変動金利の段を5年ごとに置きます・変動金利の段に…（固定金利の段は変わりません） | 変動金利の段階を5年ごとに置きます・変動金利の段階に…（固定金利の段階は変わりません） |
| 生活費の推定の根拠・学費の知らせ | 退職後の段に合わせて…・学校の費用が空欄の段は… | 退職後の段階に合わせて…・学校の費用が空欄の段階は… |

- 変えない所: 事務所の設定の「表の段」（公式の表の行の区切りの意味。時期の段階とは別の言葉）。
