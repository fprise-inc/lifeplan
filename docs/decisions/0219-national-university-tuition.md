# 0219. 国立大学の学費の実データ（入学年度ごとの入学料・授業料と学部・学科の一覧。学費を学校から出す第2段）

- 状態: 採用（一部未確定）（2026-11-16）
- 固定の強さ: パックの ID `master.education.tuition`・段に写す行の形（0010 の3 の「入学年度×在学年次×費目×支払月」。`goals[].education.stages[].school` の `{school, unit, track, termStartMonth, rows, source}`）・部局ID（`<学校コード>/d001`。使い回さない）は 0010 の骨格のまま。正本の YAML の欄（`plans`・`revisions`・`appliesTo`・`latestEntryYear`）・学費の区分の名前・画面に配る形・欄の文は内部（後から変えてよい）
- 前提にする記録: 0010（学費データ。国立大学は全校の実データ・入学年度ごと・省令の上限の検査・確かめられなければ標準額で補う）、0217（学校の一覧と学校名の欄。第1段）、0007（値の状態 reviewed・pendingReview）、0009（写した値は「更新」まで変わらない）、0011・0035（世帯ファイルの形式の版）、0017（署名つきの更新の経路）

## 背景

- 0010 の追記（2026-10-09）で、国立大学は約80校の全校を、標準額で補うのではなく学校ごとの実データで持つと決めた。国立大学の授業料の標準額（年535,800円・入学料282,000円。国立大学等の授業料その他の費用に関する省令 第2条）から、省令 第10条の上限（標準額の1.2倍。授業料642,960円・入学料338,400円）まで上げる大学が毎年増えていて、標準額で補うと上げた大学を安く計算するため。
- 値上げは多くの大学で新入生から当てる（在学生は据え置き）が、在学生にも当てる大学もある。だから額は入学年度ごとに持ち、改定を在学生に当てるかも大学ごとに持つ。
- 0217 で、学校名の欄から国立大学を選べるようになったが、学費の行（`rows`）は空で、国立大学の標準額で計算していた。学部・学科の欄は、一覧の中身が無いので出ていなかった。

## 決定

### 1. データ（`data/tuition/`・`data/schools/departments.yaml`）

- 正本は `data/tuition/national.yaml`（パックの見出しは `pack.yaml`。版 2026.1.0。CC0）。廃止していない国立大学の全校 85 校（学部のある 81 校と大学院大学 4 校）。
- 学校ごとに、学費の区分（`plans`）: `day` 学部・`evening` 学部の夜間主コース（夜間の学部の標準額 267,900円・141,000円の区分）・`medDent` 東京科学大学の医学部・歯学部（旧2大学で額が違う）・`master` 修士・博士前期・`doctor` 博士・博士後期・`professional` 専門職大学院（法科大学院を除く）・`law` 法科大学院。
- 区分ごとに、入学年度の区間（`revisions`）: 最初の区間（`from: null` = それより前から）と、改定ごとの区間（`from` = 改定の始まりの年度、`appliesTo` = `newEntrants` その年度からの入学者〔在学生は据え置き〕か `allStudents` その年度から在学生も）。額は入学料と授業料の年額。入学料の年度別の記載が無い過去の入学者は入学料を `null` にし、行を作らない（計算基準月より前に払い終わっている）。
- `latestEntryYear`: 額が公式に出ている最も先の入学年度（学部は 67 校が2026年度入学、14 校が募集要項の予定額・改定の発表で2027年度入学まで）。
- 案内にある在学中の改定の一般の注記（「在学中に授業料の改定が行われた場合には新しい額」など）は `general` に持つ（多くの大学にある。計算には使わず、発表された改定だけを区間にする）。
- 出典（`sources`）: 大学の公式ページ・PDF の URL・題名・取得日・原本の指紋（sha256）。行ごとに出典の ID と短い位置（表の名前など）を持つ。ページの文章は写さない。原本の写しは公開しない（0010 の6）。
- 学部・学科の一覧 `data/schools/departments.yaml`（`master.education.schools` の一部。CC0）: 大学の公式の学部の一覧から、学部ごとに1行。同じ学部の中で修業年数か学費の区分が違う学科・コース（医学科と看護学科、薬学科と薬科学科、夜間主コースなど）だけ分ける。部局ID は学校の中の通し番号（`d001`…）で、使い回さない（廃止しても `retired: true` で残す）。修業年数は学校教育法第87条（4年。医学・歯学・薬学〔臨床〕・獣医学は6年）、夜間の5年の課程は大学の学則・募集要項。各学科の学費の区分（`plan`。省略は学部 `day`）。81 校・491 行。
- 大学名の読み: 大学の公式サイトのふりがな・ルビで確かめた 9 校だけを `aliases.yaml` の `readings` に足した（推測では足さない。0217 の理由）。

### 2. 取り方と確かめ方

- 各大学の公式ページ（入学料・授業料の案内・授業料の改定のお知らせ・募集要項・学部の一覧）と、文部科学省・省令（e-Gov 法令 API の条文）からだけ取った。進学情報サイト・まとめサイト・大学ポートレートからは取らない。2026-11-16 に取得。
- 2つの読み方で照らし合わせた: ① 写しを人の読み方で読んで、区間・額・改定の在学生の扱いを取り出す、② 写しの文字（HTML の本文と表のセル・PDF の文字）を機械で読み直し、取り出した額が費目の言葉（授業料・入学料）の近くにあるか、改定の年度が写しにあるかを確かめる。標準額と違う額（上げた額）は、その区間が指す写しで読めることを要る。上げた大学は、改定の表と在学生の扱いの文をもう一度読んで確かめた。
- 一致しない区分は「確かめ待ち」（`status: pendingReview`）にし、行を写さない（計算エンジンは国立大学の標準額で計算し、画面に補ったことを出す）。今回の確かめ待ち: 東北大学の専門職大学院（研究科で額が2つ）、政策研究大学院大学の大学院（年度の記載が無い上限の額）、横浜国立大学の夜間主コース・法科大学院（写しで額を読めない）、高知大学の博士課程（入学料0円の扱い）。学部の額は 81 校とも確かめ済み。確かめ待ちの夜間主コースは学部・学科の一覧にも出さない。
- 検査（`app/scripts/tuitionData.ts` の `checkTuition`。画面の準備 `prepare-assets` と単体テストで流し、誤りがあれば止める）: 学校が廃止していない国立大学であること、省令の上限（`pack.yaml` の標準額×1.2）の外の額と標準額の9割を下回る額（読み違い）、入学料が授業料を上回る、区間の形（最初は `null`・年度は増える・額が変わる区間は `appliesTo` を持つ）、出典の必須項目、行が入学年度ごとに全年次そろうこと、部局ID の形と重なり・修業年数・学費の区分が確かめ済みであること。

### 3. 段に写す行

- 学校名の欄で国立大学を選ぶと、その段の学費の区分（大学の段は学部・学科の区分か `day`、大学院の段は課程。専門職大学院は系統 `law` なら法科大学院）の行を `app/src/workspace/input/tuition.ts` の `tuitionRows` で作り、段の `school.rows` に写す（`source` は `{pack: "master.education.tuition", version}`、大学院は `track` に課程）。
  - 入学年度は 2021年度（今の6年制の学部の6年生）から `latestEntryYear` まで。在学年次は区分の年次（学部6・夜間主5・修士2・博士4・専門職2・法科大学院3）まで（計算エンジンは段の在学年数より後の行を使わない）。
  - 授業料は年次の始まり（4月）と6か月後（10月）に半分ずつ、入学料は入学の前の月（3月）。統計の平均の国立大学の払い方と同じ月。
  - 年次の授業料は、その入学年度の人に当たる区間: `newEntrants` の改定は入学年度で、`allStudents` の改定は払う年度で見る（例: 熊本大学は2027年度から全学年で改定。2025年度入学の人も3年次から改定の後の額）。
- 計算エンジン（`education.cost`）は前から行のとおりに払う（0010 の3。変えていない）: 子の入学年度（生年月と浪人の年数で決まる）の行があればその額（在学中は名目のまま。改定の発表が無い限り据え置き）、無ければ最も近い前の入学年度の行に、その入学年度から教育費の上昇率を当てて推計し、知らせ `N_ESTIMATED` を出す（0010 の7 の「データの最新の入学年度より先の入学は、最新の入学年度の行に教育費の上昇率をかける」）。
- 確かめ待ちの区分・学費のデータの無い区分（学部の無い大学院大学の学部など）は行を写さない（`rows: []`。標準額で計算する）。
- 学部・学科の欄（学部・学科の一覧のある学校）: 選ぶと `unit` を `<学校コード>/<部局ID>` にし、その区分の行を写し直し、在学年数を修業年数に合わせる（標準と同じなら省く）。後で在学年数を変えて合わなくなったら欄の下で知らせる。
- 写した行は、学費データが新しくなっても黙って変えない（0009）。学校名の欄は、今の学費データから作る行と写した行が違えば（データの更新・課程の変更）知らせ、「学費の行を今の学費データにする」で入れ直せる。

### 4. 画面

- 学校名の欄の横: 「学費は〇〇大学の公式の学費の案内「（ページの題名）」（取得日）で計算しています（授業料 年○万円・入学料 ○万円・2026年度入学の額）」。子の入学年度の額がまだ出ていなければ「○年度入学の額はまだ出ていないので、この額を教育費の上昇率で伸ばして計算します」。確かめ待ちの区分は「この大学の〇〇の額は確かめ待ちなので、国立大学の授業料の標準額（国の省令の額）で補って計算しています」。
- 段の見出しの下の1行: 「学費 年○万円・入学金 ○万円（学校の学費データ・○年度入学の額）」。見出しの横の目安（今の値段）・教育ローンのひな形の額も行の額で数える。
- 学費の年額・入学金の欄: 行のある段は推定を出さず、空欄なら学校の額を欄の横に出す。額を入れてあれば「学費データで計算しているので、入れた額は使っていません（入れた額で計算するときは学校名を「学校未定」に）」と知らせる（計算エンジンは行のある段の年額・入学金の欄を使わない。黙って消さない）。
- 出どころの文は欄の横の1行に置く。推定の出どころを「推定」の印の吹き出しにまとめる直し（別の変更）が入ったら、先の入学年度の推計の文をその吹き出しに移せる（文を部品 `schoolRowsInfo` から作っている）。

### 5. 世帯ファイルの形式の版

- **上げない**（今のまま）。段の `school` の `track`・`termStartMonth`・`rows`・`source` は 0010 の9 で前からあり、今のスキーマ（`engine.input.json` の `schoolTuition`）で通る。

### 6. 配り方

- 学部・学科の一覧と学校別の学費は、学校の一覧と同じ画面の部品（`src/generated/schools.data.js`。学校名の欄を開いたときに遅れて読む）に入れた（約0.1MB 増えて 3.86MB）。

## 理由

- **入学年度×改定の当て方で持つ**: 大学の発表は「○年度の入学者から」「○年度から全学年」の形なので、そのまま持てば発表と照らし合わせやすい。行（0010 の3）はこの形から機械で作るので、6年制・夜間主・大学院の年次の違いも同じ作り方で済む。
- **確かめ待ちは行を写さない**: 確かめていない額を行にすると、計算エンジンは学校の額として名目のまま使う。標準額の計算（統計の形の値）に任せれば、補ったことを画面に出すだけで済む。
- **先の入学年度は最新の額を上昇率で伸ばす**: 0010 の7 の決まりのとおり。上げた大学は上げた額から伸ばすので、標準額で補うより漏れが少ない。2027年度入学の額まで出ている大学は2027年から伸ばす（標準額の計算は計算基準年から伸ばすので、標準額のままの大学でも1年分の上昇率の差が出る）。
- **年額・入学金の欄を黙って消さない**: 学校を選び直したときに FP が入れた額が消えると気づけない。使っていないことを知らせ、使うときの戻し方を出す。

  - 2027年度入学の額まで出ている標準額の大学（北海道大学など）: 2027年から伸ばすので、標準額の計算より1年分の上昇率だけ少ない。

## 未確定
