# 0098. 率の欄の範囲（利回り・上昇率・変化率）と、範囲の外の値が入っている世帯の扱い

- 状態: 採用（2026-10-31）
- 固定の強さ: 内部（範囲の値・知らせの文言・つまみの端は、使う人の声と測定に合わせて変えてよい）。世帯ファイルの形（形式の版）・計算エンジンの入力の形は変えない。「範囲の外の値が入っている世帯の数字を黙って変えない」（4）は変えない
- 前提にする記録: 0002（率は10進の文字列）、0041（確かめの一覧）、0070（前提条件のカード・注意の線）、0073（事務所の既定値）、0015（AI接続口の候補は承認制）

## 背景

- 利回り・上昇率・変化率の欄には範囲が無く、どんな率でも入れられた。999% を入れると金額が安全に扱える整数（2^53 − 1 円）を超えて計算が止まり（`E_UNSAFE_INTEGER`）、賃金上昇率・物価上昇率に -100% を入れると年金の改定の計算で率を 0 で割って止まった（`E_ARGUMENT`・`rateDiv.zero`）。どちらも画面には「計算できませんでした（符号）」だけが出て、どの欄が原因か分からなかった。
- 見本の世帯（`data/modelHouseholds/` の51世帯）で、入っている率の欄を1つずつ 999% と -100% にして計算した。止まったのは次の欄（どれも 999% で止まる。-100% で止まるのは賃金上昇率・物価上昇率・年金の調整率）:
  - 前提条件: 運用利回り・資産の種類ごとの利回り・物価上昇率・賃金上昇率・年金の調整率
  - 口座の利回り・評価額の増減率、収益不動産の家賃の変化率・年額の変化率、住まいの家賃・固定資産税・修繕費の変動率、出るお金の行の決まった変動率、FP顧問料の値上げの率
- 止まらなかったのは、借入の金利（住宅ローン・借り換え・車のローン）・保険の解約返戻率・退職金の倍率と予定利率・家賃の更新料・空室率（0〜100% の割合の欄は #212 で範囲を付けた）。
- 同じ見本で、範囲の端の値（-10%・+10%・+20%）を1つずつ入れたときは、どの欄も止まらなかった。ただし、運用利回り 20% と上昇率 8% 以上を重ねると、表の標準の長さ（若い方が100歳まで）の見本 `lifetime100`（99年）で金額が整数の上限を超えて止まった。

## 決定

### 1. 範囲（パーセント。年の率。長い期間の平均の値として）

| 欄 | 範囲 | 置き場所 |
|---|---|---|
| 運用の利回り: 前提条件の運用利回り・資産の種類ごとの利回り（と例外の年）、口座の利回り・平均の利回り・利回りの段・その年の利回り、資産の評価額の増減率（その他の資産・不動産の器）、万一のタブの相場の下落の後の利回りの上限 | -10%〜+15% | `RETURN_RANGE` |
| 上昇率・変化率・伸び率: 物価上昇率・賃金上昇率・教育費の上昇率（と例外の年）、土地の上昇率（と例外の年）、収益不動産の土地の評価額の増減率・家賃（売上）の変化率・年額の変化率、住まいの家賃・固定資産税・修繕費の変動率、働き方の期間の伸び、生活費・出るお金の行・車の決まった変動率、FP顧問料の値上げの率 | -10%〜+10% | `GROWTH_RANGE` |
| 年金の調整率（マクロ経済スライド。基礎年金・厚生年金と例外の年） | 0%〜5% | `SLIDE_RANGE` |
| 運用の費用（信託報酬など） | 0%〜5% | `FEE_RANGE` |

- 置き場所は `app/src/workspace/input/rateRanges.ts` の1か所。欄の定義は割合の欄の `min`・`max`（#212 の仕組み）にこの値を渡す。
- 運用の利回りの上の端は、初めの案の 20% にせず 15% にした。上昇率の上の端（10%）と重ねても、表の標準の長さで見本のどの世帯も計算が止まらない範囲にするため（背景の4つ目。15% と 10% を重ねた形・-10% と -10% を重ねた形など4つの組で、見本の51世帯すべてが計算できることを試験で確かめている）。長い期間の平均で年15%を超える見込みは、株式だけの配分でも置かない。
- 下の端の -10% は、長い期間のマイナスの見込み（値下がりする資産・家賃の下落・物価の下落）を入れられるようにしつつ、-100% のような計算できない値を除く。
- 年金の調整率は年金額の伸びから差し引く正の率（エンジンの入力の説明のとおり）なので 0% から。調整率は年 0.3% 前後の見込みで、5% までなら十分に広い。
- 運用の費用は 0% から。年 5% を超える費用の商品は見込みに置かない。
- 範囲を付けない欄: 借入の金利・保険の解約返戻率・退職金の倍率と予定利率・家賃の更新料（止まらない。金利は利回りと別の性質で、範囲は今は決めない）。子ども・教育の欄（奨学金・教育ローンの利率、保育料の自治体の水準など）はこの記録では扱わない（見本に入っている奨学金の利率は 999% でも止まらなかった。ほかは見本に無く確かめていない）。

### 2. 入力の欄と、ほかの書き込み口

- 入力の画面の欄（と、それを動かす項目にした結果のタブのプランの欄）は、範囲の外の値を書かず（#212 と同じ。前の値のまま）、欄の下に越えた側の端を出す。
- 範囲の外の値を打ったときの知らせ（2026-10-31 追記）: 上の端を越えたら「15%より大きい値は設定できません。」、下の端を越えたら「-10%より小さい値は設定できません。」と、その欄の端の値で出す（`rateRanges.ts` の `outOfRangeText`。割合の欄すべてと事務所の既定値の前提条件の欄。古い世帯の値の知らせと「範囲の端にする」は 4 のまま）。
- 結果のタブの「運用の利回り（預金を除く）」のつまみは、右の端を「今の利回り＋3ポイント」のうち 15% まで、今の利回りがマイナスなら左の端もそこまで（-10% まで）にする。
- AI接続口から来た候補: 当てはめる項目の範囲（割合の欄の `min`・`max`、つまみの `limit`）の外の値は「入れてよい範囲（…）の外の値のため、取り込みません」として取り込まない。
- 事務所の既定値の前提条件の標準値は、欄ごとに入力の画面と同じ範囲（物価・賃金 -10〜10%、運用利回り -10〜15%、年金の調整率 0〜5%）でだけ保存できる。今までの事務所データ（-5〜20% で保存できた値）は読み込みで捨てない。新しい世帯に写すと、範囲の外の値は 4 の知らせが出る（事務所の既定値の画面で直して保存し直す）。

### 3. 範囲の端の値で止まらないことを、試験で守る

- `app/test/rate-ranges.test.ts`: 見本の51世帯のどれでも、すべての率の欄を範囲の端（利回りの上の端と上昇率の上の端・下の端の組など4つ）にして計算が止まらない。範囲を広げるときは、この試験が通る範囲にする。

### 4. 範囲の外の値が入っている世帯（古い世帯・取り込んだ世帯・ほかの書き込み口）

- 世帯の値は**変えない**。開いても、計算の前にも範囲に収めない。範囲の外でも計算できる値（例: 運用利回り 25%）は、今までと同じ数字で計算する。
- その欄の下と、入力の確かめの一覧（0041）に「範囲（-10%〜15%）の外の値（25%）が入っています。今はこの値のまま計算しています（大きすぎる値では計算が止まります）。-10%〜15%の範囲で入れ直してください」と出し、「15%にする」（範囲の端）を押したときだけ直す（0070 の表の最後の年の「標準にする」と同じ、押したときだけ直す形）。
- 計算が止まったときの文: `E_UNSAFE_INTEGER` は「金額が大きくなりすぎて計算できません。運用の利回り・上昇率が高いか、表の最後の年が遠いと起きます。入力の確かめの一覧に出る範囲の外の率と、表の最後の年を見直してください」、`E_ARGUMENT`（`rateDiv.zero`）は「計算に使えない率（-100% の上昇率など）が入っています。…」と、見直す場所を出す。

### 5. 計算エンジンには範囲の確かめを足さない

- 範囲は画面で入れる値の目安の決めごとで、エンジンの入力の約束（0006）ではない。エンジンで範囲の外を止めると、今は計算できている世帯（運用利回り 25% など）が止まる。エンジンで範囲に収めると、結果の数字が黙って変わる（4 の「変えない」に反する）。
- エンジンは今までどおり、計算できない値では符号つきで止まる（止まったときの文は画面の側で 4 のとおり案内する）。

## 理由

- 欄の下に範囲を出して書かない形は、割合の欄（#212）と同じで、入れたその場で理由が分かる。
- 範囲を1か所にまとめると、入力の欄・つまみ・AIの候補・事務所の既定値の範囲が食い違わない。
- 古い世帯の値を黙って範囲に収めると、提案書や控えと数字が合わなくなる。知らせて、押したときだけ直す。

## 代案（採らなかったもの）

- 運用の利回りの上の端を 20% にする（初めの案）: 背景の4つ目のとおり、範囲の中の値の組で計算が止まる世帯がある。
- 計算の前に範囲に収める（エンジンか画面の側で）: 5 の理由。
- 開いたときに範囲の端に書き換えて知らせる: 世帯ファイルが黙って変わる（0035 の「古い世帯は黙って書き換えない」）。
- 借入の金利にも範囲を付ける: 止まらないうえ、利回りとは別の性質の値（いつの・どの借入か）なので、範囲を決める材料が無い。
