# 0243. 取り消しのボタンのまわりを直す（言葉は1つにそろえない。確かめの文を足す・くっついた言葉を分ける・入力の途中は「キャンセル」・進むボタンを左に）

- 状態: 採用（一部未確定）（2026-11-22）
- 固定の強さ: 内部（画面の言葉と見せ方）。世帯ファイルの形・保存される値・計算・文言の一覧（差し替えられる文）は変えない。決まりとして残すのは「取り消しの言葉を1つにそろえない」「言葉の目安（下の 1）」「確かめには何をするかの文を出す」「進むボタンが左・取り消しが右」の4つ。どの文にするか・どの所をどの言葉にするかは後から変えてよい
- 前提にする記録: 0130（入力項目をまたぐ言葉。選び直しの取りやめは「キャンセル」）、0239（重ねて出す画面の閉じ方。取り消しの言葉は別に決める、とした）、0240（ボタンの段。危ない操作は赤・文や行の中は控えめ・ほかの部品と同じ行は小）

## 背景

- 取り消しのボタンの言葉は「キャンセル」と「やめる」の2つがあり、0239・0240 では「別に決める」としていた。
- 取り消しのボタンのある所を、見えないブラウザで全部開いて並べて見た。言葉そのものは、おおむねその場に合っていた（入力項目のパネルの足元は「キャンセル／保存」、消す・外すの確かめは「やめる」など）。利用者の判断（2026-11-22）で、**言葉は1つにそろえない**ことにした。
- 一方で、言葉より前の所が崩れている所があった。
  - **確かめの文が無く、ボタンだけが並ぶ**: 控えの一覧の「外す」を押すと「外す　キャンセル」だけ、面談の履歴の開いた記録は「直す・外す・キャンセル・一覧へ戻る」の4つ、明細の口座・カードと取り込んだ明細は「外す／やめる」だけ。何をやめるのかが読めない。
  - **2つの言葉がくっついて読める**: 下線の文字のボタンが文の後ろに間を空けずに続き、「外すやめる」「戻すやめる」と読める（機能のコードを外す・説明の文を公式に戻す）。URL生成のひな形を選び直す確かめ・受け取った書類を消す確かめは、文とボタン・ボタンどうしの間が無い。
  - **問いと答えが合っていない**: ひな形を選び直す確かめは、文が「直した項目は、選んだひな形の項目に戻ります。…よろしいですか。」で、進むボタンが「選ぶ」。
  - **入力・設定の途中をやめるのに「やめる」**: コードを入れる・推定の値を変える・書類の値を直す・明細を取り込む など。同じ形のほかの所（入力項目のパネル・この時点を残す・面談の記録を足す・保存の前の注意）は「キャンセル」。
  - **並びと色が逆**: 発行した URL の「取り消す」の確かめは「やめる」が左・「はい、取り消す」が右。AI が発行した URL の同じ確かめは、進むボタンに危ない色が無く、「やめる」が次の行に落ちる。

## 決定

### 1. 言葉は1つにそろえない。目安は3つ

| 何をやめるか | 言葉 |
|---|---|
| 開いて見るだけの物を閉じる | 「閉じる」（または右上の ×。0239） |
| 何かを入力・設定している途中でやめる | 「キャンセル」 |
| 「外しますか」「消しますか」などの確かめで、しないほうを選ぶ | 今の言葉のまま（「やめる」でも「キャンセル」でもよい） |

- 3つめをそろえないのは、今の言葉がその場に合っていて、変えても読みやすくならないため。
- 「共有をやめる…」の確かめの「やめない」（「やめる」だと、進むほうと読み違える）と、選ばせる問い（世帯を離れる・プランを帯から外す）の「やめる」も、今のまま。

### 2. 確かめには、何をするかの文を出す（確かめの間は関係ないボタンを出さない）

| 所 | 前 | 後 |
|---|---|---|
| 控えの一覧の「外す」 | 「外す　キャンセル」 | 「この控えを外しますか（元に戻せません）　外す　キャンセル」 |
| 面談の履歴の開いた記録の「外す」 | 「直す・外す・キャンセル・一覧へ戻る」 | 「この面談の記録を外しますか（元に戻すで戻せます）」と「外す／キャンセル」だけ |
| 明細の口座・カードの「外す」 | （取り込んだ明細があれば「取り込んだ明細 N件もいっしょに外します。」）「外す／やめる」 | 「この口座・カードを外しますか（〔取り込んだ明細 N件もいっしょに外します。〕元に戻せません）」「外す／やめる」 |
| 取り込んだ明細の「外す」 | 「外す／やめる」 | 「この明細を外しますか（元に戻せません）」「外す／やめる」 |

- 文の形は、プランの一覧の「このプランを外しますか（…）」に合わせる。
- 元に戻せるかは、今の働きのとおりに書く。面談の記録は「元に戻す」で戻る（外した後の知らせも「面談の記録を外しました（元に戻すで戻せます）」）。控えと明細の記録は「元に戻す」の対象でないので「元に戻せません」。
- 確かめを持ち越さない: 控えの一覧を閉じたら確かめも閉じる。面談の確かめは記録ごとに持つ（ほかの記録を開いたときに付かない）。明細の口座・カードは、ほかの行の「直す」を押したら確かめを閉じる。

### 3. 文と2つのボタンを分ける

| 所 | 後の形 |
|---|---|
| 事務所の既定値の「コードを外す」の確かめ | 文の後ろに、2つ一緒に折り返す枠で「外す（赤）」「やめる」（間 12px） |
| 説明の文（カスタム層）などの「公式に戻す」の確かめ | 同じ形で「戻す」「やめる」 |
| URL生成のひな形を選び直す確かめ | 文の後ろに、小のボタンで「切り替える」「キャンセル」（間 8px。下の追記） |
| 受け取った書類の「消す」の確かめ | 文と「消す」「やめる」の間を空け、2つのボタンを一緒の枠に（言葉・ボタンの段は今のまま） |
| 明細の口座・カード、取り込んだ明細の確かめ | 「外す」「やめる」を2つ一緒の枠に（幅が狭いときに1つずつ別の行に落ちない） |

- ひな形の確かめの進むボタンは「選ぶ」→「切り替える」、文は切り替え先の名前と消える物を書く形に（下の追記 2026-11-23。初めは「選んだひな形にする」にしたが、文と合わせても何が起きるかが読み取りにくかった）。
- 段は 0240 のとおり: 文の中に置く物は控えめ（下線のリンク）、行の中でほかの部品と並ぶ物は小、外す・消す・取り消すは赤。

### 4. 入力・設定の途中をやめるのは「キャンセル」

| 所 | 前 | 後 |
|---|---|---|
| 事務所の既定値の「機能を有効にするコードを入れる」 | 確かめて入れる／やめる | 確かめて入れる／キャンセル |
| 事務所の既定値の「推定の値」を変える所 | この値にする／やめる | この値にする／キャンセル |
| 書類の読み取りの確かめの表で、候補の値を直す所 | 入れる／やめる | 入れる／キャンセル |
| 明細の取り込みの「取り込む（○行）」 | 取り込む／やめる | 取り込む／キャンセル |
| 明細の「承認して仕分けに入れる」 | 承認して仕分けに入れる／やめる | 承認して仕分けに入れる／キャンセル |
| 明細の「確認シートを書き出す」の前の注意 | 分かったうえで書き出す／やめる | 分かったうえで書き出す／キャンセル（提案書・持ち帰り用のレポートの保存の前の注意と同じ） |

### 5. 進むボタンが左・取り消しが右

| 所 | 前 | 後 |
|---|---|---|
| 発行した URL の「取り消す」「受け付けを終える」の確かめ | やめる／はい、取り消す | はい、取り消す／やめる |
| AI が発行した URL の「取り消す」の確かめ | ボタンの段の中に、文・「取り消す」（色なし）・「やめる」（次の行に落ちる） | 発行した URL の確かめと同じ形（元のボタンの段とは別の枠・「はい、取り消す」〔赤〕／「やめる」）・同じ文（1か所の `CANCEL_ASK_TEXT`。下の追記）。確かめの間、元の「取り消す」は押せない |

## 変えないもの

- 「やめる」のままにした確かめ: 入力項目のパネルの「一緒に外す物」、受け取った書類の「消す」、要望・不具合を送るの「すべて消す」、書類の候補を「捨てる」、お客さまの回答ページの「この端末の入力を消す」、明細の「同じ明細ではありませんか？」、機能のコードを「外す」、説明の文を「公式に戻す」、発行した URL・AI が発行した URL の「取り消す」。（ひな形を選び直す確かめは、追記 2026-11-23 で「キャンセル」にした）
- 選ばせる問い（世帯を離れる・プランを帯から外す）の「やめる」と、「共有をやめる…」の「やめない」。
- 今の「キャンセル」（入力項目のパネルの足元・世帯の一覧の行の操作・区分の設定・プランの一覧の確かめ・この時点を残す・面談の記録を足す／直す・保存の前の注意 など）。
- Esc の動き（0239）: 行の中の確かめは重ねて出す物ではないので、Esc は確かめを出している画面を閉じる（確かめだけを閉じない）。開き直したときに確かめは残らない。

## 追記（2026-11-23）: ひな形の確かめの言葉・取り消しの確かめの文を短く・法人経営者向けの機能の説明

利用者が画面で見て、次の3点を直した（利用者の判断）。

1. **URL生成のひな形を選び直す確かめ**は「直した項目は、選んだひな形の項目に戻ります。…よろしいですか。」「選んだひな形にする」では、何が起きるかがひと目で分からなかった。切り替え先の名前と、消える物を書く。ひな形を切り替えるのは、項目を選んでいる途中をやめる物なので、取り消しは「キャンセル」（1 の目安）。

   | 切り替え先 | 文 | ボタン |
   |---|---|---|
   | シンプル・詳細・見直し（項目を直したときだけ聞く） | 「詳細」に切り替えると、項目に加えた変更は消えます（書類・独自の質問は残ります）。 | 切り替える／キャンセル |
   | 保存したカスタム（項目を直したか、書類・独自の質問があるときに聞く） | 「（名前）」に切り替えると、項目に加えた変更と、今の書類・独自の質問は消えます（「（名前）」の項目・書類・独自の質問になります）。消える物が片方だけなら、その片方だけを書く | 同じ |

   - 「選んだひな形」でなく名前を書くのは、押したラジオのすぐ下に出る確かめで、どれに切り替えるのかを読み返さなくて済むため。「戻ります」は、元のひな形に戻るとも読めたので、「切り替える」「消えます」と書く。
2. **発行した URL の「取り消す」の確かめ**の文を短くし、文字「中」・幅 1440px・1000px で、文の右に「はい、取り消す」「やめる」が1行に並ぶようにする（幅が足りないとき・文字「大」・幅 1000px では、2つのボタンが一緒に次の行へ）。文は FP が作った URL と AI が発行した URL で1か所（`hearing/web.ts` の `CANCEL_ASK_TEXT`）。

   | 確かめ | 前 | 後 |
   |---|---|---|
   | 取り消す（届く前） | お客さまはこの URL を開けなくなります（途中の回答も送れません）。取り消しますか。（AI が発行した URL は「途中のお答え」） | お客さまはこの URL を開けなくなります。取り消しますか。 |
   | 取り消す（回答が届いている） | 届いている回答を受け取らずに、サーバーから消します（もう受け取れません）。お客さまもこの URL を開けなくなります。取り消しますか。（幅 1000px で2行） | お客さまはこの URL を開けなくなり、届いた回答も消えます。取り消しますか。 |
   | 受け付けを終える | お客さまはこの URL を開けなくなり、書類も届きません。受け付けを終えますか。（幅 1000px でボタンが次の行） | お客さまはこの URL を開けず、書類も届きません。受け付けを終えますか。 |

   - 「途中の回答も送れません」は、開けなくなることに含まれるので外した。回答が届いているときの「受け取らずに消す」は「届いた回答も消えます」として残した（意味は変えない）。
3. **事務所の既定値の「法人経営者向けの機能」の説明**の「会社を顧問先に持つ FP 向けの機能です」を「法人を顧問先に持つ FP 向けの機能です」に（見出しの「法人経営者向け」と同じ言葉）。記録 0105・0107・0110 の同じ言い方も合わせた。

## 確かめたこと

- 直した所を、見えないブラウザで実際に押して確かめた（文字の大きさ 中・大 × 幅 1440px・1000px）。文とボタン・ボタンどうしの重なりは 0、ボタンの中の折り返しは 0、2つのボタンが別々の行に分かれた所は 0。ボタンどうしの間は 6〜14px。
  - 幅が足りないときは、文が折り返して、2つのボタンが一緒に次の行に並ぶ（控えの一覧の文字「大」・幅 1000px、取り込んだ明細の幅 1000px、コードを外す・公式に戻す・ひな形の確かめ）。
- 取り消しを押すと元の並びに戻ること、進むボタンの働きが今までどおりなこと（控え・面談の記録・口座・取り込んだ明細が外れる、面談の記録は「元に戻す」で戻り、控えは戻らない、URL が取り消される、公式に戻る、選んだひな形になる）。
- 確かめを出したまま別の行の操作を押したとき・画面を閉じて開き直したとき・Esc で閉じて開き直したときに、確かめが残らないこと。
- キーボード: 確かめを出すボタンを Enter で押した後、Tab で確かめの最初のボタン（進むボタン）に移る。
