# 0028. 住まい以外の不動産の家賃収入・経費・不動産所得と、土地と建物の行

- 状態: 採用（一部未確定）（2026-10-20）
- 固定の強さ: β公開から変えない（骨格）。世帯のデータの欄（`accounts[].property` とその中の `structure`・`builtYear`・`landShare`・`acquisition`・`rental`・`expenses`・`sale`、`debts[].property`）、行ID（`cf.balance.account.realEstate.land`・`cf.balance.account.realEstate.building`・`cf.expense.other.realEstate`。家賃収入は既存の `cf.income.other.rental`）、計算部品ID（`asset.realEstate`）、合計所得金額の任意の欄 `realEstate`（`tax.totalIncome` の約束の版 1.4）、負債の返済の任意の欄 `interest`（`debt.schedule` の約束の版 1.2）は骨格。法定の耐用年数・償却率の持ち方と、画面・帳票の見せ方は後から変えてよい（変えたら追記に書く）

## 背景

- 住まい以外の不動産（資産の器の種類 `realEstate`。0025 の6）は評価額と増減率だけで、賃貸に出している物件の家賃収入・経費・ローン・税を入れる場所が無かった。資産の多い世帯では、貸しているマンションの家賃収入とその不動産所得の税・国民健康保険料が家計に効く。
- エンジンは持ち家の評価額を土地と建物に分けて計算していた（0025 の2）が、表には合計の1行（`cf.balance.account.realEstate`）しか出していなかった。資産と負債のタブ（0027）で「建物は年数とともに減り、土地は残る」を見せるには、土地と建物の行が要る（0027 の未確定）。
- 0002（金額・率・丸め）、0003（年の値・月の値）、0004 の6（科目の木。中分類は固定）、0006（部品・約束の版）、0008 の9（器の型）、0011 の5（形式の版と一方向の移行）、0025（全資産・全負債のバランスシート）が前提。

## 決定

### 1. 入力（`accounts[].property`・`debts[].property`）

- 不動産の器に、任意の「中身」`property` を足す。入れた器は計算部品 `asset.realEstate` が評価・家賃・経費・売却を計算する。入れていない器は今までどおり（評価額の増減率か資産クラスの利回りで1行）。
  - `structure`（構造。省略は木造）・`builtYear`（建った年。省略は取得の年、取得も無ければ時価の時点の年＝新築）・`landShare`（土地の割合。省略は前提 `realEstateValuation.landShare` → 目安 0.3、目安を使ったら知らせ `N_DEFAULT_USED`）
  - `acquisition`（取得: `price` 土地と建物の合計の取得価額・`at` 取得の年月。減価償却の基）
  - `rental`（貸している: `monthly` 月額の家賃（値の箱）・`vacancyRate` 空室を見込む割合（省略は0）・`growth` 家賃の変化率（省略は0）・`from` 貸し始め（省略は取得の月。取得も無ければ前から）・`to` 貸し終わり（省略は売却の前の月か表の最後））
  - `expenses`（経費: `annual` 年額（値の箱。持っている間、12か月に分ける）・`rate` 受け取る家賃に対する割合（管理委託料など）・`growth` 年額の変化率（省略は0））。年額と割合は足す。
  - `sale`（売却の予定: `at`・`price`（省略はその年の評価額）・`costRate`（省略は前提 → 目安 0.04））
- その不動産のローンは既存の負債の型で入れ、`debts[].property` に不動産の器の ID を書く（種類は `other`。返済はこれまでどおり `cf.expense.debt.other` に出る）。住宅ローン控除の対象にはしない。
- 空欄と推定の印は既存の決まり（省略の既定は画面に薄く見せ、書き戻すと省略に戻る）。

### 2. 評価額（土地と建物）

- 器の時価（`asOf` の時点）を土地の割合で分け、持ち家と同じ決まり（0025 の2）で動かす: 土地は器の `valueGrowth`（入れていれば土地の増減率として使う）→ 前提の `landGrowth` → 物価上昇率、建物は構造の耐用年数で定額で減らし下限より下げない（中古は今の築年数の割合に対する比）。計算は持ち家と共通の SDK の関数（`landBuildingValuer`）。
- 売った年の年末には持っていない（0025 の4 と同じ）。

### 3. キャッシュフロー表の行

- 家賃収入は既存の `cf.income.other.rental`（貸している月ごと、月額×(1−空室の割合)。家賃の変化率は計算基準年（貸し始めが後ならその年）の翌年から）。経費は新しい明細 `cf.expense.other.realEstate`。売却の手取りは既存の `cf.income.lumpSum.realEstateSale`（計算式ID `asset.realEstate.sale`）。どれも名義の人と器の ID を付ける。
- **不動産の評価額は土地と建物の行に分ける**: `cf.balance.account.realEstate.land`・`cf.balance.account.realEstate.building`（持ち家は `housing.valuation`、中身を入れた住まい以外の不動産は `asset.realEstate`）。合計の行は出さず、**不動産の合計は `cf.balance.account.realEstate` とその下の行の合計**（科目の木の親＝子の合計。0004 の6）。中身の無い不動産の器だけが今までどおり `cf.balance.account.realEstate` そのものに出る。金融資産の合計には入れない（0025 の1）。
- 画面と提案書の表は、家賃収入・経費のある世帯だけ「家賃収入」「不動産の経費」の行を出し、「その他の収入」「その他の支出」から外す。

### 4. 不動産所得と税・社会保険

- 年ごと・名義の人ごとに、**不動産所得＝家賃収入−経費（貸している月の分）−減価償却費−借入の利息**。計算基準年の2年前から出す（前の年の所得で決まる住民税・国民健康保険料のため）。
- 減価償却費: 建物の取得価額（取得価額×(1−土地の割合)）×定額法の償却率。償却率は1÷耐用年数を小数3桁に切り上げた値（減価償却資産の償却率等表の定額法と同じ値になる）。耐用年数は住宅用の建物の法定耐用年数（木造22・軽量鉄骨19・重量鉄骨34・鉄筋コンクリート47年。0025 の3 の目安と同じ値だが、こちらは前提で変えない）。中古（建った年が取得の年より前）は簡便法（全部過ぎていれば法定×0.2、一部なら法定−経過＋経過×0.2。端数は切り捨て、2年未満は2年）。貸し始め（取得が後なら取得の月）から、貸している月数で月割りし、帳簿の残りが1円になるまで。円未満は切り捨て（規則ID `conv.realEstate.depreciation`。法令の端数の扱いは原本で確かめる前の仮の規約）。取得の入力が無ければ減価償却費を入れない（知らせ `N_INPUT_REQUIRED`）。
- 借入の利息: `debts[].property` でその不動産を指す負債の、年ごとの利息（`debt.schedule` の任意の欄 `interest`。計算基準月から。ボーナス返済の分を含む）の、貸している月数の分。
- **損益通算**: 合計所得金額（`tax.totalIncome`）に不動産所得を足す。損失（マイナス）はほかの所得から引く。ただし**損失のうち土地の取得のための借入の利息の分は引けない**（租税特別措置法41条の4）。土地の分は、借入額のうち建物の取得価額を超える部分の割合（借入は建物から先に充てたとみなす）で分ける。合計所得金額は0より下げない。
- 合計所得金額を読む部品（所得税・住民税・国民健康保険料・後期高齢者医療・介護保険・配偶者控除などの所得の要件）には、何も変えずに入る。

### 5. 売却

- 持ち家（0025 の4）と同じ考え方: 売る月に、売却価格から費用を引いた手取りを一時金の収入にし、その年の年末からは持っていない。家賃は前の月まで、経費の年額は持っている月まで。ローンの残りは返済の予定のまま（売るときに返すなら繰上返済で入れる）。

### 6. バランスシート（アプリと提案書。`report/src/bsGroups.ts`）

- 換金しにくい資産の中を「土地」「建物」（持ち家と住まい以外の不動産の合計）と「その他の不動産」（中身の無い不動産）に分ける。持ち家（土地・建物）の1つの箱はやめる。住まい以外の不動産のローンは負債の側の「不動産のローン」。
- 資産と負債のタブ: 図・推移のグラフ（不動産の区分は土地・建物・その他の不動産の合計）・箱の説明に、年に応じた「建物は年数とともに価値が減りますが、土地は残ります」の一言（先の年は「今より○万円少ない○万円ですが、土地（○万円）は残ります」）。
- 提案書: バランスシートの図の換金しにくい資産を「土地」「建物」「車・その他」の箱に、年の抜粋の表の不動産に「土地」「建物」の内訳の行を足す。

### 7. 世帯ファイルの形式

- 任意の欄を足したので、形式の版を `0.6` に上げる（0011 の5。足すだけの MINOR）。`0.5` → `0.6` の変換は版だけを書き換える（中身の無い不動産の器は今までどおりに読む）。中身とローンの指定を持つ `0.6` の見本を `tests/fixtures/household-format/0.6/` に足す。古い版のアプリは `0.6` のファイルを読むだけで開く。
- AI に渡す縮約版の許可リストに `account.property`・`debt.property` を入れ、版を `reduced@4` にした（計算に要る数の項目。0015 の6）。

## 理由

- **器に中身を足す（新しい集まりを作らない）**: 住まい以外の不動産は既に器 `realEstate` として持っていて、評価額・名義・時点を使い回せる。中身の無い器は今までどおりに動くので、移行の段は版を書き換えるだけで済む。
- **ローンは負債の型のまま、不動産を指す**: 返済の計算（金利の段階・繰上返済・借り換え）を作り直さずに済み、BS の負債・キャッシュフロー表の返済にもそのまま載る。
- **土地と建物を子の行にし、合計の行を出さない**: 合計と子を両方出すと、器の行を足す計算（金融資産・純資産・提案書の表）が二重に数える。科目の木の決まり（親は子の合計）に合わせ、合計は木の上で足す。
- **合計所得金額の部品1か所で足す**: 所得税・住民税・国民健康保険料などは合計所得金額を読む作りなので、そこに足せば全部に入る。
- **法定の耐用年数は前提にしない**: 評価の耐用年数（0025 の3）は市場の価値の減り方の目安で FP が直すが、減価償却は税法の値なので変えさせない。

## 代案（採らなかったもの）

- 新しい集まり `rentalProperties`: 器 `realEstate` と二重になり、評価・BS の分け方を2つ持つことになる。
- 合計の行 `cf.balance.account.realEstate` を残し、土地と建物を別の中分類（`cf.balance.land` など）に置く: 0004 の6 の中分類の固定を変えることになる。
- 家賃収入の新しい行（`cf.income.other.rent`）: 既に `cf.income.other.rental`（不動産の賃料）がある。

## 影響

- 計算部品: `asset.realEstate`（新しい）、`housing.valuation`（土地と建物の計算を SDK の関数に移した。結果は変わらない）、`plan.cashflow` 改訂10（不動産の行を土地と建物に分けた。中身を入れた器は器の残高の計算から外す）、`plan.flows` 改訂7（`asset.realEstate` のお金の動きを集める）、`tax.totalIncome` 約束の版 1.4・改訂5、`debt.schedule` 約束の版 1.2・改訂4。
- 表を読む側: 不動産の合計をちょうど `cf.balance.account.realEstate` の行で読んでいた所は、その下の行も足すように直した（画面・提案書・テスト）。
- テストで確かめること: 土地と建物の評価、家賃（空室・変化率）・経費（年額と割合）、減価償却費（新築・中古の簡便法・月割り・1円まで）、利息（返済額−残高の減りと一致）と土地の分、不動産所得の合計所得金額への反映（損益通算・土地の利息の制限）、所得税・住民税・国民健康保険料が増えること、売却、土地＋建物＝不動産の合計（エンジン・画面・提案書）。

## 未確定・未対応（控えめに扱っていること）

- **譲渡所得の税**（住まい以外の不動産を売るときの分離課税。長期・短期）は計算しない（知らせ `N_NOT_SUPPORTED`（`realEstate.saleTax`））。
- **青色申告**（青色申告特別控除・純損失の繰り越し）と、事業的規模（5棟10室）の扱いは無い。引ききれない損失は捨てる（合計所得金額は0より下げない）。損益通算の順序（一時所得との順など）は合計で近似。
- **自分で住んでいた家を貸すとき**（転用）の帳簿の価額（非業務用の期間の1.5倍の耐用年数で減らす）は扱わず、貸し始めから取得価額で償却する。取得の年月は月で、中古の経過年数は年で数える（月の端数は無視）。
- 計算基準月より前の利息は返済の予定に無いので、前の年の不動産所得には入れない（計算基準年の利息も計算基準月から）。前の年の住民税・国民健康保険料は少し高めに出る。
- 健康保険の被扶養者・国民年金の第3号の判定（収入の要件）には家賃収入を入れない。消費税・不動産取得税・個人事業税は扱わない。
- 将来に買う投資用の不動産（購入の支出・頭金）は無い（中身は今持っている不動産の情報）。
- 共有名義（持分）は無く、名義の人1人の所得にする。
- 法定の耐用年数・償却率を制度データ（0007）に移すか。β公開までに決める。
