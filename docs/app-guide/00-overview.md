# 画面のつくり

アプリの上の帯・タブ・FP のメニューの場所と、アプリに無い操作です。

## 上の帯とタブ {#overview.layout}
探す言葉: 画面の見方、タブ、上の帯、切り替え、文字の大きさ、ベル、どこにある
要点: 上の帯の左に世帯の選択、中ほどにタブ（「入力」「結果」「資産と負債」「収益不動産」「万一のとき」「提案書」）、右に ↶↷・FP のメニュー・文字の大きさ・お知らせのベルがあります。
関係: overview.fpMenu、households.list、households.save、app.notices

- 左: アプリの名前（事務所の名前とロゴを決めていれば、それに替わります）と、開いている世帯の箱です。箱を押すと世帯の一覧が開きます。
- 中ほど: タブです。「入力」「結果」「資産と負債」「収益不動産」「万一のとき」「提案書」が並びます。「収益不動産」は、収益不動産のある世帯にだけ出ます。打ちかけの欄の値が読めないときは、その欄に戻り、タブは切り替わりません。
- 右: 「元に戻す」（↶）・「やり直す」（↷）は、世帯を開いているときだけ出ます。FP のメニューはいつも出ます（世帯を開いていないときは、世帯が無くても開ける物だけが並びます）。そのあとに文字の大きさ（「中」「大」）と、お知らせのベルがあります。
- 左の急ぎの印: 自動保存を止めている・閲覧だけ・保存できなかった・AI と共有中のときと、重大なお知らせがあるときに、短い印が出ます。押すと、それぞれ直す所（世帯の一覧・同意と共有の画面など）へ移ります。

## FP のメニュー {#overview.fpMenu}
探す言葉: FP のメニュー、メニュー、かばん、記録、メモ、面談の履歴、控え、面談の準備、情報を集める、取り込む、事務所の設定、要望
要点: 上の帯の右の「FP のメニュー」に、記録（メモ・面談の履歴）・控え・面談の準備・情報を集める（事前ヒアリング・書類の読み取り）・事務所の設定・要望を送る が入っています。世帯を開いているときだけ出ます。
関係: meeting.memo、meeting.snapshot、meeting.prepare、import.open、office.open、app.notices

「FP のメニュー」を押すと、次のまとまりが開きます。項目を押すか、Esc・外を押すと閉じます。

- 「記録」: 「メモ」（右の端の引き出し）・「面談の履歴」（入力のタブの上に開く）
- 「控え」: 「この時点を残す」・「控えの一覧」
- 「面談の準備」: 「世帯の中身の一覧」・「次の1年に起きること」・「前回から変わったこと」
- 「情報を集める」: 「事前ヒアリング（URL生成・取り込み）」・「AI で書類を読み取る」（保存した世帯のときだけ。プランの編集中は「事前ヒアリング・取り込む」が開きます）
- 「事務所の設定」: 「保存先」・「事務所の共有」・「事務所の既定値」

「情報を集める」と「事務所の設定」は、アプリ（本体）で開いているときだけ出ます。
- 「ファイナンシアへ」: 「要望・不具合を送る」

世帯を開いていないとき（読み込み中・世帯を開けなかったとき）は、「事務所の設定」と「ファイナンシアへ」だけが並びます。

控え・面談の準備・面談の履歴・事前ヒアリングを押すと、入力のタブに切り替わり、入力のホームの上に開きます。

## 開いた画面を閉じる {#overview.close}
探す言葉: 閉じる、閉じ方、×、バツ、Esc、エスケープ、閉じない、画面が消えない
要点: 上に重ねて出る画面（世帯の一覧・お知らせ・入力項目のパネル・事務所の既定値・メモ・根拠など）と、入力のタブの上に開いた物は、どれも右上の「×」か Esc で閉じます。
関係: overview.fpMenu、input.item、households.list

- 重ねて2つ出ているときの Esc は、上の1つだけを閉じます。もう一度押すと、その下の1つを閉じます。お知らせの1件の中身を開いているときの Esc は一覧に戻り、もう一度押すとお知らせが閉じます。
- 文字を打つ欄・選ぶ欄にいるとき、日本語の変換中、プルダウンを開いているときの Esc では閉じません。欄から出てから押すか、右上の「×」を押します。
- 入力項目のパネルは、欄にいても Esc で閉じます。保存していない変更があるときは、すぐには閉じず、変更を捨てるかを選ぶ画面が出ます。
- 事務所の既定値などの中央のパネルは、下の「閉じる」でも閉じます。
- FP のメニューは、項目を選ぶ一覧なので「×」はありません。Esc か外を押すと閉じます。
- どちらを残すかを選ぶ画面（世帯の分岐など）は、選ぶまで閉じられません。保存の前の確かめの画面の「×」と Esc は「やめる」と同じです。
- 面談の記録を足している途中・事前ヒアリングの取り込みを確かめている途中は、Esc では閉じません（書いた物を消さないため）。

## アプリに無い操作 {#overview.notInApp}
探す言葉: できない、無い、CSV、Excel に書き出す、エクセル、印刷、ゴミ箱、複製、コピー、世帯を閉じる、並べ替え、ダークモード、ほかのソフトから移す
要点: 次の操作は今のアプリの画面にありません: 世帯を閉じる・ゴミ箱・お客さまの世帯の複製・世帯の一覧の並べ替え・キャッシュフロー表の CSV や Excel の書き出し・表や提案書の印刷のボタン・暗い画面を選ぶ所・ほかのソフトのデータの取り込み。
関係: export.report、export.takeaway、households.delete

今の画面に無い操作です。手引きに無いからといって、別のボタンで代わりにできるとは限りません。

- 世帯を閉じる: 何も開いていない状態に戻す操作はありません。別の世帯を開いて切り替えます。
- ゴミ箱: ありません。世帯の削除は「完全削除」だけで、元に戻せません。
- お客さまの世帯をそのまま複製する: ありません（見本は「写して手直しする」で写せます）。
- 世帯の一覧の並べ替え: ありません（番号で探す・区分で絞ることはできます）。
- キャッシュフロー表を CSV・Excel で書き出す・表や提案書を印刷する: ボタンはありません（印刷できるのは、事前ヒアリングの送られた内容だけです）。外に出すのは、提案書の「PDFを保存」と、持ち帰り用のレポートです。AI と接続していれば、AI に頼んで表を CSV にすることはできます。
- 暗い画面（ダーク表示）を選ぶ所: 画面にはありません。
- ほかのライフプランソフトのデータを取り込む: 画面の入口はまだありません。
- Excel のヒアリングシート: 今の版では画面に出していません。事前ヒアリングは URL で聞く形だけです。
