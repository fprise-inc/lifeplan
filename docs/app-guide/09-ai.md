# AI と接続する

FP が使う AI のアプリ（Claude など）をファイナンシアと接続します。事務所全体の設定でオンにし、お客さまの世帯は同意を記録してから、期限つきで AI に渡します。AI からの候補は、FP が画面で承認したときだけ入ります。

## 事務所全体で AI と接続する {#ai.connect}
探す言葉: AI と接続、AI接続、AI とつなぐ、AI の設定、オンにする、オフにする、接続の設定、文面をコピー、Claude、MCP
要点: 世帯の一覧のいちばん下の「AI との接続」を押し、「AI との接続（事務所全体の設定）」の「AI と接続する」に印を付けてオンにします。使う AI のアプリには、「AI のアプリに登録する」の「登録する」で登録します（手で書くときは「手動で登録する」の「文面をコピー」）。
関係: ai.register、ai.share、ai.consent

1. 上の帯の世帯の箱を押して世帯の一覧を開き、いちばん下の「AI との接続」を押します（横に「オン」か「オフ（既定）」と出ます）。
2. 「AI との接続（事務所全体の設定）」が開きます。「AI と接続する」に印を付けるとオンになります。
3. 「AI のアプリに登録する」で、使う AI のアプリの「登録する」を押します（AI のアプリに登録する の節）。
4. 「登録する」を使わないときは、「手動で登録する」で使う AI のアプリに合う欄を開き、「文面をコピー」を押して（写した文面には本物の場所が入ります）、AI のアプリの設定に足し、AI のアプリを起動し直します。

- オフにするときは、「AI と接続する」の印を外します。共有していた世帯はすべて取り消されます。
- 「事前ヒアリング・取り込む」の「AI と接続する」と、共有中の帯の「AI との接続の設定」からも、このパネルを開けます。
- 「共有中の世帯」の行の「止める」（2件以上なら「すべて止める」）で、渡している世帯を止められます。
- AI のアプリの設定をアプリが書き換えるのは、「登録する」「場所を直す」「登録を外す」を押したときだけです。

## AI のアプリに登録する {#ai.register}
探す言葉: AI のアプリに登録する、登録する、登録、場所を直す、場所が古い、登録を外す、Claude Desktop、Claude Code、Claude のアプリ、チャット、Codex、ChatGPT、Gemini、設定のファイル、claude_desktop_config.json、claude mcp add、config.toml
要点: 「AI との接続（事務所全体の設定）」の「AI のアプリに登録する」で、「Claude」か「Codex」の行の「登録する」を押すと、その AI のアプリの設定にファイナンシアが登録されます。「Claude」は1回押すと、チャット（Claude のアプリ）と Claude Code の両方に登録します。Claude のアプリは完全に終了してから押します。アプリを入れ直した・動かしたときは「場所が古い」と出るので「場所を直す」を押します。
関係: ai.connect

1. 世帯の一覧のいちばん下の「AI との接続」を押します。
2. 「AI のアプリに登録する」に、「Claude」と「Codex」の行が出ます。行には「登録済み」「未登録」「場所が古い」「このPCに見つかりません」などが出ます。「Claude」の行には、「チャット（アプリ）」と「Claude Code」の2つの状態が並びます。
3. 書く中身を見たいときは「書き込む場所と中身」を開きます（Claude Code の側は「呼ぶコマンド」）。
4. 使う AI のアプリの行の「登録する」を押します。「Claude」は1回押すと、チャット（Claude のアプリ）と Claude Code の両方に登録します。
5. AI のアプリを起動し直します（Claude Code は新しく始めた会話から使えます）。

- 「Claude」は、Claude のアプリをメニューの「終了」で完全に終了してから押します（ウィンドウを閉じるだけでは足りません）。起動中に押すと、Claude Code の側だけ登録し、「Claude のアプリが起動中のため、Claude Code の側だけ登録しました。」と出ます。Claude のアプリは終了するときに設定を書き直すので、起動中に書き込んだ登録は消えてしまうためです。チャットでも使うときは、Claude のアプリを完全に終了してから、もう一度「登録する」を押します。
- Claude のアプリと Claude Code の片方しか無いPCでは、ある側だけに登録します。Claude Code の側は claude コマンドで登録するので、claude コマンドが見つからないときは、チャット（アプリ）の側だけ登録します。Claude Code でも使うときは、「手動で登録する」の文面をコピーしてターミナルで実行します。どちらも無いときは「このPCに見つかりません」と出ます。
- 「Codex」は、パソコン用の Codex（アプリ・ターミナル）です。ブラウザの ChatGPT は接続できません。
- 「場所が古い」: アプリを入れ直した・別の場所に動かしたときに出ます。「場所を直す」で今の場所に書き直します。
- 「登録を外す」で、ファイナンシアの登録だけを外します。「Claude」は1回で、チャット（アプリ）と Claude Code の両方の登録を外します（Claude のアプリが起動中のときは、終了してからもう一度押します）。
- ほかの設定は消しません。書く前の設定のファイルは、このアプリのデータの場所に控えを残します。
- 設定のファイルを読めないとき（コメントが入っているなど）は書きません。「手動で登録する」の文面で手で足します。
- Mac で dmg から直接開いたアプリは登録できません。「アプリケーション」フォルダに入れてから開き直します。
- Gemini は、今は一覧に出していません。Gemini のアプリがパソコンの中の接続の道具に対応したら足します。

## 世帯ごとの同意を記録する・撤回する {#ai.consent}
探す言葉: 同意、外部AIへの提供の同意、同意を記録する、撤回、撤回を記録する、同意を記録し直す、同意しなかった
要点: 世帯の一覧のいちばん上の「この世帯の同意と共有」で「AIとの共有」の画面を開き、「外部AIへの提供の同意」の説明をお客さまに見せて、欄を埋めて「同意を記録する」を押します。
関係: ai.share、households.fictional、ai.connect

1. 世帯を保存しておきます（保存していない世帯は AI に渡せません）。
2. 世帯の一覧のいちばん上の「この世帯の同意と共有」を押します（AI と接続していれば、FP のメニューの「AI で書類を読み取る」からも開けます）。
3. 「同意と共有」のタブの「外部AIへの提供の同意」で、説明の文をお客さまに見せます。
4. 「同意の取り方」と「同意を得た日」を入れ、確かめの印を付けて「同意を記録する」を押します。断られたときは「同意しなかったことを記録する」を押します。

- 撤回: 「撤回を記録する」を押し、撤回の受け方と日付を入れ、確かめの印を付けて、もう一度「撤回を記録する」を押します。その世帯の共有はすぐに止まります。
- 前の版の説明やヒアリングシートの同意欄で同意した世帯は、書類を AI に渡す前に「今の説明で同意を記録し直す」で取り直します。
- 架空の世帯は同意が要りません。
- AI と接続していないときは、「この世帯の同意と共有」の行が出ず、同意と共有の画面には「AI と接続していません（既定）。」と出ます。先に「AI との接続」でオンにします。
- 同意の記録が無くても、事務所のプライバシーポリシーを確かめていれば渡せます（事務所のプライバシーポリシー の節）。

## 事務所のプライバシーポリシー {#ai.officePolicy}
探す言葉: 事務所のプライバシーポリシー、プライバシーポリシー、同意が無い世帯、同意の答えが無い、同意を取らずに渡す、個人情報の取り扱い
要点: 「AI との接続（事務所全体の設定）」の「事務所のプライバシーポリシー」で、事務所のプライバシーポリシーに AI の利用を書いていることを確かめて印を付けると、同意の答えが無い世帯も AI に渡せます。「同意しない」と答えた世帯・撤回した世帯は渡せません。
関係: ai.connect、ai.consent、ai.share

1. 世帯の一覧のいちばん下の「AI との接続」を押します。
2. 「事務所のプライバシーポリシー」の区画で、事務所のプライバシーポリシーに、お客さまの情報を外部の AI サービスで扱うこと（AI を使った資料の読み取りや分析）を書いていることを確かめ、印を付けます。確かめた日時が残ります。
3. 同意の答えが無いお客さまの世帯も、「この世帯をAIに渡す」で渡せるようになります。

- 渡せないのは、お客さまが「同意しない」と答えた世帯と、同意を撤回した世帯です（印を付けていても渡せません）。
- 印を外すと、同意の記録が無いまま渡していた世帯の共有は、すぐに取り消されます。
- 保険の書類・課税明細書・路線価図を AI で読み取るときも、同じ考え方です。
- この印は、PC ごとの設定です。

## 世帯を AI に渡す・取り消す {#ai.share}
探す言葉: 世帯を AI に渡す、世帯を渡す、AI に渡す、共有、この世帯をAIに渡す、期限、取り消す、共有を取り消す、AI に見せる
要点: 「AIとの共有」の画面の「この世帯をAIに渡す」で、使うAIのアプリの名前と期限（既定1時間）を選んで「この世帯をAIに渡す」を押します。止めるときは「共有を取り消す」です。
関係: ai.consent、ai.connect、ai.records

1. 同意を記録した世帯（か架空の世帯）を開き、「この世帯の同意と共有」で「AIとの共有」の画面を開きます。
2. 「この世帯をAIに渡す」の所で「使うAIのアプリ（申告）」に名前を入れ、「期限」を選びます（15分〜8時間）。
3. 「この世帯をAIに渡す」のボタンを押します。
4. 共有中は画面の上に「AIに渡しています」の帯が出ます。AI のアプリで、この世帯について頼みます。

- 取り消すときは「共有を取り消す」か、帯の「取り消す」を押します。期限が来る・アプリを閉じると自動で止まります。
- 止まるのはこれからの読み取りだけで、すでに送った内容は AI の会社の側に残ります。
- 渡すのは計算に要る項目だけの縮約版です。メモ・面談の履歴・相談内容などの文章は渡しません。
- 保存していない変更は AI に届きません（保存すると届きます）。

## 世帯をまとめて AI に渡す {#ai.bulkShare}
探す言葉: まとめて渡す、まとめて AI に渡す、複数の世帯を渡す、顧問契約のお客さま全員、区分で渡す、一括、選んだ世帯をまとめてAIに渡す、まとめて取り消す
要点: 世帯の一覧で区分や番号で絞り込み、一覧の上の「選んだ世帯をまとめてAIに渡す」を押します。渡す世帯を選び、「使うAIのアプリ（申告）」と「期限」を入れて「選んだ世帯をAIに渡す」を押します。渡せない世帯は渡さず、理由ごとに件数と顧客番号が出ます。
関係: ai.share、ai.consent、ai.followUp、households.list

1. 上の帯の世帯の箱を押して世帯の一覧を開きます。
2. 「区分」で絞り込みます（例 A 顧問契約）。「番号で探す」でも絞り込めます。
3. 一覧の上の「選んだ世帯をまとめてAIに渡す」を押します（AI と接続しているときだけ出ます）。
4. 絞り込んだ世帯が並びます。初めはすべて選んであります。外したい世帯の印を外します（「すべて選ぶ」「すべて外す」も使えます）。
5. 選ぶとアプリが渡せるかを確かめ、渡せる世帯・もう共有中の世帯・渡せない世帯（理由ごとの件数と顧客番号）が出ます。
6. 「使うAIのアプリ（申告）」に名前を入れ、「期限」を選んで、「選んだ世帯をAIに渡す」を押します。
7. 渡した後は、AI に見える名前（共有中の世帯A など）と顧客番号の対応が出ます。AI の答えはこの名前で並ぶので、どのお客さまかはこの対応で確かめます。

- 渡すときの確かめ・期限・申告・記録は、1件ずつ渡すときと同じです。渡すのは計算に要る項目だけの縮約版で、メモと面談の履歴の文は渡しません。
- 渡せないのは、同意が記録されていない世帯（事務所のプライバシーポリシーを確かめていないとき）、お客さまが「同意しない」と答えた世帯、同意を撤回した世帯、見本の世帯、開けなかった世帯、閲覧だけで開く世帯です。
- 1回に渡せるのは、共有中の世帯と合わせて50件までです。超えるときは、区分や番号で絞り込むか、選ぶ世帯を減らします。一覧が50件を超えるときは、選んでいない状態で始まります。
- 開いている世帯に保存していない変更があるときは、保存した内容を渡します（保存すると AI にも届きます）。
- 止めるときは、一覧の上の「この一覧の共有をまとめて取り消す」を押します（一覧に出ている世帯の共有をまとめて止めます）。1件ずつ止めるときは、帯の「取り消す」か、その世帯の「共有を取り消す」です。

## AI に顧客のフォローを頼む {#ai.followUp}

## AI が発行した URL（Web のヒアリング） {#ai.hearingUrls}
探す言葉: AI が URL を発行しました、AI が発行した URL、AI にヒアリングの URL を作らせる、AI でヒアリングを作る、AI が発行、出どころ AI、まだ世帯の決まっていない、取り消す
要点: AI に頼むと、AI が Web のヒアリングの URL を発行できます。画面の上に「AI が URL を発行しました」の帯が出たら「確かめる」を押し、「AI が発行した URL」で中身を確かめます。世帯に結びついた URL は、その世帯の「発行した URL」に「AI が発行」の印つきで並びます。まだ世帯の決まっていない URL は、帯が消えた後は「発行した URL」の下の「まだ世帯の決まっていない、AI が発行した URL」（件数つき）から開きます。要らなければ「取り消す」を押します。
関係: import.open、import.webCreate、import.webReceive、ai.hearingTemplates、ai.connect

1. AI と接続して、AI のアプリで、渡した世帯の足りない所だけを URL で聞く、新しいお客さまに URL でヒアリングを送る、のように頼みます（新しいお客さまなら世帯を渡さなくても作れます）。AI は発行の前に数と中身を見せて確かめます。
2. 発行すると、画面の上に「AI が URL を発行しました」の帯が出ます。「確かめる」を押すと「AI が発行した URL」が開きます。後から開くときは、「事前ヒアリング・取り込む」の「発行した URL」の下の「まだ世帯の決まっていない、AI が発行した URL」（件数つき）を押します（世帯の決まっていない受け付け中の URL があるときだけ出ます）。
3. 行ごとに、聞く項目・どの世帯の依頼か が出ます（「AI が発行」の印）。
   - 「案内文をコピー」「URL をコピー」で写し、FP がメールなどでお客さまに送ります（アプリも AI もメールは送りません）。
   - 「届いたかを確かめる」で答えが届いたかを確かめます。
   - 世帯の決まっていない依頼は、答えが届いたら「新しい世帯を作って取り込む」か、開いている世帯に取り込むボタンで世帯に移します。世帯の依頼は「この世帯を開く」で、その世帯の「発行した URL」に進みます。
   - 要らなければ「取り消す」を押し、確かめの「取り消す」を押します（お客さまはこの URL を開けなくなります）。
4. 答えの受け取りと取り込みは、ふだんの事前ヒアリングと同じく FP がアプリで行います（AI からは答えを読めません）。

- AI が発行できるのは、アプリが起動していて AI と接続しているときだけです。FP の承認は挟まないので、発行後にここで確かめます。
- 帯は、まだ見ていない URL があるときだけ出ます。一度見ると帯は消えます。その後、世帯に結びついた URL はその世帯の「発行した URL」で、まだ世帯の決まっていない URL は「発行した URL」の下の「まだ世帯の決まっていない、AI が発行した URL」（件数つき）で確かめます。世帯の決まっていない URL に答えが届いていれば、その横に「届いています」と件数が出ます。
- 世帯の決まっていない依頼（新しいお客さま向け）は、どの世帯の「発行した URL」にも並びません。答えが届いたら「AI が発行した URL」で取り込む世帯を選びます（新しいお客さまの世帯を先に作って開いておけば、開いている世帯に取り込むボタンも使えます）。世帯の依頼は、その世帯の「発行した URL」に、「URL生成」で作った URL と一緒に「AI が発行」の印つきで並びます（閲覧だけで開いた世帯では、まだ世帯に移していない依頼に「AI が発行した URL で確かめる」だけが出ます）。
- AI との接続をオフにしても、世帯の決まっていない受け付け中の URL があれば「まだ世帯の決まっていない、AI が発行した URL」（件数つき）から開けます。届いたかを確かめ、取り込む世帯を選び、要らなければ取り消せます（受け取りと取り込みに AI は使いません）。
- 見直し（今の値を見せる）を含む依頼の URL は AI に返さないので、アプリでコピーします。

## AI からのヒアリングのひな形の案 {#ai.hearingTemplates}
探す言葉: ヒアリングのひな形の案、ひな形、テンプレート、AIからのヒアリングのひな形の案、ひな形として保存する、カスタム
要点: AI がヒアリングのひな形の案を出すと、画面の上に「AIから、ヒアリングのひな形の案が届いています」の帯が出ます。「事務所の既定値で確かめる」を押し、「AIからのヒアリングのひな形の案」で「ひな形として保存する」か「捨てる」を押します。
関係: ai.hearingUrls、import.webCreate、office.open

1. 帯の「事務所の既定値で確かめる」を押すと、事務所の既定値の「AIからのヒアリングのひな形の案」が開きます。
2. 票・聞く項目の数・書類と、AIの理由を確かめます。
3. 「ひな形として保存する」を押すと、事務所のひな形に入ります（押すとすぐ保存されます）。要らなければ「捨てる」を押します。

- 保存したひな形は、「URL生成」の「ひな形から始める」の「カスタム」として選べます。
- 同じ名前の事務所のひな形があるときは置き換えます。数に上限があるので、いっぱいのときは要らないひな形を消してから保存します。

## AI に不具合を調べてもらう {#ai.issueReport}
探す言葉: 不具合を調べる、計算がおかしい、計算できない、バグ、不具合の報告、報告をまとめる、不具合を調べて報告をまとめる、エラーの記録、AI に調べてもらう
要点: AI のアプリで使い方の例「不具合を調べて報告をまとめる」を選び、世帯と何がおかしいかを書くと、AI が世帯を調べて、入力が原因か計算の仕組みの不具合の疑いかを根拠と一緒に答え、フォームに貼れる報告の文をまとめます。送るのは FP が「要望・不具合を送る」から行います。
関係: app.errorLog、app.notices、ai.share

1. おかしい世帯を AI に渡しておきます（世帯を AI に渡す・取り消す の節。見本の世帯なら渡さなくてよい）。
2. AI のアプリで使い方の例「不具合を調べて報告をまとめる」を選び、世帯と、何がおかしいか（どの画面の・どの行の・何年目の数字か）を書きます。
3. AI が、エラーの記録・入力の確かめ・計算・数字の根拠で調べ、入力が原因（ここを直せば戻る）か、計算の仕組みの不具合の疑いかを答えます。入力が原因なら、アプリで直せば戻ります。
4. 報告の文ができたら、中身を確かめます。再現の手順は見本の世帯に変更を足す形で書かれ、お客さまの名前・生年月日・実際の金額は入りません。
5. 「要望・不具合を送る」を開き、「フォームを開く」を押して、ブラウザで開いたフォームに報告の文を貼って送ります。

- AI はフォームを開かず、送りません。アプリも何も送りません。
- 見本の世帯で再現できないときは、報告の文にそう書かれます。お客さまの値を書くかは FP が決めます（書くときも、名前・生年月日は書きません）。
- AI がエラーの記録を読めるのは、アプリが起動していて AI と接続しているときだけです。読めないときは、「エラーの記録」の「記録を写す」で写して、AI のアプリに貼ります。
