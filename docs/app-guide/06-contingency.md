# 万一のときのタブ

上のタブの「万一のとき」です。亡くなった・働けなくなった・大きな病気・収入が減った・相場が下がった ときの見通しと、必要保障額を見ます。

## 場面と起きる年を選ぶ {#contingency.scenes}
探す言葉: 万一のとき、死亡、亡くなったら、働けなくなったら、病気、収入が減った、必要保障額、遺族、保険の見直し
要点: 「万一のとき」のタブの上の「場面」で場面を選び、「起きる年」で起きる年を選びます。グラフは「資産の推移」と「必要保障額の推移」を切り替えます。
関係: contingency.premises、contingency.protection、results.market

1. 「万一のとき」のタブを開きます。
2. 「場面」で場面（亡くなったら・働けなくなったら・大きな病気のとき・収入が減ったとき・相場が下がったとき）を選びます。
3. 起きる年の帯で年を押します。「▶ 1年ずつ見せる」で順に動かせます。
4. グラフを「資産の推移」か「必要保障額の推移」に切り替えます。必要保障額の推移では、加入中の死亡保険金も並びます。

- 帯のプランが2つ以上あるときは「見るプラン」で選べます。
- 「気づき」に、保険が切れる年などが出ます。
- 遺族（配偶者・子）がいない世帯では、必要保障額は出しません。

## 想定の前提を直す {#contingency.premises}
探す言葉: 想定の前提、遺族の生活費、整理資金、葬儀費用、働けない期間、減る割合、下がる幅、前提を直す
要点: 「万一のとき」のタブの「想定の前提」で、その場面の前提（遺族の生活費の割合・整理資金など）を直します。直すとすぐ計算し直します。
関係: contingency.scenes、office.display

- プランを見ているときは「前提を直す先:」で「全プラン共通」か、そのプランだけかを選べます（保存したプランだけ）。そのプランだけで変えた所は「↺ 共通に戻す」で戻せます。
- 項目を足すときは「＋ 動かす項目を追加」を押します。足した項目は「外す」で外せます。
- 最初から出す項目と場面の並びは、事務所の既定値の「万一のときのタブ」で決めます。

## 必要保障額の数え方 {#contingency.protection}
探す言葉: 必要保障額の数え方、積み上げ方式、逆算方式、いつまでの資金、保障額の計算方法
要点: 必要保障額の数え方（いつまでの資金を数えるか・出し方）は、万一のときのタブでは直せず、事務所の既定値の「必要保障額の数え方」で決めます。これから作る世帯に写すので、今の世帯には万一のときのタブの「事務所の値にする」で入れます。
関係: office.open、contingency.scenes

1. 世帯の一覧の下か FP のメニューの「事務所の既定値」を開きます。
2. 「万一のときのタブ」の区画の「必要保障額の数え方」で、「いつまでの資金を数えるか」と「出し方」（積み上げ方式か逆算方式）を選びます。
3. パネルの「保存」を押します。

世帯の数え方が事務所の既定値と違うときは、万一のときのタブに案内と「事務所の値にする」が出ます。
