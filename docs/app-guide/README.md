# 画面の操作の手引き（AI接続が読む物）

ファイナンシアの画面の操作（どこを押すか）を、画面ごと・やりたいことごとの短い節で書いた手引きです。
AI接続（`lifeplan mcp`）の `search_app_guide`・`get_app_guide` が、ビルドで同梱したこの手引きを読んで FP の問いに答えます（設計記録 [0227](../decisions/0227-ai-app-guide.md)）。
FP がそのまま読んでも分かるように書きます。

## 書き方

- 1つのファイルが1つの画面（かまとまり）です。名前は `NN-<画面>.md`（2桁の数で並べる）。1行目は `# 画面の題`、その下に短い前書きを書けます。このファイル（README.md）は同梱しません。
- 節は次の形で書きます。

  ```text
  ## 題 {#画面.名前}
  探す言葉: 言葉、言葉
  要点: 1〜2文の答え
  関係: 画面.名前、画面.名前（任意）

  本文
  ```

  - id は英小文字で始まる `画面.名前`（例 `results.planSave`）。AI がこの id で節を読むので、むやみに変えません。
  - 「探す言葉」は FP が言いそうな言い方（読点で区切る）。「要点」は問いへの短い答えです。
- **画面のボタン・見出し・タブ・メニューの名前は、画面の文そのまま（一字一句）を「」で書きます。** 「」はそれ以外に使いません（言葉を目立たせたいときは、言い方を変える）。
  - `app/test/app-guide.test.ts` が、「」の中が今の画面の文（`app/src` の文・差し替えられる文の一覧・提案書の章の名前など）にあるかを確かめます。画面の言葉を変えたら、手引きも一緒に直してください（直し忘れると CI で落ちます）。
  - 件数など画面で変わる所（「控えの一覧（3件）」の 3件）は、変わらない頭の部分だけを「」に入れます（「控えの一覧」）。
- 書くのは、今の画面にある物だけです。まだ入っていない画面・開いている変更の画面は書きません。
- 言葉: です・ます で短く。「接続口」は書かず「AI と接続」「AI接続」と書きます。入力のまとまりは「入力項目」と呼びます。
