# 控え・面談・書き出し

控え（その時点の写し）・面談の準備と履歴・メモと、提案書（PDF）・持ち帰り用のレポートの書き出しです。

## 控えを残す・控えの一覧 {#meeting.snapshot}
探す言葉: 控え、スナップショット、この時点を残す、記録を残す、前回の状態、控えの一覧
要点: FP のメニューの「控え」の「この時点を残す」で、今の世帯の写しを残します。残した控えは「控えの一覧」で見られます。
関係: meeting.prepare、balance.view、export.report

1. 上の帯の「FP のメニュー」の「控え」の「この時点を残す」を押します。
2. 入力のタブの上に「この時点を残す」が開きます。「メモ（任意）」を入れて「残す」を押します。

- 「控えの一覧」で、日時・きっかけ・メモ・プランが並びます。要らない控えは「外す」で外せます（押すと確かめが出ます。外した控えは元に戻せません）。
- 提案書の PDF・持ち帰り用のレポートを保存したときも、自動で控えが残ります。
- 保存していない新しい世帯の控えは、アプリを閉じると消えます。見本の控えは見本に残ります（「最初の状態に戻す」を押すと消えます）。
- 控えとの比較は、資産と負債のタブの「前回と比較」か、面談の準備の「前回から変わったこと」で見ます。

## 面談の準備 {#meeting.prepare}
探す言葉: 面談の準備、面談の前、世帯の中身の一覧、次の1年に起きること、前回から変わったこと、見直し面談
要点: FP のメニューの「面談の準備」に「世帯の中身の一覧」「次の1年に起きること」「前回から変わったこと」があります。押すと入力のタブの上に開きます。
関係: meeting.snapshot、meeting.history

- 「世帯の中身の一覧」: 入っている物を一覧で読みます。押すと、その入力項目が開きます。
- 「次の1年に起きること」: 基準の月から1年の出来事が並び、行の「開く」でその入力項目が開きます。
- 「前回から変わったこと」: 「比較する控え」を選ぶと、控えの時点の見込みと今の見込み、入力の違いが出ます。「前回の面談の記録を開く」で前回の記録も開けます。

AI と接続していれば、AI に面談でお客さまに聞くことをまとめてもらうこともできます。

## 面談の履歴 {#meeting.history}
探す言葉: 面談の履歴、面談の記録、議事録、話したこと、決めたこと、次までにやること
要点: FP のメニューの「記録」の「面談の履歴」を開き、「＋ 面談の記録を足す」で記録を足します。
関係: meeting.prepare、meeting.memo、export.takeaway

1. FP のメニューの「面談の履歴」を押すと、入力のタブの上に「面談の履歴」が開きます。
2. 「＋ 面談の記録を足す」を押し、「面談の日」と、お客さまと一緒に見てよい欄（「話したこと」「決めたこと」「次までにやること」）、FP だけの欄を入れます。
3. その日の控えをつなぐこともできます。
4. 「足す」を押します。

- お客さまと一緒に見るときは「FP だけの欄を隠す（お客さまと一緒に見るとき）」に印を付けます。
- 一覧の行の「開く」で中身を見て、「直す」「外す」ができます。
- 面談の履歴とメモは AI に渡しません。
- 保存していない新しい世帯の面談の記録は、アプリを閉じると消えます。見本の面談の記録は見本に残ります（「最初の状態に戻す」を押すと消えます）。

## メモ {#meeting.memo}
探す言葉: メモ、FP のメモ、覚え書き、顧客に見せないメモ
要点: FP のメニューの「記録」の「メモ」を押すと、右の端にメモの引き出しが開きます（お客さまには見せません）。
関係: meeting.history

メモは1行に1つ書きます。AI には渡しません。

## 提案書（PDF）を作って保存する {#export.report}
探す言葉: 提案書、PDF、PDF を保存、書き出し、印刷、プレゼン資料、章、宛名
要点: 上のタブの「提案書」で、載せるプランと章を選んで「見本を作る」を押し、右の見本を確かめて「PDFを保存」を押します。
関係: export.takeaway、meeting.snapshot、overview.notInApp

1. 結果のタブでプランを作り、帯に並べておきます（帯にプランが無いと作れません）。
2. 上のタブの「提案書」を開き、「提案書（PDF）」を選びます。
3. 左で「載せるプラン」（「提案」のプランと比較に載せるプラン）・「章」・「紙の向きとキャッシュフロー表」・「宛名と担当」を決めます。
4. 「見本を作る」を押すと、右に見本が出ます（「次へ →」「幅に合わせる」などで見ます）。設定を変えたら「作り直す」を押します。
5. 「PDFを保存」を押します。アプリを起動して最初の保存のときに、暗号化されないことの注意が出るので「わかりました。保存する」を押します。

- 保存すると、その時点の控えが自動で残ります。
- 印刷のボタンはありません。保存した PDF を開いて印刷します。
- 提案書のタブはアプリでだけ出ます。

## 持ち帰り用のレポート {#export.takeaway}
探す言葉: 持ち帰り用のレポート、お客さまに渡す、HTML、ブラウザで開くファイル、パスワード、お客さまが動かせる
要点: 上のタブの「提案書」で「持ち帰り用のレポート」を選び、載せるプラン・お客さまが動かせるつまみ・載せる画面を選んで「ファイルを保存」を押します。お客さまはブラウザで開きます。
関係: export.report、meeting.snapshot

1. 結果のタブでプランを作り、帯に並べておきます（帯にプランが無いと作れません）。上のタブの「提案書」を開き、「持ち帰り用のレポート」を選びます。
2. 「載せるプラン」「顧客が動かせるつまみ」「載せる画面」と宛名を決めます。
3. 中身を守るときは「開くときのパスワード」で「パスワードを付ける（中身を暗号化します。おすすめ）」に印を付け、パスワードを入れます（「作る」で自動で作れます）。
4. 「ファイルを保存」を押します。

- パスワードを付けないときは、保存のたびに注意が出ます。
- パスワードは、ファイルとは別の方法（電話・別のメッセージなど）で伝えてください。
- 保存すると控えが自動で残ります。
