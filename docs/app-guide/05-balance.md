# 資産と負債のタブ・収益不動産のタブ

上のタブの「資産と負債」（家計のバランスシート）と「収益不動産」（収益不動産のある世帯だけ）です。

## 資産と負債のタブの見え方 {#balance.view}
探す言葉: 資産と負債、バランスシート、BS、純資産、時点を並べる、1年ずつ見る、プランを比較、前回と比較
要点: 「資産と負債」のタブで、見せ方を「1年ずつ見る」「時点を並べる」「プランを比較」「前回と比較」から選びます。
関係: balance.health、results.planCompare、meeting.snapshot

- 「1年ずつ見る」: 下の年のつまみで年を動かします。「▶ 1年ずつ見せる」で順に動き、「主な年へ」で主な年に跳べます。
- 「時点を並べる」: 今・子の独立・退職などの時点を並べます。「＋ 時点を足す」で足し、時点の見出しを押すと年を選び直せます。
- 「プランを比較」: 帯のプランが2つ以上あるときだけ出ます。左右のプランを選んで並べます。
- 「前回と比較」: 控えがあるときだけ出ます。「比較する控え」を選ぶと、前回の見込みと今の実際が並びます。
- 「表で見る」を開くと、資産・負債・純資産の表が出ます。
- 法人経営者向けの機能を使っている世帯では、「見るもの」で家計のバランスシートと合算BS を切り替えます。

## 家計の体力の目安・お金の3つの分け方・表示の設定 {#balance.health}
探す言葉: 家計の体力の目安、すぐ使えるお金、お金の3つの分け方、使うお金・貯めるお金・増やすお金、資産と負債の表示の設定
要点: 「1年ずつ見る」の下に「家計の体力の目安」、その下に「お金の3つの分け方」が出ます。出すかどうか・呼び方・目安の幅は、タブの「表示の設定」で変えます。
関係: balance.view、office.display

- 「家計の体力の目安」: すぐ使えるお金・値動きのある資産・負債の重さ・純資産の目安が出ます。「目安の幅を変える（表示の設定）」で幅を変えられます。
- 「お金の3つの分け方」: 今の時点のお金を3つに分けた説明用の図です（計算には混ぜません）。「何か月分」「何年先まで」で分け方を変え、「内訳を見る」で中身を見られます。
- 資産と負債のタブの「表示の設定」（結果のタブの設定とは別）で、「時点を並べる」の既定・家計の体力の目安を出すか・お金の3つの分け方の呼び方を選びます。

## 収益不動産のタブ {#rental.view}
探す言葉: 収益不動産、賃貸物件、不動産投資、物件ごとの数字、売る年、利回り
要点: 収益不動産のある世帯だけ「収益不動産」のタブが出ます。物件ごとの年ごとの数字と指標、売る年を変えた比較が見られ、「この売り方でプランを作る」でプランにできます。
関係: results.planCreate

- 物件が2つ以上のときは「見るもの」で全体と物件を切り替えます。
- 物件の表の年を押すと、その年の指標が出ます。
- 「売る年を変えた比較」の行の「この売り方でプランを作る」で、その売り方の新しいプランができます。
- 物件の入力は、入力のタブの「収益不動産」で入れます。
