# 取り込む（事前ヒアリング・書類の読み取り）

お客さまに URL で聞く事前ヒアリングと、書類の読み取り（保険の書類と、相続税の試算に使う課税明細書・路線価図）です。取り込んだ値は、確かめて承認した物だけが現状に入ります。

## 取り込むを開く {#import.open}
探す言葉: 取り込む、事前ヒアリング、ヒアリング、取り込み、インポート、回答を取り込む
要点: FP のメニューの「情報を集める」の「事前ヒアリング（URL生成・取り込み）」を押すと、入力のタブの上に「事前ヒアリング・取り込む」が開きます。
関係: import.webCreate、import.webReceive、import.documentAi、import.documentLand、ai.hearingUrls

1. 上の帯の「FP のメニュー」を押します。
2. 「情報を集める」の「事前ヒアリング（URL生成・取り込み）」を押します。
3. 入力のタブに切り替わり、「事前ヒアリング・取り込む」が開きます。中には次が並びます。
   - 「事前ヒアリング内容を作る」（「URL生成」）
   - 「事前ヒアリングを取り込む」（回答が届いたとき・取り込み待ちがあるときだけ。件数の知らせが出ます）
   - 「発行した URL」（この世帯の URL の一覧。「URL生成」で作った URL と、AI が発行した URL が新しい順に並びます）
   - 「AI で書類を読み取る」

   「AI で書類を読み取る」の見出しのすぐ下に、今読める書類が「読める書類: 」に続けて1行で出ます（今は保険の設計書・証券、固定資産税の課税明細書、路線価図）。

- まだ何も入れていない新しい世帯では、入力のホームの「取り込む」からも開けます。
- 回答が届くと、入力のホームとお知らせのベルにも知らせが出ます。
- 「発行した URL」の行には、作った側の印（「FP が作成」か「AI が発行」）と状態（「発行済み」「回答あり」「受け取り済み」「取り込み済み」「期限切れ」「取り消し」など）が出ます。URL が1件も無い世帯では「発行した URL」は出ません。
- まだ世帯の決まっていない、AI が発行した URL（新しいお客さま向け）は、どの世帯の「発行した URL」にも並びません。1件以上あるときは「発行した URL」の下に「まだ世帯の決まっていない、AI が発行した URL」（件数つき）が出るので、押して取り込む世帯を選びます（AI が発行した URL の節）。
- 取り込みは現状に入るので、プランの編集中は取り込めません（「現状に切り替える」を押します）。
- Excel のヒアリングシートは、今の版では画面に出していません。

## URL で聞くヒアリングを作って送る {#import.webCreate}
探す言葉: URL のヒアリング、Web のヒアリング、URL生成、URL を発行、ヒアリングを送る、お客さまに聞く、事前ヒアリングの URL、ヒアリングシート
要点: 「事前ヒアリング・取り込む」の「URL生成」で聞く項目を選び、「URL を発行する」を押します。「URL をコピー」「案内文をコピー」でお客さまに送ります（アプリはメールを送りません）。
関係: import.open、import.webReceive、import.webManage、ai.hearingUrls

AI と接続していれば、AI に URL を作ってもらうこともできます（AI が発行した URL の節）。

1. 世帯を保存しておきます（保存していない世帯では発行できません）。
2. 「事前ヒアリング・取り込む」の「URL生成」を押すと、「URL生成（Web の事前ヒアリング）」が開きます。右にお客さまの画面の見本が出ます。
3. 「ひな形から始める」で「シンプル」「詳細」「見直し」か、保存したひな形を選びます。
4. 「聞く項目」で聞く項目を選びます。必要なら「FP の独自の質問を足す」で質問を足し、「送っていただきたい書類」で頼む書類を選びます。
5. 「URL を発行する」の所で「顧客番号（英数字）」「事務所名」などを入れ、「URL を発行する」のボタンを押します。
6. 発行できたら「URL をコピー」と「案内文をコピー」で写し、メールなどでお客さまに送ります。

- 選んだ項目は「カスタムとして保存」で、次から使うひな形にできます。
- 期限は発行から30日です（延長できます）。

## 届いた回答を取り込む {#import.webReceive}
探す言葉: 回答が届いた、回答を受け取る、受け取る、取り込む、承認して現状に入れる、ヒアリングの結果
要点: 「発行した URL」の行の「受け取る」を押すと、取り込みの候補の画面に進みます。入れる候補に印を付けて「承認して現状に入れる」を押します。
関係: import.webCreate、import.receivedDocs

1. 回答が届くと、入力のホームに「事前ヒアリング」の知らせが出ます。「開く」を押すか、「事前ヒアリング・取り込む」を開きます。
2. 「発行した URL」の行の「受け取る」を押します。答えと書類が世帯に入り、取り込みの候補の画面に進みます。
3. 候補ごとに「新規」「変更」「同じ」などが出ます。入れる候補に印を付けます（新規と変更は初めから印が付いています）。
4. 「承認して現状に入れる」を押します。

- 一度閉じても、行の「取り込む（候補を確かめる）」で候補の画面に戻れます。
- 送られた内容は「送られた内容を見る・印刷」で見られます。取り込んだ後は、「発行した URL」の下の「取り込み済みの URL の回答」を開き、行の「送られた内容を見る・印刷」で見ます。

## 発行した URL の延長・取り消し {#import.webManage}
探す言葉: 延長、期限を延ばす、取り消す、受け付けを終える、届いたかを確かめる、依頼の一覧、発行した URL、URL の依頼
要点: 「発行した URL」の行で「延長」「取り消す」「届いたかを確かめる」を押します。受け取った後は「受け付けを終える」で閉じます。
関係: import.webCreate

- 届く前: 「届いたかを確かめる」・「延長」・「案内文をコピー」・「取り消す」が出ます。取り消すときは確かめの「はい、取り消す」を押します。
- 受け取った後: 「取り込む（候補を確かめる）」・「送られた内容を見る・印刷」・「書類の期限を延長」・「受け付けを終える」が出ます。
- 延長は押した日から30日です（発行から90日まで）。
- AI が発行した URL には「AI が発行」、「URL生成」で作った URL には「FP が作成」の印が付きます（AI が発行した URL の節）。
- 取り込み済みで書類待ちも届いた書類も無い URL は、「発行した URL」の行から外れ、同じ欄の下の「取り込み済みの URL の回答」に移ります。取り消し・期限切れの依頼と、書類待ちが残る取り込み済みの依頼は1行にたたまれ、「詳しく」で開きます。

## 受け取った書類を見る・保存する {#import.receivedDocs}
探す言葉: 受け取った書類、届いた書類、書類を見る、書類を保存、PDF を保存
要点: 入力のホームの上の「受け取った書類」を押すと一覧が出ます。行の「見る」「保存」で見る・PC に保存します。
関係: import.webReceive

- 一覧の行ごとに「見る」「保存」「消す」があります。まとめて保存するボタンもあり、保存先のフォルダを1回選ぶと保存します。
- 入力のパネルの中にも「届いた書類」が出て、パネルを開いたまま横に書類を出せます（「幅に合わせる」「↻ 回す」など）。

## 書類の読み取りを確かめて承認する {#import.documentReview}
探す言葉: 書類の候補、読んだ書類を確かめる、承認、まとめて承認、書類の名義、AI から書類の候補が届きました
要点: 「書類の読み取りの確認」で、書類の名義を選び、行ごとに「✓ 承認」「直す」「入れない」を選びます（「まとめて承認」もあります）。承認した物だけが現状に入ります。
関係: import.documentAi

1. 画面の上の帯の「確かめる」（AI から書類の候補が届いたとき）で「書類の読み取りの確認」が開きます。「AI で書類を読み取る」の「読んだ書類を確かめる」からも開けます。
2. 左で書類を選び、「書類の名義」を選びます（決めていないと承認できません）。
3. 右の「書類から読んだ所」で、行ごとに「✓ 承認」「直す」「入れない」を選びます。新しい保険の契約は「足す」か「足さない」を選びます。課税明細書・路線価図の土地・建物は、どの不動産の値かを選びます（課税明細書と路線価図を読み取る の節）。
4. まとめるときは「まとめて承認」を押します。終わったら「閉じる」です。

書類ごと捨てるときは「この書類の候補を捨てる」を押します。

## AI と接続して書類を読み取る {#import.documentAi}
探す言葉: AI で書類を読み取る、AI に資料を渡す、AI に書類を読ませる、AI から書類の候補、保険証券、保険の書類を読む、書類の読み取り、設計書、ご契約内容のお知らせ、架空の見本
要点: 「事前ヒアリング・取り込む」（か FP のメニュー）の「AI で書類を読み取る」で、世帯を AI に渡します。AI が読んだ保険の契約の値（と課税明細書・路線価図の値）が候補として届き、承認した物だけが現状に入ります。
関係: ai.share、ai.consent、import.documentReview

1. 「事前ヒアリング・取り込む」の「AI で書類を読み取る」の所のボタンを押します。
   - AI と接続していないときは「AI と接続する」と出ます。押すと「AI との接続（事務所全体の設定）」が開くので、先に接続します（AI と接続する の節）。
   - 接続しているときは「この世帯を AI に渡す」と出ます。押すと同意と共有の画面が開くので、同意を確かめて世帯を AI に渡します。
2. AI のアプリで保険の書類（保険証券・ご契約内容のお知らせ・設計書）か、課税明細書・路線価図を渡し、ファイナンシアに候補を出すよう頼みます（課税明細書・路線価図の頼み方は、課税明細書と路線価図を読み取る の節）。書類のお名前・番号は伏せてから渡します。
3. 画面の上に「AI から書類の候補が届きました」の帯が出たら「確かめる」を押し、承認します。

- 書類を AI に渡すことを含む外部AIへの提供の同意がある世帯と、架空の世帯だけで使えます。事務所のプライバシーポリシーを確かめていれば、同意の答えが無い世帯（お客さまが「同意しない」と答えていない世帯）でも使えます。
- 保険の書類の「この書類を読む」からも、「AI で読み取る」のボタンで同じ画面に進めます。
- 読んだ書類があると、「読んだ書類を確かめる」が出ます（未決の数つき）。
- 保存していない世帯と見本は AI に渡せません。見本の世帯では「架空の保険証券の見本で試す」で、書類の読み取りの確認画面を試せます（読んだ書類は見本に残ります。「最初の状態に戻す」を押すと消えます）。
- ほかの書類は、書類を見て欄に入れます（欄の「?」に書類のどこを見るかがあります）。
- 面談の履歴とメモは AI に渡しません。

## 課税明細書と路線価図を読み取る {#import.documentLand}
探す言葉: 課税明細書、固定資産税の課税明細書、固定資産税評価額、路線価図、路線価、借地権割合、地積、相続税の土地の評価、土地の面積を読む
要点: 相続税の試算をする世帯で、課税明細書（土地の地積と価格・家屋の価格）と路線価図（路線価と借地権割合の記号）を AI に読ませ、「書類の読み取りの確認」で、どの不動産の値かを選んで承認します。
関係: import.documentAi、import.documentReview

1. 先に、相続・贈与の入力項目で「相続税も試算する（土地の評価・小規模宅地等の特例）」に印を付けます（印が無いと、書類の読み取りの確認画面で入れられません）。
2. 「AI で書類を読み取る」で世帯を AI に渡し、AI に書類を読ませます（AI と接続して書類を読み取る の節）。AI のアプリの使い方の例（課税明細書を読み取る・路線価図を読み取る）から頼めます。
3. 「書類の読み取りの確認」で、書類の土地・建物ごとに、どの不動産の値かを、不動産の名前のボタン（例: 持ち家に入れる）で選びます。入れないときは「入れない」を押します。
4. 行ごとに「✓ 承認」「直す」「入れない」を選びます。承認した物だけが「相続税の試算」の欄に入ります。

- 課税明細書: 土地の地積（同じ敷地の筆の合計）・土地の価格（固定資産税評価額）・家屋の価格を読みます。課税標準額・税額は読みません（相続税の倍率方式に使うのは価格です）。家屋は価格がそのまま相続税の評価額です。
- 土地の価格は、「土地の評価の入れ方」が「固定資産税評価額×倍率（倍率地域）」か「固定資産税評価額から推定（×8/7）」のときに入ります。ほかの入れ方のときは、書類の読み取りの確認画面に理由が出ます。
- 共有の土地: 家族の共有なら物件全体の値が入ります（亡くなる人の分は名義の割合で分けます）。マンションの敷地は、持分の分の値が入ります。AI の添え書きを確かめてください。
- 路線価図: 「250C」なら、1㎡あたり250,000円（数は千円単位）と借地権割合 C（70%）です。記号は A 90%・B 80%・C 70%・D 60%・E 50%・F 40%・G 30% です。先に「土地の評価の入れ方」の行を承認すると、路線価の行を承認できます。
- 借地権割合は、貸している物件にだけ入ります。
- 2つ以上の道路に面する土地は、路線価1つ（ふつうは高い方）だけが入ります。側方路線影響加算・二方路線影響加算は計算しないので、必要なら「補正の率」に入れます。読めなかった路線価は「直す」で入れます。
- 所有者・納税義務者の名前と番号、土地・家屋の所在（地番）、路線価図の図の番号は、読まず・残しません。書類を AI に渡せるのは、保険の書類と同じく、書類を AI に渡すことを含む同意がある世帯（か事務所のプライバシーポリシーを確かめた世帯）と、架空の世帯だけです。
