# 入力のタブ

上のタブの「入力」です。入力のホームに入力項目（「家族」「働き方と収入」「年金」「基本生活費」「住まい・ローン」「保険」「貯蓄・運用」「前提条件」など）が並び、押すと入力のパネルが開きます。

## 入力のホームの見え方 {#input.home}
探す言葉: 入力のホーム、入力の画面、入力項目の一覧、進み具合、入力済み、未入力、推定で計算中、まだ入れていない
要点: 「入力」のタブに入力項目が並び、それぞれに状態（「入力済み」「推定で計算中」「未入力（0円の所あり）」「該当なし」など）が出ます。上に進み具合と「確かめの一覧」のボタンがあります。
関係: input.item、input.chooser、input.find、input.checklist

- 見出し「入力」の下に、確かめの一覧のボタン・「書類のお願い」（書類待ちの欄があるときだけ）・「受け取った書類」（Web で受け取った書類があるときだけ）が並びます。
- 右に進み具合（入力済み・推定で計算中・該当なし・まだ入れていない の数）が出ます。状態の名前を押すと、その状態の入力項目だけを出します。戻すときは「全部の入力項目を出す」を押します。
- 入力項目には、名前・要約と状態が出ます。入っていない項目には「推定で入れる」と「該当なし」のボタンが出ます。
- 状態の見た目: 「入力済み」は緑の ✓、「推定で計算中」は黄土色の「!」（押すと、推定のままの欄の一覧が出ます）。「未入力（0円の所あり）」の入力項目は、絵が灰色になり、絵の左上に赤い「未入力」の印が付きます。まだ入れていない入力項目は、絵が灰色で「まだ入っていません」と出ます。「該当なし」は入力項目の全体が灰色です。
- 右端の「入力項目を選ぶ」で、出す入力項目を選べます。
- いちばん下に「探して開く」の欄があります。

## 入力項目を開いて値を入れる {#input.item}
探す言葉: 入力する、値を入れる、入力項目を開く、入力のパネル、欄、標準と詳細、続きを見る、保存、閉じる
要点: 入力のホームで入力項目を押すとパネルが開きます。欄に入れて、パネルの下の「保存」を押します。
関係: input.estimate、input.likelihood、households.save

1. 入力のホームで入力項目（例「家族」「住まい・ローン」）を押します。
2. 入力のパネルが開きます。上の「標準」「詳細」で欄の出し方を切り替えられます（その場だけ）。
3. 欄に値を入れます。まとまりによっては「続きを見る」で残りの欄が開きます。
4. 欄の横の「?」を押すと、その欄の説明が出ます。
5. パネルの下の「保存」を押すと世帯に入ります。「キャンセル」は確かめずに変更を捨てて閉じます。

- 保存していない変更があるまま「×」か Esc で閉じようとすると、「入力に戻る」か「変更を捨てて閉じる」を選ぶ画面が出ます。
- 保険のパネルには「書類から読む」があり、保険の書類を AI に読ませた答えを取り込めます。

## 推定・該当なし・この値にする {#input.estimate}
探す言葉: 推定、推定で入れる、該当なし、この値にする、推定に戻す、書類で確かめる、0円、目安で入れる、確定
要点: 入っていない所は「推定で入れる」で目安の値を入れ、該当しなければ「該当なし」にします。推定の値をそのまま確定するときは「この値にする」を押します。
関係: input.checklist、input.item

- 入力のホームの入力項目か、パネルの頭に出る「推定で入れる」「該当なし」で、入っていない所をまとめて埋められます。
- 欄の状態の印（「推定」「書類待ち」「該当なし」など）を押すと根拠が開きます。欄ごとに次を選べます。
  - 「この値にする」: 推定の値をそのまま入れて確定にします（家族や収入を直しても入れ直されなくなります）。
  - 「推定に戻す」: 推定の値に戻します。
  - 「書類で確かめる」: 書類待ちにします（「書類のお願い」に載ります）。
  - 「該当なし」: 該当しない欄にします。
- 入力のホームの入力項目に出る「推定で入れる」「該当なし」のボタンは現状を直す操作なので、プランの編集中は使えません。入力のパネルの中の欄ごとの操作は、プランの編集中はそのプランに入ります。

## 見込み「確実」「不確実」 {#input.likelihood}
探す言葉: 見込み、確実、不確実、計算に入れない、入るかわからないお金、相続の見込み
要点: 入るお金・一時的な支出などの欄に「見込み」があり、「確実」か「不確実」を選びます。「不確実」の物はふだんの計算に入れません。
関係: results.dreams、input.item

- 入るお金・出るお金（一時的な支出）・受け継ぐ借金の欄に、「見込み」の選択があります。
- 「不確実」にした物は、ふだんの計算に入りません。結果のタブの「夢と予定」で、1件ずつ入れて見られます（見方の切り替えだけで、保存はしません）。

## 出す入力項目を選ぶ・ピン {#input.chooser}
探す言葉: 入力項目を選ぶ、入力項目を隠す、表示しない、入力項目を足す、ピン、ホームに出す
要点: 入力のホームの右端の「入力項目を選ぶ」で、この世帯で出す入力項目に印を付けます。よく使うまとまりは「📌 ホームに出す」でピンにできます。
関係: input.home、office.inputOrder

1. 入力のホームの右端の「入力項目を選ぶ」を押します。
2. 「この世帯で出す入力項目」で、出す項目に印を付けます。行ごとに、開いたときの入れ方（「標準」「詳細」）も選べます。
3. 「閉じる」で閉じます。

- 「家族」「前提条件」と、値が入っている項目は外せません。
- この選び方を事務所の既定にするときは「この選び方を事務所の既定にする」、事務所の既定に戻すときは「事務所の既定にそろえる」を押します。
- ピン: 入力のパネルのまとまりの見出しの「📌 ホームに出す」を押すと、ホームの「ピン」に出ます。外すときは「ピンを外す」です。

## 探して開く {#input.find}
探す言葉: 探す、検索、欄を探す、どこに入れる、どの入力項目、探して開く
要点: 入力のホームのいちばん下の「探して開く」の欄に言葉（例: 留学・奨学金・iDeCo）を入れると、それを入れる欄の候補が出ます。選ぶとその欄が開きます。
関係: input.home

- 候補を選ぶと、その入力項目が開き、その欄へ移ります。
- ホームに出していない入力項目の欄も出ます（「ホームに出していない入力項目」の印）。
- 見つからないときは、ほかの言い方で探します。

## 確かめの一覧 {#input.checklist}
探す言葉: 確かめの一覧、チェックリスト、未入力の一覧、推定の一覧、確認すること、次回確かめる、漏れ
要点: 入力のホームの上の「確かめの一覧」を押すと、未入力・まだ入れていない項目・書類待ち・確かめの注意・推定などが一覧で出ます。行の「開く」でその欄へ移ります。
関係: input.estimate、input.docRequests

- 種類ごとのまとまり（「未入力（0円で計算中）」「まだ入れていない項目」「書類待ち」「確かめの注意」「推定」など）に並びます。
- 「入力項目」「状態」「出どころ」「確かさ」で絞れます。
- 行ごとに「根拠」を開く・「開く」（その欄へ移るだけ）・「次回確かめる」の印を付けられます。注意の行は「確認した」で消せます。
- まとめて埋めるボタン（「入っていない所を推定で入れる」など）もあります。
- 書類待ちのまとまりの「書類のお願いにまとめる」で、書類のお願いが開きます。

## 書類のお願い {#input.docRequests}
探す言葉: 書類のお願い、書類の依頼、必要書類、お客さまに頼む書類、お願いの文
要点: 書類待ちの欄があると、入力のホームの上に「書類のお願い」が出ます。押すと頼む書類の一覧と、お客さまへのお願いの文が出ます。
関係: input.estimate、import.webCreate

- 書類ごとに、写す欄と代わりの値が出ます。保険証券などは「この書類を読む」で読み取りに進めます。
- 「お客さまへのお願いの文」で「お名前」「事務所名」を入れて「文をコピー」を押すと、お願いの文を写せます（名前は保存しません）。
- URL のヒアリングで書類を頼むこともできます（「送っていただきたい書類」）。

## 入力のタブでプランを直す {#input.planEdit}
探す言葉: 編集の対象、プランを入力で直す、プランの編集、現状とプラン、違いの一覧、このプランを入力で開く
要点: 入力のホームの「編集の対象」でプランを選ぶと、そのプランを入力のタブで直せます（現状は変わりません）。プランが1つ以上あるときだけ出ます。
関係: results.planCreate、results.planList

1. 入力のホームの「編集の対象」で、直したいプランを選びます（結果のタブの「このプランを入力で開く」からも来られます）。
2. そのプランを編集中だという帯が出ます。入力項目を開いて直します。
3. 「違いの一覧」で、現状から変えた所を見られます。行ごとに「計算に入れる」の印・「開く」・「↺ 戻す」があります。
4. 「プランの操作」から「結果を見る」「＋ 現状から新しいプラン」「このプランを複製」を選べます。

- 取り込みと、入力のホームの入力項目の「推定で入れる」「該当なし」のボタンは、いつも現状を直す操作なので、プランの編集中は使えません。取り込むときは「現状に切り替える」を押します。

## 表を何歳まで見るか {#input.tableEnd}
探す言葉: 何歳まで、表の最後の年、100歳まで、90歳まで、表の期間、シミュレーションの期間
要点: 入力のタブの「前提条件」の欄「表を何歳まで見るか」で選びます。結果のタブには選ぶ所はありません。
関係: office.premises、results.table

1. 入力のタブで「前提条件」を開きます。
2. 「表を何歳まで見るか」で、人と年齢を選びます（年で決めることもできます）。
3. 「保存」を押します。

どのプランにも共通の欄です。事務所の既定の年齢は、事務所の既定値の「前提条件の既定値」で決めます。

## 明細から生活費を出す {#input.statement}
探す言葉: 明細、家計簿、通帳、クレジットの利用明細、生活費を出す、明細の取り込み
要点: 入力のタブの「基本生活費」を開き、見出しの横の「明細から出す」を押します（現状を直すときだけ出ます。プランの編集中は出ません）。明細のファイルを取り込み、生活費の候補を承認して入れます。
関係: input.item

1. 「基本生活費」の入力のパネルを開き、「明細から出す」を押します（保存していない変更があれば、先に保存します）。
2. 「明細から生活費を出す」が開きます。口座などを決め、「明細のファイルを選ぶ」で明細を選んで取り込みます。
3. ヒアリングで分け方を確かめ、生活費の候補を確かめて「承認して現状に入れる」を押します。
4. 「閉じる」で基本生活費のパネルに戻ります。

## 相続税の試算と一次・二次の推移 {#input.inheritanceSecondary}
探す言葉: 相続税の試算、二次相続、一次相続と二次相続、遺産の分け方、配偶者の取得割合、相次相続控除、小規模宅地等の特例、取得する人
要点: 「相続・贈与」の入力項目で「相続税も試算する（土地の評価・小規模宅地等の特例）」にチェックすると、「遺産の分け方」と不動産ごとの欄が出て、入力項目の下に「一次と二次の相続税の推移」と分け方の比較が出ます。チェックしない世帯の入力と目安は今までどおりです。
関係: input.item、input.planEdit、import.documentLand

1. 入力のタブで「相続・贈与」を開きます。区画「相続税の試算」は、チェックしていない世帯では「詳細」にだけ出ます。
2. 「相続税も試算する（土地の評価・小規模宅地等の特例）」にチェックします。
3. まとまり「遺産の分け方」で、先に亡くなる人・一次の相続で配偶者が取得する割合・子ごとの割合を入れます（入れなければ法定相続分どおり。先に亡くなる人の省略は年上の人）。子の割合は合計が100%になるように入れます（1人を空欄にすると残りを受け取ります。100%にならないときは法定相続分どおりで計算し、確かめの一覧に出ます）。
4. 不動産ごとのまとまりで、土地の評価と小規模宅地等の特例の取得する人を、一次の相続と二次の相続（二人とも亡くなった後）で別に選びます。配偶者のほかの人を選んだ土地は、取得する子も選べます。二次の取得する人の説明には、表の最後の年の家族（子が独立する見込みか、同居の見込みか）を書いています。二次は、選ぶまで特例を使いません。
5. 入力項目の下の「一次と二次の相続税の推移」で、先に亡くなる年ごとの一次・二次・合計を見ます（ふだんは5年ごと。「毎年を見る」で毎年）。「分け方の比較」で年を選ぶと、入れた分け方・「法定相続分どおり」・残された配偶者が全部取得する・残された配偶者は取得する土地だけ、の合計を並べます。表の上には、一次で取得したお金を二次まで使わないとして出していることを書いています。

- 表示だけです。キャッシュフロー表・金融資産の推移は変わりません。
- 分け方をプランごとに変えて比較するときは、入力のタブでプランを選んでから「遺産の分け方」を直します（プランの差分になります）。
- 二次の財産は、後に亡くなる人の名義の財産に、一次で取得した財産を足して出します。二次には相次相続控除と、一次で受けた未成年者控除の残りを入れています。
